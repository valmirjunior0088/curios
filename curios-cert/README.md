# curios-cert

The Curios certifier: the kernel deciding, from a finished term alone, whether the elaborator's output is well typed — reduction, sort, conversion, the typing judgment, nominal elimination, subsumption, the whole-module walk that applies them, the erasure obligations, and its two decisions over a universe constraint set, level entailment and satisfiability. It is the side of the two-checker design that only checks, inventing nothing — no metavariable, no search, no inference beyond typing what is written — and it shares with the elaborator only the layer both judge through, `curios-core`, `curios-num`, `curios-algebra` and `curios-analysis` ([An independent kernel re-checks what the elaborator accepts](../documentation/design/soundness/an-independent-kernel-re-checks-what-the-elaborator-accepts.md)). This crate owns what a term *means*; what the kernel covers belongs to [roadmap.md](../documentation/roadmap.md), and local architecture to the crate rustdoc.

## Design

### The trusted base is a crate boundary

**Decision.** The trusted base is this crate's dependency closure, `cargo tree -p curios-cert --edges normal`, rather than the call-closure of checking entry points inside a larger crate. It reaches the shared layer — `curios-analysis`, `curios-algebra`, `curios-core`, `curios-num` — and their foundations: `curios-utilities`, `curios-abi`, `curios-archive` with its derive macro `curios-archive-derive`, `curios-print` and `curios-profile`, which serialize, format and time rather than decide. Beneath those are three third-party roots and what each pulls: `num-bigint` with `num-integer` and `num-traits`, the unbounded arithmetic under `curios-num`; `sha2` and its `digest` family under `curios-utilities`; and `stacker` with `psm` and `libc`, the stack growth every recursive walk stands on. The shipped compiler builds the kernel with its `archive` feature, which adds `rkyv`'s family, and a profiling build adds `tracing`'s. Nothing of the elaborator is reached: `curios-elab` takes this crate as a **dev**-dependency only, which does not propagate — the property `curios-prelude-archive`'s build script rests on, since a build script reaching the kernel would re-elaborate the whole standard library on every certifier edit.

**Rationale.** A call-closure is enumerated by tracing and drifts silently as code moves; a crate boundary is enforced by the compiler and read off the manifest, and it makes "not trusted" structural: nothing of the elaborator — its metavariable store, refinement layer or caches — can sit inside the base. A foundation crate is on the soundness board for as long as the kernel's types name it.

**Rejected.** Sharing the representation through `curios-utilities`, a crate for stage-independent utilities; `curios-core` owns the representation and this crate builds on it.

### The judgments flatten onto the root

**Decision.** Every module re-exports at the root, so a consumer names `curios_cert::Kernel`, `curios_cert::convert`, `curios_cert::certify_module`. The crate name is the disambiguator: the judgments here name the same things the elaborator names its own, and `curios_cert::convert` beside the elaborator's `convert` reads as the second opinion it is.

**Rejected.** A `kernel::` namespace, which spells the disambiguation the crate name already makes.

### The kernel memoizes its own evaluation, and a memo changes only resource verdicts

**Decision.** The kernel carries evaluation memos — weak-head reducts of terms, and the types inferred for local-free terms — after Lean's trusted `type_checker`. Every reduct entry records the binder identities its computation minted and always replays them, so a hit mints exactly what a recomputation would; an inferred-type hit replays nothing and hands back the type alone. No hit is charged, and every table is cleared where the budget is restored ([A reduction step costs what it builds](../documentation/design/soundness/a-reduction-step-costs-what-it-builds.md)). Switching the memos off may move an exhaustion point and the identities minted after an inferred-type hit, and nothing else; `kernel_memo_parity` holds the semantic half, and `Kernel::uncached` exists so it can.

**Rationale.** A metavariable heap or refinement store injects answers a term alone could not produce; a memo replays the kernel's own pure function of `(term, definitions)`. Refusing it costs a whole-prelude re-check by a large factor, spent re-deriving prelude spines for every recursive group the totality gate walks (`kernel_memo_parity` runs that walk both ways). Charging a hit what a memo-free evaluator would have spent compounds — a subterm hit twice per level makes the charge exponential in a structure the memos evaluate linearly — and refuses programs the elaborator accepts within the same budget (the `spend` module states the compounding; `curios`'s `kernel_memo_charge_measurements` holds the floors). A free hit only reduces what a judgment spends, so it can turn an exhaustion refusal into an acceptance and never move a semantic refusal. The inferred-type table gives up identity replay because the replay would count what the table avoids: it types a reduct — a graph whose tree can be exponential in its depth — once per node, and replayed, a `Str/split_once` claim in a type exhausts the 32-bit identity space. Freshness is the one property a judgment reads off an identity, and a counter that never falls keeps it; the `spend` module states what that concedes.

### A later walk reads the certifier's own totality record, never elaboration's stamp

**Decision.** `certify_module` returns, beside its verdicts in one `Rechecked`, a record of each definition it judged, that definition's totality closed over everything it mentions, and what judging it read of other items — each type, universe scheme or registry entry consulted and each body asked for (`curios_core::Certification`, `Reads`). Only this walk makes one; it is filed with the unit it classifies, and `Globals::of` and `Globals::mount` take it. Where it covers its unit its classifications seed the non-total set (T) and (V) close from; where it names fewer definitions than the unit holds — an empty one for a hand-built environment included — the unit's items are classified from their terms by `partial_definitions`, as an item the walk judges is. Elaboration's stamp is read only on an item the walk judges, to compare it with the walk's own verdict. A registry entry is accepted as part of its type former; positivity, one judgment over the whole declaration set, is attributed to no item. `curios-pipeline`'s `the_prelude_reads_along_the_graph_its_definitions_reach` holds the reads to the graph elaboration built.

**Rationale.** What a proof reaches runs out of the environment as readily as out of the module, so the environment's classification decides (V) for every proof reaching it. Reading the elaborator's stamp there, cross-checked once at filing, makes the transitive half of every carried verdict the elaborator's conclusion; reading the certifier's own removes the input rather than guarding it. The record is part of the unit and found under the unit's address, which names the compiler whose certifier made it. The board entry is [The certifier's totality record](../documentation/design/soundness/totality/the-certifiers-totality-record.md).

**Rejected.** A strengthened cross-check of the stamp, still the only thing between a later walk and another component's verdict; reading a record one name at a time, when a record naming fewer definitions than its unit was not made by a walk over it; refusing a unit whose record does not cover it, which costs a fault every hand-built environment must avoid where re-deriving costs only time; an optional record, when an empty one already says so; a digest of the certifier beside the record, which the unit's address already carries.

### A group's calls are the ones the kernel types

**Decision.** The kernel does not look for a group's recursive calls with a traversal of its own. `check_group` opens a frame for the group, and every application the walk types whose head is a member is recorded as a call and graded at once by `curios-analysis`'s shared `grade`, under the size context the arms around it built: the solutions each arm's case value and index inversion put in force, its payload binders, the nonzero fact a boolean or switch arm establishes — read before the arm assumes its case equation, which would reduce the comparison to the arm's own literal — and each binder of a lambda applied on the spot standing for its argument. A member named anywhere but at an application's head is a call with no arguments, graded unknown. Once every body is checked, the shared `decide` closes the calls; a group the walk never typed reads `Partial`. A type is typed as written (`infer_type`), and a nominal value's parameters are typed as an occurrence's are, so a call stands nowhere the walk does not see.

**Rationale.** A traversal separate from typing fails open: a position it never visits contributes no edge, and a group with no edges is accepted. The kernel types every position it accepts, so calls taken from its typing fail closed. Separate call inspection is where Rocq's guard checker was found unsound — its `find_uniform_parameters` inspected self-calls and missed the calls between bodies ([rocq#21682](https://github.com/rocq-prover/rocq/issues/21682)) — while Agda's [`TermCheck`](https://agda.readthedocs.io/en/latest/language/termination-checking.html) and Idris 2 extract calls from terms after typing, and Lean 4's kernel compiles recursion to recursors. Grading and closure stay shared, so the checkers grade a call alike and differ only in how they find it; the elaborator keeps its discovery walk over the same two functions.

**Rejected.** Having the kernel check that discovery is complete, which closes the fail-open case in less code but leaves the verdict resting on a traversal the kernel does not own; keeping discovery for the kernel as the elaborator does.

**Evidence.** `kernel::calls::tests` puts four groups that must descend to the local gate, each mutation-checked against the one piece of recording it depends on: a call at the caller's own argument, descent through a `Nat` arm, through a lambda applied on the spot, and through a guard behind a definition. `recheck::proposition_tests::a_wait_inside_a_proof_is_refused_with_no_definition_to_blame` holds an inline group's verdict reaching the proof around it, and `kernel::calls::tests::a_call_in_a_nominal_values_parameter_is_recorded` the parameter position. A differential against discovery agreed on all 951 groups of `/sys` and `/std` — 870 total, 81 partial — and on all 55 across the 26 programs of `programs/`. To retake it, have `close_group` also run `curios_analysis::group_totality(self, group)` with the recorder set aside and `curios_profile::note!` both verdicts, then read the notes out of `curios-prelude/.artifacts/profile.tsv` after `cargo xtask clippy` and out of each program's `curios --profile <PATH> wonder diagnostics` stream, attributing each to the `certify_declaration` span it falls inside.

### A type is accepted by typing it, and reduction is total on arbitrary terms

**Decision.** Three mechanisms, each doing a job the others cannot. **Reduction is total on arbitrary terms**: `whnf` never asserts on a shape a caller could hand it — an application that does not saturate its lambda, an arm that does not match its payload, a projection out of range — but goes stuck, since `certify_module` walks a module from anywhere to the end with each verdict independent, and a reduction that declines to fire admits nothing. **A type is accepted by `infer_type`, not by `Sort::of`**: `infer_type` types the term and destructs its type as a sort, Rocq's `infer_type`, Lean's `inferType`, Agda's sort carried on the type, and it types a type as written, never its reduct; `Sort::of` classifies structurally and is a fast path reached only where typing has run, the role Rocq gives `Retyping.get_sort_of`. **Counts are checked at the boundary**: an occurrence's parameters and indices, a value's parameters and a constructor tag's uniqueness are checked where the declaration is consulted, since no typing rule reads a length; a plicity vector's parallelism with its telescope is asserted where the term is constructed.

**Rationale.** Defects arrive through the gap between "the kernel reads a field" and "something established the field": level capture, a bypassed large-elimination guard, and walks that abort. Typing a type's reduct is how reduction meets untyped terms by construction — an occurrence whose level floats above its argument's, `List.{v,w}(Waker)`, is typed as its former's `Type v` where its reduct sits at `Type 0` — and the elaborator settles that level at its argument's (`UniverseSolver::finalize`), so a spelling and its reduct land in one sort. Shapes are made safe by typing, counts by the boundary, and neither can abort, which closes each class rather than instances of it.

### Level entailment is forward reasoning to a least model

**Decision.** Whether a declaration's assumed constraints force `lower ≤ upper` is decided forward: from the facts `upper` states, every hypothesis `L ≤ U` whose upper side is bounded fires at the largest shift it is bounded by, raising its lower side, until a pass raises nothing, and the answer is whether that least model bounds `lower`. It is Bezem and Coquand's decision procedure for the semilattice with an inflationary successor (TCS 913, 2022), with one rule the naturals add — a parameter carries its offset, so `h + k` bounds the constant `k` — and the bound on the least model's values (their Corollary 4.2) refuses a set holding a loop. Satisfiability reads the same model from the other end: started with every head at the largest offset any upper side carries, a set has a least model exactly when it holds no loop, which is exactly when it has a model in the naturals (their Corollary 3.5).

**Rationale.** A backward search — one atom of `lower` at a time, through the first hypothesis mentioning it, into every part of its upper side, with a cycle guard, fuel, and nothing remembered between branches — is exponential in the hypotheses' width, and `/std/Try`'s lift between two `Try`s assumes constraints whose sides are maxima of up to seventeen parameters, where the search's costliest question asks for a bound the hypotheses state verbatim, which forward reasoning fires in its first pass. Forward reasoning accepts every goal the search accepted, since each of its three rules is a step of the forward derivation, and also the true chains the search's fuel cut, which the brute-force sweep the soundness board names holds sound.

**Rejected.** Memoizing the backward search, whose refuted subgoals depend on the path they were reached on; normalizing the constraint set before searching, which narrows each branch and keeps the search; Rocq's incremental model, when a declaration's hypotheses are fixed and a model per question costs a pass or two.

## Measuring the certifier

`cargo xtask clippy` builds `curios-prelude` with `--all-features`, and its build script certifies the fixed prelude under a record stream filed at `curios-prelude/.artifacts/profile.tsv`; elaboration's is `curios-prelude-archive/.artifacts/profile.tsv`. The walk carries three kinds of span:

- **per item:** `certify_declaration`, grouped by `Item::describe` as the elaborator's `declaration` span is, so one item's cost in each checker is found under one key;
- **per stage:** `universe_verdict`; `partial_definitions` and `check_positions` for (T) and (V); `check_entrypoint`; `check_induct_decl` and `check_struct_decl`; the shared `positivity_vectors`. The residue and escape checks are `recheck_module`'s self time;
- **per judgment:** `convert`, with `convert::enter` where a goal enters the recursion history and `convert::unfolded_retry` for the one unfolding granted before a structural refusal; `reduce` and `reduce_forced`, the second past its memo so a hit costs no row; `Sort::of`; `entails`; and the shared analyses' `grade`, `decide` and `invert_with`. Typing is `certify_declaration`'s self time. The `nat::*` and `truth::decide_bool` rows are `curios-core`'s folds over the carriers' algebra.

Fold the stream with `cargo run --all-features --package curios -- profile curios-prelude/.artifacts/profile.tsv` and read the self columns, which attribute each nanosecond and byte to the innermost span. The stream is an instrumented debug build script's, so durations are inflated and call counts and allocation are the stable figures. An item's cost in the kernel is read beside its cost in the elaborator by summing each stream's per-item span by group and joining the two:

```sh
per_item() { awk -F'\t' -v span="$1" '$1=="D"{n[$2]=$4} $1=="S"&&n[$3]==span{g="";for(i=5;i<=NF;i++)if(substr($i,1,6)=="group=")g=substr($i,7);of[$2]=g} $1=="E"&&($2 in of){at[$2]=$4} $1=="X"&&($2 in at){t[of[$2]]+=$4-at[$2];delete at[$2]} END{for(g in t)printf "%.1f\t%s\n",t[g]/1e6,g}' "$2" | sort -t$'\t' -k2; }
join -t$'\t' -1 2 -2 2 <(per_item declaration curios-prelude-archive/.artifacts/profile.tsv) <(per_item certify_declaration curios-prelude/.artifacts/profile.tsv) | sort -t$'\t' -k3 -rn | head
```

The columns are the item, its elaboration milliseconds and its certification milliseconds; `Item::describe` names every witness of a module alike, so a module's witnesses share one row.
