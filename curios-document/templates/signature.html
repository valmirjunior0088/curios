{#- A printed signature, segment by segment: a keyword set apart, a link to a declaration in this bundle, the name of one outside it, and text as it is. Every tag trims both sides, so the segments join with nothing between them. -#} {%- macro segments(items) -%} {%- for segment in items.iter() -%} {%- match segment -%} {%- when Segment::Text(text) -%} {{ text }} {%- when Segment::Keyword(word) -%} {{ word }} {%- when Segment::Link { href, text } -%} {{ text }} {%- when Segment::Name(name) -%} {{ name }} {%- endmatch -%} {%- endfor -%} {%- endmacro -%}
