# curios-prelude-archive

Build-scoped ownership of Curios's fixed `/sys` and `/std` prelude: the authored `/std` sources, the canonical registry of compiler-emitted names, and the build script that folds the two roots into the rkyv images production compilation replays — `sys.rkyv` then `std.rkyv`, one per unit. `/sys` has no `.crs` here: `curios-text`'s `sys_module` builds it whole from `curios-abi`'s host store and the intrinsic table, preconditions included. An authored source module joins `/std` only through a `mod` line in its parent header. Consumers depend on `curios-prelude`, never on this crate, because the image here has been elaborated and not judged; the archive and replay APIs belong to the crate rustdoc.

## Design

### This is not `curios-prelude`, and it never reaches the kernel

**Decision.** This crate's build script elaborates and serializes; `curios-prelude`'s restores the image and certifies it with `curios-cert`. This crate never gains a `curios-cert` dependency in any kind that propagates, which `cargo tree -p curios-prelude-archive --edges build` checks.

**Rationale.** Cargo's rebuild granularity is the build script, so one script doing both would re-elaborate the whole standard library on every kernel edit, for work no kernel rule can affect. What keeps the kernel out transitively is `curios-analysis` standing apart from `curios-cert` and `curios-elab` taking the certifier as a dev-dependency only.

### The archive is build-scoped, not an interchange format

**Decision.** The prelude ships as one rkyv image of an `Uncertified` unit per root, filed under the build script's `OUT_DIR` and scoped to one compiler build. The build script emits one rebuild directive per file the lowering read — every file a `mod` line reaches — and production compilation replays the images with no source fallback and no cache-miss branch: construction or restoration failure is a compiler invariant and fails loudly. Each image is framed as a store slot is, `curios-unit`'s record of what the unit was compiled from ahead of the unit: `/sys` records no reads and nothing before it, `/std` every file of its tree by canonical path and the `/sys` image as its one predecessor. `/sys` comes first and `/std` is folded against it, its erased arena resuming above `/sys`'s while every counter it mints starts at zero, since no term `/sys` stores carries one; the order is a constant of `restore.rs`.

**Rationale.** A fallback would turn an invariant violation into a silent recompile and let the archive drift from its sources. Scoping the image to one build frees the format to change with the representations it serializes, and `OUT_DIR` suits a product whose one reader is the crate that includes it — `curios document` reads the standard library off the prelude the compiler embeds. The record makes the archive's provenance a fact the compiler wrote down, and the rerun directives are read off the read log it is built from. One image per root keeps one framing for every file a store read meets, and rkyv's sharing by pointer address is per image, so a table spanning both would report a structure count neither has. The other order would hand a successor a scope its names were never resolved in.

### /sys mirrors the host store, and `Io` owns only the sequencing

**Decision.** `/sys` is a 1:1 mirror of `curios-abi`'s `ForeignStore`: one declaration per wire row, in store order, placed by the subject the row names — a column of the `for_each_host_op!` table. A row joins the module its subject names, creating one where no carrier claims the label, so `Handle`'s rows join its type module (`/sys/Handle/read`) and every other subject is a module of operations alone (`/sys/socket/bind`, `/sys/clock/wall`), capitalized only when a type backs it. Leaf names are the labels the placement spells — `file/remove`, not POSIX's `unlink` — and the qualification disambiguates. Every row returns `Io(T)`, and `/sys/Io` holds exactly `pure` and `bind`. `/sys` reads each row's outcome as ordinary certified code: a fallible row answers `Result(Nat, T)`, a stream `Result(Nat, Option(T))`, a lookup `Option(T)`, the status compared before any payload is projected, so a failure's padding never reaches a binding a program can name. `/std` owns the taxonomy — `Io` for the standard streams and the failure vocabulary `Io/Error`, `Tty`, `Serial`, `File`, `fs`, `Path`, `Command`, `Child`, `proc`, `time`, `rand`, `tcp`, `http` — each wrapping the raw rows in the shapes a program wants, and a program never holds a raw handle: a stream type wraps one behind a private representation and satisfies `Async/Read` and `Async/Write`. A wrapper may rename, reshape, retry or decode — `Handle`'s `Write` witness resends a short write, `Io/Error/of_result` names a row's failure, a wrapper that retries compares the status with `/sys/status/would_block`, and one refusing an argument before any call raises the errno `/sys/errno` names — but may not perform, since nothing turns an `Io(T)` into a `T` ([Effects are descriptions](../documentation/design/theory/effects-are-descriptions-and-the-carrier-has-no-eliminator.md)). Which rows wait, and at which monad a wrapper is typed, are [Only a fiber waits](../documentation/design/standard-library/only-a-fiber-waits.md) and [A fallible operation returns `Try`](../documentation/design/standard-library/a-fallible-operation-returns-try-and-bang-lifts-along-declared-edges.md).

**Rationale.** The mirror is about coverage — every row declared, none invented — so the store and the prelude can be checked against each other mechanically, and a flat root reads `/sys/bind` as the monadic `bind` and puts `read`, `open` and `env` at a global root. Nesting by subject fixes the reading without touching the wire, since a `ForeignFunction`'s identity is its `(namespace, name)` pair. `Io` is the type a result wears, not the subject an operation belongs to, so grouping operations under it would sort the library by their type rather than by what they do. A failure is a fact about the effect rather than the handle that reported it, which is why `Io` owns `Io/Error`. Reading the status in `/sys` replaces the same few lines at forty wrapper sites, each free to project a payload before checking the status that says whether it is one.

### The compiler emits names, not a root of its own

**Decision.** Every name `curios-text`'s lowering or `curios-elab` emits is an ordinary `/sys` or `/std` declaration reached through the filled `SyntaxRegistry` (`src/syntax.rs`), never through a root reserved for it: the concepts syntax dispatches through, the certified literal structures `/std/Char` and `/std/Str`, the test vocabulary and the spell renderers sit beside the types and witnesses that consume them. `/sys` holds only what `/sys` itself needs — the propositions its rows and intrinsics state as preconditions, and the guest outcomes those operations return. The registry contract belongs to `curios-utilities`.

**Rationale.** The emission contract needs a closed, auditable surface, and the registry makes it mechanical: the build asserts every registered name is declared and every registered concept declares the method the elaborator projects. A root of the compiler's own would create a cycle — it imports `/std` for the types its concepts mention while `/std` imports it for the concepts its witnesses satisfy — so the prelude could not be split into units nor `/std` be a package. The compiler is not a unit, so an emitted name lives wherever it belongs without an edge in the fold.

**Rejected.** Moving the emitted names down into `/sys`: `Test/main` needs `List`, `Str`, `Io` and `Bool`, and `Test/equal` needs `Equal`, `Spell` and `Show`, so `/sys` would absorb most of `/std` and re-create the cycle a level lower. `/sys` membership is decided by what `/sys` itself must name.

### Optional and fallible values belong to the guest foundation

**Decision.** `/sys/Option` and `/sys/Result` are ordinary universe-polymorphic inductives, `some` before `none` and `success` before `failure`, the failure's type first; `/std/Option` and `/std/Result` re-export each family and its constructors, and their functions, witnesses and derivations stay in `/std`. The registry names each declaration and its constructors directly. The generated declaration keeps source identities for its `Type` occurrences, so its type former and constructor signatures share their universe seeds.

**Rationale.** `/sys` constructs them without reaching into `/std`, as a cell's poll answers an `Option`. Anonymous generated occurrences would assign unrelated levels and specialize consumers such as `Cli` wrongly.

### `/std` invents no value where a proof belongs, and text is addressed by position

**Decision.** Where a branch cannot be reached, its unreachability is proved and the branch is gone; where it can, the caller sees an `Option`, a `Result` or a refusal. A default stays only where a standard or the operation's own contract specifies it — an absent header, an IEEE substitution, an omitted terminal parameter, a function taking its default as an argument — and its documentation says so. A position is `Str/At(s)`: a byte offset into `s` with an erased proof that a character begins there, decided by the one byte at it, so a literal's positions discharge by reduction and any offset is checked in O(1), UTF-8's self-synchronization, proved once, making that byte a boundary of valid text. A piece of a string is a string cut between two positions in O(1), a walk over text recurses over positions (`Str/At/forward`, `backward`) with the proof that each step progresses, and characters are counted only where the count is the meaning; `find_index` and `index_of` answer a position, and a search starts at the beginning of the string it is given. `Char` and `Str` carry their certificates end to end — decoding carries a decided pending state to `Char/Valid`, encoding builds each lead byte from the range its guard and the character's validity establish, and validity is checked once, where bytes become text through `Str/of_bytes`. One parser type, `Parse(I, A)`, is indexed by the carrier it reads — `Parse(Bytes, A)` with positions within the input, `Parse(Str, A)` with positions that are boundaries of valid text — so its combinators and `run` are written once, and `or` reports the refusal that reached further. A value built under a bound is built from the bound's proof, never re-established by a mask. A host's facts reach `/std` first-order: a read asks for a positive count and a chunk holds at least one byte, an empty resolution is `NotFound`, a spawned child's streams are read by the modes the call asked for, and no reply is read through its padding. A format reads numbers by its own grammar and hands the parts to its type's one conversion.

**Rationale.** An invented value turns a broken invariant into a plausible wrong answer — `'?'` for a code point that was not a scalar value, `""` for bytes that were not UTF-8, a default element for an index out of range — so a defect surfaces far from its cause, if at all. The proofs that replace such values are erased and a position erases to its offset, so an invariant costs checking time and nothing at run time. A character count re-walks everything before it, making every cut linear in its index and a loop over indices quadratic, while a boundary is one byte. One parser type keeps the combinators' commitment and progress rules in one place. First-order host facts keep the wire vocabulary simple and the soundness board where it is: a reply's shape, `/sys`'s reading of it, or a match in `/std` whose every arm has a meaning carries each fact, and no proposition crosses the host boundary.

**Rejected.** Character indices as the public currency, as Haskell's `Text` has them; unproven byte offsets, where Go has no boundary, Rust panics off one and Lean 4's `String.get` answers a default character; a separate substring type, since `Str`'s ropes make a piece a view; "the scan lands between characters" as the stored invariant, uncheckable in O(1) and with no `prev`. Character and position APIs side by side, and searches taking a starting position, two spellings of one operation. A bytes parser checking its text at the end, and a parser type per carrier. Keeping `to_utf8`'s masks and proving each changes nothing. Decoding in `fold` through `decode_head` at each lead byte, which changes the walk `curios/src/tests/codegen/ladder.rs` measures. Handing a format's number text to `Flt/of_str`, which is how `Json` accepts `01`. A host fact as a proposition on the wire, resting the proof on the emitted reply check. A reflection law for `Bytes/eql`, which waits for a consumer. Bounded increase as a totality rule, a measure `e - k` a guard `k < e` decreases, when the recursion principle states the progress where its proof already is.

### `Map` is a crit-bit trie, and its shape is its API

**Decision.** `/std/Map` is a crit-bit trie keyed by the byte string a `Key` witness produces, with byte-string identity and write-side injectivity stated at the `Key` boundary where they can be checked. Its canonicity is API: `Toml/encode` promises one deterministic document in the map's structural order, and same entries, same shape is what makes map equality structural, so a proof about a map binds to its entries and get-extensionality rather than its nodes.

**Rationale.** A map's performance is bought by the compiler classes every consumer shares ([A value costs when it is kept, not when it is named](../documentation/design/compilation/a-value-costs-when-it-is-kept-not-when-it-is-named.md)), and a shape that stays canonical is what lets it be a value.

**Rejected.** A qp-trie, built and measured slower per insert once the key was an immediate: its bit test costs a few register operations while a wide fork copies an O(width) child array per rebuilt level, and a get-weighted consumer reopens it against `map_wall_spines_slope`. A 16-field `fork16`, a 16-way `br_table` per descent and a 17-ary constructor hostile to certification; a flat child carrier, a parallel storage abstraction for one consumer; HAMT or CHAMP, which needs a hash and loses the sorted order; balanced trees and treaps, whose shape depends on history or hashing; an intrinsic `Map` carrier, which grows the trusted base with map laws. Persistent index-update functions, `List/set`, `insert`, `delete`: `/std` has no index-update vocabulary, and mutation stays in `Cell`.

### A screen is a size-indexed frame and a layout is a typed pane tree

**Decision.** `/std/Tui` draws with Notty's algebra and the size in the type: a screen is a `Frame(w, h)`, `Vec` twice, so `beside` and `above` refuse a mismatched join where it is written, a `view` produces exactly the frame it was asked for, and the renderer diffs two frames of one type. A layout is a `Layout` tree of named panes under `rows` and `cols`, split into `Sizes(l, w, h)`, an inductive whose constructors mirror the tree's, so a pane's name and size travel together and `render` is checked at every join; `fitted` absorbs what a share's rounding leaves, and `Frame/fit` is the one coercion where a runtime-sized value meets a typed one. Above the algebra the program is brick's model-update-view record, `Tui`, driven by one bounded event channel with readiness waits, and the same fold runs with no terminal as `Tui/drive`, so a whole program is asserted as a `test`. Session state is carried by values: the reader keeps its returned input buffers, the ticker its returned sizes, the drawing loop its returned frame history, and the drawing loop waits for its first event, drains the queued burst, applies resize events and draws once.

**Rationale.** A column that does not fill its pane, a widget that overflows it, a border off by one fill every surveyed library's issue tracker, and Notty and brick pad the mismatch away silently. The size in the type costs no proof: `fit` recurses on the target size, so cropping and padding are one function and no `Eq/subst` appears. Input decoding and rendering are pure functions, tested without a terminal, and the session is the only module that touches one.

**Rejected.** Notty's implicit padding; an untyped `Layout/split(len, parts) -> List(Nat)` beside the tree; a `select` over fibers in place of the channel, which would cancel a reader mid-park; a typestate for the session, which `using` brackets once; a handler typed by the GUI, as the Agda GUI library does; separate public role types for the loops, whose values already state the ownership. A retained widget tree, styling, a constraint solver, the mouse and grapheme clustering wait for a consumer.
