# Arithmetic: findings

- **A bound inside a recursive member's body is filled through the member's own body, which the kernel holds standing for nothing.** [A bound is stated in a decided proposition and discharged by reduction](../../design/arithmetic/a-bound-is-stated-in-a-decided-proposition-and-discharged-by-reduction.md) fills a bound whose proposition reduces to `True`, a parked one retried under the refinements its slot was born under, and `curios-cert`'s README checks a group's bodies "over members that stand for nothing". `attempt_discharge` (`curios-elab/src/elaborate/apply.rs`) parks a bound waiting only on a `rec` group's slot ("Waiting on the group's own members alone: reduction may yet decide the bound once they are defined") and retries it once the slot is solved to the member's body, so `trivially_inhabited` reduces through that body. `let f(n: Nat) -> Nat = match n | 0 => 0 | _ + 1 => List/get([1, 2, 3], f(0)) end;` is admitted by the elaborator, which fills `Holds(f(0) < List/len([1, 2, 3]))` with `True/qed()`, and refused by the kernel: "the kernel refused /f: expected `Holds(#0(0) < List/len(@Nat, [1, 2, 3]))`, found `True`". The same holds in an `and` group (`g` reading `h(0)`, refused at `/g`) and in a local group (`r` inside `outer`, refused at `/outer`), while the same fact written in the body, `let h: Holds(f(0) == 0) = True/qed();`, is refused by the elaborator as a type position reaching `f`. No `False` follows, since the kernel refuses every such term; a sound program's author meets the kernel's refusal where the elaborator should have reported the bound. Fix: a bound born inside a group's body is retried with that group's slots held unsolved, as `at_birth` (`curios-elab/src/context.rs`) re-installs the guards it was born under, so the fill and the procedure answer there as the kernel does and the elaborator reports the bound unproved; `attempt_discharge`'s comment and `waits_past_its_group`'s doc are restated. Check: the program above in `curios/src/tests/bounds.rs`, refused by the elaborator with the bound's own report and no "kernel refused", the `and`-group and local-group variants beside it; `cargo xtask workspace lint`. Size: one commit.
