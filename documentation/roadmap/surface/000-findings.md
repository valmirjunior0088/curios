# Surface: findings

- **A whole dump is built as a shown tree, which no type keeps out of what a reader reads.** The Core text writer (`curios-surface/src/core_text/`) builds `Term<Shown>` (`Tree`, `frame.rs`) for every print, so text written whole (`Spelling::written_whole`), which `every_unit_of_the_prelude_reads_back_from_its_core_text` reads back, holds no shown form — `…`, `?7`, `.{…}` — only because the writer elides nothing there and takes no reader-spelling branch: one written whole would surface as a parse refusal rather than a type error. Fix: make the writer generic over the dialect it builds, in one walk, building Core text's own tree (`Term<CoreText>`, `CoreFile`) where it writes whole and a shown tree otherwise, so a whole print is the reader's inverse and reaches `to_core` without a parse. No consumer reads a dump as a tree today: each parses its text. Check: the round trip read from the tree, and `every_unit_of_the_prelude_is_written_as_curios_format_writes_it`. One commit.
- **A `choose` with no default arm is refused as a missing bar.** `parse_choose_default` (`curios-surface/src/parse/match_expr.rs`) fails at the `end` of `choose | n > 2 => 1 end` with `Expected '|', obtained 'e'`, where the rule is that a final `| _ =>` arm is required ([Guarded ladders](../../language.md#guarded-ladders-choose)). Fix: an `end` met where the default arm stands is refused by that rule, naming the arm to add. Check: a parse test pinning the message and its caret at `end`. One commit.
- **A pattern in a list leaf's operand is refused as a stray token.** `match v | some([some(x), ..tail]) => 0 | _ => 1 end` reports `Expected '=>', obtained '(['`, where the rule is that the operands of the `Nat`, `List` and `Bytes` leaves are binder names ([Inductive patterns](../../language.md#inductive-patterns)). Fix: the list and packed leaves commit past their bracket and refuse an operand that is no binder by that rule, naming the nested `match` that takes it apart. Check: a parse test for `[some(x), ..tail]` and `x[0x01, ..tail]` pinning the message. One commit.
- **A missed literal names a fragment of what stands in its place.** `obtained` (`curios-parse/src/primitive.rs`) quotes as many characters as the expected literal holds, so a one-character `|` meets `end` as `'e'` and a two-character `=>` meets `([` as `'(['`. Fix: quote the token that stands there — a word whole, and otherwise the run of characters up to the next blank or word character. Check: `curios-parse`'s tests, and the parse tests that pin an `obtained`, restated. One commit.
