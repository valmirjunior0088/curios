# Surface: findings

- **A higher-kinded witness keyed through a definition under its binder is refused as one whose head is that definition.** `satisfy (@S: Type) => Tag((A: Type) => through(S, A))`, over `let through(S: Type, A: Type) -> Type = Box(S, A)`, is refused as "this witness of 'Tag' is for head 'through', which its signature does not spell … write 'through' where the signature computes it", and so is the same with `through` a name bound to `Box`: the advice is to write what is already written, and `through` is no type former a witness could be keyed at. The refusal itself is the reasoning `Keying::under_binders` states (`curios-core/src/witness.rs`): reduction does not descend under a binder, so a definition applied there is not read through and the spelled key is `None`. The elaborated key is read by `HeadKey::of_whnf`, whose partially-applied arm takes whatever global heads the body's spine as `HeadKey::Nominal`, a definition included, so `register_witness` (`curios-elab/src/resolve.rs`) compares a key no declaration has with the spelled `None` and raises `WitnessKeyNotSpelled` with that key. Fix: a key whose head names no type former, no registry entry and no intrinsic former, is refused as unkeyable, `InvalidWitnessHead`, which states what a head must be, before it is compared with the spelling; `of_whnf`'s sentence that "the reference's global *is* the declaration's key" is restated to say where it holds.
