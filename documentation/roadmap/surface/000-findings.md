# Surface: findings

- **A binder takes only tuple and structure patterns, narrower than the patterns coverage proves total.** `documentation/language.md`'s Irrefutable binder patterns admits a tuple or structure pattern in a `let`, a lambda and a parameter, so a pattern of one constructor that index inversion leaves alone is written as a one-arm `match`: `match p | refl() => Eq/refl() end` (`curios-prelude-build/std/Eq.crs`), `match whole | cons(head, _) => head end` (`List/Pairwise.crs`), `match layered | level(over, _) => over end` (`List/sort_by.crs`); and over a `Vector(T)(3)` declared as the reference's indexed family, `match v | cons(a, cons(b, cons(c, nil()))) => … end` compiles where the same `let` is a syntax error. Fix: a binder takes any pattern the match compiler finds total where its type is known, what follows checked as that one arm so a specialization such as `refl`'s reaches it, and a pattern that can fail refused by coverage's own `missing arm`. Check: the three `/std` matches written as `let`s, and a refutable pattern refused with the case it misses. Size: two commits, the grammar, lowering and reference, then the editor grammars.
- **Uncertain: a case the facts in scope refute must still be written as an arm.** Over `r: Vec(Nat, 3)`, `match r.list | [a, b, c] => … end` is refused with "no arm matches `[]`", though a bound refused in the same scope lists `r.counted: List/len(@Nat, r.list) <= 3` and `3 <= List/len(@Nat, r.list)` among its facts, and the four arms the facts rule out compile written as `match proved(@Bool/False) end`. Coverage reads its cases off types ([Patterns are compiled where their types are known](../../design/surface/patterns-are-compiled-where-their-types-are-known.md)), and an arm is absent only where index inversion proves it impossible ([An arm is checked in a context specialized by index inversion](../../design/theory/an-arm-is-checked-in-a-context-specialized-by-index-inversion.md)). Not yet known: the cost of asking the facts at each leaf no arm reaches, how a refusal reports facts that do not refute, and the amendment each decision takes. Settled by closing such a leaf with the contradiction the elaborator proves as it proves a bound, which the certifier checks as a written arm, measured against the cases where no arm is missing. Size: unknown.
