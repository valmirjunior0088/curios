# Surface: findings

- **A source that opens with a byte-order mark is refused with an invisible character as the fault.** A file beginning with U+FEFF reports `expected a term, obtained '﻿'` at `1:1` under `run`, `format` and standard input alike, the quoted character rendering as nothing; [the reference](../../syntax.md) says nothing of a mark, and editors on some platforms write one. The empty quotes are what any character that prints as nothing gets — a zero-width space inside a file reports the same — since `refuse_non_term` (`curios-text/src/parse/expr.rs`) and `take_exact` (`curios-parse/src/primitive.rs`) quote what they obtained as written. Fix: skip a leading U+FEFF at the head of the program and the module grammars, so every span keeps the file's own offsets and `format` writes none, which `format --check` then reports as it reports a carriage return; [Go's specification](https://go.dev/ref/spec#Source_code_representation) lets a compiler ignore a mark that is the first code point and refuse one anywhere else, and [rustc](https://doc.rust-lang.org/reference/input-format.html) removes one where it normalizes line endings. Wherever a report quotes what it obtained, a character that prints as nothing is spelled by its code point, `U+200B`, and the reference states both. Check: a fixture with a leading mark compiles and formats to the same text without it, and a mark or a zero-width space past the first position reports its code point. Size: quick.
- **Whitespace is every character Unicode calls white space, where the reference names three.** **Uncertain, and warrants investigation:** which of the two is meant. `parse_whitespace` (`curios-text/src/parse.rs`) and the grammar's other blank-skipping sites take whatever `char::is_whitespace` answers for, so a no-break space (U+00A0) or a line separator (U+2028) separates tokens: `let` and `x` joined by either compile as `let x`, where [the reference](../../syntax.md#whitespace-and-comments) has spaces, tabs and newlines separate them. `format` rewrites each as a space, so `format --check` reports one, and nothing else does. [Go](https://go.dev/ref/spec#Tokens) takes the space, the tab, the carriage return and the newline alone, and [Rust](https://doc.rust-lang.org/reference/whitespace.html) the `Pattern_White_Space` set, which leaves the no-break space out. Fix: the grammar takes the reference's three and the carriage return it accepts today, and refuses any other blank by its code point, as the entry above spells a character that prints as nothing; or the reference names the set the grammar takes. Check: a fixture per character, on the side chosen. Size: quick.
- **A report spells a projection by its slot, where its reader writes a position.** Core's printer (`curios-core/src/print.rs`, the `Subterm::Proj` arm) prints `(v).N` from an elaborated projection's slot and has no type to count the plain fields by, so over a concept value held as a plain value a report shows `(dict).1` for the method an author reads as `dict.0`, the edge ahead of it being in the slot count and out of the position count ([A hidden member takes no position](../../design/theory/a-hidden-member-takes-no-position.md)). A witness in scope is unaffected, its methods printing by name (`method_doc`). A structure value is spelled slot by slot the same way, its normal form holding every slot: a concept value prints its edge as a plain entry, `Over { Base { … }, (n) => "over" }`, where its author writes `use` before it or leaves it out. Fix direction: the printer learns the head's field marks — from the spelling tables it already carries for witnesses, or from a projection that names its structure. Size: moderate.
- **A refusal inside a structure update names the update's base by a name nobody wrote.** A spread binds its base to a hintless local (`elaborate_struct_spread`, `curios-elab/src/elaborate/struct_.rs`), and that local's proof fields are facts in scope like any hypothesis's. Over `struct Positive: Type { n: Nat, @ok: Holds(0 < n) }` and `p: Positive`, `Positive { ..p, n = 0 }` is refused with `the facts in scope do not refute each other: x.ok: 0 < (x).0`, where the author wrote `p` and the printer minted `x`. Fix direction: a fact read off the spread's base is spelled through the base term, `p.ok`. Size: small.
- **Parsing costs a box for every combinator it runs.** The standard library's 167 files, 802,370 bytes, parse in 28,952,798 allocations, 36 a byte, counted at `8f1cb4982` — the `run_parser` rows of its files in the profile the prelude's build files, `curios-prelude-archive/.artifacts/profile.tsv`, folded by `curios profile`. `Flt.crs`, 46,282 bytes, is 1,587,391 of them, which a session pays at every keystroke in it, a file being parsed whole: the one an edit touched, and a standing one where a declaration of it is lowered again ([A file is parsed where a declaration of it is lowered](../../design/compilation/a-file-is-parsed-where-a-declaration-of-it-is-lowered.md)). Nearly all of them are parsers: a `Parser` is a boxed `FnOnce` built for every application of a combinator that captures anything ([`curios-parse`'s README](../../../curios-parse/README.md#a-parser-is-a-single-use-fnonce)), and a grammar function builds its parser again at every position it is tried at. Of `Bool.crs`'s 112,310 allocations, 3,102 bytes, 108,763 are those boxes: its parse builds 124,634 parsers, the rest capturing nothing, and runs 89,679, the others being operands a grammar still hands over as a call, a parameterized nonterminal's ([A combinator takes a parser or a nonterminal](../../../curios-parse/README.md#a-combinator-takes-a-parser-or-a-nonterminal)) — a counter in `Parser::new`, apart for the closures that capture nothing, and one in `Parser::parse`, read where `run_parser` ends. A session parses a file once for each text it holds (`curios-text/src/root_source.rs`), and a question the files of a unit whose text moved from its baseline's; a build and a test run parse every file of every unit the store misses. Fix: a grammar built once and run at every position, a nonterminal being a function of the input where it is the builder of a closure, which revises the README's first decision; beside it, one declaration parsed from where its head places it ([A compile costs what it reads](../compilation/03-a-compile-costs-what-it-reads.md#open-questions)). Check: the same rows, retaken. Size: every grammar function of `curios-text` and `curios-wasm`.
