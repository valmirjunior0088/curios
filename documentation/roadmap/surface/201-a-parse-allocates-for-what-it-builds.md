# A parse allocates for what it builds

**Not refined yet.** This specification reserves a grammar built once and run at every position, where a grammar function builds its parser again wherever it is tried. It is not an implementation plan.

## What is missing

**Parsing costs a box for every combinator it runs.** The standard library's 167 files, 802,370 bytes, parse in 28,952,798 allocations, 36 a byte, counted at `8f1cb4982` — the `run_parser` rows of its files in the profile `cargo xtask profile-prelude elaboration <PATH>` files, folded by `curios profile`. `Flt.crs`, 46,282 bytes, is 1,587,391 of them, which a session pays at every keystroke in it, a file being parsed whole: the one an edit touched, and a standing one where a declaration of it is lowered again ([A file is parsed where a declaration of it is lowered](../../design/compilation/a-file-is-parsed-where-a-declaration-of-it-is-lowered.md)). Nearly all of them are parsers: a `Parser` is a boxed `FnOnce` built for every application of a combinator that captures anything ([`curios-parse`'s README](../../../curios-parse/README.md#a-parser-is-a-single-use-fnonce)), and a grammar function builds its parser again at every position it is tried at. Of `Bool.crs`'s 112,310 allocations, 3,102 bytes, 108,763 are those boxes: its parse builds 124,634 parsers, the rest capturing nothing, and runs 89,679, the others being operands a grammar still hands over as a call, a parameterized nonterminal's ([A combinator takes a parser or a nonterminal](../../../curios-parse/README.md#a-combinator-takes-a-parser-or-a-nonterminal)) — a counter in `Parser::new`, apart for the closures that capture nothing, and one in `Parser::parse`, read where `run_parser` ends. A session parses a file once for each text it holds (`curios-text/src/root_source.rs`), and a question the files of a unit whose text moved from its baseline's; a build and a test run parse every file of every unit the store misses.

## Refinement

- **A grammar built once.** A grammar built once and run at every position, a nonterminal being a function of the input where it is the builder of a closure, which revises the README's first decision; beside it, one declaration parsed from where its head places it ([A recompile walks the unit it does not redo](../compilation/203-a-recompile-walks-the-unit-it-does-not-redo.md#refinement)). Check: the same rows, retaken. It reaches every grammar function of `curios-text` and `curios-wasm`.
