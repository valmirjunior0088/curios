# A refusal names what its reader wrote, and where

Working specification for holding a report to the program its reader wrote: a term it shows is one the reader can write back, a name it gives is one resolution takes back, and it stands at a place the reader can act on. It is held to [A diagnostic spells what its reader can write](../../design/tools/a-diagnostic-spells-what-its-reader-can-write.md), whose rule it keeps and whose mechanism it replaces: the rule is kept today by convention at each site, and this specification moves it to four seams a site cannot bypass.

## What this builds on

- **A report is spelled for a reader standing at a position** ([A diagnostic spells what its reader can write](../../design/tools/a-diagnostic-spells-what-its-reader-can-write.md)): the declaration it arose in, whose module and imports decide what reaches a name, and the witness binders in scope there (`curios_core::ReaderPosition`). Each unit keeps what a report spells its names by (`curios_core::Lexicon`), and the text stage lists the paths a unit gives a name where a report first asks (`curios_text::PreparedText::spellings`).
- **A term keeps where it was written.** A Core term's position is an `Extent` on the occurrence, no part of its identity (`curios-core/src/extent.rs`), and elaboration puts it back on what it rebuilds (`elaborate`, `curios-elab/src/elaborate.rs`; `Term::rebuilt`, `curios-core/src/term.rs`).
- **The lowering keeps where a declared name is written**: `Declared::label` (`curios-text/src/into_core/references.rs`), an extent in the declaration's own text, stored with the unit and read by the `unused-declaration` lint alone.
- **The surface tree prints back as written** (`curios-text/src/print.rs`), held by the formatter's tests over every authored source, and holds each form a report needs: a literal's entries under their marks (`StructLitEntry`), a constructor pattern's marked payloads, the `Nat`, `List` and packed leaves with their hypothesis (`NatPattern`, `ListPattern`, `BinPattern`), a projection by position or label.
- **A refusal is its declaration's.** A declaration the parser could not read is refused alone, its dependents withheld, and a bare name that resolves to nothing lowers to a binder nothing binds (`Context::unbound_binder`, `curios-text/src/into_core/context.rs`), which elaboration reports in the declaration that wrote it.
- **A name is an identity, not a record** ([`curios-core`'s README](../../../curios-core/README.md)): "No path leads from a `Free` to a `&str` except through the printer" (`curios-core/src/names.rs`).

## The gap

Each claim is a program put to `wonder diagnostics -` at `ca95d7595`.

**A report prints Core through a second printer of the surface language.** `curios-core/src/print.rs` is taught the surface form of one Core form at a time, beside the printer that formats source (`curios-text/src/print.rs`), and nothing holds it to the grammar: `.claude/rules/surface.md` does not list it as reached by a grammar change, and the paste-back tests are each "written the first time a rendering broke it".

- *A stuck `match` is shown in Core's notation.* `let f(b: Bool) -> Eq()(match b | true => 1 | false => 2 end, 3) = ?;` reports `Bool.match b ~ Nat; | false => 2; | true => 1;`, and the other forms read `Nat.fold n: n2 => Nat; | 0n => 1; | p ih => ih + p;`, `Nat.match n ~ Nat; | 0n => 1; | 7n => 2; | _ => 3;`, `List.fold xs: xs2 => Nat; | [] => 0; | [h, ..t]; ih => h + ih;` and `match c ~ Nat; | 'chunk(n, @x) => n; | 'empty => 0;`. The step of `lemma(n: Nat) -> Eq()(add(n, 0), n)`, a goal in the arm `| p + 1; ih => ?`, is offered `? ≈ Nat/eq_of_eql(Nat.fold p: n2 => Nat; | 0n => 0; | p2 ih2 => ih2 + 1; + 1, p + 1, ?)`.
- *A projection is shown by its slot.* Over `struct Wide: pub Type { a: Nat, @h: Holds(a < 10), b: Str, c: Str }`, the goal `Eq()(s.1, "x")` reports `(s).2`; written back, `(s).2` is the field `c`, and its report reads `(s).3`. A hidden field read by its label, `s.len`, reports `(s).0`. Over a concept value `dict: Over(Nat)`, `concept Over(A: Type): pub Type { use Base(A), over(A) -> Str }`, `dict.0(3)` reports `(dict).1(3)`, which is refused when written back (`tuple index 1 out of bounds (arity 1)`). The head may be any term: `g(n).name` reports `(g(n)).2`.
- *A literal is shown slot by slot.* Over `struct Small: pub Type { value: Nat, @bound: Holds(value < 10), name: Str }`, `Small { 3, "three" }` reports `Small { 3, /std/Bool/True/qed(), "three" }`, refused when written back (`struct '/Small' has 2 field(s) but the literal supplies 3`), where `Small { 3, @/std/Bool/True/qed(), "three" }` is accepted. A concept literal `Over { over(n) = "over" }` reports its edge as `Over { /witness@/Base(Nat), (n) => "over" }`, which does not parse, and a spread `Over { ..dict }` as `let x: Over(Nat) = dict; Over { (x).0, (x).1 }`.
- *Nothing checks more than a signature.* The two sweeps of `curios-pipeline`'s `tests::paste_back_tests` report each public declaration of `/std` by its type, with no import and under `use /std/*`, and hold that the spelling reads back, never that it is the shortest.

**A refusal holds a name as text.** Forty-five sites of `curios-elab` build an `Error` from `Global::symbol()` (`rg '\.symbol\(\)' curios-elab/src` lists sixty-one outside its tests, sixteen of them an invariant's message, an erased debug name or an operator's symbol) and its totality driver five more from a `Global`'s `Display`, into some twenty-five variants that hold a `String`, and `error/display.rs` interpolates it where every term goes through `spelling.symbol`. `Global::symbol`'s own comment reads "which a diagnostic names a declaration by", against the module comment beside it.

- A missing `none` arm reports `missing match case for constructor 'none' of '/sys/Option'`, a root a program may not name; an arm over `Ordering` names `/std/Ord/Ordering/Ordering`; under `use Inner/{Colour};` a missing arm names `/Inner/Colour`; a local proposition is `/P` and a local structure `/Pair`.
- Every wrapped report opens `while elaborating /f:` (`Item::describe`), a totality refusal reads `the type of '/x' is a type position but reaches '/T'` (`curios-elab/src/totality/reach.rs`), and an initializer that reads itself is `` `/n` evaluates itself as it is initialized ``, a debug name of the erased program (`curios_ersd::CycleStep`).
- A positivity refusal names its payload `mk(0)`, an ordinal in the place of an argument (`labelled`, `curios-analysis/src/positivity.rs`).
- `curios-text`'s exposure refusal reads `public item '/Inner/leak' exposes private item '/Inner/Hidden' in its signature` (`into_core/audit.rs`).

**A place is attached by whoever raises.** `Error::at` is called where a raise site remembers to, and a refusal no term is being elaborated for has nothing to remember.

- `induct Bad: pub Type | mk((Bad) -> Nat) end` reports `'/Bad' is not strictly positive: through 'mk(0) : (Bad) -> Nat' it occurs in itself negatively` with no place (`curios-elab/src/positivity.rs`).
- `let loop(n: Nat) -> Type = loop(n);` reports `the recursive definition '/loop' is a type position but does not terminate on every input`: no place, and a definition called a position. `let loop(P: Prop, n: Nat) -> P = loop(P, n);` reports `a proof in '/loop' is a proof position but reaches '/loop', which is not known to terminate` with neither a place nor the line naming its declaration: an erasure obligation is rendered to a string and wrapped by `Report::unlocated` (`elaborate_and_zonk`, `curios-pipeline/src/compile.rs`), and `settle_published` (`curios-elab/src/elaborate/module.rs`) hands it back attributed to nothing.
- A cycle between `let f(n : Nat) -> Nat = g(n);` and `g` is underlined at the first `Nat` of `f`'s signature (`first_written`, `curios-elab/src/elaborate/module/demand.rs`), where the label is two words to its left and already kept by the lowering.
- Three `curios-text` refusals carry none: the exposure refusal, `export conflict for label: x` and `private child module: Sealed` (`into_core/interface.rs`).

**A name that fails to resolve is nine refusals in two crates.** `curios-text` raises `UnresolvedQualifier`, `UnresolvedNominal`, `ChildModuleNotFound`, `PrivateChildModule`, `BindingNotFound`, `PrivateBinding`, `NotAModule`, `NotABinding` and `NoSuchUseTarget` from `into_core/context.rs`, `into_core/interface.rs` and `into_core/lowerer.rs`, and `curios-elab` raises `UnboundVariable`.

- One fault reads six ways: `unresolved qualifier: List`, `unbound variable: Bool`, `binding not found: lenght`, `no module or binding named Nta in /std`, `child module not found: foo`, `unresolved struct name: Piar`. The first two say how to reach the name and the rest nothing.
- None offers a near miss: `coutn` beside a parameter `count`, `totl` beside a declaration `total`, `Option/sme`, `use /std/Nat/{to_srt};`.
- A bare name refuses its declaration and the unit goes on; a path, `List/lenght(xs)`, stops the unit at the first one.
- `pub let x: /sys/Nat = 1;` reports `` `sys` is internal to the standard library; use the corresponding `/std` module ``: a module it does not name, and a correspondence the compiler does not hold.

**A name through an imported module is spelled in full.** `Spellings::spell` (`curios-core/src/names.rs`) offers a child of the reader's module, an absolute path, an imported binding, and a direct member of an imported module (`Imports::brought`). Under `use /std/{Nat, Bytes, Str};` a goal over `Str/Valid/from(Str/Scan/lead(), x[])` reports `/std/Str/Valid/from(/std/Str/Scan/lead(), x[])`, and a bound's suggested proof reads `/std/Nat/le/add(@a, @b, @c, @d, p, q)` where `Nat/le/add(…)` elaborates. The reverse of resolution is stated a second time, in another crate than resolution, and nothing compares the two.

**A refusal with two sides has one place.** `Report` (`curios-utilities/src/span.rs`) holds one span, so `SortDecidedTwice` and a postponed conversion's watched goal write `at 12:5` into their sentence (`curios-elab/src/error/display.rs`), a duplicate witness says `both are declared in the entry module`, and a name conflict names one claim: `use /std/{Nat, print, Nat};` reports `qualifier conflicts with existing scope entry: Nat`, and a `let Nat` beside an imported `Nat` reports `binding conflicts with existing scope entry: Nat` with its caret on the import alone.

## Prior art

- **A term in an error goes back through the surface tree.** Lean 4: "The delaborator is the first stage of the pretty printer, and the inverse of the elaborator: it turns fully elaborated `Expr` core terms back into surface-level `Syntax`, omitting some implicit information again and using higher-level syntax abstractions like notations where possible" ([`Delaborator/Basic.lean`](https://github.com/leanprover/lean4/blob/master/src/Lean/PrettyPrinter/Delaborator/Basic.lean)). Agda: "The translation of abstract syntax to concrete syntax has two purposes. First it allows us to pretty print abstract syntax values without having to write a dedicated pretty printer, and second it serves as a sanity check for the concrete to abstract translation: translating from concrete to abstract and then back again should be (more or less) the identity" ([`AbstractToConcrete.hs`](https://github.com/agda/agda/blob/master/src/full/Agda/Syntax/Translation/AbstractToConcrete.hs)). Rocq's `constrextern` is the "Translation of pattern, cases pattern, glob_constr and term into syntax trees for printing" ([`constrextern.mli`](https://github.com/rocq-prover/rocq/blob/master/interp/constrextern.mli)), and Idris 2 prints an error's term by `resugar` ([`Idris/Error.idr`](https://github.com/idris-lang/Idris2/blob/main/src/Idris/Error.idr)).
- **Reading back is checked, not assumed.** Lean's analysis for it "aims to determine the minimal annotations necessary to ensure that the delaborated expression can be re-elaborated correctly" and is "neither sound nor complete" ([`TopDownAnalyze.lean`](https://github.com/leanprover/lean4/blob/master/src/Lean/PrettyPrinter/Delaborator/TopDownAnalyze.lean)).
- **A shortened name is one resolution accepts.** Lean's `unresolveNameGlobal` finds "an efficient name that unambiguously resolves to the given name", trying each suffix through `resolveGlobalName` and taking one that resolves to that constant alone ([`ResolveName.lean`](https://github.com/leanprover/lean4/blob/master/src/Lean/ResolveName.lean)). Rocq keeps one table for both directions, `locate` and `shortest_qualid_of_global` ([`nametab.mli`](https://github.com/rocq-prover/rocq/blob/master/library/nametab.mli)), and Agda inverts the scope, "unqualified names first", names reached through an import among them ([`Scope/Base.hs`](https://github.com/agda/agda/blob/master/src/full/Agda/Syntax/Scope/Base.hs)).
- **A projection names its structure.** Lean's `Expr.proj (typeName : Name) (idx : Nat) (struct : Expr)`: "The kernel and elaborator check whether the `typeName` matches the type of `struct`" ([`Expr.lean`](https://github.com/leanprover/lean4/blob/master/src/Lean/Expr.lean)).
- **An error is data with a place.** Idris 2's `Error` constructors take an `FC` first and hold a `Name` and a `Term vars` with its `Env` ([`Core/Core.idr`](https://github.com/idris-lang/Idris2/blob/main/src/Core/Core.idr)). Lean's `throwError` takes its place from the monad: "The result of `getRef` is used as position information" ([`Exception.lean`](https://github.com/leanprover/lean4/blob/master/src/Lean/Exception.lean)).
- **A near miss is one edit in three letters, a swap counting once.** rustc "takes an optional limit for the maximum allowable edit distance, which defaults to one-third of the given word", `cmp::max(lookup_len, 3) / 3`, over the restricted Damerau–Levenshtein distance, after a match that differs in case alone ([`edit_distance.rs`](https://github.com/rust-lang/rust/blob/master/compiler/rustc_span/src/edit_distance.rs)). GHC takes the same distance within `(length + 2) / 4` and shows three ([`Utils/Misc.hs`](https://github.com/ghc/ghc/blob/master/compiler/GHC/Utils/Misc.hs)), and OCaml a cutoff by length and every tied best ([`misc.ml`](https://github.com/ocaml/ocaml/blob/trunk/utils/misc.ml)). `coutn` is one swap from `count` and two substitutions: the plain distance at a third of five letters offers nothing.

## Decisions

1. **A term a report shows is translated back to the surface tree and printed by the printer that formats source.** The translation is the inverse of lowering and elaboration, lives beside the lowering in `curios-text`, and reads what the Core printer reads today: the reader's position and each unit's lexicon. The Core printer prints what is read about the compiler, a `wonder stage` dump and a kernel refusal.
2. **A translation is whole or it is none.** It hands back a surface term, or says it cannot: the term is past the print's bound ([A printer states each fact once, where it is bound](../../design/tools/a-printer-states-each-fact-once-where-it-is-bound.md)), or holds a form no program spells — a witness resolution would not put back, a hidden member with no label read off a plain value. The report then shows that term as the compiler holds it, bounded as a dump is, and says so. The surface tree gains no node and the grammar no token.
3. **A projection out of a structure names the structure.** The kernel holds the name to the head's type. A tuple's projection names none, a tuple type's field taking no mark.
4. **A refusal holds identities.** A declaration is a `Global`, a site a typed value, and a `Global` has no `Display`: what is read about the compiler asks for the faithful spelling by name.
5. **A refusal stands at a place.** The narrowest written term it is about, and where it is about none, the label of the declaration it arose in. The line naming that declaration spells it as any name is spelled.
6. **A report may hold a second place**, a note with a line of its own.
7. **A name that fails to resolve is one refusal.** One resolver raises one value — what was written, the step that failed, why it found nothing, what was in scope there — and one rendering shows it. A name written in a declaration refuses that declaration alone, a path as a bare name; a `use` refuses the unit. A step into a root the unit may not name is such a failure, for a reason of its own: the root is the compiler's, or the unit declared no dependency on it. It is offered what any is, the paths the unit may write that carry the name it reached for, found by that name in the namespace it was sought in. The compiler holds no notion of a facade: that `/std` exports what `/sys` declares is how the library is written, and a module and a declaration of one name are two things.
8. **The nearest name is offered by rustc's rule**: one that differs in case alone, else one within `max(length, 3) / 3` of the restricted Damerau–Levenshtein distance, among the names in scope where the step failed.
9. **A name's spelling is held to resolution.** The spelling a report gives resolves forward to that name, and no shorter one does.

## Stages

1. **Identities.** Decision 4. `Global` loses `Display` and `symbol`, and the compiler lists every site: a refusal takes the `Global` and renders it through `spelling.symbol`, and what is read about the compiler — a dump, a kernel refusal, an erased debug name, a `UniverseInvariant`, a profile's label — asks for the faithful spelling. `InDeclaration` holds the declared names. The sites a totality position stands in (`curios-elab/src/context/checked.rs`, `totality/reach.rs`) are typed, positivity's part is a constructor with a payload by label or ordinal, or a field, rendered by each driver, and `Error::refused_by_verifier` names a cycle's member by the `Global` its value was minted for. Check: the probes report `Option`, `Ordering`, `Colour`, `P`, `Pair`, `n` and `f`.
2. **Places.** Decision 5. `Declared::label` is kept for a constructor, a `satisfy` and a test as for a definition, and reports are handed a lookup from a `Global`; a report with no extent stands at its declaration's label, and `first_written` goes. `settle_published` attributes an obligation to its declaration and the pipeline reports it as it reports a refusal. Positivity stands at the payload's type, a totality refusal at the position's term, a recursive definition at its label, each worded as what is reached from there. The exposure refusal stands at the item's label, and an export conflict, a cyclic re-export and a refused re-export at the `use` they are about. What a report reads of the unit — its module, the lexicons, the registry, the unresolved names, the spellings, the anchors, the labels — is one value the pipeline hands over. Check: a fixture per refusal asserting its span.
3. **Second place.** Decision 6. `Report` holds notes, each rendered with its snippet, carried by both transports of `curios-wonder` and by the archive. A cycle notes each member's label, a duplicate witness the other declaration, `SortDecidedTwice` and a watched goal the other term, and a name conflict the first claim, both named. Check: a fixture per taker asserting both spans; `re_export_tests.rs`' and `use_tests.rs`' conflict assertions reworded.
4. **Resolution.** Decisions 7 and 8. The distance and the nearest-name rule are `curios-utilities`'. One function of `curios-text` resolves a path a step at a time and raises the one value, for the lowering and the interface pass alike. In a declaration, a path that fails lowers to the binder a bare name does, the table handed to elaboration holds the value, and `UnboundVariable` renders it. `InternalRootModule` and `UndeclaredPrefix` are that value too, the root being the step that failed, and list the paths that carry the name reached for under it. Check: a fixture per probe above, wording and suggestion; a unit holding two failed paths reports both; a `sys_tests.rs` fixture asserting that `/sys/Nat` is offered `/std/Nat`.
5. **Names.** Decision 9. `Spellings::spell` offers a path through a module import in scope, from the paths the units list and the imports the scope holds. `curios-text`'s own refusals spell a name through it. Check: the differential under *Verification*; both probes print the reader's spelling.
6. **Projection.** Decision 3. `Field` distinguishes a structure's slot, with its structure, from a tuple's; every site that builds one says which, `Telescope::field_type_from` being told how a slot of its value is read; the kernel's projection rule compares the name. Expected to move: the prelude images' size.
7. **Translation.** Decisions 1 and 2, in six steps that land apart. A `Spelling` may hold the reader's printer, set by the pipeline, and a spelled term asks it. The translation covers every Core form: a name, a call with its marks and the `use` arguments resolution puts back, a nominal type, a constructor, a literal with its marked entries, a projection by position or label, each match form as its patterns, a `let` and a local group, a lambda and a function type, a tuple, a literal, an operator, a goal, and a binder's name; `Lexicon` holds each structure's field marks and labels. Its tests are a program per form, the expected text being the program. Reports are switched to it, and the expectations that pin a layout move to the formatter's. The Core printer loses what only a reader read, and `Spellings::spell` moves beside the resolver. The paste-back sweep takes bodies. Check: the round trip under *Verification*.

## Verification

- **A probe is a fixture.** Each program under *The gap* is a test asserting the report's wording and its span, in the suite of the crate that raises it.
- **No name is text.** `Global` implements no `Display`: a refusal built from a name's text does not compile.
- **A spelling is the shortest that resolves.** For every public declaration of `/std` and each of four reader positions — a program with no import, one under `use /std/*`, one importing a single top-level module of `/std`, for each, and a module nested in such a program — the spelling `Spellings::spell` gives is written as a declaration's body in a program generated for that reader, and the lowering resolves it to that declaration; every name of fewer segments that is a suffix of one of its paths, written beside it, resolves to another declaration or to none (`curios-pipeline`'s `spelling_tests`). Counted.
- **A report's term reads back.** Every file of `/std` is printed again with each declaration's type and body replaced by the translation of what it elaborated to, the reader standing in that declaration; the files are compiled as the library, each read through an overlay (`RootSource::with_overlay`); each declaration's term is held to the one it replaces by the kernel's conversion, and no term is left untranslated. Counted, and run under a memory cap until it has passed once.
- **Nothing a dump prints moves**: `wonder stage core-elab` over the corpus prints what it printed.

## Design decisions this overturns or corrects

- [A diagnostic spells what its reader can write](../../design/tools/a-diagnostic-spells-what-its-reader-can-write.md): "Printing runs resolution in reverse at that position" becomes the translation, its rejection of "rendering through the surface syntax tree" is reversed, and "the faithful spelling stays" becomes the whole term shown as the compiler holds it. Its first reason, that a surface tree "guarantees output that parses, not output that elaborates to the same term", holds of both: the Core printer guarantees neither, and the round trip checks the second. Its second, that it "makes the checkers depend on the surface crate", does not follow: `curios-text` depends on `curios-core`, and no checker depends on `curios-text`. Translation.
- [A printer states each fact once, where it is bound](../../design/tools/a-printer-states-each-fact-once-where-it-is-bound.md): "One rule serves a `wonder stage` dump and a report" is the bound's alone, which decides the terms a report translates. Translation.
- [A hidden member takes no position](../../design/theory/a-hidden-member-takes-no-position.md): "a projection naming its slot" names its structure with it. Projection.
- [`curios-core`'s README](../../../curios-core/README.md), *A name is an identity, not a record*: the capability it says is absent is removed. Identities.
- `.claude/rules/surface.md`: a change to the grammar reaches the translation. Translation.

## Rejected

- **Teaching the Core printer each form in turn.** A stuck `match` alone asks it for the patterns of five forms, a second copy of what `curios-text/src/print.rs` prints, and the next form is found by the next reader.
- **A term for what a report leaves out**, a token of the grammar that parses and is refused (Lean's `⋯`) or a node the parser never builds: what a report shows is the report's to decide where it is made, and a translation that is whole or none leaves the tree holding only what the grammar produces.
- **A translation above the elaborator that asks it for types**, as Lean's and Agda's do: a report is then a function of elaboration state that has to outlive the refusal, where it is a function of its term and its units' tables.
- **A printer that learns a head's structure from the binders it opens.** It reaches a variable and not `g(n).name`.
- **A written-form mark on a projection outside its identity.** Terms are hash-consed, and the mark of the node interned first would stand for every occurrence.
- **Counting plain members in Core's projection**, which the theory decision rejects, and which would have the kernel read a mark.
- **One typed value with each crate's own stop**, a failed path still ending the unit: a typo then hides every other.
- **The plain Levenshtein distance.** It prices a swap at two and offers nothing for the commonest typo of a short name.

## Non-goals

- A kernel refusal and a `wonder stage` dump keep the faithful spelling: they are read about the compiler.
- What the command line and a manifest say ([An argument names one subject and each command states what it accepts](../../design/tools/an-argument-names-one-subject-and-each-command-states-what-it-accepts.md)).
- A bound's counterexample spelled as its statement spells it, and a sign with no literal behind it, each a finding of its own ([findings](000-findings.md)).
