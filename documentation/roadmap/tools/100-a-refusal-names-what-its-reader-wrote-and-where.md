# A refusal names what its reader wrote, and where

**Not refined yet.** This specification reserves five places where a report shows its reader a spelling nobody wrote, or no place to act on. It is not an implementation plan.

It is held to [A diagnostic spells what its reader can write](../../design/tools/a-diagnostic-spells-what-its-reader-can-write.md): a term a report shows is spelled so that, written where the reader stands, it elaborates back to the term shown, and a name takes the shortest spelling resolution would take back to it there.

## What is missing

**A report spells a name through an imported module in full.** [A diagnostic spells what its reader can write](../../design/tools/a-diagnostic-spells-what-its-reader-can-write.md) gives a name "the shortest spelling resolution would take back to it there", but `Spellings::spell` (`curios-core/src/names.rs`) offers only a child of the reader's own module, an absolute path, or an import naming the global itself, and `record_module_import` (`curios-text/src/into_core/context.rs`) records a module import's direct bindings alone. Under `use /std/{Nat, Bytes, Str};`, a hole over `Str/Valid/from(Str/Scan/lead(), x[])` reports `/std/Str/Valid/from(/std/Str/Scan/lead(), x[])`, and a bound's suggested proof reads `/std/Nat/le/add(…)` where `Nat/le/add(…)` elaborates.

**A refusal naming a declaration prints its internal path.** About forty `curios-elab` sites build an `Error` from `Global::symbol()` (`rg '\.symbol\(\)' curios-elab/src`), and `error/display.rs` interpolates the string raw rather than through `spelling.symbol(global)`, as every term in a report is: a missing `none` arm reports `missing match case for constructor 'none' of '/sys/Option'`, a root a program may not name; an arm over `Ordering` names `/std/Ordering/Ordering`; a local proposition is `/P`. `curios-text`'s mutual-reference refusal lists `/even` and `/odd`, and `curios-ersd`'s evaluation cycle `/n`.

**A report spells a projection by its slot, where its reader writes a position.** Core's printer (`curios-core/src/print.rs`, the `Subterm::Proj` arm) prints `(v).N` from an elaborated projection's slot and has no type to count the plain fields by, so over a concept value held as a plain value a report shows `(dict).1` for the method an author reads as `dict.0`, the edge ahead of it being in the slot count and out of the position count ([A hidden member takes no position](../../design/theory/a-hidden-member-takes-no-position.md)). A witness in scope is unaffected, its methods printing by name (`method_doc`). A structure value is spelled slot by slot the same way, its normal form holding every slot: a concept value prints its edge as a plain entry, `Over { Base { … }, (n) => "over" }`, where its author writes `use` before it or leaves it out.

**One fault, a name that resolves to nothing, reads five ways, with no near miss.** `unresolved qualifier: List`, `unbound variable: Bool` (a type is no variable), `binding not found: length`, `no module or binding named Nta in /std` and `child module not found: foo`; the first two carry the `use /std/{X};` hint and the last three nothing, not even the members the parent has. A misspelled local gets none either: `coutn` beside a parameter `count` reports `unbound variable: coutn`.

**Positivity and totality refusals carry no location, and the totality one misreads its grammar.** `positivity.rs` and `totality.rs` (`curios-elab`) build their errors with no span: `induct Bad: pub Type | mk((Bad) -> Nat) end` reports `'/Bad' is not strictly positive: through 'mk(_0) : (Bad) -> Nat' …` with no caret and a minted `_0`; `let loop(n: Nat) -> Type = loop(n);` used at a type reports `the recursive definition '/loop' is a type position …`, its site slotted into `"{site} is a {erased} position"`. A cycle between declarations is placed at the first position written in its first member's signature for the same reason (`first_written`, `curios-elab/src/elaborate/module/demand.rs`): where a declaration's label is written does not reach Core, so `let f(n : Nat) -> Nat = g(n);` is underlined at its first `Nat`.

## Refinement

- **A path through an imported module.** Spell a path through an imported module, which resolution already takes back; `record_module_import`'s comment argues for the narrower rule, and taking it instead is a revision of the decision. Check: both probes print the reader's spelling.
- **A declaration by its reader's spelling.** Carry the `Global` and render it through the reader's spelling. Check: the probes report `Option`, `Ordering`, `P`, `even` and `n`.
- **A projection by its position.** The printer learns the head's field marks — from the spelling tables it already carries for witnesses, or from a projection that names its structure.
- **One message family for a name that resolves to nothing.** One message family across `curios-text`'s resolution errors and `curios-elab`'s `UnboundVariable`, naming the nearest name in scope or declared sibling by edit distance where one is close; [rustc](https://doc.rust-lang.org/nightly/nightly-rustc/rustc_span/edit_distance/fn.find_best_match_for_name.html) offers one within a third of the name's length, compared without case. Check: a fixture per probe, asserting the wording and a suggestion for each typo.
- **A position for a positivity, a totality and a cycle refusal.** Carry the label's position to Core, locate each at it, phrase the site as what is reached from the position, and name the payload by its label or ordinal. Check: a fixture per probe asserting its span and wording.
