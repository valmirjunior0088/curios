# Tools: findings

- **Rendering a report costs the file before it and the whole line it is on.** `Span::line_column` (`curios-utilities/src/span.rs`) counts the newlines from the start of the source to the span for every report, so n reports in a file of m bytes read n × m; and `Span::render_snippet` quotes every line a span starts on whole, so n reports on one long line print n times the line. A program of 1 600 nested lambdas on one line, 1 599 binding a name nothing reads, gets as many unused-binder warnings, each quoting the 30 914-character line: `wonder diagnostics -` prints 85 MB, and two of eight samples of its 10.5 s are `render_snippet`'s grapheme walk (`e6aed0f60`, timed, one reading on a loaded machine). Fix: a source keeps its line starts, found once, so a span's line and column are a search; and a quoted line is clipped to a window around its marks, an elision at each cut end — the second a choice of what a report shows, which the fix settles. Check: the program above prints in proportion to its warnings, and a module of n unused definitions renders its warnings in proportion to n. Size: `Source`, its two readers and their tests.
