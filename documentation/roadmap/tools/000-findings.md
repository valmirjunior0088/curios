# Tools: findings

- **A totality refusal names the partial definition that sorts first.** `partial_offender` (`curios-elab/src/totality.rs`) and `check_positions` (`curios-cert/src/obligation.rs`) take the first partial global in the order of the term's free-variable set, which orders globals by their spelling, so a type reaching two partial definitions is refused by whichever spells first, wherever it is written: shown at `0fc2fc1bd` with `wonder diagnostics -` over `pub let zeta(n: Nat) -> Nat = zeta(n);`, `pub let alpha(n: Nat) -> Nat = alpha(n);`, `pub let F(a: Nat, b: Nat) -> Type = Nat;` and `pub let x: F(zeta(0), alpha(0)) = 0;`, refused as reaching `alpha`, and the same with the arguments swapped, refused as reaching `alpha` again. Renaming a definition moves which one a refusal names, which [`curios-core`'s README](../../../curios-core/README.md#a-name-is-an-identity-not-a-record) rules out ("behaviour never branches on a name's characters, prefix or collation order"), and `partial_offender`'s own contract says "the first global `term` names by spelling", meaning the first written. Fix: in both checkers, the first offender met in a walk of the term in written order, which passes over a subterm whose cached set holds no partial global. Check: the first probe refused as reaching `zeta` and the swapped one as reaching `alpha`; both checkers' totality tests. Size: one commit.
