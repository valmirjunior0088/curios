- **Uncertain: a failed assertion names neither where it was written nor what it asserted.** `Test/assert` (`curios-prelude/std/Test.crs`) fails with `the condition was false`, which `curios test` relays under the test's path, so a test that asserts twice gives its reader no way to tell which failed; `Test/equal` reports the two values and no place. A library function cannot learn where it was called from: an assertion is an ordinary call, `/std` has no macros, and a value carries no place. A parameter the compiler fills with the call's place, as Rust's `#[track_caller]` with `Location::caller()` and Swift's `#file` and `#line` defaults do, and a keyword were each weighed with the user on 2026-11-18 and set aside. The direction kept reads the place off the failing call at run time, with no change to the language: the compiler writes, beside a unit's code, a table from each call site it emits to that call's extent, and where a program fails, the runner maps the frames of the engine's backtrace through it to the innermost frame that stands in the code under test, as a test framework shows the first frame of the code it runs, and prints the place and the source text written there — what was asserted, and where. Nothing in the compiler or the runner names `Test/assert`, or any declaration: a table read for one name would be a rule stated twice, kept in step by hand, so every call site is recorded alike and which frame is shown is decided by where it stands. Go's `runtime.Caller`, reading a program counter against line tables, and Rust's backtraces through debug information answer where a call stood the same way. Not yet known: what the table weighs per unit, and whether it is written always or only for a test program; what Wasmtime's backtraces give a frame, and whether a page's engine gives the same; what "the code under test" is, the tested unit or every unit of the package; and whether a closed condition is better judged at compile time, which the elaborator could decide by reduction and report at its place. Settled by a design restating `curios test`'s report and what a unit carries, which makes this a capability specification. Size unknown.
