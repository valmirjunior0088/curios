# Tools: findings

- **A package cannot state the compiler it needs as a minimum.** `CompilerVersion` (`curios-package/src/compatibility.rs`) reads `compiler` as one bare SemVer version, and `require_current` holds the running compiler to exactly it, a dependency's own line included ([A compiler version belongs to the package or its enumerating umbrella](../../../curios-package/README.md#a-compiler-version-belongs-to-the-package-or-its-enumerating-umbrella)), so a package pinned as a dependency is refused by every compiler but the one it names, and each release of the compiler needs a new revision of it. Fix: `compiler` also takes a comparison, `">= 0.17.0"`, as the `programs` of `xtask/tasks.toml` write a minimum, which accepts that version and every later one by SemVer precedence, a bare version still meaning that one exactly; the decision and the manifest section of `documentation/usage.md` state both spellings. Check: `curios-package`'s compatibility tests, a package stating `>=` an older version accepted and one stating `>=` a newer one refused, naming both versions. One commit.
- **The transcript's kept copy is made by stripping escape codes out of what was painted.** `say` (`curios/src/report.rs`) writes each line to standard error painted and keeps it for a served test page through `plain`, which reads the attribute codes back out of the text `painted` wrote, so the two forms agree only while nothing a line carries holds an escape of its own, which a path or a test's name may. Fix: each piece of a line is built in both forms, as its reader sees it and plain, and `say` writes one to each; the callers that hand the tree painted text (`curios/src/test_runner.rs`, `curios/src/main.rs`) hand it the piece. Check: the kept-transcript tests of `curios/src/report/tests.rs`, and a line carrying an escape sequence kept as it was written. One commit.
