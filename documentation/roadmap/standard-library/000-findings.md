# Standard library: findings

- **A reply its row rules out reads as the failure no errno names.** `/std/internal/unnamed`, `Io/Error/other(0)`, stands for three things: a status a row cannot answer, a read's end or a wait reaching `Status/succeeded` (`curios-std/src/internal/Status.crs`); a file kind no code of `/sys/file_kind` names (`fs/stat`, `curios-std/src/fs.crs`); and a write that accepted nothing of a buffer holding something (`curios-std/src/internal/Handle.crs`), which `curios-abi` itself names the errno-less `Other(0)`. A program told `other(0)` cannot tell a host that broke its row's contract from a failure that carried no errno. Uncertain: whether the first two deserve an `Io/Error` case of their own, a change to the vocabulary every program matches on, so a choice for the user. Fix, once chosen: one case of `Io/Error` with its `Show`, and `unnamed`'s two uses for a reply its row rules out moved to it. Check: `curios-std`'s tests, and `curios-abi`'s, which hold `Io/Error` to naming every failure the table does. Size: one commit.
