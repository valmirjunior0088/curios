# Tools: findings

- **A test that exits before it reports is counted by its exit code.** `curios/src/test_runner.rs` counts `Ok(0)` as passed and `Ok(1)` as failed, and `curios/src/tests/corpus.rs`'s `run_unit` counts `Ok(0)` as passed, while `run_bytes` answers `0` both when `main` returns and when the program calls `proc/exit(0)`, and `1` both for `Test/main`'s own failure and a stray `proc/exit(1)`. Under `curios test`, `test quits_early = Test/perform(() => proc/exit(@Test, 0));` prints no line and is tallied passed, and `Test/perform(() => proc/exit(@Test, 1))` prints its body with no `path: failed` line naming it. A test that asserts nothing passes, and a corpus test that exits early passes `cargo test`; `run_unit`'s comment files a stray exit under its trap arm, where it arrives as `Ok`. Knowing how the guest ended is not enough on its own: `instantiate` (`curios-runtime/src/engine.rs`) tells a return from an exit when it catches the exit, but `Test/main` (`curios-text/std/Test.crs`) reports its own failure with `proc/exit(1)`, so the harness's failure and a stray `proc/exit(1)` are one event. Fix: the verdict leaves the exit code. The synthesized tail answers `Io(Bool)` — `Test/main` returns what `report` answered rather than exiting — `instantiate` hands back the entry's value, which it drops today, beside how the guest ended, and the runner reads the verdict from it; every exit is then a stray one, reported `exited N` whatever `N`. [A test is a declared description, and a proof is a `let`](../../design/tools/a-test-is-a-declared-description-and-a-proof-is-a-let.md) checks the tail against `Io({})` and changes with it. [Go](https://go.dev/doc/go1.16) counts a test that calls `os.Exit(0)` as failed for the same reason. Check: those two report `/quits_early: exited 0` and `/fails_quietly: exited 1`, and a corpus fixture of the same shape fails `cargo test`. Size: medium.
- **`curios format` moves a comment written after an arm's `=>` one arm up, idempotently.** Over `| some(x) => -- the value`, `x`, `| none() => -- nothing`, `0`, the first comment climbs to the `match` line and the second lands on `| some(x) => x`, beside the arm it does not describe. Each output is a fixed point, so `format --check` passes it. An arm records no position of its own, so `member_start` (`curios-text/src/print.rs`) takes its body's for the mark reported before the break above the arm, and that mark already covers a comment written between the pattern and the body, which is then owed on the line above. Fix: an arm records where its pattern begins, as a term records its span, and the mark above it reports that. Check: a `format/tests.rs` fixture holding the probe as a fixed point, with `formatting_converges_from_every_comment_position` passing as it stands. Size: medium.
- **A bound's counterexample spells an atom as its unfolded definition.** Refusing `Holds(0 < Nat/pow(10, k))`, the report reads "it fails at rec x: (a: /std/Nat, b: /std/Nat) -> /std/Nat = (base, exp) => …; x(10, k) = 0", printing `pow`'s whole recursive body where the reader wrote `Nat/pow(10, k)`, while the report's fact lines keep the reader's spellings. Fix: spell a counterexample's atom as its statement does. Check: a fixture asserting `Nat/pow(10, k) = 0`. Size: quick.
- **An implicit a call does not determine is located in its callee, and reported twice.** `let _ = proc/exit(1)!;`, with nothing pinning the result, reports the postponed conversion at the call, then `implicit argument 'A' of 'proc/exit' was not inferred` at `/std/proc.crs`'s declaration, spelled as the absolute path of the checkout that built the prelude; `wonder diagnostics` prints that second report once and `curios run` twice, identically. Fix: locate the second at the call, once. Check: a fixture asserting both spans and one report each. Size: quick.
- **A `--filter` that matches nothing does not say what would.** `curios test t1.crs --filter /t1/sum_is_right` refuses with `no test matches '/t1/sum_is_right'` where the tests are `/sum_is_right` and `/sum_is_wrong`, a loose program's entry owning the empty prefix (`curios/src/test_runner.rs`). Fix: name the nearest paths, or `curios wonder tests <TARGET>`, which lists them. Check: a fixture asserting the refusal names `/sum_is_right`. Size: quick.
- **A report spells a name through an imported module in full.** [A diagnostic spells what its reader can write](../../design/tools/a-diagnostic-spells-what-its-reader-can-write.md) gives a name "the shortest spelling resolution would take back to it there", but `Spellings::spell` (`curios-core/src/names.rs`) offers only a child of the reader's own module, an absolute path, or an import naming the global itself, and `record_module_import` (`curios-text/src/into_core/context.rs`) records a module import's direct bindings alone. Under `use /std/{Nat, Bytes, Str};`, a hole over `Str/Valid/from(Str/Scan/lead(), x[])` reports `/std/Str/Valid/from(/std/Str/Scan/lead(), x[])`, and a bound's suggested proof reads `/std/Nat/le/add(…)` where `Nat/le/add(…)` elaborates. Fix: spell a path through an imported module, which resolution already takes back; `record_module_import`'s comment argues for the narrower rule, and taking it instead is a revision of the decision. Check: both probes print the reader's spelling. Size: medium.
- **A refusal naming a declaration prints its internal path.** About forty `curios-elab` sites build an `Error` from `Global::symbol()` (`rg '\.symbol\(\)' curios-elab/src`), and `error/display.rs` interpolates the string raw rather than through `spelling.symbol(global)`, as every term in a report is: a missing `none` arm reports `missing match case for constructor 'none' of '/sys/Option'`, a root a program may not name; an arm over `Ordering` names `/std/Ordering/Ordering`; a local proposition is `/P`. `curios-text`'s mutual-reference refusal lists `/even` and `/odd`, and `curios-ersd`'s evaluation cycle `/n`. Fix: carry the `Global` and render it through the reader's spelling. Check: the probes report `Option`, `Ordering`, `P`, `even` and `n`. Size: medium.
- **One fault, a name that resolves to nothing, reads five ways, with no near miss.** `unresolved qualifier: List`, `unbound variable: Bool` (a type is no variable), `binding not found: length`, `no module or binding named Nta in /std` and `child module not found: foo`; the first two carry the `use /std/{X};` hint and the last three nothing, not even the members the parent has. A misspelled local gets none either: `coutn` beside a parameter `count` reports `unbound variable: coutn`. Fix: one message family across `curios-text`'s resolution errors and `curios-elab`'s `UnboundVariable`, naming the nearest name in scope or declared sibling by edit distance where one is close; [rustc](https://doc.rust-lang.org/nightly/nightly-rustc/rustc_span/edit_distance/fn.find_best_match_for_name.html) offers one within a third of the name's length, compared without case. Check: a fixture per probe, asserting the wording and a suggestion for each typo. Size: medium.
- **Positivity and totality refusals carry no location, and the totality one misreads its grammar.** `positivity.rs` and `totality.rs` (`curios-elab`) build their errors with no span: `induct Bad: pub Type | mk((Bad) -> Nat) end` reports `'/Bad' is not strictly positive: through 'mk(_0) : (Bad) -> Nat' …` with no caret and a minted `_0`; `let loop(n: Nat) -> Type = loop(n);` used at a type reports `the recursive definition '/loop' is a type position …`, its site slotted into `"{site} is a {erased} position"`. Fix: locate each at the declaration's label, phrase the site as what is reached from the position, and name the payload by its label or ordinal. Check: a fixture per probe asserting its span and wording. Size: medium.
- **A duplicate match arm is reported over the whole match.** `match o | some(x) => x | none() => 0 | none() => 1 end` reports `duplicate or overlapping match arm` under the entire `match`, where the fault is the second `none()`. Fix: locate it at the later arm, which `curios-text`'s matrix compiler holds when it finds the overlap, once an arm records where its pattern begins, as the formatter's entry above has it do. Check: a fixture asserting the span. Size: quick.
- **Name conflicts are reported in the lowering's vocabulary, naming one side.** `use /std/{Nat, print, Nat};` reports `qualifier conflicts with existing scope entry: Nat`, and a `let Nat` beside an imported `Nat` reports `binding conflicts with existing scope entry: Nat` with its caret on the import alone (`curios-text/src/error.rs`, with `PrivateBinding` and `NotAModule` in the same voice). Fix: say which two things claim the name, the other site as a note span. Check: `re_export_tests.rs`' and `use_tests.rs`' assertions reworded, and a fixture asserting both spans. Size: quick.
- **Naming `/sys` is refused without the facade the reference promises.** `pub let x: /sys/Nat = 1;` reports `` `sys` is internal to the standard library; use the corresponding `/std` module ``, where [the reference](../../syntax.md#paths) says the refusal points at `/std/Nat`. Fix: name the facade path when one re-exports the referent, from the lowering's re-export index. Check: a `sys_tests.rs` fixture asserting `/std/Nat`. Size: quick.
- **The CLI keeps two hidden migration shims**, `misplaced_budget` and `misplaced_manifest` (`curios/src/cli.rs`, read in `contract.rs`), which parse `--budget` and `--manifest` written before the command only to refuse them with the spelling that works. Every release since 0.14.1 carries them, [the reference](../../usage.md#flags) states the refusal as the command line's behaviour, and nothing says when the old spelling stops deserving one. Fix: name the release that drops them, and remove them and the reference's sentence there; or keep the refusal as the documented behaviour it already is, and drop this entry. Check: `curios --budget 1 run` reports an ordinary usage error. Size: quick.
- **A sign with no literal behind it is reported as a missing `inf.0`, and a blank as the end of the file.** `let x: Int = - ;` reports `Expected 'inf.0', obtained 'end-of-file'` with the file going on, and `= -y;` reports `Expected 'inf.0', obtained 'y;'`. `take_exact` (`curios-parse/src/primitive.rs`) cuts what it obtained at the first blank and calls an empty cut the end of the file, so any literal expected where a blank stands reads that way; and behind a sign the failure that reaches the reader is the last alternative's, the non-finite literal's first word (`curios-text/src/parse/literals.rs`), in the combinator's wording, where [the reference](../../syntax.md#numeric-literals) has a sign belong to the literal it touches. Fix: `take_exact` names the end of the file only at it, and a blank as a blank; and a sign at the head of a term that touches no literal is refused in the surface's voice, saying what a sign may lead. Check: a `literals_tests.rs` fixture per probe. Size: quick.
- **A file written as a module whose stem is no name is checked as a program.** Over a file of items with no final term, `wonder diagnostics my-file.crs` reports `expected a term, obtained 'end-of-file'` at its last line, where the same text in `myfile.crs` is checked item by item and reports nothing, and `run` says of either that it `is written as a module, with no final term to compile a program from`. `RootSource::loose_module` (`curios-text/src/root_source.rs`) mounts such a file at its stem only where the stem is an identifier, and `Subject::formed` (`curios-wonder/src/diagnostics.rs`) then falls back to the program's grammar without saying why. Fix: the refusal names the cause, that the file is written as a module and its stem is no name a module can take. Check: a `curios/tests/wonder.rs` fixture asserting the wording. Size: quick.
- **`wonder stage core` prints an applied lambda without the parentheses that make it a call.** `((x: Str) => x)("a")` reprints as `(x) => x("a")` at `core` and `core-elab` (`curios-core/src/print.rs`), which reads as a lambda whose body is the call. Fix: parenthesize a lambda in head position, as the surface printer does. Check: a `curios-core/src/print/tests.rs` fixture over an applied lambda. Size: quick.
- **Two reports print a blank through a binder hinted with the blank's spelling.** `required_region_type` (`curios-elab/src/typing.rs`) replaces every metavariable of a region's type with one variable hinted `_`, and `suggest.rs` stands one hinted `?` for every unsolved slot of a candidate, so each is a local that [`Free::nameable`](../../../curios-core/src/names.rs) answers source can write. Nothing reads either as a name today. Fix: a term the printer renders as the blank, in place of a hint that spells it. Check: both reports unchanged with no hint minted. Size: quick.
- **A refused bound that is an inductive proposition as written is reported as reducing to itself.** `insert_auto_argument` (`curios-elab/src/elaborate/apply.rs`) keeps a bound's reduct whenever that is an inductive type, so over a local `induct Even: (Nat) -> Prop`, `let other(n: Nat, m: Nat, p: Even(m)) -> Even(n) = True/proved();` reports "nothing discharged Even(n), which reduces to Even(n)": the clause that tells `Has(spec, "prot")` from the `False` it reduces to repeats the bound where reduction moved nothing. Fix: keep the reduct only where it differs from the bound. Check: a fixture asserting that report carries no "which reduces to". Size: quick.
- **Uncertain: what the prelude's build counts depends on which build ran it.** **Warrants investigation:** what differs between the builds. The prelude's two build scripts file their profiles at one path each (`curios-prelude-archive/.artifacts/profile.tsv`, `curios-prelude/.artifacts/profile.tsv`) whichever cargo invocation runs them, so each file holds the last build's. On one tree, built on `fd4087299`, `cargo xtask clippy` files `budget::consumed` summing 22,136,063 over elaboration and 12,978,988 over certification, in two checkouts of one tree alike, while `cargo xtask test curios` files 22,138,128 and 12,979,992 on two runs and 22,133,235 and 12,980,271 on a third, the other counted samples moving with them (`reduce::classable_fold` is 2,533, 2,568 and 2,553 stuck terms). Every run counts 2,430 and 2,585 declarations. Not known: whether the two invocations unify features differently, or a build reads something an earlier one left. A counted figure is therefore one protocol's, and a profile does not say which build wrote it. Fix: once the cause is known, a profile filed per build, or one that names its build. Check: two builds of one tree by each invocation, folded by `curios profile` and compared. Size: small.
