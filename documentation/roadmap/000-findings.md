# Findings

- **Forty-one test modules hold more than the 25 tests past which a module splits.** `.claude/rules/rust.md` says that past 25 tests a module splits by subject into `foo/<theme>_tests.rs`. At `71a5a82ed`, counting `#[test]` per file, 41 files across 11 crates hold more, from `curios-elab/src/reduce/reduction_tests.rs` (69), `curios-elab/src/convert/solve_tests.rs` (57) and `curios-text/src/parse/top_level_tests.rs` (56) down to `curios-cert/src/kernel/infer/eliminate/tests.rs` (26). Some are already one theme of a split, among them `curios-cert/src/kernel/whnf/equations_tests.rs` (34) and `curios/src/tests/board/eta_tests.rs` (37), so their subjects split again. The cost is a reader's: a module of 69 tests no longer says by its name which claims it holds, and a test added to one lands beside others of another subject. Fix: split each file by subject as the rule states, each new file opening with a `//!` naming its subject, moving tests and changing none. Check: `rg -c '^\s*#\[test\]' --glob '*.rs' --glob '!target/**' --glob '!.curios/**' .` lists no file above 25; `cargo xtask workspace format`, `cargo xtask workspace lint`, `cargo xtask workspace test`. Size: one commit.
- **172 of `Context`'s methods are `pub`, part of `curios-elab`'s API, though no other crate may call most of them.** [Visibility is decided at each hop](../design/visibility-is-decided-at-each-hop.md) has a member reach as far as its type and one meant for fewer readers carry `pub(crate)` or `pub(super)`, since a method has no facade. `Context` is exported at the crate's root, so a `pub` method on it is public in whatever module its `impl` stands; `73f0ed7a4` turned all 277 of its `pub(crate)` methods `pub`, and the 111 whose documentation links a private item went back when the docs build refused them. Counted in the commit that files this entry, the 172 left are the `pub` methods of `curios-elab/src/context.rs` and of `context/{scope,universes,registries,budget,reduction,metavariables,parked}.rs`. The cost: rustc's dead-code analysis sees neither a public method nor what only it reaches — `UniverseMutation::fresh`, which only tests call, stood hidden behind `universes_mut` until that was narrowed. Fix: narrow each that no other crate calls to `pub(crate)`, moving into a module's `test_support` what then only tests reach and deleting what nothing does. Check: `cargo xtask workspace lint`, `cargo xtask docs build`, `cargo xtask workspace test`. Size: one commit.
- **Ten methods only tests read stand in production files, behind `#[cfg(test)]`.** `.claude/rules/rust.md` has production code carry nothing only a test reads, and a test reach scaffolding through a `test_support` module; a method a test calls on a production type is one, in an `impl` block of the type's own subtree, as `curios-elab`'s `universes/mutation/test_support.rs` and `context/retyping/test_support.rs` hold theirs. Counted at `79cd5c916` with the erasure move in hand: `curios-elab/src/universes/solver/constraints.rs`'s `speculation` and `journal_len`, `universes/solver.rs`'s `constraint_count`, `context/metavariables.rs`'s `birth_metavar`, `context/scope.rs`'s and `context/frame/frames.rs`'s `locals`; `curios-cps/src/optimize/clone.rs`'s `functions`, `continuation` and `new`; and `curios-cert/src/kernel.rs`'s `consumed`. The cost is a reader's: a production file reads as holding what no build that ships compiles, and a method gated in place cannot be shared with another crate's suite through a feature, which the erasure move needed for `Retyping::new` and `consumed`. Fix: move each into a `test_support` module of its type's subtree, gated `#[cfg(test)]`, or `#[cfg(any(test, feature = "test-support"))]` where another crate's suite reads it, changing no body. Check: `rg -n -U '^    #\[cfg\(test\)\]\n\s+(pub(\([a-z]+\))? )?fn ' --glob '*.rs' --glob '!**/*tests*.rs' --glob '!**/test_support*' --glob '!target/**' .` lists nothing; `cargo xtask workspace lint`, `cargo xtask workspace test`. Size: one commit.
