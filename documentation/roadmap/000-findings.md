# Findings

- **172 of `Context`'s methods are `pub`, part of `curios-elab`'s API, though no other crate may call most of them.** [Visibility is decided at each hop](../design/visibility-is-decided-at-each-hop.md) has a member reach as far as its type and one meant for fewer readers carry `pub(crate)` or `pub(super)`, since a method has no facade. `Context` is exported at the crate's root, so a `pub` method on it is public in whatever module its `impl` stands; `73f0ed7a4` turned all 277 of its `pub(crate)` methods `pub`, and the 111 whose documentation links a private item went back when the docs build refused them. Counted in the commit that files this entry, the 172 left are the `pub` methods of `curios-elab/src/context.rs` and of `context/{scope,universes,registries,budget,reduction,metavariables,parked}.rs`. The cost: rustc's dead-code analysis sees neither a public method nor what only it reaches — `UniverseMutation::fresh`, which only tests call, stood hidden behind `universes_mut` until that was narrowed. Fix: narrow each that no other crate calls to `pub(crate)`, moving into a module's `test_support` what then only tests reach and deleting what nothing does. Check: `cargo xtask workspace lint`, `cargo xtask docs build`, `cargo xtask workspace test`. Size: one commit.
