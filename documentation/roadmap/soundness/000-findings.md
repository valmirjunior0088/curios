# Soundness: findings

- **A witness expecting a mismatch names no rule.** Twelve witnesses expect a bare `curios_elab::Error::TypeMismatch { .. }` or `curios_cert::Error::Mismatch { .. }`, eleven in `xboard/src/elimination.rs` and one in `xboard/src/conversion.rs`, and `Expected::meets` (`xboard/src/support/expect.rs`) takes any member of the elaborator's batch, and the kernel's error whatever its `Verdict` names. `Witness::expect` states that the rule is named, or a witness broken in some other way would pass, and a mismatch is every conversion's refusal: a witness that gains an unrelated mismatch still holds, the construction its flaw reached never judged. Fix: an expectation names the declaration it is refused in, as `refused!` writes it — the elaborator's by the innermost `curios_elab::Error::InDeclaration` its error is raised under, which `raised` unwraps today, and the kernel's by `Verdict::name`, `None` for the closing term — every mismatch witness names its own, and `xboard`'s README states it beside the named error. Check: `cargo xboard report` holds every ticket, and a test in `xboard/src/support/report/tests.rs` where a witness refused by a mismatch in another declaration than it names regresses. Size: one commit.
