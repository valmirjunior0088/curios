# Soundness: findings

- **A unit compiled while the package `std` stood in for `/std` is reused over the archived `/std`, whose reads it never recorded, so a verdict that stood on the package's `/std` stands on the archived one.** A package named `std` first in a fold takes the archived `/std`'s place (`curios-pipeline`'s `standard::withheld`; `documentation/usage.md`, *One name is reserved*), so a unit compiled after it read a `/std` that is not the compiler's own. Once nothing reaches the package — the unit's dependency `q` drops it — `/std` is the archived root again, while the unit's address (`curios_package::unit_slot`: the compiler, its mounts, its declared prefixes, its kind) is the one it was filed under, so its slot is offered as a baseline; `After::moved` (`curios-pipeline/src/compile.rs`) answers `false` for every fixed unit, and nothing records a read of one. Both checkers then keep `p`'s `pub let d: NonZero(0) = True/qed()`, judged where the package's `/std/Nat/NonZero` held of every number, and `let x: False = d` is admitted over the archived `/std`, where `NonZero(0)` is `Bool/Holds(0 != 0)`; with nothing stored the same build refuses `d`. Every byte of the store is one a walk wrote, so this is a proof of `False` inside [the soundness board](../../design/soundness/the-soundness-board.md)'s claim, and the board has no witness form for it: a history compiles each step over every prelude root, so a step mounted at `/std` collides with the archived root. The sentence that fails is [Cached verdicts](../../design/soundness/cached-verdicts.md)' "The fixed prelude's units are the compiler's own, which the address names, so nothing is recorded of a read of one". Fix, a choice among three: name in the address whether `/std` is the archived root (`unit_slot`, `entry_slot`), which makes the quoted sentence true as written; decline as a baseline, and as a hit, a slot whose record names a unit claiming a prefix a fixed unit of the fold claims; or carry the record's units no unit of the fold matched into `After`, so `moved` answers `true` for a fixed unit whose prefix the record names and the certifier asks again the reads of the package's `/std` it recorded, the elaborator still keeping `d`. `curios-wonder`'s kept session reads the same `After::moved`. Check: `a_unit_compiled_after_the_package_std_is_judged_again_over_the_archived_std` in `curios-verdict`'s `verdicts/tests.rs`, `p` built over a store `q` once reached the package `std` through, answering what a build with nothing stored answers. Size: one commit.
- **The certifier reads a lambda applied on the spot to a `let`-bound local as standing for the local's name, which no graded call names, so a descent through the lambda's binder is refused.** `infer_telescope` (`curios-cert/src/certifier/infer.rs`) hands `Certifier::refine_size` each argument as written, and `Grader::shape_of` (`curios-analysis/src/totality/grade.rs`) reads a variable as its atom, so in `let u = n; ((x) => …)(u)` the binder `x` stands for `u`; but every graded call reads a `let`-bound local by its graded value (`Certifier::graded`, in `record_call`, `handed_to` and `record_handed`), so no call inside names `u`, and what an arm on `x` refines or rules nonzero reaches `u` and never the parameter `n` the call is graded against. So `f(n) = let u = n; ((x: Nat) => match x | 0 => false | k + 1 => f(k) end)(u)`, reached by a type, is refused by the certifier alone ("a type position reaches `/f`, which is not known to terminate"), as is the same with `| _ => g(x - 1)`, while the lambda applied to `n`, and a match on `u` itself, pass both checkers. The compilation fails closed, so it reaches no `False`. Fix: `infer_telescope` hands `refine_size` the argument as a graded call reads it, `certifier.graded(argument)`, so the binder stands for what the `let` stands for and a variable an arm's index inversion solved stays as written, as [Totality of the erased program](../../design/soundness/totality-of-the-erased-program.md) reads a lambda applied on the spot and `curios-cert`'s README reads a `let`. Check: both programs pass both checkers beside `zero_ruled_out_of_an_applied_lambdas_binder_is_ruled_out_of_what_it_stands_for` in `curios`'s `tests/rules/totality_descent.rs`, each with a refusal whose call hands back `x`, and a `curios-cert` test beside its twin in `certifier/calls/tests.rs` with the lambda applied to a `let` over `n`. Size: one commit.
- **The certifier converts a `List` arm's carrier element type with its scrutinee's and never types it where the scrutinee is no variable, so an ill-typed type stands there and a member's call there is no edge.** `check_free_monoid`'s `Carrier::List` arm (`curios-cert/src/certifier/infer.rs`) only asks whether `elem` converts with the scrutinee's element type; a variable scrutinee has `elem` typed by `bind_solutions`, which infers the case value the variable is bound to, while an expression scrutinee records an equation (`Certifier::refine`) and nothing types `elem`. That departs from `curios-cert`'s README, *A type is accepted by typing it*, which `stated`, the match's other annotation, keeps by being typed before it is converted. So `/g`, matching `/id(l)` under `elem = ((x: #NatType) => #NatType)(true)`, is admitted, and so is `rec /T(n) -> Type` whose one call of itself stands in `elem` (`((x: Type) => #NatType)(/T(n))`): the walk never types the call, so it is no edge and the group closes `Total`, against *A group's calls are the ones the certifier types*, while the elaborator's discovery walk does walk `elem`. No `False` is built from it: `elem` is read only by conversion against a typed type, by the cons arm's head binder and by the case value, each of which the scrutinee's type already holds, and a transport through it needs an arm body typed at the ill-typed instance, which the body's binders refuse. Fix: type `elem` (`infer_type`) before converting it, as `stated` is. Check: the two modules, `/g` refused by `Mismatch` in `/g` and `/T` by `NotDescending` in `/T`, as `curios-cert` tests, the second beside `certifier::calls::tests` as `a_call_in_a_carriers_element_type_is_recorded`. Size: one commit.
- **The certifier unfolds a group's member to the value it took where the group was read, so in an arm that solves a variable the member's body names, reduction meets the variable as written and the certifier refuses what the elaborator accepts.** `check_group` (`curios-cert/src/certifier/module.rs`) files each known member's selection, built from the group `infer_within` read by value at its `Rec` node, as the frame's value `Calls::member_value` hands reduction (`step_var`, `certifier/whnf.rs`). An arm in a body that solves a variable the selection names binds it as a `let` (`bind_solutions`, `Certifier::bind_as`), reads the scope's types and `let`s again (`read_again`) and restates the equations in force (`Scope::restate`), and leaves the frame's values as they were, so a reading is handed a term naming a `let`-bound local and reads it as a neutral, against `curios-cert`'s README, *A `let` is bound for typing and read by value* ("a walk behind a door is handed only … what the scope and the definitions hold, all by value"). So in `f(c: Bool)`, with `g(i) = match c | true => 7 | false => i end` and `m` stating `Holds(g(3) == 7)` in its `true` arm on `c`, the certifier refuses `f` (its `g(3)` is `match c | true => 7 | false => 3 end`, stuck) and the elaborator accepts it. The direction is safe: a value read with the variable as written is the general case of the one the arm specializes. Fix: read a member's value as the scope stands where reduction unfolds it — `step_var` reading the selection by value (`Scope::by_value`, as a door reads its terms), or `read_again` binding the innermost frame's values again where they name the local bound, as it binds a `let` again. Check: that program elaborates and certifies, and a `curios-cert` test of the same text through `test_support::Put` expects it admitted. Size: one commit.
- **Uncertain: no hunt has attacked the premises a call read off a path, and a summary read through parts, add.** Both checkers grade a call through a record's field as a call of the part its path reaches, a member handed or named short of a field lambda as a call of each of its parts, and a record handed at a summarized parameter field by field (`part_calls`, `handed_member`; [Totality of the erased program](../../design/soundness/totality-of-the-erased-program.md), *A call is read off a path*); they read a field of a record below the record whatever binds it (*A field is below its record*, `Shape::Smaller`); and a definition publishes a summary for each of its parts, a definition of no group and `/sys/List/map`'s and `/sys/List/fold`'s callbacks among them, composed through a callee's where it hands a parameter on (`group_applications`, `definition_applications`, `handed`, `curios-analysis`; *A call in a callback is graded where its callee applies it*). Each rests on a premise no hunt has put to the board: that the part a path reaches, and the path and part a summary records, are the part and the path the call reaches when it runs; that a field lambda's applications of a definition's parameter are never stated as its leading lambdas'; and that a record's field is a proper part of the record's value. A member handed bare and projected by its callee broke the first once before it landed, and both refusals are held by `curios`'s `tests::rules::totality_record`. Settled by a `/hunt-soundness` round with those premises as its charters, its attacks left as tests and any `False` filed as a ticket. Size unknown.
