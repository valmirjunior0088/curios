# Soundness: findings

- **Uncertain: a model small enough to run locally can be the candidate oracle of a hunt.** [A probe asks the board's question of a program on no ticket](../../../xboard/README.md) puts a candidate to the checkers exactly as a witness and exits 0 where it is admitted, so a hunt needs of its oracle programs, not judgment: every ticket on the board was found by a frontier model under an agent, and nothing shown says the question needs one. Seen by the paper's review of 2026-10-24, as an observation on the discipline, not a measurement. Not known: whether a model small enough for one RTX 4070 Super, run on its own, produces an admitted candidate against a commit known to admit one (a fixing commit's parent, its ticket's witnesses withheld), how long it takes to the first, whether different models reach the same flaw or different ones, and so whether a hunt scales out to many small oracles rather than a few large ones. Settled by: a run per model, sequential on that machine, against that commit under a time cap, each candidate put to `cargo xboard probe`, the time to the first admission and the flaw it shows recorded; an admission within the cap restates this as a finding on the hunt's harness, and none within the cap drops it. Size: unknown.
- **Uncertain: a binder an arm solved to a value holding a proof's constructor is graded below it through that constructor.** `Kernel::assume_arm` (`curios-cert/src/kernel/calls.rs`) enters an arm's index solution for a binder that binds data as the binder's shape, and the size order reads a payload below that shape through every constructor in it, a proposition's among them, though irrelevance makes any proof stand where that constructor does. With a `Prop` `Wit` whose constructor holds a `Box`, `Box : Type` whose constructor holds a `Wit`, declared together, and `Q : (Box) -> Prop` whose constructor `c(n : Box)` targets `box(w(n))`, `f(t : Box, q : Q(t)) -> False` matching `q` as `c(n)` refines `t` to `box(w(n))`; a match of `n` as `box(p)` then types `f(n, q)` by irrelevance, and the call grades below `t` through `w` while handing `f` the same `q`, so it repeats for ever. Seen by `cargo xboard probe -` at `a2ac62b97`: refused by the elaborator, `PartialInErasedPosition` in `/f`, the module it built admitted by the kernel. `ebf65a7c0` keeps a proof binder's solutions out of the size order and reaches nothing here, since `t` binds data. Not known: whether the kernel admits it as a module witness built by hand, the form a ticket of totality takes. Settled by: that witness put to `cargo xboard report`; admitted, it is filed open and this entry goes; refused, this entry drops and the refusal is a test. Size: unknown.
