# Soundness: findings

- **Uncertain: a model small enough to run locally can be the candidate oracle of a hunt.** [A probe asks the board's question of a program on no ticket](../../../xboard/README.md) puts a candidate to the checkers exactly as a witness and exits 0 where it is admitted, so a hunt needs of its oracle programs, not judgment: every ticket on the board was found by a frontier model under an agent, and nothing shown says the question needs one. Seen by the paper's review of 2026-10-24, as an observation on the discipline, not a measurement. Not known: whether a model small enough for one RTX 4070 Super, run on its own, produces an admitted candidate against a commit known to admit one (a fixing commit's parent, its ticket's witnesses withheld), how long it takes to the first, whether different models reach the same flaw or different ones, and so whether a hunt scales out to many small oracles rather than a few large ones. Settled by: a run per model, sequential on that machine, against that commit under a time cap, each candidate put to `cargo xboard probe`, the time to the first admission and the flaw it shows recorded; an admission within the cap restates this as a finding on the hunt's harness, and none within the cap drops it. Size: unknown.
- **The size order reads a proof's constructor inside an arm's solution as structure.** [Totality of the erased program](../../design/soundness/totality-of-the-erased-program.md) rests descent on a size order "well founded on the values the calls are made at", and what an arm learns by conversion is no fact about a proof's shape, since irrelevance makes every proof of a proposition one. `ebf65a7c0` keeps a proof binder's solution out of the size context (`Kernel::assume_arm`, `curios-cert/src/kernel/calls.rs`), but a binder that binds data still enters its solution, and the shared reader (`Grader::shape_read`, `curios-analysis/src/totality/grade.rs`) reads a constructor of a `Prop`-sorted family inside it as a node like any other, so a payload under that constructor grades below the binder. Seen by `cargo xboard probe -` at `a2ac62b97` on a program the elaborator refuses with `PartialInErasedPosition` and whose module the kernel admitted; not known whether a module witness built by hand reaches `False`, which would make this a ticket of totality. Fix: the size order reads what reduction took apart and nothing conversion concluded, stated in the totality decision and made once in `curios-analysis` for both checkers, with the scrutinee's own case still read as the arm spells it, so recursion on an accessibility proof keeps its descent. Check: the kernel refuses a recursion graded below a payload under a proposition's constructor in a solution, and `/std` still certifies. Size: one commit.
