# Soundness: findings

- **An arm's payloads of a scrutinee that is no binder are below nothing, so a recursion through a field and then a case on it is refused.** [Totality of the erased program](../../design/soundness/totality-of-the-erased-program.md) reads into the size order "what reduction took apart": "an arm's case stands for a binder it scrutinizes, its payloads are that case's children". `refined_by_arm` (`curios-analysis/src/totality/grade.rs`) refines an arm "for nothing where the scrutinee is an expression", in both checkers (the elaborator's `Walk::walk_arms`, `curios-analysis/src/totality.rs`, and the certifier's `Certifier::assume_arm`, `curios-cert/src/certifier/calls.rs`), so a payload of a case on `x.next` stands for no value below `x`, though the scrutinee reads strictly below `x` (`Shape::Smaller`, the `Subterm::Proj` arm of `Grader::shape_read`). With `struct S: Type { next: Option(S) }`, `let F(x: S) -> Type = match x.next | none() => {} | some(y) => F(y) end;` is refused by the elaborator ("the recursive definition `F` is a type position / it does not terminate on every input"), probed at `7ac1b7d64`, and so is the same recursion destructuring `x` first (`match x | S { next } => match next | … end end`); the same descent through a helper over the `Option`, `let G(o: Option(S)) -> Type = match o | none() => {} | some(y) => G(y.next) end;`, passes. Fix: an arm whose scrutinee is no binder enters each payload binder of its case as below the scrutinee's shape where that shape reads below a binder, in both drivers through `refined_by_arm`'s one home, and the decision's sentence names an expression's case beside a binder's. Check: `F` passes both checkers beside a control whose call hands back `x`, refused, in `curios`'s `tests/rules/totality_projection.rs`, and a `curios-cert` test of its Core text. Size: one commit.
