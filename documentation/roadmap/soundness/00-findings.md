# Soundness: findings

- **The claim the law grid puts to the kernel alone can set a row's two sides at two universe instances.** `kernel_alone` (`curios/src/tests/laws.rs`) states a row as one call of `claimed` under a signature that restates the left side, so a level the left side leaves open is the statement's own and is generalized, and the same level in the right side is the body's and is minimized. A row whose sides are two calls of one recursive definition at such a level is then put to the kernel as `carry.{v}(…)` against `carry.{0}(…)`, which it refuses as two instances, as it must: `Eq(@(Box(Box(Nat))))(carry(count, Box { held = Box { held = u.held.held } }), carry(count, u))`, over the grid's own `Box` and `carry`, reads as held by the elaborator and refused by the kernel, where the program that states it compiles. No seed reaches it, each standing at a type that fixes its levels or, at a struct of units, decided before a head is read; and a near miss there would be refused for its levels whatever its sides, which is the half that would hide a flaw. Fix: a statement whose signature names neither side — `claimed` returning `{T: Type, claim: Prop, left: T, proof: Eq(@T)(left, left)}` — so that both sides' levels are the body's and settle alike. Check: the row above keeps its side under every context, and so does every seed. Size: small.
- **The zonk evidence does not see an unsolved universe level.** `Zonked::project` (`curios-core/src/module.rs`) refuses a module by two cached flags per term, an unsolved metavariable and an elaboration-only node, and a universe metavariable lives in a `Level`, which neither covers: a module declaring `held : Type(?u)` takes the evidence. Nothing is admitted by it — the kernel's walk refuses the level itself (`universe_residue`, `curios-cert/src/recheck.rs`), erasure discards levels, and the elaborator refuses an unsolved level before a module exists, so only a module built by hand reaches it — but the type promises less than its name says, and a third consumer of the evidence would inherit the gap. Fix: refuse a level holding a universe metavariable in `zonked_refusal`, by a walk with `universe_metas` or by a third cached flag beside the two; the walk reads every term where the flags are read once, so its cost over `/std` is measured before it is taken. Check: the two modules `curios-cert`'s `recheck::universes_tests::a_level_holding_an_unsolved_universe_metavariable_is_refused` builds are refused by `Zonked::project`, in `curios-core`'s own tests. Size: small.
- **Index inversion's cycle guard does not see a key-shaped actual behind an instance.** `unify_index` (`curios-analysis/src/invert.rs`) declines to solve a flex arm binder against a key-shaped actual at the top of a position — `matches!(&*actual, Subterm::Var(_) | Subterm::Proj(_))` — because index refinement may have refined that key *to* the binder, and solving it back ties a reduction cycle. An instance whose head is a variable is such a key, and `Term::head_key` (`curios-core/src/term.rs`) says so by giving it the `HeadTag::Name` a bare variable gets; `judge.force` leaves one standing, `step_instance` (`curios-cert/src/kernel/whnf.rs`) having no value for a local, so the pattern misses it and the binder is solved against it. The guard below catches only an actual whose own free variables are the arm's, which a key refined elsewhere is not. Nothing is admitted by it — a solution substitutes in one pass, and a reduction that loops is the budget's refusal — and no program reaches it, since a local is monomorphic and the elaborator mints an instance only for a polymorphic name, so only a module built by hand gets there. It is the third site of one asymmetry: the kernel's call recorder (`infer_within`, `curios-cert/src/kernel/infer.rs`) and the polarity walk (`Walk::walk`, `curios-analysis/src/positivity.rs`) each read an instance's variable head as the occurrence it is, and `Subterm::has_local_free` (`curios-core/src/term/subterm.rs`) always did. Fix: state the key shape once — a variable head, bare or under an instance — and have the guard read it through that, `Term::head_key` being where the shape is already named. Check: the inversion fixtures, and a pair whose actual is an instance over a refined key, refused rather than solved. Size: quick.
- **Which dictionary a call uses depends on whether its key type was solved when the walk reached the premise.** **Uncertain, and warrants investigation:** whether the order should matter. `elaborate_apply` attempts a `use` slot where it stands (`insert_auto_argument`, `curios-elab/src/elaborate/apply.rs`), so a premise whose concept arguments are already known resolves before a later argument's type can name another dictionary: with `struct Slot(K: Type, use Key(K), V: Type)`, a value `b: Slot(Nat, use other, Str)` and `holds(@K: Type, use Key(K), @V: Type, at: Slot(K, V), key: K)`, `holds(b, 3)` takes `b`'s dictionary, while `holds(@Nat, b, 3)`, a premise over a closed type and a key pinned by an earlier argument each resolve the registered one and refuse `b` as a type mismatch (`a_key_type_fixed_before_the_slot_takes_the_registered_dictionary`). Attempting every such slot after the later arguments is not the fix: a numeral resolves eagerly (`elaborate_num_lit`), so `f(@Bool, 5, true)` over `x: Sized/Carrier(@A)` would meet a type still stuck on the witness. Fix: none taken; a slot would wait only where a later type holds the witness itself rather than a projection of it. Check: a fixture per order, stating the verdict chosen. Size: medium.
- **A recursive group of 65 or more members that all reach each other is never total.** The size-change closure holds at least one call for every ordered pair of such members and is abandoned past `CLOSURE_LIMIT`, 4096 (`curios-analysis/src/totality/matrix.rs`), so `decide` answers partial for 65 members whatever they descend on, where 64 are judged: a ring of 65 functions, each descending on its one argument and calling the next, is refused in a type as not known to terminate, and the same ring of 64 compiles. `a_closure_past_its_limit_claims_nothing` holds both sides at the analysis. It refuses, and admits nothing. Fix: a bound that grows with the group, since n members that all reach each other close to at least n² calls. Check: the ring of 65 is total. Size: medium.
- **The shared level walk's memory is held to no recomputation.** `rewrite_universe_levels_scoped_shared` (`curios-core/src/scope.rs`) asks its hook once per node and depth and hands every later occurrence the answer it remembers; `curios-core/src/term/sharing_tests.rs` holds that it asks once and keeps the graph, and nothing puts its result beside `rewrite_universe_levels_scoped`'s, which [the kernel's grade](../../design/soundness/an-independent-kernel-re-checks-what-the-elaborator-accepts.md) asks of a cache. Fix: a differential over a term holding two levels under shared nodes, small enough to walk per occurrence. Size: quick.
- **Whether a rigid head that depends on the run can reach the elaborator's witness keying is unprobed.** **Uncertain, and warrants investigation.** The closed machine contracts eta because witness keying reads rigid heads off weak-head forms (`curios-core/src/machine.rs`), and nothing asks whether a head it hands back can vary with the run that produced it.
- **Uncertain: a descent through a local definition is graded where the function returns a value and not where it returns a proof.** `let g(n: Nat) -> Holds(0 <= n) = match n < 2 | true => True/qed() | false => let half = n / 2; let inner = g(half); True/qed() end;` is refused at `bf21a9065` as a proof that reaches `/g`, "which is not known to terminate", and is accepted with the call written `g(n / 2)`. `let f(n: Nat) -> Nat = match n < 2 | true => 0 | false => let half = n / 2; f(half) end;` is accepted as it stands, and a type may mention it. The refusal admits nothing. Not known: which reading parts the two, the walk that finds a proof's calls or the grading both checkers share (`curios-analysis/src/totality/grade.rs`), and whether the kernel refuses it too. Check: the two definitions beside each other in `curios-analysis`'s totality tests. Size: unknown until the cause is.
- **Conversion's own walks are not charged, so a comparison that grows is bounded in rounds and not in time or in memory.** A round of the elaborator's worklist spends a step where it dequeues a problem and what its reductions build, and nothing for comparing the two sides structurally, aligning their levels, asking whether a reduct still mentions its group or renaming a problem's opened binders for the history (`Term`'s equality, `level_differences`, `mentions_rec_member` and `history_key`, reached from `Convert::drain`, `curios-elab/src/convert.rs`), each a walk of the term. Where every round's terms are one level larger than the last — the delta step taken on both sides of two copies of one recursive member that differ, which `curios`'s `tests::inference::implicit_tests::a_local_recursive_function_elaborated_again_is_itself` reaches with a rebuilt match taking the type it is checked at — the budget counts the rounds while the time each takes grows with the round: a declaration is refused only where its budget runs out, which at the default takes longer than ten minutes. The kernel's conversion is unpriced the same way, and its history with it: `History::enter` (`curios-cert/src/kernel/convert.rs`) files a key for every goal it enters — the local context, the type and both terms — and spends nothing for it, so a comparison that opens a binder a round keeps a key a round larger than the last. On the program of the next entry, at `aae5446d7`, the kernel refuses by its budget at 200,000 units and at the default exhausts a 6 GB memory cap first, one reading each. The curve is not measured. [A reduction step costs what it builds](../../design/soundness/a-reduction-step-costs-what-it-builds.md) prices what a step allocates and the depth it takes. Fix: charge each of those walks by the nodes it visits, or hold them to the nodes two sides do not share, and charge a history's key as what it builds. Check: both regresses refused within seconds at the default budget, and the budget `/std` consumes read before and after. Size: unknown until the walks are counted over `/std`.
- **The two recurrence keys decide two relations, and the kernel does not answer where the elaborator accepts.** With `let f(n: Nat) -> Nat = match n | 0 => 0 | k + 1 => f(k) + 2 end;` and `let h(n: Nat) -> Nat = match n | 0 => 0 | k + 1 => 2 + h(k) end;`, `let same(n: Nat) -> Eq()(f(n), h(n)) = Eq/refl();` elaborates, and the kernel's comparison of the two calls unfolds a round after a round: the arms compared, their sums put to the intrinsic chain, the two calls it leaves compared in turn. The elaborator's key renames the binders its conversion minted and records no local context, so `f(k) ≟ h(k)` under an arm's fresh `k` is the goal met again and is assumed; the kernel's key records the context, one binder longer each round, so no round meets a goal again ([Conversion recurrence](../../design/soundness/conversion-recurrence.md)). The same two functions written with one text are accepted by both. Nothing is admitted by it: the kernel refuses by its budget or, by the entry above, does not answer; but [Conversion is one relation in both checkers](../../design/soundness/conversion-is-one-relation-in-both-checkers.md) holds a verdict to follow no checker. **Uncertain** as to the cause, which is read off the decision and one stack sample of the kernel (`ground_cases`, `convert_intrinsic` and `History::enter` in a cycle), not stepped. Fix, not chosen between two: a goal is met again only with its context, in both checkers, so the elaborator refuses and the equation is a lemma by induction; or both take a goal up to the binders its own comparison opened, which is an induction principle in the kernel and needs its argument written before it is a rule. Check: the program refused by the elaborator or accepted by both, within seconds at the default budget, and a row of the law audit that holds whichever is chosen. Size: unknown until the choice.
- **The goal an arm is checked at can hold an elimination whose scrutinee computes to another case, and the kernel types its other arm.** With `let g(c: Bool, @ok: Holds(c)) -> Nat = 1;`, `let f(c: Bool, k: Nat) -> Holds((match Bool/not(c) | true => g(Bool/not(c), @True/qed()) | false => 0 end) <= 1) = match c | false => True/proved() | true => match k | 0 => True/qed() | _ + 1 => True/qed() end end;` elaborates, and `run` stops on ``the kernel refused /f: `Holds(… Bool.match Bool/not(true) ~ Nat; …)` is not a valid motive``; it is accepted with the inner match's motive written. `MatchResult::at` (`curios-core/src/term/shape.rs`) puts the case in the scrutinee's place through the goal, the goal's own match is then over `Bool/not(true)`, which names no local, so no equation is recorded for its arms ([Case equations and their key](../../design/soundness/case-equations-and-their-key.md)), and the proof under its `true` arm rested on that arm's guard. A goal matching on `0 < n`, under a match on `n`, is the arithmetic shape. The kernel types no arm of a case split under a scrutinee that already is a value of another case (`never_taken`, `curios-cert/src/kernel/infer/eliminate.rs`), and computes no scrutinee to learn that it is one: typing must not evaluate a term that runs, and evaluating only within a type would make a typing follow where it was made, which the typing memo does not key (`kernel_memo_parity`). Separately, `at` replaces an expression scrutinee where the goal spells it as the match does, and an occurrence behind a solved metavariable not yet substituted is another term to it, so which occurrences are specialized follows the order two metavariables were solved in; substituting first is exact, and leaves more scrutinees to compute. Fix, not chosen between two: compute a scrutinee that names no local where the elimination stands within a type, the typing memo keyed by that; or have the result at a case take the arm of each elimination its substitution decides, in the shared layer. Check: the program accepted by both checkers, and `/std` certifying with `at` reading substituted terms. Size: days either way.
