# An elimination in a goal is typed alike by both checkers

**Not refined yet.** This specification reserves two eliminations the elaborator accepts and the kernel refuses, each accepted by both once the inner match's motive is written. It is not an implementation plan.

It is held to [Case equations and their key](../../design/soundness/case-equations-and-their-key.md): within an arm the scrutinee is definitionally the case's value, and both checkers record that equation by one rule, so what one accepts under an arm the other does. Which rule the second elimination falls short of waits on its cause.

## What is missing

**The goal an arm is checked at can hold an elimination whose scrutinee computes to another case, and the kernel types its other arm.** With `let g(c: Bool, @ok: Holds(c)) -> Nat = 1;`, `let f(c: Bool, k: Nat) -> Holds((match Bool/not(c) | true => g(Bool/not(c), @True/qed()) | false => 0 end) <= 1) = match c | false => True/proved() | true => match k | 0 => True/qed() | _ + 1 => True/qed() end end;` elaborates, and `run` stops on ``the kernel refused /f: `Holds(… Bool.match Bool/not(true) ~ Nat; …)` is not a valid motive``; it is accepted with the inner match's motive written. `MatchResult::at` (`curios-core/src/term/shape.rs`) puts the case in the scrutinee's place through the goal, the goal's own match is then over `Bool/not(true)`, which names no local, so no equation is recorded for its arms ([Case equations and their key](../../design/soundness/case-equations-and-their-key.md)), and the proof under its `true` arm rested on that arm's guard. A goal matching on `0 < n`, under a match on `n`, is the arithmetic shape. The kernel types no arm of a case split under a scrutinee that already is a value of another case (`never_taken`, `curios-cert/src/kernel/infer/eliminate.rs`), and computes no scrutinee to learn that it is one: typing must not evaluate a term that runs, and evaluating only within a type would make a typing follow where it was made, which the typing memo does not key (`kernel_memo_parity`). Separately, `at` replaces an expression scrutinee where the goal spells it as the match does, and an occurrence behind a solved metavariable not yet substituted is another term to it, so which occurrences are specialized follows the order two metavariables were solved in; substituting first is exact, and leaves more scrutinees to compute.

**Uncertain: a motive whose body is a match with no motive of its own is accepted by the elaborator and refused by the kernel.** Over `induct In(@T: Type): (T, List(T)) -> Prop` with `here(@x: T, @l: List(T)): (x, [x, ..l])` and `there(@x: T, @y: T, @l: List(T), rest: In()(x, l)): (x, [y, ..l])`, the inversion `match i: (y, m, _) => match m | [] => True | [k, ..r] => (head: (Eq()(y, k)) -> P, tail: (In()(y, r)) -> P) -> P end | here() => (head, tail) => head(Eq/refl()) | there(rest) => (head, tail) => tail(rest) end(head, tail)`, at `i: In()(x, [h, ..l])` and `P: Prop`, elaborates, and `run` and `wonder diagnostics` stop on "the kernel refused /in_uncons: cannot eliminate the proposition `/In` into a relevant result", with no position. With the inner match's motive written, `match m: (_) => Prop`, both checkers accept it. Not known: whether the elaborator applies the guard on eliminating a proposition before the inner match's sort is settled, or settles it at `Prop` and hands the kernel a term that says `Type`. It is no finding of a former's sort: a function type is sized from its parts' sorts as typing read them, where the kernel sizes it, and the refusal stands.

## Refinement

- **A scrutinee that computes to another case.** Not chosen between two: compute a scrutinee that names no local where the elimination stands within a type, the typing memo keyed by that; or have the result at a case take the arm of each elimination its substitution decides, in the shared layer. Check: the program accepted by both checkers, and `/std` certifying with `at` reading substituted terms. Either takes days.
- **An inner match with no motive.** Once its cause is known, the elaborator refuses where the motive is written, or hands over the sort it concluded. Check: the declaration as a fixture in both spellings.
- **Whether the two are one cause.** Each is accepted by both checkers once the inner match's motive is written, and whether one change settles both is not known.
