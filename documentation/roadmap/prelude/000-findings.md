- **A command `Cli/try_main` checks as the program runs cannot be read by name.** `try_main` (`curios-prelude-build/std/Cli.crs`) checks a command built as the program runs and hands `run` its `Parsed(command)`, but `Cli/get` decides its name and its type by reduction (`Has`, `Lookup`), which stand stuck over such a command: `Cli/get(p, "fast")` over flags named from `Proc/args()` is refused, `Cli/Lookup(List/map(…), "fast")` against `Bool` (probed at `77ed86f49`), so such a program parses its line and can read nothing of it.
