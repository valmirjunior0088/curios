- **A command `Cli/try_main` checks as the program runs cannot be read by name.** `try_main` (`curios-prelude-build/std/Cli.crs`) checks a command built as the program runs and hands `run` its `Parsed(command)`, but `Cli/get` decides its name and its type by reduction (`Has`, `Lookup`), which stand stuck over such a command: `Cli/get(p, "fast")` over flags named from `Proc/args()` is refused, `Cli/Lookup(List/map(…), "fast")` against `Bool` (probed at `77ed86f49`), so such a program parses its line and can read nothing of it. Fix: readers that make `get`'s checks as the program runs and answer an `Option`, sharing its decisions rather than restating them — `Has`'s `List/any` decided by `Bool/holds`, its proof handed to the walk `get` reads through, and the kind tested at the slot that walk finds, each `Slot` keeping the `Kind` its type is `Carrier` of: `Cli/read_flag` and `Cli/read_count`, and `Cli/read(p, name, v)` for an option or a positional, reading what the line gave as the `Value` its caller hands reads it. So `try_main` is the door for a command built as the program runs as `main` is for one written in it; clap's `try_get_one::<T>` asks the same of its caller, its type downcast where here the reader is handed. Check: the probe above written with `Cli/read_flag`, run with `--fast` and without; `Cli`'s tests passing. Size: one commit.
