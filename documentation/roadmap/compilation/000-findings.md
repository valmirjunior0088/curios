# Compilation: findings

- **Uncertain: what a mutable slot costs a row of a program's own.** A slot some rebuild writes is declared mutable, which Binaryen no longer reads as the constant its construction stored and V8's collector charges a barrier on. Measured for `/std/Map`'s `Node` alone, where it costs nothing measurable; a loop started on a constant or a literal now rebuilds rows of a program's own, which no measurement covers. Not known: whether any such row pays. Settled by: the programs of `a_loop_started_on_a_constant_rebuilds_the_forks_it_takes_apart` and `a_loop_started_on_a_literal_rebuilds_the_links_it_takes_apart` (`curios/src/tests/codegen/rebuild.rs`) at an input that runs a second, timed with the row's rebuilds made and with them suppressed in a scratch copy, seven interleaved rounds, median and span, natively and under V8. Size unknown until then.
- **Uncertain: two reads of one slot on arms of a loop that exclude each other are both shared.** `sources` (`curios-cps/src/sharing.rs`) shares two reads of one slot where either can run after the other, a loop's header between them included: a loop that hands its parameter on as it took it reads on a later round the object an earlier round read and stored. Where neither read is followed, while the value stays bound, by a consumption of the value it reads, no object outlives the round that read it, and the rule shares what nothing else holds. Not known: whether any program loses a rebuild to it; a zipper over a tree does not, its descent building a `Path` where a `Tree` dies and its climb the reverse. Settled by: a program holding a value once whose construction beside a dying value of its row is declined for this rule alone. Size unknown until then.
