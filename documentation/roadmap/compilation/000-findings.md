# Compilation: findings

- **Uncertain: a call's frame weight counts every value its callee's body binds, though the emitter folds them onto the locals their live ranges allow, so a recursion of many arms runs its fifth level on the heap.** [A recursion is as deep as the heap allows](../../design/compilation/a-recursion-is-as-deep-as-the-heap-allows.md) weighs a call "a fixed overhead plus one for each value its callee's body binds", a weight that "stands in for its bytes" in code Binaryen has not optimized, while [Locals are allocated by liveness](../../../curios-emit/README.md#locals-are-allocated-by-liveness) folds a function's values onto "the fewest its values' live ranges allow", so a body whose arms bind values no other arm holds weighs their sum and holds about their largest. Counted at `8ed961f9c`: a generic sixteen-way trie insert, each of its arms rebuilding a seventeen-slot fork, weighs 1,024, the cap a quarter of `FRAME_BUDGET` sets (`curios-cps/src/frames.rs`), against 108 for `/std/Map/internal/Node/insert`, so four of its levels run natively and the fifth of every insert runs its heap twin. Not yet known: how far the weight and the folded frame part for the recursions `/std` holds, which a count of each recursive function's weight against its emitted locals settles, and whether the weight can be read after the folding it stands in for, `bound_frames` running in the continuation IR before the emitter folds. Size: unknown.
- **Uncertain: an inlined or copied callee is weighed by its nodes, a `Nat` operation one of them, though its emitted form carries a fallback many times its size.** `MULTI_SITE_INLINE_LIMIT` (`curios-cps/src/optimize.rs`) counts a callee's live nodes, and each `Nat` operation is one node, emitted as an `i31` fast path beside a call into the big-number helpers. Counted at `8ed961f9c` on a prototype: a generic sixteen-way trie insert whose arms each call two small helpers compiles to an `ins` of 72,839 lines at `wasm-optm`, each arm holding its own copy of the helpers' digit reads with their fallbacks, and its program spends 14.5 s in `emit` against 1.1 s for the same program over `/std/Map`; with the arms' cold path moved into one helper, `ins` is still 61,597 lines and the `emit` 7.1 s, that helper copied into each arm. Not yet known: whether any program of `/std` or the corpus pays for it, the one seen being a fork of sixteen fields, which [`Map` is a trie forking sixteen ways, and its shape is its API](../../../curios-prelude/README.md#map-is-a-trie-forking-sixteen-ways-and-its-shape-is-its-api) rejects, and which pass makes each copy; settled by counting, over `/std`'s test program and the corpus, the emitted bytes each inlined or copied callee adds against the node weight that admitted it. Size: unknown.
- **Uncertain: the rejection of a constructor context's destination gives a rope's reason, and it also holds out a row.** [A recursion closed by a monoid is a loop](../../../curios-anf/README.md#a-recursion-closed-by-a-monoid-is-a-loop) rejects "a destination with a hole, OCaml's tail modulo constructor and Koka's constructor contexts" because "a rope node states its length where it is built, and that length is the part not yet built"; a row states no length, and under [the rebuild in place](../../../curios-cps/README.md#a-construction-beside-a-dying-value-of-its-row-is-rebuilt-in-place) its hole is the slot a descent writes. A descent that rebuilds one slot a level, as a trie's insert does, keeps a frame, a guard and a return a level where a destination would make it a loop that writes once. Not yet known: whether a program pays enough for those frames to want the loop, `/std/Map`'s descent being about five levels deep over 65,537 keys ([`Map` is a trie forking sixteen ways, and its shape is its API](../../../curios-prelude/README.md#map-is-a-trie-forking-sixteen-ways-and-its-shape-is-its-api)), and whether rows are held out for a reason the paragraph does not state; settled by timing such a descent as written and as a hand-written loop in a scratch copy, then restating the paragraph's reason or reopening the destination for rows. Size: unknown.
- **A dead call whose callee applies a method of a dictionary its caller was handed stays at run time.** `droppable_functions` (`curios-anf/src/summary.rs`) makes a function droppable given the values it applies, so `/std/Map/internal/Node/first_in`, which applies its `Key`'s `hash`, is droppable only where a call hands it a dictionary droppable on its own; `insert` and `remove` are handed theirs, so a `let a = first_in(l)` that only their proofs read walked to the leftmost leaf, and hashed its key, at every level of the descent. The node spells `first_in(l)` only where proofs read it. A program links its dictionaries, so which one a call is handed is known by the time it is placed, and a method a certified unit declares has the totality its record states.
- **Constant data handed to a parameter a reuse version assumes reaches the base version, whose result is one fact for all its calls, so one call that hands the base version a shared value makes shared what every call handing it a constant answers.** `route` (`curios-cps/src/sharing.rs`) sends a call to the base version where it hands an assumed parameter a constant, a rebuild there writing into what it is handed, and `Key::Returned` is one fact per version; over a root that is an `empty()` node, a walk filling a map from `Map/empty()` hands its first insert a constant, so a program inserting elsewhere into a map it reads again left every map it built copied at every level (`an_insert_into_a_map_read_again_leaves_the_maps_held_once_their_rebuilds`). `/std/Map/insert` answers an empty root itself; `Map/remove` of an empty map, and any other function constant data enters ahead of what it rebuilds, still meet it. A reuse version handed a constant where a test of its tag guards every rebuild of it, as the module's **Constants by tag** already rules within one version, would need no detour.
- **An element a search passes over is judged shared where the search stops on it and hands it out.** `Shape::element_kept_after` (`curios-cps/src/sharing.rs`) counts a consumption of the list after a read of its element on any path, so a loop that reads an element, goes on with its list where the element is empty and answers the element where it is not, as `/std/Map/internal/Node/lone` collapses a branch left one twig, answers an element judged shared, and every map `remove` touched lost its rebuilds. The node searches for the index and reads once there (`filled_at`). Counting only the consumptions where the element is still named is unsound, since an element dead there may already have been rebuilt into on the way, as `an_element_an_update_writes_over_is_held_by_nothing_else` holds; the rule wants every construction that may reuse the element, and every consumption of a field read off it, ruled out between the read and the consumption.
