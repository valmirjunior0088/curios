# Compilation: findings

- **A free-variable set already filled is read through a walk.** `Term::get_or_init_free_vars` and `Term::mentions_free` (`curios-core/src/term.rs`) call `warm_frees` at every read, and `warm_frees` starts a `Term::walk` — a heap-allocated frame stack and a clone of the node — before its first hook finds the node filled, where `Term::scalars` reads its cache first and walks only where it is empty. Over `/std`'s elaboration at `0fc2fc1bd`, counted in a scratch copy, returning from `warm_frees` where the set is filled retires at least 1.18 billion fewer instructions of 211.6 billion (0.56%), a profile span over each fill added in the same build. Fix: read the cache first, as `scalars` does. Check: `/std`'s image unchanged at one path; its elaboration instructions counted before and after. Size: one commit.

- **A settlement's window is filed on a frame the settlement has left.** `Frames::keep_settled_window` (`curios-elab/src/context/frames.rs`) files a settlement's window on the deepest frame the settlement read (`Frames::end_reads`), and a settlement that opens binders reads frames it has left by the time the window is kept: the `Prefix` then names a depth no frame holds, `still_stand` never holds it again, and the next settlement under the same refinements starts from nothing. What a settlement read in a frame it left rests on nothing that still stands: a frame that registers a refinement cleared what read it at its exit, and anything else that read it names its locals, which nothing asks again. Over `/std`'s elaboration at `0fc2fc1bd`, counted in a scratch copy, 2 of the 7,335 windows kept; what settling those again costs is not measured. Fix: file the window on the shallower of the deepest frame read and the innermost frame. Check: `std_memo_census`; `/std`'s image unchanged at one path and its elaboration units no higher. Size: one commit.
