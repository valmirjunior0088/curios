# Compilation: findings

- **The window split reads the whole module again for each region it splits.** `split_windows` (`curios-cps/src/optimize/fields.rs`) calls `split_widest_window` until it declines, and each call reads `window_uses` off every live node and `resume_targets` off every slot of the arena, grows a region from every continuation parameter, and rewrites the region it admits with a walk of the live nodes for the edges into its continuations and a walk for each length it aliases (`Module::replace_atom`); so a call costs the regions it splits times the module, where [A pass applies the independent plans its snapshot admits](../../../curios-cps/README.md#a-pass-applies-the-independent-plans-its-snapshot-admits) rejects rebuilding the analyses after each candidate. Counted at `b610143c7` in a profiling scratch copy with temporary samples, over `curios test` in a copy of `curios-prelude/std` holding no store with a `--filter` for the tests of each of `Json`, `Html`, `http`, `Str`, `Char`, `Fmt`, `time` and `Cli`: the first of its two calls splits 261 regions and reads the module 262 times, growing a region from each of between 1,547 and 1,821 continuation parameters at each read. The fix: plan every admissible region off one read, widest first and ties by seed order as today, and apply the prefix of them that share no member and no continuation with a region applied before them, reading again at the first that does, so that each split is the one the sequential loop makes, which the check holds; a split leaves another region's members, uses and continuations as they stood, its guards being bindings and its new values its own. The rewrite's walks are shared the same way, one index of the edges into the batch's continuations and one substitution a region. Check: the corpus's optimized CPS and Wasm and `/std`'s test program unchanged byte for byte, and the reads counted. One commit.
