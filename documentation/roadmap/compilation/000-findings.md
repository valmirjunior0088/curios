# Compilation: findings

- **A settlement's window is filed on a frame the settlement has left.** `Frames::keep_settled_window` (`curios-elab/src/context/frames.rs`) files a settlement's window on the deepest frame the settlement read (`Frames::end_reads`), and a settlement that opens binders reads frames it has left by the time the window is kept: the `Prefix` then names a depth no frame holds, `still_stand` never holds it again, and the next settlement under the same refinements starts from nothing. What a settlement read in a frame it left rests on nothing that still stands: a frame that registers a refinement cleared what read it at its exit, and anything else that read it names its locals, which nothing asks again. Over `/std`'s elaboration at `0fc2fc1bd`, counted in a scratch copy, 2 of the 7,335 windows kept; what settling those again costs is not measured. Fix: file the window on the shallower of the deepest frame read and the innermost frame. Check: `std_memo_census`; `/std`'s image unchanged at one path and its elaboration units no higher.
