# What a compiled program still pays at run time

**Partly refined.** This specification reserves costs a compiled program pays that its source does not ask for, each taken alone and given a specification of its own when it is refined, as [a chain of `Nat` or `Int` steps](203-a-chain-of-nat-or-int-steps-runs-in-a-word.md) is. A float crossing a function boundary has landed in [`curios-cont`](../../../curios-cont/README.md#representation-is-decided-wherever-every-party-is-visible), held in a register wherever every party to it is visible or its type states it; reconstruction recovery has landed within the envelope in [curios-ersd](../../../curios-ersd/README.md#reconstruction-recovers-the-existing-value), and a recursion closed by a monoid is a loop there ([its decision](../../../curios-ersd/README.md#a-recursion-closed-by-a-monoid-is-a-loop)); the other costs and conservative reconstruction cases remain open.

## What is missing

**A function with several return contexts stays a function.** `curios-cont`'s `contify_calls` turns a function into a continuation where every call returns to one context. A function with two external return contexts stays a function, and nothing downstream contifies it: `curios-emit`'s machine lowering performs no contification.

**Reconstruction whose source fields remain opaque can still take a frame a level.** The erased optimizer forwards exact product and constructor reconstruction and retained unit fields established by immutable return-and-field flow. An unknown callback's answer, a mutable read or a computed recursive member supplies no such field facts, so `match found(t) | some(hit) => Option/some((at = hit.at, seen = hit.seen, low = True/proved())) | none() => Option/none() end` can still rebuild a product around that opaque answer. Extending the envelope needs a consumer and a sound source of the missing facts; an anonymous schema states width, never that a slot holds unit, and a callable proof placeholder is a function. The direct recursive anonymous-record walk and its nested `Option` form are covered by `curios`'s `tests::codegen::reconstruction`, which checks erased tail position, Cont backedges or tail calls, raw Wasm and raw/optimized execution.

**A closure a combinator is passed stays a closure.** `Handle/wait` states that readiness is advisory, so what waits asks again where the host would still block, and six readings of `/std` write that step as their own `blocked()` arm (`curios-std/src/internal/Handle.crs`'s write, flush and finish loops, `tcp/Listener.crs`, `tcp/Socket.crs`, `Process/Child.crs`); a reading that forgot it raised `would_block` as `other(0)`, as `Child/wait` did. One combinator, `Handle/retried(h, interest, attempt, status)`, states it once and costs two things the print path relies on: the description a constant `print` copies weighs past the closed evaluator's cap (`DESCRIPTION_COPY_NODE_LIMIT`, `curios-ersd/src/optimize/evaluate/budget.rs`, 213 nodes against 160, held by `curios`'s `tests::fmt::a_constant_prints_descriptions_are_copied_within_the_evaluators_cap`), so no constant `print` folds; and the projection of each reply's status stays an indirect call (`tests::codegen::structural::closure_tests::a_returned_closure_every_caller_applies_is_absorbed`, `loop_tests::trees_hot_arithmetic_has_no_indirect_calls`). Written as a local loop that captures the attempt and the projection, the copy stays under the cap and a constant `print` still does not fold (`tests::fmt::print_constant_args_collapses_at_ersd`, `tests::fmt::constant_args_leave_no_formatter_in_cont`), for a reason the closed evaluator holds. So the six readings stay written until a combinator's closures cost what a loop written in place costs.

## Refinement

- **Contification across several contexts.** Common-dominator placement for a function returned to from several contexts, which analysis owns it — the continuation IR or the machine CFG — and which programs it moves, measured.
- **Reconstruction past an opaque source.** Refine only for a consumer the current immutable analysis declines. Result or callback facts must preserve structural layout, effects, traps and recursive-member forcing; a precision limit may decline an optimization but never establish equality. Check beside the existing reconstruction controls, including ordinary numeric fields, changed layouts, opaque callbacks and callable proof slots.
- **A closure a combinator is passed.** Its consumer is `Handle/retried`. Which of two answers it: a specialization of a function at a call that passes it known closures, so the combinator's loop runs over direct calls and its description is the loop's own; or a weight for a description that counts a combinator's body once where several descriptions share it. Check: the five tests above with `Handle/retried` in `/std`'s six readings, and `curios-std`'s tcp, fs, Tty and Tui units.
