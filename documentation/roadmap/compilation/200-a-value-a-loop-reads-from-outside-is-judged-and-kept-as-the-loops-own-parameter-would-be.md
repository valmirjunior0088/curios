# A value a loop reads from outside is judged and kept as the loop's own parameter would be

Two spellings of one loop part ways in the back end: a part a round reads out of a value bound outside the loop is shared outright, where the same part read out of a parameter every back edge hands on is judged by what the round does with it, at the back edge. Substituting such a parameter by its value waits on that, since it turns the second spelling into the first. The next step is stage 1, a ready fix.

## What is wrong today

- **A part a loop reads out of a value bound outside it is shared on every round, whatever the round does with it.** `read_again` (`curios-cps/src/sharing.rs`) makes a field or an element read a source of sharing where it may name what another read names, "or with itself on a later round of a loop that binds `of` once": wherever a run can come back to the read without binding the value again (`returns_without_rebinding`), though the round may only read the part and hand it on where the loop exits. The same list a loop takes as a parameter every back edge passes on is bound again each round, so the clause does not fire, and the part is judged by ownership at the back edge instead (`part_kept_after`): the verdict moves with the spelling. Shown at `5930c771a` with stage 2's substitution prototyped: `/std/Map/internal/Node/remove`'s `lone` loop reads its element out of the updated twigs bound before it, `remove` returns that element as shared, and so are the map a `drain` loop hands back, the node, its twigs and their update: `map_remove_rebuilds_its_node_at_every_level_in_a_loop_using_its_map_once` and `a_maps_descent_writes_each_levels_twigs_in_place` (`curios/src/tests/codegen/rebuild/map.rs`) fail, and the other 25 rebuild tests pass. The clause's two other readers, a rebuild of the outside value itself inside the loop and an overwrite of it (`Facts::rebuilds`, `Facts::writes`), refuse a write a loop body makes on every round into what it does not bind, as Futhark's uniqueness types let a function consume no free variable, so what a loop updates in place enters as its parameter ([Futhark's uniqueness types](https://futhark-lang.org/blog/2022-06-13-uniqueness-types.html)), and they stay.
- **A loop parameter every transfer hands itself or one value from outside stays a parameter, since the invariant fixpoint takes only a function.** [A known function a call hands is followed into it](../../../curios-cps/README.md#a-known-function-a-call-hands-is-followed-into-it) substitutes a function or a literal every entry of a loop hands a parameter its back edges pass on, and `known_values` (`curios-cps/src/analysis.rs`) takes nothing else from the fixpoint (`invariant_fixpoint`), `resolve_atom` reading an argument that is a value from outside the fixpoint's domain as a conflict, "an unobservable runtime value". So a recursion that hands a value on unchanged keeps it as a parameter of the loop contification makes of it: at `5930c771a`, `programs/parse_digits.crs` optimizes to `/loop(k, digits, acc)`, each back edge handing its own `digits`. Counted at `5930c771a` with stage 2 prototyped, a census beside the substitution: 3 to 50 parameters a program of `programs/` taken as their value, 643 in `toml_round_trip`, and the corpus's binaries (`wonder --stage wasm`, `wasm-tools parse`) 0.85% smaller, 5,729,990 bytes to 5,681,396 over the programs but `toml_round_trip`, from 0.26% (`sort_scattered`) to 2.91% (`parse_bindless`). LLVM folds a phi whose operands are itself and one value into that value (`simplifyPHINode`), MLIR's region simplification drops a block argument every predecessor hands the same value (`dropRedundantArguments`), Braun et al. remove such a φ as trivial (*Simple and Efficient Construction of Static Single Assignment Form*, CC 2013), and GHC's static argument transformation takes such an argument out of a recursion at the source.

## Goal

A read a run can come back to while what it reads names one object is judged by what the round does with the part, whatever binds that object; and a loop parameter every transfer hands itself or one value in scope where its continuation is bound is that value, with no verdict of the sharing analysis lost.

## Settled

- A value bound outside a loop takes no virtual parameter: it has no holder apart from itself, so a part read out of it is judged by its own round, and the value's own later uses as they are today. A loop parameter keeps the test its back edge makes, which is the same test.
- The substitution, as the user settled it on 2026-11-19: the fixpoint carries a value from outside, `resolve_atom` reading it as known rather than a conflict, so a parameter every transfer hands itself, another invariant parameter or one outside value is found, and `known_values` takes such a value as it takes a function, only where it is in scope where the continuation is bound; that scope is read off the walk `Module::scope_walk` makes (`curios-cps/src/verify.rs`), which holds the values beside the functions at each `LetCont` and keeps only the functions, and hands its maps as a struct with named fields where it hands a tuple.

## Stages

**1. A read of a value bound outside a loop is judged by what its round does with the part.** The clause of `read_again` that makes such a read a source becomes the test the back edge makes of a parameter's part: the part is kept where it, or a field read off it, is consumed, or a construction a rebuild may become runs, on a path from the read back to it. That is the conflict One-Shot Bufferize finds in a repetitive region, where an op may run again after a write that follows it ([`2e21003`](https://lists.llvm.org/pipermail/mlir-commits/2022-October/009164.html)), and the write into a free variable Futhark keeps out of a loop body, while handing the part on where the loop exits stays free. A part handed round the loop under a borrowed name is held by the borrow rule (`Shape::named_with`). Check: twin fixtures, one loop reading a part of a list or a row bound outside it and one taking it as a parameter its back edges hand on, one verdict each — a part only read and handed on where the loop exits written in place, a part a round writes into refused, a part handed round the loop through a borrowed join refused; `rebuild::tests::a_read_a_loop_comes_back_to_names_one_object_on_every_round` passing; mutation-checked by restoring the clause.

**2. The substitution.** As settled above, and the decision restated to values. Check: tests of a value substituted, of one handed through another loop's invariant parameter, of two values kept and of one out of scope kept, each mutation-checked; `remove`'s rebuild tests and the ladder's passing; the corpus's binaries smaller, counted at the fix's commit by the protocol above; every program's answers unchanged.
