# Architecture: findings

Small fixes and possible bugs, worked as one pass. Each entry names where, what is wrong, the fix, its check and its size.

- **The kernel's conversion infers a scrutinee's type.** Comparing a stuck match whose result is a family against one whose result is an ambient goal, `family_at_head` (`curios-cert/src/kernel/convert.rs`) calls the full `infer` on the scrutinee to read its indices, against `kernel/sort.rs`'s rule that conversion only looks a type up. A stuck scrutinee is a neutral spine, and `synth_neutral` is the lookup for one. Fix: read the scrutinee's type through `synth_neutral`. Check: the kernel's conversion tests, and `cargo x clippy`'s certification of `/std`. Size: quick.
- **`could_reduce_to` is written twice, identically** (`curios-elab/src/reduce.rs`, `curios-cert/src/kernel/scope.rs`). Fix: one copy in `curios-analysis`, which both checkers call. Check: both crates' tests. Size: quick.
- **The Ersd and Cont printers hand-roll their frames** (`curios-ersd/src/print.rs`, 1 069 lines; `curios-cont/src/cps/print.rs`, 812), each walking an explicit job stack, where [depth is bought with stack](../../design/architecture/depth-is-bought-with-stack-not-with-hand-rolled-frames.md) and neither is among the decision's four exceptions. Fix: recurse under `recurse`, printing in the same order. Check: each crate's `a_deep_module_prints_without_native_stack`, renamed for what it then shows, prints its 50 000-deep module on the default test-thread stack, and every printed rung of the corpus is unchanged. Size: medium.
- **`curios-cert` declares `curios-algebra` and never names it** (`curios-cert/Cargo.toml`); only its crate documentation mentions the algebra, as part of the layer it shares. Fix: drop the dependency, and let the trusted base's enumeration in `curios-cert`'s README follow `cargo tree`. Check: `cargo tree -p curios-cert --edges normal`. Size: quick.
- **The prelude build takes a stack segment twice.** `curios-prelude-archive/build.rs` wraps `elaborate_and_zonk_unit` in `grown`, which the callee already takes (`curios-elab/src/elaborate/module.rs`). Fix: drop the outer one. Check: the prelude builds. Size: quick.
- **`Proxy::from_archivable` is fallible and never fails** (`curios-archive/src/proxy.rs`): its four implementors — interned symbols and qualifiers, `curios-num`'s integers, `curios-text`'s ordered map — each return `Ok`, and `Via`'s deserialization wraps an error path nothing reaches. Fix: make it infallible, or keep it with the first fallible proxy's reason. Check: the archive round-trip tests. Size: quick.
- **`curios-binaryen/build.rs` narrates history in two doc comments**: the replaced `BUILD_SCHEMA` constant, and the cache that once sat under `target/`. Held: `build_schema` hashes the file, so any edit discards the Binaryen cache. Fix: restate both in the present tense the next time the file changes for a reason that pays the rebuild. Check: `/full-gate`'s Binaryen extras. Size: quick.
- **The two checkers bound a dispatch's resolved spelling by one number written twice** — `0..16` in `curios-elab/src/typing.rs`'s `spine_whnf` and `curios-cert/src/kernel/whnf.rs`'s `resolved_spelling` — though the kernel's documentation says the checkers agree on which guards refine only by sharing it. Fix: one constant in `curios-analysis`, beside `records_case_equation`, which both sites already share. Check: both crates' tests, and `rg '0\.\.16'` finds neither loop. Size: quick.
- **Names of the retired `/syn` root survive in code.** `curios-elab/src/elaborate/binding.rs` panics with "a syn operator concept declares …" about `/std/ops` concepts, and `curios-text`'s proof-carrying literal node is `Subterm::Syn`, built by `Lowerer::syn_literal`, though no `/syn` exists. Fix: reword the three messages, and name the node for what it is, `ProofLiteral`. Check: `rg -w syn` in the two crates finds nothing. Size: quick.
- **`Term::match_ambient` is a public constructor only tests call** (`curios-core/src/term.rs`): the elaborator builds `MatchResult::Ambient` directly, and every caller is a `curios-cert` test. Fix: move it to `curios_core::test_support`, or have the elaborator build through it. Check: `curios-cert`'s tests build with the feature on. Size: quick.
