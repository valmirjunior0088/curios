# Architecture: findings

Small fixes and possible bugs, worked as one pass. Each entry names where, what is wrong, the fix, its check and its size.

- **The truth table reads a shared `Bool` term once per path, and the proved door is exponential behind it.** `Table::read` (`curios-core/src/reduce/intrinsic/truth.rs`), which `decide_bool` puts both sides of a comparison through in both converters, forces every node and recurses into both operands of a connective, remembering nothing, so a term whose graph shares its subterms is read as its tree. The atom cap does not stand in the way: it counts distinct atoms, and a tree of any size may hold two. `scrutinee_refinement_measurements` (`curios/src/tests/unfolding.rs`) reaches it through its proved door, a web of predicates each naming the one before it twice, put against `true` by index inversion. Taken in debug on `x86_64-unknown-linux-gnu` with the proved door's ladder extended to the others', it reads 4.54, 5.01, 7.55, 11.97 and 22.47 s at 8, 10, 12, 13 and 14 definitions, beside about 4.4 s for every other door at every size, and at 20 `/probe` is refused while elaborating, after 196 s; the growth is `1 + √2` a definition, the tree's. Under the profile at 12 definitions, `truth::decide_bool` is 3.1 s of a 7.9 s compile, over six calls under `invert_with` that allocate 769 MB between them. The measurement does not show it: it stops the proved door at 13 where the others run to 20, and its recorded rows read every door flat from 8 to 13. It is one more walk of [A shared term costs its size](01-shared-term-costs.md), small enough to take alone. Fix: `Table` remembers where each term it has read stands in the formula, keyed on the term as written and as forced, so a shared node is read once and the formula is the graph; with that change alone, a web of 20 definitions and one of 40 compile in the time one of 8 does. The measurement runs every door on the full ladder with its rows retaken, and a fixture beside `a_ten_definition_numeric_web_compiles` holds a proved web of twenty definitions. Check: the retake reads every door flat through 20, the fixture compiles, and a walk harness's `every_walk_answers_a_doubling_term_in_its_own_size` gains the table's row, failing with the memory off. Size: quick.
- **The Ersd and Cont printers hand-roll their frames** (`curios-ersd/src/print.rs`, 1 069 lines; `curios-cont/src/cps/print.rs`, 812), each walking an explicit job stack, where [depth is bought with stack](../../design/architecture/depth-is-bought-with-stack-not-with-hand-rolled-frames.md) and neither is among the decision's four exceptions. Fix: recurse under `recurse`, printing in the same order. Check: each crate's `a_deep_module_prints_without_native_stack`, renamed for what it then shows, prints its 50 000-deep module on the default test-thread stack, and every printed rung of the corpus is unchanged. Size: medium.
- **`Proxy::from_archivable` is fallible and never fails** (`curios-archive/src/proxy.rs`): its four implementors — interned symbols and qualifiers, `curios-num`'s integers, `curios-text`'s ordered map — each return `Ok`, and `Via`'s deserialization wraps an error path nothing reaches. Fix: make it infallible, or keep it with the first fallible proxy's reason. Check: the archive round-trip tests. Size: quick.
- **`curios-binaryen/build.rs` narrates history in two doc comments**: the replaced `BUILD_SCHEMA` constant, and the cache that once sat under `target/`. Held: `build_schema` hashes the file, so any edit discards the Binaryen cache. Fix: restate both in the present tense the next time the file changes for a reason that pays the rebuild. Check: `/full-gate`'s Binaryen extras. Size: quick.
- **`Term::match_ambient` is a public constructor only tests call** (`curios-core/src/term.rs`): the elaborator builds `MatchResult::Ambient` directly, and every caller is a `curios-cert` test. Fix: move it to `curios_core::test_support`, or have the elaborator build through it. Check: `curios-cert`'s tests build with the feature on. Size: quick.
