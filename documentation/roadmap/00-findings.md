# Findings

- **`Proxy::from_archivable` is fallible and never fails** (`curios-archive/src/proxy.rs`): its four implementors — interned symbols and qualifiers, `curios-num`'s integers, `curios-text`'s ordered map — each return `Ok`, and `Via`'s deserialization wraps an error path nothing reaches. Fix: make it infallible, or keep it with the first fallible proxy's reason. Check: the archive round-trip tests. Size: quick.
- **No crate boundary the documents state is held by a step.** Six are sentences that nothing runs: the certifier's closure (`curios-cert`'s `README.md` and `lib.rs`); `curios-unit` reaching no `curios-cert`, and `curios-pipeline` depending on neither `curios-package` nor a back end (`.claude/rules/pipeline.md`); `curios-prelude-archive`'s build reaching neither `curios-emit` nor `curios-wasm` (`.claude/rules/prelude.md`); `curios-elab` taking `curios-cert` as a dev-dependency only (`.claude/rules/checking.md`); and the launcher naming neither `cranelift-codegen` nor `curios-binaryen`, which the gate checks by hand and only where `curios-runtime`'s own dependencies changed (`.claude/commands/run-full-gate.md`). A dependency added to any crate on the way enters a boundary unannounced. Fix: one `cargo xtask` step over `cargo metadata`, reading a table of boundaries — a root, an edge kind, and the crates it must or must not reach — and failing in both directions, as rustc's `tidy` holds its compiler's dependencies to a list; [the certifier's closure](01-soundness/03-checked-evidence.md) is one row of it, taken under the features the shipped `curios` resolves. Check: an edge added across each boundary fails the step, and so does a listed crate no longer reached. Size: small.
