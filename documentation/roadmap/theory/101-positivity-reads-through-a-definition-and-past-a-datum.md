# Positivity reads through a definition and past a datum

Adopted: a type that holds itself through a container whose hidden proof is computed from its payload is admitted where its functor is polynomial, where today the analysis answers that it cannot see through the proof. `Vec(T, n)` stands in a recursive type, a list stands beside a proposition about its length, and `/std/Map` holds its soundness as the recursive proposition its proofs read, with no family restating it beside bridges each way.

Working specification for strict positivity reading three forms it reads at `Mixed` today: an application whose value is a datum, the arms of a `match` a type-level definition is stuck on, and a recursive member met again on its own path. [Strict positivity, modulo polarity](../../design/theory/strict-positivity-modulo-polarity.md) states the rule; its acceptance test, that no declaration reaches itself through a non-strict path, is unchanged, and only how precisely the walk finds a path moves. Its first consumer is [A map forks sixteen ways](../standard-library/100-a-map-forks-sixteen-ways.md).

Its next step is stage 1, a delivery.

## What this builds on

- **The walk reads at `Mixed` what it cannot see through.** `curios-analysis/src/positivity.rs` forces a type-level definition to weak-head normal form (`Walk::forced`) and reads the form it is stuck on through `Walk::opaque`, which walks every child at `Mixed`: a `match` stuck on a variable, its head and its arms alike, an application, a projection, a value; and a `rec` member the path is already inside, left folded so the descent ends (`Walk::walk_within`). A family's index arguments are walked at `Mixed` (the `InductType` arm), and every intrinsic that is no type former is opaque (`Walk::intrinsic`). `Mixed` is a result, never a stop: what stands in an arm is still read.
- **Both checkers run it through `Env`** (`curios-analysis/src/judge.rs`), which answers reduction, a definition's body, a local's type, a family's vector and whether a family was judged. What it files of a definition is its totality and its `Applications` (`Env::applications`), each checker its own.
- **What a form states.** A recursive member states its type (`RecGroup::member_type`, `curios-core/src/term/shape.rs`), and a `match` its head, goal and arms (`Match`, `Cases`); `curios-analysis/src/totality.rs`'s `walk_arms` opens an arm against fresh binders.
- **What the walk's caution closes is on the board.** [Two families declared apart that mention each other …](../../../xboard/tickets/formation/2026_11_05_two_families_declared_apart_that_mention_each_other_are_each_analysed_with_the_other_as_a_sink_and_the_negative_cycle_through_the_two_is_admitted/metadata.toml) reaches `False` through a definition placed before both families, and [A family of a unit with no vector on record …](../../../xboard/tickets/admission/2026_11_05_a_family_of_a_unit_with_no_vector_on_record_digests_alike_whatever_its_vector_so_a_verdict_a_store_filed_composes_through_one_that_moved/metadata.toml) through a vector a stored verdict did not digest. Both are fixed, and both are why a definition is read where it is used and never through a vector filed for it.
- **Peers.** Agda analyses how a definition uses its arguments and admits by it a recursive occurrence nested in a `Vec` ([Positivity checking](https://agda.readthedocs.io/en/stable/language/positivity-checking.html)), and its checker has needed fixes over the years ([issue 1899](https://lists.chalmers.se/pipermail/agda/2017/009442.html)). Rocq refuses a constructor taking `length l = n` beside `l : list T` ([an example](https://vonavi.github.io/coq-examples/examples/using-length-of-list-x-as-an-argument-for-a-constructor-of-x-in-coq.html)), and Lean's kernel reads no occurrence in an argument of a head it does not nest through.

## The gap

Each of the following is refused at `8ed961f9c` by the elaborator as "occurs in itself in a position the checker cannot see through", and each is a polynomial functor, a container and a predicate over its shape:

- `struct Box(T: Type): Type { items: List(T), k: Nat, @ok: Eq()(List/len(items), k) }` beside `induct N: Type | tip() | node(kids: Box(N)) end`: `T` stands only as `List/len`'s implicit argument, inside an index of `Eq`. The same fact stated as a family indexed by the list, `induct Long(T: Type): (List(T), Nat) -> Prop`, is admitted, and so is `Eq()(List/len(@T, []), k)`, which reduces. `Vec(T, n)` is this `Box`, so a family holding `Vec(Self, k)` is refused too.
- `let Good(@V: Type, r: Option(List(V))) -> Prop = match r | none() => Bool/True | some(l) => Bool/Holds(List/len(l) < 9) end;` and `struct M(V: Type): Type { root: Option(List(V)), @ok: Good(root) }` beside a type holding itself through `M`: the `match` is stuck on `root`.
- A recursive proposition over a tree, `let Balanced(@V: Type, t: Tree(V)) -> Prop = match t | tip(_) => Bool/True | fork(l, r) => {Balanced(l), Balanced(r)} end;`, held by a struct as `M` holds `Good`: the member is met again on its own path.

`curios`'s `an_occurrence_behind_a_stuck_type_level_match_is_rejected` (`tests/rules/positivity_computed_type.rs`) pins the second refusal with both arms strict. `/std/Map` meets the third: it holds its soundness as `Node/Shaped`, a family that restates `Node/Sound` with no function applied to the trie, bridged by `Node/shaped`, `Node/read`, `Rooted`, `grounded` and `rooted` (`curios-prelude/std/Map.crs`, `curios-prelude/std/Map/internal/Node.crs`), because `/std/Toml` holds itself through a map.

## Decisions

- **A datum carries no parameter.** In an application whose result type is data, a parameter of the declaration analysed that stands inside a type argument is read at `Unused`; every declaration the application names, and every argument that is no type, a dictionary among them, is read as today. A type is data where it names no sort and no target of the walk and every family in it carries payloads that are data at the parameters it is given; a family's classification is computed once a family and kept by each checker as its vector is. It rests on a property the decision states: no term computes on a type, so a datum a type argument reaches is one datum at every instance of the argument, and the predicate a field states of a payload is kept by the functor's action. Decided on 2026-11-17.
- **The arms of a stuck `match` in a type are read at the polarity the `match` stands at**, every arm and a default among them, each opened against fresh binders as `walk_arms` opens them; the head, the goal and a stated instance are read at `Mixed`. Every instance reduces the `match` to one arm whose binders its head supplies, so the arms joined with the head at `Mixed` bound every instance; a sort left to a caller selects one of the arms walked, as definitional K selects a proposition's sole arm. Decided on 2026-11-17.
- **A recursive member met on its own path is read through its vector**: the polarity each of its parameters stands at in its body, a least fixpoint seeded at `Unused` over its group's members together, computed by the walk and kept for that walk alone. The fixpoint bounds every finite unfolding, the argument the decision makes for a declaration, and needs no termination. Decided on 2026-11-17.
- **Nothing is filed per definition**, since a vector filed for a definition would reopen the two tickets above. Decided on 2026-11-17.
- **`Env` gains a global's declared type**, which each checker answers from its own registry; it is read to tell a datum. Decided on 2026-11-17.
- **`curios-analysis/src/variance.rs` keeps its reading**, a stuck form marking every level it carries, which is the refusing direction there; [A map forks sixteen ways](../standard-library/100-a-map-forks-sixteen-ways.md) checks that the map's variance vector holds. Decided on 2026-11-17.

## Stages

1. **A datum carries no parameter.** The rule, the classification of data, and `Env`'s method in `curios-elab`'s `Context` and `curios-cert`'s `Certifier`. Check, in both checkers (`curios/src/tests/rules/positivity_computed_type.rs`, `curios-cert`'s `recheck::positivity_tests` and `curios-analysis/tests/driven/positivity.rs`): `Box` admitted, and a family holding `Vec` of itself; refused, each mutation-checked against the rule reading it at `Unused`: a datum computed with a witness for the declaration analysed, a family with a payload at a sort read as no datum, a dictionary argument naming the parameter, and a proposition field that uses the parameter left of an arrow under a function.
2. **A stuck `match`'s arms.** Check: `an_occurrence_behind_a_stuck_type_level_match_is_rejected` restated as admitted, beside a control whose one arm holds the occurrence left of an arrow, refused; `an_occurrence_a_sort_left_to_a_caller_would_uncover_is_refused` refused still, and `a_parameter_a_sort_left_to_a_caller_would_uncover_is_read_at_mixed` renamed for the polarity it reads now, in both checkers (`recheck::sort_tests`, `recheck::assignment_tests`); a head carrying a type into an arm, `match r | some(X) => (X) -> Bool/False end` over an argument naming the declaration, refused.
3. **A recursive member through its vector.** Check: `M` over `Good`, and the struct over `Balanced`, admitted; a definition wrapping its own call left of an arrow refused, its vector climbing to `Mixed`; a mutual pair of members; the formation ticket's definition-before-both witness refused still.
4. **The rule restated, and a hunt round.** [Strict positivity, modulo polarity](../../design/theory/strict-positivity-modulo-polarity.md) states the three readings, their rationale and the property the first rests on, and `positivity.rs`'s module documentation follows; a hunt round's charters cross the three readings with `Prop`, definitional K, a sort left to a caller, large elimination, recursion and dictionaries.

## Verification

`cargo xtask workspace lint` and the suites a stage reaches after each stage, its checks by name first; `curios-analysis/tests/driven/` runs both drivers. Stored bytes that may change are the polarity vectors `/std`'s families file where a computed type was read at `Mixed`; every verdict, every refusal a test pins but the ones restated above, and every emitted module stay equal. `/std`'s elaboration and certification units are counted before and after. The full gate runs once, after the fourth stage.

## Rejected

- **A vector filed per definition**, read wherever the definition is used: it is the sink the formation ticket's second witness walks through, and a vector every verdict over it must digest.
- **Polarity written in the surface**, Agda's `@++`: the decision rejects it, the property being computed.
- **`Mixed` as a stop** at a stuck form: the decision rejects it, and every reading here reads deeper, never less.
- **A datum read at `Unused` whole**, the declarations it names included: a witness for the declaration analysed computes the datum by eliminating that declaration, which the walk must still see.
