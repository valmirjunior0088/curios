Two sites show it refusing what no reduction forces. With `let spin(n: Nat) -> Io(Nat) = Io/bind(Io/yield(), (()) => spin(n));`, the parameter type `Vec(Io(Nat), List/len(List/map([1, 2, 3], spin)))` is refused ("it reaches `spin`"), though `List/len` over a map reduces to its list's length "whatever `f` does" (`curios-core/src/reduce/intrinsic.rs`), and the same type formed by instantiating `counted(work: List(Io(Nat)), v: Vec(Io(Nat), List/len(work)))` at `List/map([1, 2, 3], spin)` is accepted, so the verdict follows the spelling; a result counted by its list, `all(@A: Type, actions: List(Io(A))) -> Io(Vec(A, List/len(actions)))`, is refused by it at every caller that maps an action that loops — a send, a receive, a read — `/std/Tui`'s `running` and a fail-fast `Try/all` among them. And over `concept Joint(T: Type): Type { Answers: Type, run(T) -> Io(Answers) }` witnessed at `{Io(A), Io(B)}` with `Answers = {A, B}` and `run(t) = Io/both(t.0, t.1)`, a call of `let all_of(@T: Type, use Joint(T), actions: T) -> Io(Joint/Answers(@T))` is refused ("it reaches `/witness~/Joint({_, _})`"), where the field the type reads is `{A, B}`. Of the decision's two reasons for the aggressive reading, one no longer holds: the precise reading "buys nothing (V) does not already refuse", and it buys these. The other, that a total type-level function applied to a partial value reties the knot (`Shape(inf)`), stands against reading what a type scrutinizes, not against holding a loop folded. Settled by the reading [Lean](https://lean-lang.org/doc/reference/4.26.0/Definitions/Definitions/) (a `partial def` is an opaque constant, never δ-reduced), [Agda](https://agda.readthedocs.io/en/latest/language/termination-checking.html) (a `NON_TERMINATING` function does not reduce during type checking) and [Idris](https://arxiv.org/abs/1610.07978) (a partial function is not evaluated during type checking) share: neither checker unfolds a definition whose own recursion does not descend, an inline group's included, so `Shape(inf)` and `Bad` stay folded and no knot is tied; (T) narrows to the declaration being judged, whose verdict comes only after its elaboration; and a definition that merely mentions such a root unfolds as any other. Lean asks an opaque constant's type to be inhabited because a proof could use it, which is (V)'s job here. Not yet known: whether (V) reaches through a proof's type arguments, as a bound discharged over a mapped list asks it to; and what the decision's "the expression would have returned" says of an erased type naming a folded loop.
