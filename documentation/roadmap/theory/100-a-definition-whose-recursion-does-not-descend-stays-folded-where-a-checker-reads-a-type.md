## Peers

- [Lean](https://lean-lang.org/doc/reference/4.26.0/Definitions/Definitions/): a `partial def` is an opaque constant, never δ-reduced, its mutual block opaque together, and its type must be inhabited because a proof may use it. Adopted: the opacity, by the block. Avoided: the inhabitation the user states; proof totality keeps every proof from keeping one.
- [Agda](https://agda.readthedocs.io/en/latest/language/termination-checking.html): a `NON_TERMINATING` function is not unfolded during type checking, and `TERMINATING` unfolds on the user's word. Adopted: no unfolding of a loop. Avoided: the pragma; a body says whether it descends, as the decision's rejected `rec` keyword argues.
- Idris: a partial function is not reduced while a type is checked ([Eisenberg's survey](https://arxiv.org/abs/1610.07978), of Idris; [Internalizing Extensions in Lattices of Type Theories](https://arxiv.org/abs/2510.26839)). Adopted as Agda's.

Adopted: the split — type totality free to name what proof totality keeps a proof from using, and proof totality reading what a proof uses rather than what it spells.
