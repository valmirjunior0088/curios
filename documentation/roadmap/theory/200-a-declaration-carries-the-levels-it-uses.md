# A declaration carries the levels it uses

**Not refined yet.** This specification reserves two places where a declaration takes a universe parameter no caller can use. It is not an implementation plan.

## What is missing

**A member of a group takes the group's levels, its own telescopes mentioning them or not.** A group shares its parameters, so `/std/Async`'s `Pause`, which takes no parameter, carries `Step`'s. The family's vector calls the level irrelevant, every instance converts with every other, and the parameter offers a caller nothing: each occurrence mints a level for the solver to settle and for a signature to carry. Lean 4.29 stopped promoting one ("Universe level metavariables present only in constructor fields are no longer promoted to be universe level parameters", [release notes](https://lean-lang.org/doc/reference/4.34.0/releases/v4.29.0/), #12514). A level no member's parameter is typed at and no instance holds is minimized where the group closes, so what is left is one member's level that another never mentions.

**A definition whose signature names an associated type through a witness takes the witness's level.** With `pub concept Sized(T: Type): pub Type { Carrier: Type }` and `satisfy Sized(Nat) { Carrier = Str }`, the witness takes the level `Sized` is invariant in, and `pub let named(x: Sized/Carrier(@Nat)) -> Nat = 0;` takes one parameter, `Carrier.{0,u}(@Nat, use witness.{u})`, where the type is `Str`. A concept that states a proposition among its fields does the same to every method, the proposition's level being one its family is invariant in: `/std/ops/Div` and `Rem` state `Ok(A) -> Prop`, so each written `/` or `%` in a signature is a parameter of its declaration, `let one(n: Nat) -> Eq()(n / 256, n / 256) = Eq/refl();` taking two and the same equation over `n / 256 + m / 16` four. A signature is read as it is written (`compared_levels`, `curios-elab/src/variance.rs`), and the witness's instance stands in an argument of a definition applied in full, which the alignment compares; that the projection's reduct drops the level is seen only by reducing. The parameter is one no caller can use and no program is refused for, and a family whose payload names the same type takes none, its telescopes being read by their reducts.

## Refinement

- **A group's member.** A member's context holds the group's levels its own entries mention, an occurrence of it inside the group carrying the projection. Every signature naming such a member loses a level, so what it moves across `/std` is taken first. Check: `curios-prelude-archive`'s `family_variance_inventory` lists no parameter of a family whose entries do not mention it, and `/std` certifies. It reaches how a group's instance is stamped.
- **An associated type through a closed witness.** A concept's method applied to a closed witness read by the field it projects, one step that runs nothing else; whether another head needs the same is measured first. Check: `named` and `one` take no parameter, and `universe_parameter_census` moves nowhere else.
