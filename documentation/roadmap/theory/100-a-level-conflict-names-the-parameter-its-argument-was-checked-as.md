# A level conflict names the parameter its argument was checked as

Adopted: a level conflict an argument closes says which parameter of which callee the argument was checked as, where today it stands at the argument with an inequality between levels its reader never wrote. What a checked term fills is stated once, as one identity carried with the type the term is checked against, and read by every refusal raised against that type: a level conflict, decided long after the check, through the constraint the check raised; a type mismatch at an argument, which names no parameter today; and a lambda handed where no function is wanted, which names one today by a path of its own; an inserted argument names its slot by the same identity, so a witness goal's report spells its concept as its reader can write it. A constraint's origin becomes the reason it was raised, each reason holding the facts it has, and a scheme's bounds are raised once, where an occurrence mints its instance and names it.

Its next step is stage 1, a delivery.

## The gap

Under `let coerce(A: Type, F: (Type) -> Type) -> Type = F(A);` and `let tie(@T: Type, x: T) -> Type = T;`, the declaration `let bad(G: (Type) -> Type) -> Type = coerce(tie(G), G);` is refused with `this Type would need to be strictly below itself` and `required: max(?u1+1,?u2+1) ≤ ?u1`, standing at `tie(G)`, probed at `7ac1b7d64`. `coerce` closes at `(A: Type.{u}, F: (Type.{u}) -> Type.{v}) -> Type.{v}` and `tie` at `(@T: Type.{u}, x: T) -> Type.{u}`, neither stating a constraint, so nothing a scheme restates is on the cycle and no line names a declaration. What is on it is the argument held under its parameter's sort, whose origin holds where it was raised and nothing of the parameter it was raised for; the level `A` and `F`'s domain share is one by assignment, which raises no constraint. So it goes where the argument closes the conflict in a `match`'s arm, in a `let`'s tail, inside another call (`coerce(id(tie(G)), G)`, standing at the inner `tie(G)`), or where its check waits until a later argument decides the type it is checked against: `take(pick(tie(G), (X) => X), G)` under `let pick(@F: (Type) -> Type, a: F(/std/Nat), k: (X: Type) -> F(X)) -> F(/std/Nat) = a;` and `let take(A: Type, F: (Type) -> Type) -> Type = F(A);`.

A refusal made where an argument's check fails names the slot for one refusal alone: `apply((x) => x, 1)` under `let apply(n: /std/Nat, f: (/std/Nat) -> /std/Nat) -> /std/Nat = f(n);` reads `checked as \`n\`, the 1st argument of \`apply\``, while `pair(1, 2)` under `let pair(n: /std/Nat, s: /std/Str) -> /std/Nat = n;` reads `inferred: /std/Nat` and `expected: /std/Str` and nothing of `s`. A level conflict passes through neither: it is decided where the declaration's levels are finalized (`Context::finalize_universe_metas`), after every check has returned.

A witness goal's slot is named by text written where the goal is minted, so its report spells a concept as the minter did, not as its reader can write it: under `use /std/{Nat};` and `pub induct Tree(A: Type): pub Type | leaf(A) | node(Tree(A), Tree(A)) end`, `satisfy (@A: Type) => /std/Spell(Tree(A)) { .. }` is refused with `wanted: /std/Spell(A)` beside `needed by \`Tree/leaf\` for payload #1 — add \`use Spell(A)\` to the telescope`, and `Spell` resolves to nothing there, so the premise pasted into the telescope is refused ([A diagnostic spells what its reader can write](../../design/tools/a-diagnostic-spells-what-its-reader-can-write.md)).

The conflict's report closes on five lines whatever its cycle holds: levels have no syntax, a definition is generalized only at the top level, hoist a local one used at two levels, a recursive group is monomorphic in its own levels, and a member's own calls constrain them. `coerce(tie(G), G)` holds no local definition and no group, and is told about both.

## What this builds on

- **Where a term is checked.** The checking mode is `Mode::Check(Term)` (`curios-elab/src/elaborate.rs`). A written argument is checked by `check` in `elaborate_apply` (`curios-elab/src/elaborate/apply.rs`), a struct literal's written field by `check` in `check_dependent_fields` (`curios-elab/src/elaborate/struct_.rs`), and an operator's operands at `Mode::Check(operand_type)` in `elaborate_infix` (`curios-elab/src/elaborate/binding.rs`). The mode flows on whole into a `let`'s tail, and is rebuilt from a bare `Term` for each arm of a `match`: ten `check` calls in `curios-elab/src/elaborate/match_.rs` and eight `Mode::Check` constructions in `curios-elab/src/elaborate/matrix.rs`. A form that cannot be checked yet parks as `ParkedWork::Checking { term, expected, placeholder }`, read back as a `ParkedChoice` by the term that awaits it (`curios-elab/src/context/solutions.rs`).
- **What a refusal knows of the slot.** `ArgumentSite` (`curios-elab/src/error.rs`) holds the callee as its identity (`CalleeId`), the parameter's name, its plicity, its position among the arguments of that plicity and a later parameter of function type. It is built once the check has failed, `opened_link` costing the rest of the telescope, and attached by `Error::at_argument`, which every error but `NotAFunctionType` ignores. An inserted argument's slot is named apart: `ImplicitOrigin` by its callee and its binder's name, `WitnessOrigin` by its callee and a role its minter writes as text (`curios-core/src/term/shape.rs`) — a premise's position (`premise_label`), a literal's superclass by its concept's last segment (`curios-elab/src/elaborate/struct_.rs`), an operator's implementation by its field (`infix_method`), and a derived payload with the premise to add as `use {concept.last()}({faithful type})` (`witness_call`, `curios-elab/src/derive.rs`).
- **Where a constraint's origin is made.** `expect` (`curios-elab/src/typing.rs`) asks `subsume_outcome` with the term's extent, which the conversion run holds (`Convert::extent`, `curios-elab/src/convert.rs`) and builds an origin from at two places: a sort held under a sort (`decide_below`) and a sort given a level of its own beside another (`sorts_of_its_own`). A problem that waits parks as `ParkedWork::Conversion(Problem)` beside the term it was asked for, and its retry asks again with that term's extent.
- **What an origin is.** `UniverseConstraintOrigin` (`curios-core/src/universe.rs`) is an extent, a `UniverseConstraintKind`, a `declaration`, a `binder` and the declaration an occurrence `instantiated`, all optional. Of the kind's thirteen variants, `TypeSuccessor`, `FunctionFormation` and `TupleFormation` are constructed nowhere, and `Other(String)` is a label `UniverseMutation::fresh_sort` mints that no report reads. `declaration` and `binder` are written by `size_domains` (`curios-elab/src/elaborate/module.rs`) alone and read only by `curios-surface`'s `Spelled<UniverseError>`, which no report prints, the elaborator wording a conflict itself; `WrittenSort`, archived with every lowering, stores the joined path of the module it was written in for that same reader alone. The live store holds each constraint beside its origin (`ConstraintStore`), and nothing stored holds one ([`curios-unit`'s stored-form decision](../../../curios-unit/README.md#a-stored-unit-says-what-its-items-mean-not-where-they-were-written-or-how-they-were-come-by)).
- **What the report reads.** `inconsistency_from_path` (`curios-elab/src/universes/solver.rs`) gathers the origins of the constraints on the cycle and of the levels they name. `Error::UniverseInconsistency` stands at the first place they know, notes each other use whose scheme's bound is on the cycle, words itself by their kinds (`inconsistent_sort`, `names_a_proposition`, `instantiated_on`), and closes on the five lines above.
- **Where a scheme is restated.** `UniverseSolver::instantiate_at` takes an `Option<Occurrence>`. Six calls pass none: `resolve.rs`'s goal for a concept, and five helpers of `curios-elab/src/context/universes.rs` reached from 25 callers in 14 files, most of them reading a facet of a type node a term already holds. Two more restate at the instance they have just restated with its occurrence: `method_form` (`curios-elab/src/elaborate.rs`) and `infix_method` (`curios-elab/src/elaborate/binding.rs`). With every restatement that passes no occurrence raising nothing, `/std`'s elaborated image is byte-identical (`std.rkyv`, `sys.rkyv` and `std.pack`), shown at `7ac1b7d64` by an experiment that returned from `instantiate_at` before its loop where no occurrence is passed; the 515 tests whose names reach universes, levels, schemes, propositions and large elimination pass under it but `universes::solver::tests::consistency::a_constraint_instantiated_from_a_scheme_carries_no_position`, which pins the restatement itself.
- **What the caches keep.** The elaboration cache keeps only a run that wrote nothing (`Context::get_or_init_elaborated`), and adding a constraint is a write. The oracle's memo keeps runs that wrote, for its bracket alone (`Context::oracle_memoizable`).

## Peers

- **GHC** keeps with every constraint a `CtLoc`: its `CtOrigin`, and a `CtLocEnv` holding the error-context stack, "used to restore the environment of a constraint when reporting errors" ([`GHC.Tc.Types.CtLoc`](https://ghc.gitlab.haskell.org/ghc/doc/libraries/ghc-9.15-inplace/src/GHC.Tc.Types.CtLoc.html)), so a constraint solved late still says `In the first argument of 'f', namely 'x'`.
- **Agda** keeps a constraint as a `Closure Constraint`: the whole `TCEnv`, its `envCall` among it, re-entered to report the constraint ([`Agda.TypeChecking.Monad.Base`](https://hackage.haskell.org/package/Agda-2.6.3/docs/Agda-TypeChecking-Monad-Base.html)).
- **Lean 4** keeps a postponed level constraint as a `PostponedEntry`: the syntax `ref` saved "at entry creation time … for reporting errors back to the user", and the context of the surrounding `isDefEq` ([`Lean.Meta.Basic`](https://github.com/leanprover/lean4/blob/master/src/Lean/Meta/Basic.lean)). That context is the pair of types being unified, and `stuck at solving universe constraint` is a report its users find hard to act on ([Zulip](https://leanprover-community.github.io/archive/stream/270676-lean4/topic/Stuck.20at.20solving.20universe.20constraint.html)).
- **rustc** keeps with every outlives constraint a span and a `ConstraintCategory`, `CallArgument` among them, and words a region error by the category of one constraint of the path, `argument requires that 'a must outlive 'b`; `best_blame_constraint` picks that constraint by a ranking that has needed revision ([`region_errors.rs`](https://doc.rust-lang.org/nightly/nightly-rustc/src/rustc_borrowck/diagnostics/region_errors.rs.html), [rust#133858](https://github.com/rust-lang/rust/pull/133858)).
- **Rocq** decides a constraint where it is enforced, so an inconsistency is a type error at the term being checked, explained by its path through the universe graph ([`uGraph.ml`](https://ocaml.org/p/rocq-runtime/9.2.0/src/rocq-runtime.kernel/uGraph.ml.html)).

Taken: where a constraint was raised is captured where it is raised and kept beside it, as all four deferring checkers keep it, and the reasons are a closed set, as rustc's categories are. Left: a captured environment (GHC, Agda), which the store would hold whole and a report would re-enter, where an identity is a few words a report spells where its reader stands ([A diagnostic spells what its reader can write](../../design/tools/a-diagnostic-spells-what-its-reader-can-write.md)); a context made of the two types alone (Lean), which names nothing the reader wrote; and a ranking that picks one constraint to blame (rustc), where every slot on the cycle is a place the reader wrote that ties the levels. Deciding consistency where each constraint is added (Rocq) is what `UniverseSolver::add_constraint` rejects for its cost, and it would still meet a parked check after its call has returned.

## Decisions

- **A scheme's bounds are raised where an occurrence mints its instance, and nowhere else.** `instantiate_at` takes an `Occurrence`, which names the declaration, and its extent where a term wrote it. A term that holds an instance holds one whose bounds its minting raised, or one a definition's body states under the scheme that definition was checked under, whose bounds that scheme's restatement entails: reading a facet of it (`induct_facet`, `struct_facet`, `instantiate_induct_decl_at`, `instantiate_struct_decl_at`, `instantiate_universe_bound_at`) and resolving a goal at it raise nothing, and `method_form` and `infix_method` raise their concept's bounds once, at the occurrence. A restated bound then names its declaration by construction. Decided on 2026-11-17.
- **A slot is one identity.** `ArgumentSite` moves to `curios-core` as the slot alone: the callee (`CalleeId`), the parameter's name (a `Symbol`, none for a `use` slot), its plicity, and its position among the slots of that plicity; the later parameter of function type goes to the one refusal that computes it, beside the site. The name stays the tree's, since `curios_core::Slot` is a pattern's, and the language calls what fills a callee's place an argument. Every place a written term fills a slot states it: a call's argument, a struct literal's written field (the structure, by the field's label), an operator's operand (the operator, by its position). An inserted argument names its slot by the same identity: `ImplicitOrigin` is an `ArgumentSite`, and `WitnessOrigin`'s role is an identity spelled where the report is made, as its callee already is — a premise as an `ArgumentSite`, a superclass by its concept, an operator's implementation by its field, a derived payload by its constructor and position with the premise to add as the concept and the variable it is wanted at. Decided on 2026-11-17.
- **An expectation carries its slot.** `Mode::Check` holds an `Expectation`, the type and the slot it is the type of, as one value. It is forwarded whole wherever the expectation flows on — a `let`'s tail, a lifted node, an ascription's outer turnaround — and kept by a `match`'s arm, which checks at the goal its case specializes (`expectation.at(goal)`), and by a parked check and the choice read back from it. A frame that checks against a type of its own making states no slot: a lambda's body against its codomain, a binding against its annotation, a tuple's component, a declaration's body against its signature. The slot is no part of the elaboration cache's key, which keeps only a run that wrote nothing; a hit of the oracle's memo leaves a constraint holding the slot of the run that raised the same inequality, which is a slot that inequality was raised for. Decided on 2026-11-17.
- **Every refusal raised against an expectation reads its slot**, in one wording, `checked as \`s\`, the 2nd argument of \`pair\``: a type mismatch at the turnaround or at a parked conversion's retry, a lambda or a tuple against a type that is none, and a conversion left undecided. It is one wrapper of the error, as `Located` and `InScope` are, made where the refusal is made from the expectation it refuses; `Error::at_argument` goes. Decided on 2026-11-17.
- **An origin is the reason a constraint was raised**, one variant a reason, each holding what it knows: a written sort (`WrittenSort`: its extent, and which of `Type`, `Prop` and `Sort`), a term held under the sort a position expects (its extent, whether what is put below is a proposition, and the expectation's slot), a nominal declaration's parameter or member sized under its sort (its extent), two levels conversion holds one or ordered, and a scheme's bound restated at an occurrence (the declaration, and the extent where a term wrote it). `UniverseConstraintKind` goes, with the three variants nothing constructs and the free-text label; `declaration` and `binder` go from the origin and the module path from `WrittenSort`, with `Spelled<UniverseError>`'s wording of a conflict, which no report prints. `inconsistent_sort`, `names_a_proposition` and `instantiated_on` read the variants. The origin's types stay in `curios-core`, `WrittenSort` archived with the lowering as today. Decided on 2026-11-17.
- **The conversion run holds where it is asked and for which slot**, as one value `subsume_outcome` hands it, kept by a parked conversion beside its problem and handed again by its retry. Decided on 2026-11-17.
- **The report states each slot its cycle holds**, once each, in the order the path meets them, beside the declarations whose bounds the cycle runs through, and a remedy only where the cycle holds what the remedy is about. It stands where it stands today, at the first place the path knows. No slot is ranked over another. Decided on 2026-11-17.
- **The work is staged by consumer**: the restatements, whose consumer is every report naming a declaration's bound; then the slot, whose consumers are the refusals made where a check fails; then the origin, whose consumer is the conflict's report. Decided on 2026-11-17.
- **A remedy is told its cycle by the reading that holds over the fixtures that pin it**: the callee of a slot on the cycle, a local definition or a member of the group the declaration belongs to, which `elaborate_apply` knows where it states the slot; or the place a level on the cycle was written, a local definition's signature or a group member's, which the lowering knows where it writes the `WrittenSort`. Whichever holds over `a_local_polymorphic_definition_applied_to_itself_is_refused_with_its_remedy` and `a_recursive_call_a_level_above_its_group_is_refused_with_its_remedy` (`curios/src/tests/universes/hierarchy.rs`) and over the same programs with their binders' types left to inference is taken, and the slot's callee where both do, since a level left to inference has no written place; the third stage reads those cycles before it words the report. Decided on 2026-11-17.

## Stages

1. **A scheme's bounds raised where an occurrence mints its instance.** `instantiate_at` and `instantiate` take an `Occurrence`; the facet reads and the goal raise nothing; `method_form` and `infix_method` raise once. Check: `/std`'s image digest unchanged at one path; the universe suites (`curios`'s `tests::universes`, `tests::rules::proposition`, `tests::rules::large_elimination`, `curios-elab`'s `universes::solver`) unchanged; `a_conflict_a_schemes_bound_closes_names_the_declaration_instantiated` and `a_conflict_two_uses_close_alone_stands_at_one_and_notes_the_other` unchanged; `universes::solver::tests::consistency::a_constraint_instantiated_from_a_scheme_carries_no_position` goes with the form it pins.
2. **A slot, carried by the expectation, read by the refusals made where a check fails.** `ArgumentSite` in `curios-core`, `Expectation`, the sites stated at a call, a struct literal and an operator, the forwarding above, the parked check and its choice, `ImplicitOrigin` as a site and `WitnessOrigin`'s role as an identity, the wrapper and its wording; `Error::at_argument` goes. Check: the derived `Tree` witness above as a fixture beside `curios-pipeline`'s `tests::paste_back_witness`, its advice `use /std/Spell(A)` pasted into the telescope and the witness derived, and a superclass slot of a concept imported under a path named by that path; beside `NotAFunctionType`'s fixtures, `pair(1, 2)` names `s` of `pair`; a mismatch in a `match`'s arm, in a `let`'s tail, at a struct literal's field and at an operator's operand each names its slot; one whose argument's check parks first names it; one at a lambda's body names none; the lambda's report reads as it does; every other pinned report unchanged but for the added line.
3. **The origin as a reason, and the conflict's report.** The variants above, the conversion run's slot, the parked conversion, the remedy's reading settled as decided above, and the report's lines. Check, as fixtures beside `a_conflict_a_schemes_bound_closes_names_the_declaration_instantiated`: `coerce(tie(G), G)` naming `A` of `coerce`, standing at `tie(G)`, and stating neither the local nor the group remedy; the conflict closed in a `match`'s arm and in a `let`'s tail naming it; `coerce(id(tie(G)), G)` naming `x` of `id` and `A` of `coerce`; the parked `pick` naming `a` of `pick`; the two remedy fixtures each keeping its own remedy and losing the other's; every other pinned report unchanged. A solver test that a constraint keeps its slot through an assignment rewriting its inequality and through the rollback of that rewrite. `/std`'s image digest unchanged but for the lowered `WrittenSort`s.

## Verification

`cargo xtask workspace lint` and the stage's tests by name after each stage, `cargo xtask workspace test` after the second and the third. Stored bytes that may change: the lowered modules, where a `WrittenSort` loses its module path and its kind narrows. Every verdict, every elaborated declaration of `/std` and the corpus, and every emitted module stay equal; every pinned report stays equal but for the lines this adds and the remedies it drops. The full gate runs once, after the third stage.

## Rejected

- **The site held by the context for one hop**, from a call's loop over its arguments to that argument's own turnaround: it reaches no check the expectation flows to past that one, so a conflict a `match`'s arm in the argument closes names no parameter, and it reaches no parked check.
- **The site attached to the error where the argument's check fails**, as `Error::at_argument` attaches one: a conflict is raised where the declaration's levels are finalized, so the error that leaves the check is never the conflict.
- **The site recovered from the declaration's term when the report is made**: it reads a fact back off source positions, which terms a desugaring writes can share, and reaches only the place the report stands at.
- **A table of sites beside the solver's store**: two structures every mark and release must move together, where an entry of the store holds both and moves as one.
- **A captured environment**, as GHC and Agda keep: what a report reads of it is the slot, and the rest is state held for a report that reads none of it.
- **One constraint of the cycle picked to blame**, as rustc picks: a ranking is a second judgment beside the cycle's, and every slot on the cycle is a place the reader wrote that ties the levels.
- **Consistency decided where each argument's constraints are added**, as Rocq decides it: the cost `add_constraint`'s decision rejects, paid at every argument, and a parked check still raises its constraints after its call has returned.
- **A bound restated with no occurrence, kept as a safety net**: over `/std` it raises nothing a minting has not, and what the elaborator leaves unraised the certifier decides apart; a restatement that names no declaration is a copy a cycle can run through and report as no one's.
- **`declaration` and `binder` kept for a conflict through an inductive's parameter**: no report reads them, and a sized member's reason is its own variant.

## Completion and retirement

What a slot is, why an expectation carries it, why an origin is a reason and where a scheme's bounds are raised go to `curios-elab`'s README as one decision with this rejected list; `curios-core`'s universe module documentation states the origin's variants; the fixtures and the solver test hold the behaviour. Once no reference to this specification remains, this file is deleted.
