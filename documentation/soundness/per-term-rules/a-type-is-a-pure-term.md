# A type is a pure term

**Assumes.** Nothing at the type level performs an effect

**Status.** **argued**, and the observation that it had no entry had been sitting in a test file rather than here. Three demonstrated routes through it are recorded in the [scrutinee refinement](scrutinee-refinement.md) row, the last of which compiled, passed the compile-path recheck, and trapped at runtime. What discharges it now is a typing fact rather than an analysis, which is why that row's walk could be deleted with no successor: every host operation returns `Io(T)`, and there is no operation taking an `Io(T)` to a `T`, so a term standing at a type position cannot have performed anything. That fact is now asserted, though only over the surface an eliminator could enter through, which is why this stays **argued**. `curios-text`'s `the_sys_io_roster_offers_no_eliminator` pins `/sys/Io`'s exports at exactly `{Io, pure, bind}` and walks every `let` in the `/sys` tree for a function taking an `Io` to a non-`Io`; both halves are mutation-checked, one against an entry added to the effect module and one against an entry hidden elsewhere, since an eliminator is an eliminator wherever it is declared. That surface is two Rust tables rather than the whole library: a foreign row cannot introduce one, because `host_fn` wraps every store row's result in `Io` at a single site and `WireType` is closed with no case that could name an `Io` in a domain; and no `.crs` can define one without already having one.

What the test establishes is that those tables are clean, not the general property, and the naive general form is already false in the corpus — `std/Async.crs`'s `lift(@A : Type, action : Io(A)) -> Async(A)` consumes an `Io` without returning one, legitimately, `Async` being itself a description. Stating the rule properly needs a notion of *what counts as an effect carrier* that admits `Async` and any future `Lift` edge while still refusing a runner for the host carrier, and Curios does have runners — `block_on` and `State/run` are the sanctioned downward direction. That is a design question rather than a fixture, and it is the successor here
