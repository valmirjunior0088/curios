# Scrutinee refinement

**Assumes.** An arm's scrutinee denotes one value, so within the arm it *is* the case's

**Status.** **probed**, and what discharges it is no longer an analysis but a *type*. Every host operation returns `Io(T)`, `Io` has no eliminator, and the only consumer of an `Io(A)` is a `bind` returning `Io(B)` — so a scrutinee whose type is not an `Io` cannot have performed anything, and the assumption above is a construction fact rather than a question anyone asks. The walk that used to decide it is deleted with no successor, and the three routes that defeated it are unwritable now: each put an effect somewhere a syntactic search could not follow, and the last of them — an effect supplied by the *caller*, through an ordinary function parameter — is what showed the question was never answerable from the term at all. The fixtures that recorded them survive as typing refusals: `tests::perimeter::an_effect_cannot_inhabit_a_pure_arrow` refuses the caller's argument before any arm is reached, and `a_stuck_application_scrutinee_still_refines` is the control that a stuck-headed scrutinee is the *ordinary* case and must keep teaching its arm. See [Effects are descriptions, and the carrier has no eliminator](../../design/language/effects-are-descriptions-and-the-carrier-has-no-eliminator.md), for the discipline that replaced the analysis, and [A type is a pure term](a-type-is-a-pure-term.md) for what now carries the premise.

**A guard is now registered in the shape the reducer will present it, operands included — and the rule that decides how far that goes is *rewriting, never evaluating*.** The store records a guard as written, and every occurrence the reducer meets has been reduced, so the two meet only through a common form. The head's half of that was already here (`spine_whnf` re-registers a concept-dispatched scrutinee as the intrinsic it resolves to); the operands' half was not, and it went unnoticed while every proposition `/sys` states was written in the guard's own operands. A window's bound is the first written over an *arithmetic expression* of them — `Le(s + l, len b)`, instantiated at a call as `Le(0 + n, len b)` — so it is the first whose probe form is a fold away rather than a spelling away. Without this, no window bound could be discharged by the guard that established it, which is the capability [A bound is stated in a decided proposition and discharged by reduction](../../design/language/a-bound-is-stated-in-a-decided-proposition-and-discharged-by-reduction.md) exists to provide.

**The line between rewriting and evaluating was drawn by measurement, not taste.** Bringing key and probe together by *reducing* the key is the obvious move and it is unaffordable: a single canonicalization of `n < 256` over an inferred implicit consumed an entire declaration's step budget, and every further attempt in that run then failed instantly on the spent counter — so there was never a first success to memoize, and a memo does not rescue it. `tests::numeric::byte_of_nat_inverts_to_nat_and_refuses_the_bound` is the program that showed it; it is a fixture about something else and is left that way, so what stands here is which direction the cost runs, not a number. What does reach both differences without evaluating: `spine_whnf` opens application layers and stops, and `reduce_intrinsic` under a reducer that returns its operands untouched performs the half of a fold that acts on operands already in hand. Both are bounded by the term, so a guard over an expensive subject stays free to register — the property `shallow_scrutinee` exists to keep.

It is the admitting direction — more refinements fire — and it rests on the same premise as the rest of this entry, that a scrutinee denotes one value. `curios`'s `tests::numeric::a_guard_discharges_a_window_bound_stated_over_a_sum` is the fixture, with a guard over a *different* window as its control: registration must collapse two spellings of one comparison and must not collapse two comparisons. The kernel re-checks either way, so an over-firing refinement fails closed at certification — the same standing the known-unsound universe erasure below has.

**One adjacent defect closed with it and is worth keeping, because the rule it stands for is still live.** The refinement key was metavariable-identity-sensitive: a scrutinee whose argument carried an inferred implicit stored a key holding one metavariable and probed with another, identically solved, so the refinement silently did not fire while the same term with the implicit written out did. Solved metavariables are now materialized into the key, and `tests::matching::an_inferred_implicit_does_not_break_a_refinement_key` is the regression — re-mutation-checked when its shape moved to a concept dispatch, since a first replacement passed with the mechanism removed and was discarded
