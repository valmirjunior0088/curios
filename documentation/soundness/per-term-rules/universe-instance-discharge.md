# Universe instance discharge

**Assumes.** An occurrence's stated universe instance satisfies its scheme's constraints before the declaration is read at it, and every level an occurrence's type or sort is reported at is the instance's rather than the scheme's

**Status.** **probed** at the instance check, at the second clause, and at the sort clause. The check fires at every polymorphic occurrence — a per-term rule — where [`validate_universes`](../whole-module-passes/validate_universes-inside-zonk_module.md) is the whole-module pass beside it; both defects that entry records were per-occurrence, a scheme accepting an instance of any width because discharging an empty constraint set says nothing, and the parameter and index counts an occurrence carries beside it. The `InductAt`/`StructAt` handle makes the three preconditions structural rather than remembered: a rule holding one holds proof that the instance's width and constraints, the parameter count, and an inductive type's index count all passed, and it cannot open an arity at parameters other than the ones they were checked against. `Instance` carries an `InstanceHead` — a variable or a group projection — rather than a general term, so the head shapes below are the only representable ones.

**A bare occurrence of a scheme is refused, because answering it from the scheme captures the scheme's parameters.** A bare `Var` naming a polymorphic definition denotes no particular instance: `Globals::value` withholds a body from one, and `curios-elab` never builds such an occurrence at all — `elaborate`'s `Var` arm rebuilds every polymorphic one as an `Instance` at freshly minted levels. A type lookup that hands the stored scheme type back whole captures the scheme's parameters — a definition's `Type v` read as the ambient item's `v`, the collapse `validate_universes` records at the neighbouring position — and runs `check_instance` nowhere, so the scheme's own constraints are discharged by nothing. The demonstration is one use spelled two ways: for `A<u, v | u + 1 <= v> : Type v = Type u`, whose constraint is load-bearing, an item with two parameters and no constraints of its own is refused at `A<u, v>` as *this instance does not satisfy its scheme's `u+1 <= v`*, and a lookup answering from the scheme accepted it at bare `A` with zero refusals. No surface program reaches it, the elaborator rebuilding the occurrence before the kernel is asked. `Globals::type_of` refuses a bare occurrence of a scheme, which is `Globals::value`'s rule applied to the other half of a definition; a local stays exempt, being monomorphic and opened at one type. `recheck::tests::a_bare_occurrence_of_a_universe_scheme_is_refused` is the regression, asserting both spellings so the witness carries what it bypassed, with `an_occurrence_stating_its_universe_instance_is_still_accepted` as the control on the two things the rule must keep — an instance that does discharge its constraint, and a bare occurrence of a *monomorphic* definition, which is how every definition without universe parameters is written. Mutation-checked: refusing every global occurrence passes the witness and fails that second half.

**The sort clause holds over both head populations.** `Sort::of`'s `Instance` arm answers `Sort::of` of the head and drops the levels, and an `Instance` survives reduction only over a head whose `value_at` is `None`, which is two populations. A *local* is the production-reachable one, and it is monomorphic, so the dropped levels say nothing — `kernel::sort::tests::a_universe_instance_over_a_local_head_takes_the_locals_sort` holds that shut under level vectors of two widths, one of them a width no typing rule would admit. A polymorphic global declared *without a body* — a permanent neutral — is where the level-dropping bites, and it lands on the bare-occurrence refusal above: fail-closed, and an over-refusal, since the correct answer is the instantiated scheme's sort, exactly what `synth_neutral`'s own `Instance` arm computes for the same head inside a spine. It is latent — the module walk `define`s every item with its real body and `Globals::of` records bodies for every `Let` and `Rec`, so only `Kernel::declare`, a public API with no production caller, can build the state — and `a_universe_instance_over_a_bodiless_scheme_is_refused_rather_than_captured` pins the diagnostic so a change here is a deliberate one. A defined scheme never reaches the arm at all, reduction instantiating its body at the instance first: `a_universe_instance_over_a_defined_scheme_classifies_at_the_instances_level` probes the second clause at the sort, `A<u> : Type (u + 1) = Type u` at `u := 1` classifying as `Type 2`, no scheme parameter surviving to be captured. One dynamic seam is reduction's: substitution can replace a bound variable head with an arbitrary value in a hand-built module — a `let`-bound head, which no elaborated term spells since locals are never generalized — and the reducer answers totally by dissolving the instance to the replacement, the same levels-inert reading the local-head fixture pins at the sort. `recheck::universes_tests::a_let_bound_instance_head_dissolves_under_reduction_rather_than_aborting_the_walk` is the regression: the walk returns a verdict where an abort would have lost every other one.
