# Sort formation

**Assumes.** Π into a proposition is a proposition whatever it quantifies over, and a record of propositions is one

**Status.** **argued** and **probed**. The entry exists because the index read as an enumeration of every rule that can admit a term while these two were not in it. Making `Prop` impredicative is what puts Coquand–Paulin's construction in range, so this rule's soundness is not its own: it is the pairing with strict positivity refusing a merely-positive diagonal and with the large-elimination guard. Both halves are graded in [the index](../../soundness.md) and neither says it is holding this rule up, which is how positivity's `a_positive_but_not_strictly_positive_occurrence_is_rejected` came to read as positivity's evidence rather than as impredicativity's — the fixture is the same, the claim it stands behind is this one. The record half needs no guard and had nowhere to say so: a `Type`-sorted component pushes a level, so a record is `Prop`-sorted only when every component is, which is what makes an anonymous Σ non-informative *by formation* where a declared `struct` needs a rule to make it so.

**Probed at both rules, in both directions, and at the two supports the argument names.** The record rule's accepting rung is a `Prop` structure carrying a Σ of propositions, admitted by formation and read through the same non-informativeness test the declaration gate asks — and its carve-out falls the other way, the unit type being refused as informative, which it has to be, since the unit type is what an effect returns and calling it a proposition would erase a value the runtime needs. The Π rule's accepting rung is a field quantifying over a universe into a proposition, with the same quantification into a relevant result refused beside it. The pairing the argument leans on was then attacked where *this* entry lives rather than where positivity's own probes ran, and both halves hold: the large-elimination guard does **not** only check where a declaration is consulted, since it computes formation, so eliminating a two-constructor proposition into a record of relevant components is refused exactly as into a bare one; and strict positivity sees through an anonymous Σ with the lattice intact, refusing a merely-positive occurrence behind one with the same verdict the bare spelling gets, which is what shows the component is analyzed rather than answered opaquely. Two further shapes were run and left uncommitted, both refused as negative: the direct negative behind a Σ, and one in a Π codomain nested in a Σ. `tests::perimeter::a_record_of_propositions_is_a_proposition` is the record rule's accepting rung and `kernel::sort::tests::a_function_into_a_proposition_is_a_proposition` the Π rule's. Three of the seven fixtures reach the kernel as accept/accept rather than as unreachable, which is unusual on that map and is this entry's own asymmetry: its accepting side is one of the few places the second opinion says anything at all. All held; the nulls are recorded so the routes are not re-attacked
