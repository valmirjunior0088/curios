# Foreign wire contract

**Assumes.** A `foreign` declaration's type is drawn from the wire grammar, so an embedder cannot supply an inhabitant of a proposition

**Status.** **probed** at the surface, where the grammar refuses, and separately **probed from Core** with a forged ABI row — the half no surface program reaches, and the one this file had once summarized as "the rule is the parser's and neither checker backs it up". That understated it. The contract is representational rather than checked: a row's signature is a closed enum of wire types with no case for a nominal type, so no forgery can *say* its result is a proposition, and typing constructs a host call's type from that enum rather than reading one off the term. Null result; the note has been corrected
