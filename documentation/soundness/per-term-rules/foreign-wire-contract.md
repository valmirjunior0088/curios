# Foreign wire contract

**Assumes.** A `foreign` declaration's type is drawn from the wire grammar, so an embedder cannot supply an inhabitant of a proposition

**Status.** **probed** at the surface, where the grammar refuses, and separately **probed from Core** with a forged ABI row — the half no surface program reaches. The contract is representational rather than checked: a builtin is an identity whose row is the roster's and cannot be written on the term, a declared row's signature is a closed enum of wire types with no case for a nominal type, so no forgery can *say* its result is a proposition, and typing constructs a host call's type through `curios_core::foreign_signature` rather than reading one off the term. `tests::perimeter::a_foreign_declaration_is_confined_to_wire_types` is the surface half; `curios-cert`'s `recheck/foreign_tests.rs` the Core half, a forged declared row and a builtin held at another row's type both refused. Null result

**What the contract does not claim.** A reply the program reads is a value its row allows: the native adapter refuses its own host's reply outside the row, and the guest holds every reply to its row before reading it — a `Bool` is `0` or `1`, a status one the row answers, a success's payload within the row's checks — so no host, native, browser or embedder, hands the program a value its type does not admit. That is all it establishes. Whether the host told the truth about the outside world — that bytes it accepted reach the file, that an address is the one a name resolves to — is assumed, not checked. The native host states one assumption of its own about its embedder: the process leaves `SIGCHLD` at its default and reaps nothing itself, which is what keeps a child's pid reserved until the host has recorded how the child ended, so `proc/kill` never signals a pid the system has handed on (`curios-runtime`'s `os_child`). The decision behind both checks is [a host operation has one contract, checked at both ends](../../design/toolchain/a-host-operation-has-one-contract-checked-at-both-ends.md).
