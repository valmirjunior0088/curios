# The closed machine

**Assumes.** On a closed, metavariable-free term with no refinement in scope, `curios-core`'s `reduce_closed` computes the same weak-head value the host's recursive strategy would — the same reduct, the same errors, the same divergence-under-budget — so that substituting the machine's answer for the strategy's admits nothing the strategy would not have admitted.

**Status.** **probed**, at the three layers the evidence names, and carrying [the perimeter's shared route](../../design/language/the-soundness-perimeter.md) at its widest: what the folds share for arithmetic the machine shares for beta, iota, delta and zeta on closed terms as well. Why closed evaluation is representation rather than judgment, and what the sharing buys, is [Evaluating a closed term is representation, not judgment](../../design/toolchain/evaluating-a-closed-term-is-representation-not-judgment.md)'s. The counterweight is that three implementations exist — the machine and both recursive strategies, which remain complete evaluators for everything the gate declines — and the differential fixture holds the machine against the strategy directly, at both demands. One divergence has been found and closed there: the machine's run-scoped value memo, keyed on the term alone, served a `rec` projection's forced answer to a plain demand, so the machine beta-reduced a recursive call the strategy leaves folded. The over-reduced answer was the call's own value, so the equation offered was true and merely earlier, and nothing was shown to admit; a projection's plain answer is decided from the shape, ahead of the memo. Whether a run-dependent rigid head could reach the elaborator's witness keying, which reads rigid heads off weak-head forms — [Witness coherence and the orphan rule](witness-coherence-and-the-orphan-rule.md) — is unprobed.

**The gate has two halves, and each is load-bearing.** `accelerable` is the representation half: no local frees and no metavariables, two bits cached per node. A local free could be a binder some in-progress judgment holds assumptions about; a metavariable's meaning is the elaborator's to resolve, not the machine's. No-refinements-in-scope is the judgment half, and it is not an optimization. Inside a match arm, a closed scrutinee *is* the arm's assumed case value, definitionally — checking the `bad()` arm of `match classify(c)` at a literal `c` proceeds under `classify(c) = bad()` even though evaluation says otherwise, because the arm is dead code that still must type. A machine that evaluated there would answer a different question than the judgment asked. Both hosts therefore decline the machine whenever any case equation or recorded refinement is live, and take their ordinary strategy, which consults the refinement stores at every step.

**Substituted terms are evaluated before substitution — except a bare global name, which stays a name.** Arguments, `let` values, and `Induct` payload binds become values first, which is what keeps an accumulator a literal instead of a chain. On closed input the reduct is unchanged by confluence. The exception is the one the strategies already make: they substitute an argument as written and unfold a name only where it is demanded, and a machine that evaluates the name and substitutes its *value* is call-by-value on definitions — on a function-valued global it inlines the definition once per occurrence, so a web of definitions each naming the one before it twice comes back as a graph whose tree is `2^n`, retained by the unfold memo and opened as a tree by the strategy's beta. `kernel::whnf::tests::the_closed_machine_keeps_a_global_argument_as_a_name` holds the two evaluators to the same function at a plain demand with a name in an argument. A substituend whose evaluation *errors* falls back to its unreduced spelling, restoring the strategy's deferral exactly; one whose evaluation exhausts the budget propagates, since spend is never refunded — so the one observable divergence from the strategy is that a program computing something expensive in a dead closed position can newly refuse on *budget*, never on a value. Acceptance moving at an exhaustion point is the budget's own contract, and it can move nowhere but earlier.

**Values may be deeper than the strategy's, except through a fold.** A more-reduced weak-head form is still a weak-head form, and conversion is closed under further reduction. Eta, by contrast, is *not* left to conversion: the machine runs the hosts' own contraction probe, because the elaborator's witness keying reads rigid heads off weak-head forms and a skipped contraction fails the prelude. The licence has one edge, which the memo divergence above found: a *folded recursive spelling* is not a form further reduction improves on. It is the answer the plain demand stops at, so unfolding one is not depth but a different normal form, and the same witness keying eta exists to protect reads a different rigid head off it. Where the licence applies is inside a value, never through a fold.

**`Induct` arms bind payload values directly on both sides**, the kernel's rule; the elaborator's projection binding exists to guard annotation holes a metavariable-free payload cannot carry.

**Evidence.** `curios-core`'s `machine::tests` is the behavioral battery: both recursion encodings and the eliminator form compute the right values under linear budgets, folded spellings survive plain reduction, a dead erroring argument defers where a demanded one surfaces, a non-productive group exhausts, and a closed *neutral* accumulator stays linear through the run-scoped value memo; `a_forced_bare_selection_does_not_answer_a_plain_probe` is the memo-keying regression, with its control on the branch the fix touches — a bare selection is the folded spelling at a plain demand and the member's value at a forced one, so answering a projection from its shape at *every* demand shuts the hole and fails the control, which is mutation-checked. `curios-cert`'s `the_closed_machine_agrees_with_the_strategy` is the differential: the same closed terms put to a machine-bearing kernel and to one with the machine disabled, asserting identical reducts **at both demands**, the battery carrying the forced-then-plain term whose plain half fails without the fix. The fixed prelude is the bulk fixture: every `/std` and `/syn` declaration elaborates and certifies with the machine live in both checkers, and `curios-prelude-archive`'s `kernel_disagreements` walk reports zero. `curios`' `str_literal_cost_measurements` and `kernel_memo_charge_measurements` are the cost-parity fixtures: the two checkers report the same figure for the same closed program, which the sharing makes structural rather than coincidental.
