# Judging only what is not in scope

**Assumes.** A declared name the handed environment already answers for was judged by the walk that built it, so no item's own declaration can arrive under a name already in scope

**Status.** **argued** for the premise, which is still discharged in another crate — the one grade shape on this perimeter that names where its evidence lives rather than what kind it is — and **probed** at the consequence, which is what a fixture in this crate can reach and what the paragraphs below record. `recheck_module_verdicts` decides what to judge by name: `fresh` is `!globals.in_scope(name)`, and it gates the per-item typing judgment, both metavariable-residue passes, and `check_induct_decl` and `check_struct_decl` themselves. So a registry entry arriving under a name the environment already holds is not judged at all. `Globals::in_scope` states the assumption in as many words: an item whose declared names it answers for "was judged by whichever walk built this environment."

**What actually holds it shut is not in this crate.** Mount-set disjointness, checked once in `curios-text`'s `into_core` before discovery, is what makes a collision unspellable; the elaborator's registries then reject a duplicate rather than overwriting one, leaving the existing entry untouched. The text-side check already enumerates what rests on it — the scoped shadowing rule, the registries' duplicate-key rejection, and the `ffi` import namespace — and the kernel's skip is a fourth dependent that neither side lists. That an entry program cannot reuse a prelude name at all is enforced there rather than assumed here: `sys`, `syn` and `std` are mounted as children of the entry's own root, so a program declaring `mod std` is refused as a `DuplicatePublicDeclaration` before the kernel runs. This is therefore the one entry where the second opinion declines to look on the strength of a refusal made by the component it exists to second-guess, and nothing in `curios-cert` asserts that declining is safe.

**The consequence is probed, and the skipped item is not merely unjudged — it is *replaced*, and a registry entry is replaced the other way round.** Every other hand-built module in `recheck::tests` is put to `Globals::default()`, where `fresh` is constantly true and the gate is inert; two fixtures build the collision against a non-empty environment. `a_definition_under_a_name_already_in_scope_is_replaced_rather_than_judged` declares `shadowed` at `Nat` in the environment and at `Bool` in the module, with `reader : Nat = shadowed` judged either way: standing alone the module is refused as a `Mismatch`, and against the environment it is certified with zero refusals, because `reader` was typed against the environment's `shadowed`. The module's own item is never typed and never read, while erasure and every stage below it go on compiling the body it actually holds. `a_declaration_under_a_name_already_in_scope_is_live_but_unchecked` is the opposite resolution of the same collision: `Kernel::declare_induct` runs over `module.induct_decls` unfiltered and *after* `Kernel::seed`, so a colliding entry overwrites the environment's and is live for every rule that reads a declaration, while `check_induct_decl` skips it — an `Oversized` payload refused standing alone is certified with zero refusals. Both are mutation-checked against the gate: forcing `fresh` to answer `true` fails each acceptance with the diagnostic its own control asserts.

**A non-positive declaration under a colliding name is refused by a pass the gate does not reach.** "A non-positive `induct` declared at `Prop` with whatever constructors it likes" is not admitted: `positivity_vectors` runs unfiltered over `Declarations::extending`, whose lookup prefers the module's entry over the base, so a colliding declaration is analyzed exactly as a fresh one is — asserted as the second half of the declaration fixture, which refuses `mk(f : (Shadowed) -> Shadowed)` with the environment in place. What the gate does drop for such an entry is the size condition, the metavariable and universe residue passes, and its universe context's satisfiability.
