# The refinement key

**Assumes.** An equation is a claim about one term, and only a term structurally equal to the scrutinee may be refined to its case value

**Status.** **probed**, and the rule it now states is not the one it stated before: the premise this entry was built on was false, and a module the kernel certified and should not have is the demonstration. `curios-cert`'s `recheck::tests::a_case_equation_does_not_refine_an_occurrence_at_another_universe_instance` is the regression, with `a_case_equation_still_refines_the_occurrence_it_scrutinized` as the mutation-checked control.

**The premise was that a universe argument cannot affect computation, and `Type u` is the counterexample.** Both storing and probing projected the scrutinee through `project_erased_universes`, so two occurrences differing only in their levels collided on one key and each was refined to whatever value the other recorded. Core has no eliminator *over* levels, which is what made the premise sound plausible — but `Type u` embeds a level *in a term*, and a definition carrying its parameter into a constructor payload therefore reduces to genuinely different values at two instances. The projection compounded it: written for the Core-to-Ersd hand-off, where levels really are irrelevant, it rebuilds every `Type` payload at one canonical ground level, so read as a quotient by definitional equality it identified `Type 0` with `Type 1` — the universe hierarchy's whole content.

**What that admitted.** For `induct E : Type 3 | wrap(T : Type 2) end`, an index-only `induct Q : (e : E) -> Type 0`, and `f<u | u + 1 <= 2> : (x : Nat) -> E = (x) => match x | 0 => wrap(Type u) | _ => wrap(Type 0) end`, the kernel certified `coerce : (x : Nat, q : Q(f<0>(x))) -> Q(f<1>(x))` — with **zero refusals** — whenever its body passed through an arm scrutinizing `f<0>(x)`. The arm recorded its equation under the key `f(x)`, and the unrelated stuck term `f<1>(x)` probed onto it and was refined to `wrap(T)`, a case value it was never shown to have. The same coercion with the arm removed and nothing else changed was refused as a `Mismatch`, which is the kernel's own verdict that the two indices are distinct types. The key is now the scrutinee itself, structural equality being the under-approximation of definitional equality that costs nothing to justify.

**No surface program reaches it, and that is why it survived.** The elaborator mints its own levels, so nothing in the corpus spells the two instances this pair needs — the shape the perimeter records repeatedly, where the second opinion was worth nothing because no program puts the question. The elaborator's store keys by the same projection through `shallow_scrutinee`, so **its copy of this defect is open**, unattacked and unrowed here; the two sides agreeing by construction is what kept any differential from observing it, the class that produced the satisfiability defect recorded in [`validate_universes`](../whole-module-passes/validate_universes-inside-zonk_module.md).

**That reach claim was a census and is now a construction, which is what makes the open copy harmless from source rather than merely unattacked.** A hunt put the question directly and found the answer one level down, in `UniverseSolver::finalize`: a parameter is minted only from a declaration's *interface*, and a level reachable only through the body is minimized to a constant instead, no occurrence being able to choose a value for one. The pair this defect needs is two occurrences of one definition at differing instances whose *values* differ, and only a level carried into a payload can make a value differ — `Type u` embedded in a term, this entry's own counterexample. Such a level is body-only by construction, so it never becomes a parameter and the pair has no surface spelling at all. `curios`'s `tests::universes::a_body_carried_level_is_minimized_rather_than_generalized` is the fixture, asserting the parameter count at a definition storing a bare sort against a definition whose level rides a `Type`-sorted parameter as the control that generalization is live in the same program. That does not close the elaborator's copy — it is still open at Core, and a Core-level route or a future generalization rule would reach it — but it moves the surface argument from *nothing in the corpus does* to *nothing can*, and only the second survives a change to the corpus.

**The divergence this entry once justified the projection by is now paid, and it did not come due.** The projection was introduced because comparing verbatim made two such occurrences two keys and the kernel then refused a program the elaborator accepted, which reads as a disagreement about the *rule* and is not one. Removing it restores exactly that exposure — and the whole prelude re-certifies, the corpus compiles, and the suite passes, so what the projection was buying is not something the standard library needs

**What the two sides no longer share is *argument* reduction, and only the elaborator ever had it.** Its store now keys on `shallow_scrutinee` — universe instances erased and solved metavariables materialized, arguments exactly as written — because reducing arguments to record a key made registering a fact cost the fact's own subject: `10 <= Bytes/len(built)` evaluated a hundred-thousand-step accumulation on the way *into* the arm that exists to avoid evaluating it. `canonical_scrutinee` survives as the escalation a probe reaches only after the written spelling missed, so the set of occurrences that match is unchanged and strictly nothing more is admitted. The kernel keeps reducing at registration, and an attempt to align it the same way is what established that the two keyings are not interchangeable: keying the written form there refused a small number of prelude items, each a decided proposition that no longer collapsed to `True`. So the two keyings differ on that axis as well as on the universe one above, and the thing that would close both is a shared statement of what a key *is* rather than a second guess at making one side match the other. That statement now exists for the kernel's half and is the one sentence this entry's **Assumes** carries: a key may identify only terms already definitionally equal. Applying it to the elaborator's half is the open work
