# The refinement key

**Assumes.** Two occurrences of one applied definition differing only in their universe levels are one scrutinee

**Status.** **argued in a code comment only**, which places it beside [Intrinsic fold laws](../per-term-rules/intrinsic-fold-laws-and-the-free-monoid-peel.md) at the weakest position anywhere here, and it is worse in one respect: the widening is in the *admitting* direction. Both storing and probing project a scrutinee with its universe instances erased, so two occurrences that differ only in the levels inference happened to mint collide on one key and each is refined to whatever value the other recorded. The justification is that a universe argument cannot affect computation.

**The reason the rule exists is a measured disagreement, not an optimization.** Comparing verbatim made two such occurrences two keys, and the divergence was doing unearned work: the elaborator would accept a program the kernel then refused over a spelling difference, which reads as a disagreement about the *rule* and is not one. The elaborator's own store keys by the same projection, so the two sides agree by construction — which is also why no differential can observe a mistake in it, the class that produced the satisfiability defect recorded in [`validate_universes`](../whole-module-passes/validate_universes-inside-zonk_module.md). Nothing states the premise beyond the comment, and Core has no eliminator over levels, which is the reason it is probably true rather than evidence that it is

**What the two sides no longer share is *argument* reduction, and only the elaborator ever had it.** Its store now keys on `shallow_scrutinee` — universe instances erased and solved metavariables materialized, arguments exactly as written — because reducing arguments to record a key made registering a fact cost the fact's own subject: `10 <= Bytes/len(built)` evaluated a hundred-thousand-step accumulation on the way *into* the arm that exists to avoid evaluating it. `canonical_scrutinee` survives as the escalation a probe reaches only after the written spelling missed, so the set of occurrences that match is unchanged and strictly nothing more is admitted. The kernel keeps reducing at registration, and an attempt to align it the same way is what established that the two keyings are not interchangeable: keying the written form there refused a small number of prelude items, each a decided proposition that no longer collapsed to `True`. So the divergence this entry opened with is now narrower than it was and no longer symmetric, and the thing that would close it is a shared statement of what a key *is* rather than a second guess at making one side match the other
