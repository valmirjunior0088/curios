# (V)

**Assumes.** Nothing at a `Prop`-sorted type is partial

**Status.** **probed**, and decided in the certifier from the kernel's own typing rather than from the elaborator's hook.

**The refusal splits in two, and both halves are probed.** The position walk asks first whether a position *reaches a definition known partial* — the named route that blames a global — and failing that whether the term is partial in itself, carrying a non-descending `rec` group or an `Exit`. The anonymous route is reachable from no surface spelling, every one being refused during elaboration so the module never arrives; `recheck::tests::an_exit_inside_a_proof_is_refused_with_no_definition_to_blame` reaches it, with `a_proof_carrying_the_unit_value_is_accepted` as its control. An `Exit` is what isolates the route rather than merely reaching it: a non-descending `rec` at a proof type is refused by `check_group`'s own gate before the position walk runs, while an exit meets no gate of its own and types at the unit, so a proposition can carry one and still be well formed

**A member selection is the group node with a tail, so the rule that checks a group *is* the rule that checks an occurrence of it.** A recursive group is checked by verifying every member's declared type, checking every body against it, and requiring descent where a member is erased, and Core has one recursion form: a selection is that same group node with a tail that selects one member. A selection node carrying its own copy of the group, with a rule answering the member's declared type outright, would certify a member at a type its body does not inhabit even where no totality rule is in play, and it is a spelling no program can write. What makes checking possible without diverging is that each member is assumed under a *fresh binder identity* and the bodies opened over those, the discipline elaboration has always used: a member occurrence inside a body is then an ordinary local gated by the scope stack, so certifying a group cannot re-enter the check it is already inside. What is given up is that a node carrying its own group is well-formed standing alone, and a node well-formed standing alone is one no scope can gate. `recheck::tests::a_recursive_member_is_certified_only_with_its_group` asserts both refusals, with `a_member_of_a_legal_group_is_still_accepted` as the control that general recursion at a relevant type stays legal, and stays fast. `kernel::sort::tests::a_groups_claim_about_its_member_does_not_decide_that_members_sort` pins the one arm still reading a group's claim without checking it: the classifier reduces before it classifies, so what it reports is the member body's own sort, and reduction is the whole defence there
