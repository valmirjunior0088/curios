**Status.** **probed**. Every program reaches this pass, and every *was not inferred* diagnostic is the rule firing; what had never been checked is its *extent*. The second clause is where the soundness sits, because it is about what runs after: `check_positivity` and `record_totality` take the module zonking returned, and positivity reads a metavariable opaquely — the spine's children at `Mixed`, never the solution, which does not exist yet — so a metavariable reaching a registry telescope would be analyzed as a hole while whatever it is later solved to is analyzed not at all. Refusal before those passes run is what closes that, not the ordering by itself. The pass's claim that concept metadata and witness markers carry no terms of their own is exact rather than approximate — those fields hold strings, indices and name sets.
