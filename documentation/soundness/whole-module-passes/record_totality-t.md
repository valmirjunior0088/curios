# `record_totality` + (T)

**Assumes.** Nothing reachable from a type position is partial

**Status.** **probed**, at the size-change engine's accepting side conditions and at its coverage.

**The arithmetic rung licenses a decrease on two facts, and both were attacked.** A `Nat` dispatch rules zero out, and so does a *boolean* arm from a comparison against a literal — the second had no fixture although real code descends on it, and was attacked in the three spellings that reach different halves of the reader: the bare intrinsic, the operands flipped, and the comparison behind a definition that only unfolding exposes. The other half is that the right operand must be a *literal* at or above the least value that shrinks, and the two halves fail independently, so both are spelled in `tests::soundness::an_arithmetic_decrease_needs_a_literal_operand_that_shrinks`, with `a_division_by_a_literal_above_one_licenses_the_decrease` as the accepting control. The fact's *extent* is a rung the guard fixtures structurally cannot reach: `a_boolean_guard_that_does_not_exclude_zero_licenses_no_decrease` puts the decrease where neither arm establishes nonzero, so a fact recorded for the whole match rather than for one arm would have nothing to leak, while `a_nonzero_fact_does_not_escape_the_arm_that_established_it` holds both operations to a refusal in the false arm.

**A projection of another group is walked like the nested group it is.** A member reference gets an arm above the general `rec` one, because materializing it as a projection carrying the whole group means descending into the group under analysis would regenerate its own bodies without end. An arm answering for every projection and not only this group's leaves a *different* group's bodies unwalked, so two groups calling into each other through a projection each close to no call whatsoever, and a group with no recursive call is accepted: both classify total while the pair diverges, and at a `Prop`-sorted declared type the forged proof erases to an `unreachable` the runtime traps on. The guard names this group alone, kept finite by a path-scoped entry set rather than by refusing to look; `tests::soundness::a_proof_looping_through_a_projected_inner_group_is_rejected` asserts the refusal, with `a_proof_projecting_an_inner_group_that_does_not_call_back_is_accepted` as the control that entering a projected group manufactures no edge.

**Eight further shapes were run against the structural rung and left uncommitted, all refused**: a growing and a constant successor argument, a swapped parameter pair whose closure is idempotent only at its square, a subtraction of zero, a default arm that refines nothing, a list re-consed from its own arm binders, and a projection through a structure literal. One is worth recording rather than discarding: a self-reference in a *nested* group's member declared type is still an edge, but only incidentally, since what the walk actually reads is the same type sitting in the body lambda's domain annotations — so a member with no lambda is not covered by it.

**The *local* gate's sort test reduces rather than reading a spelling.** `check_group` refuses a group that does not descend when one of its members is erased, deciding which members those are in two halves: whether the declared type is a proposition, asked semantically, and whether it *yields a sort*. Read off the unreduced spelling, the second half misses an ordinary definition whose value is `Type`, so a productive, non-descending member declared through one is assumed at its own type by both checkers — nothing forged, since the whole-module obligation still refuses the *use* of a partial type, but the local claim `check_group` exists to make is lost. The sort test reduces at every step and opens each binder over a fresh identity, answering *yes* on a reduction that fails, which is the refusing direction, and both checkers put the same question to the same closed term. `tests::soundness::a_sort_reached_through_an_alias_still_needs_descent` is the regression, with `an_aliased_sort_that_descends_is_still_accepted` as the control that a member declared through an alias is refused for not descending rather than for the alias.

**This is the one analysis on the perimeter whose blindness *admits*, so its position coverage is a test rather than prose.** Every other analysis turns blindness into a refusal — [the perimeter](../../design/language/the-soundness-perimeter.md) lists them — while call-site discovery contributes no edge for a position it never visits, and a group with no edges is accepted. `curios-analysis`'s `tests/driven.rs::the_walk_reaches_every_child_position_but_the_three_it_documents` plants a nullary self-call at each child position the shared child fold visits and reads the verdict — a nullary self-call is a matrix that is idempotent with no diagonal, so the group is partial exactly where the walk reached the plant and total exactly where it did not. No instrumentation is needed and no fixture need be well typed, because the engine types nothing: it is a total function of post-zonk terms, so an ill-typed plant is a legitimate input. Three positions are whitelisted, and the third is a *separate mechanism* an earlier prose audit had folded into the second: a metavariable's spine, which `zonk_module` refuses before this pass runs; a nested `rec` member's declared type; and the leading lambdas whose domain annotations the member peel discards, which is why every other row is wrapped in a tuple — a plant left at the top of a member body measures the peel instead of the walk. All three are type positions, consumed by β or read only by typing, and an edge the engine misses is dangerous only where it can complete a reduction cycle. What the test establishes is that the set cannot quietly grow, which is exactly what the prose could not. Mutation-checked

**The structural rung reads an application of a constructor payload as the payload.** Without that rule a recursive call through `below(m, lt)`, where `below` is the function-typed payload an arm bound out of `intro(x, below)`, reads as unread — an application's head is a stuck binder no unfolding can move — so a proof recursing along an accessibility predicate closes to an all-unknown matrix and is refused, while the same definition at a `Type`-valued result is accepted, since nothing there consults the verdict. The rule is the existing order extended by one step: the size order reads a value as a finite tree, a function-typed payload is a branching node whose children are its applications, and the premise that the payload *is* a finite tree is what (T) and (V) already guarantee wherever the verdict is consulted. The head is looked up in a set the arm enters and leaves exactly like its refinement, so a parameter or a lambda binder applied to anything still reads as unread. `tests::soundness::a_call_through_a_constructor_payload_descends` is the accepting probe at a `Prop`-sorted result, with `a_call_through_a_parameter_bound_function_does_not_descend` as the control that keeps the rule keyed to the arm; `curios-analysis`'s `tests/driven.rs::an_application_of_a_constructor_payload_descends_only_from_its_arm` puts the same pair to the engine under the kernel, and `totality/tests.rs::an_application_of_a_constructor_payload_grades_below_the_constructor` pins the shape read itself.
