# A host operation has one contract, checked at both ends

**Decision.** Every builtin host operation is one typed row of `curios-abi`'s `for_each_host_op!` table, and the row is its whole contract: the Rust signature the host implements, operands arriving owned and the reply typed as its outcome — `Result<Handle, Failure>` for an open, `Result<Option<Vec<u8>>, Failure>` for a read, `Option<Vec<u8>>` for a lookup, `Termination` for exit — its `/sys` placement, the failures it may answer beyond the operating system's, what its operands must hold before the host is asked, and what a success answers to, with the clauses its types cannot say in the rustdoc beside it. A term carries a builtin's identity and nothing else, and both checkers type the call through the same `Signature` an intrinsic is typed through.

The contract is enforced where each side meets the wire. The native adapter decodes each operand, refusing a malformed one — a closed code outside its table, a `Bool` past `1`, interest a guest cannot ask for — checks the row's requirements, calls the host and holds the reply to the row; a violation refuses the invocation and nothing panics the embedding process. `curios-emit` holds every reply to its row where the guest receives it, whichever host answered, and refuses a violation as `host_reply`. `/sys` reads each outcome as ordinary code over `/sys/Io/bind` and `/sys/Io/pure`, the status before any payload: a fallible row answers `Result(Nat, T)`, a read `Result(Nat, Option(Bytes))` with `none` at its end, a lookup `Option(Bytes)`, and a spawn the child with each of its streams an `Option(Handle)` present exactly when it was piped. `/std` names the failure through `Io/Error/of_result`. The browser holds a program's own `foreign` rows to the signatures `compile` hands back beside the module. Every host keeps one behavior per operation — a stream used against its direction fails with `EBADF`, a resource that cannot do what was asked with `not_found`, a poll reports a failed handle as `err` for its slot — and how the native host keeps them without waiting is [Only a fiber waits](only-a-fiber-waits.md).

**Rationale.**

- **A contract stated once cannot drift between its consumers.** Hosts that agree on every signature can still behave differently, and a status beside a placeholder payload is interpreted again by every `/std` wrapper, each free to read a failed open's empty token as a handle. A reply typed as its outcome cannot answer a success without its payload, or a failure with one.
- **Each end guards what the other cannot see.** The native adapter catches its own host's fault beside the call that made it; the guest cannot know which host it runs under, and its receiving end is the one place every host's reply passes. Neither establishes that a host told the truth about the world, only that a program never holds a value its type does not admit ([The foreign wire contract](../soundness/effects/foreign-wire-contract.md)).
- **Reading the outcome in `/sys` makes the status the first thing read**, once, in code the kernel certifies, and leaves `/std` its domain vocabulary — `Io/Error`, `Io/Chunk`, modes, readiness.

**Rejected.**

- **Host vocabulary in `/sys`, or generated semantic Core operations**: the guest outcomes need only `Option` and `Result`.
- **One codec chosen by the guest result type**: a lookup's absence and a read's end cross by different conventions, and the operation's contract chooses.
- **A defensive `/std` over unchecked replies**, validation repeated per caller and evaded by a discarded result; **a typed host return as the whole validation**, which leaves bounds relative to a request and closed codes unenforced.
- **Raw status records beside the outcomes**, two interpretations of one operation; **a general constraint schema**, where a closed set of outcomes and named checks is what the roster needs; **guest sums on the wire**.
- **Invalid tags read as defaults, failures as successes, or polling errors as inactivity**, each erasing a distinction a caller relies on; **a refusal that promises rollback or retries on its own**, when work may already have happened.
- **A builtin's row carried on every term**, which each of equality, interning, linking and cache admission would have to check.
- **A spawned stream read by its token**, which keeps the empty token alive in a success position, and **a call per stream**, which leaves a started child unguarded when one fails.
- **The browser's signatures in a custom section**, a second encoding of rows that already travel beside the program; **`/sys`'s reading built inline from the `Io` intrinsics**, whose unfoldable descriptions survive pruning into every program.
