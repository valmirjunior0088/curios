# Only a fiber waits

**Decision.** A `/std` operation whose every row answers at once — a file's open, read, write and close, the filesystem and terminal rows, a child's spawn, a socket's open — is declared in `Io`; only one that waits on a peer or a timer is declared in `Async`: a socket's connect, a read or write that can park, a child's wait, a sleep. A synchronous bracket that registers with the scheduler has its `Async` form named beside the `Io` one — `File/with` and `File/with_async`, `Tty/with_raw` and `Tty/with_raw_async`, `Child/with`. A type read and written in chunks satisfies `/std/Async`'s `Read` and `Write` at the monads it can honour — a file and the standard streams at `Io` and `Async`, a socket and a child's pipe at `Async` alone — so the region's monad selects the witness, and reading a socket in an `Io` region is refused by resolution. `Read(Io, Io/Input)` polls standard input with no timeout, so `/std/read` is `Io` and a program wanting one line pays for no scheduler.

The host never waits on a peer. Every handle whose progress another party decides — a socket in any state, an accepted stream, a pipe to a child, standard input — is non-blocking from the moment it exists, and a row that cannot progress answers `would_block`. `connect` is two rows, the second reading the outcome once the socket polls writable; a TLS session is filed without a handshake, which the reads and writes that follow drive. Every write is one attempt that reports how much it accepted, a flush row hands on what the host still holds, and close never waits. `Handle/poll` is the one row on which the host sleeps.

Fibers coordinate through write-once cells and positive-capacity channels in the guest heap, whose operations return `Io` descriptions. A cell publishes one answer. A channel's nonblocking push and take each commit and report their own outcome — `Push` taken, full or closed, `Take(A)` an item, empty or ended — and closing preserves queued items for draining; capacity zero is refused by a decided bound. Readiness observes a condition: `/std/Async/Wait` is opaque, its factories cover host readiness, elapsed time, a filled cell and readable or writable channel ends, and the scheduler scans its private probes whenever it becomes idle, before blocking or declaring deadlock. One claim cell shared across a park's alternatives permits exactly one enqueue, an offer retries its committing operation after waking, and selection keeps list-order priority. Runnable jobs, registrations, sleepers and probes are values threaded through the scheduler; a sender that needs acknowledgement sends a reply cell and waits for it.

**Rationale.**

- **`Async` promises that a value may park its fiber, and `Io` that it describes host work and nothing more.** A tool that reads a configuration file and exits has no fiber to park, and `Lift(Io, Async)` sequences any `Io` operation inside a fiber, so declaring each at its honest tier loses nothing.
- **That edge is correct only if no `Io` row can block on what a fiber waits for.** `/std/Async` drives every fiber from one host thread, so a row that sleeps on a peer stalls them all, silently — as a TLS handshake run inline on a socket the scheduler has made non-blocking hangs. Making non-blocking a property of the host removes the class: the library cannot forget what it never has to do, and the mock host can script `would_block` at every row.
- **A close that flushes waits on the peer or drops what it cannot send**, and a write that loops until the buffer is taken cannot report the prefix it wrote before a failure.
- **Observing present conditions needs no bookkeeping**, where a notification list can outlive the selection that registered it and count an abandoned receive as a willing receiver. Bounded storage makes backpressure explicit, and a reply cell states exactly which event a sender needs. [The emitter](../../../curios-emit/README.md#cells-and-channels-occupy-the-guest-heap) owns the ring layout and [the continuation IR](../../../curios-cont/README.md#mutation-hides-behind-instruction-atomicity) the operation sequencing.

**Rejected.**

- **Everything effectful in `Async`**, which makes `Async` mean "touches the host", costs every synchronous program a scheduler and hides which operations can stall; **one bracket generic over the monad**, since scheduler registration is not expressible in `Io`.
- **A `set_nonblocking` row the library calls after every open**, a no-op on stdin and files that leaves `connect` and the handshakes blocking; **timeouts as socket options**, where `Async/timeout` bounds any wait from the fiber that waits; **a blocking `connect` for local peers**, a distinction that is the kernel's to make; **a handshake run with the socket briefly blocking**.
- **A general rewritable cell beside the write-once one**, two mutation vocabularies; **a queue of write-once cells**, which retains consumed chains through old ends; **unbounded queues**, which give up the storage bound; **capacity-zero rendezvous**, which entangles buffering with receipt.
- **`Bool` for push and `Option(A)` for take**, which merge outcomes a later observation cannot recover atomically; **public arbitrary probes**, which permit effects during an idle scan; **a scheduler intrinsic probe**, compiler vocabulary where private library observations suffice.
