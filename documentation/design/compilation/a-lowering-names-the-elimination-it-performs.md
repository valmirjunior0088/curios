# A lowering names the elimination it performs

**Decision.** Where a level below Core takes a sequence apart, it names the elimination as a form of its own rather than open-coding it out of indexed reads. `curios-anf`'s is `UnconsSequence`, a case split, which is what erasure makes of Core's sequence match, and it reaches `into_cps::emit_peel`, the one implementation of taking a sequence apart, which emits a read of the head and the suffix after it — `curios_cps::Intrinsic::BytesRest`/`ListRest`, `(seq, start) -> seq`, naming no count. A loop over a sequence is no elimination of its own: it is a tail recursion through the case split, as erasure builds `List/fold`'s, whose suffix the CPS optimizer then holds as a window (`curios-cps`'s `optimize/fields.rs`), or a worker reading each element by an index below a length it measured itself, as the inversion of a structural recursion builds one ([`curios-anf`'s README](../../../curios-anf/README.md#a-structural-recursion-is-a-loop)). No compiler pass derives a window's extent from a length it was handed. A new elimination form is added to `curios-anf`'s `optimize/rebase.rs` tail-position dispatch forms and to `curios-cps`'s `WindowFamily::of`, whose pattern lists no exhaustiveness check reaches.

**Rationale.**

- **The partiality is lowering's, so the form must be too.** Core's free-monoid eliminator is total and the certifier checks a match as a match; implementing it from `get` and `slice` introduces bounds nothing below Core can state, since erasure deletes propositions and `curios-anf`'s verifier checks arity rather than values.
- **Open-coding twice is two conventions.** A peel open-coded by each pass that takes a sequence apart can disagree about a convention neither states, over operands that are `Nat` either way, and then the workspace builds, the certifier accepts the library, and every program touching a string traps — the case of a window respelled as a start and a count under two such copies. A loop that peels through the case split shares the one peel, and a worker that reads by index builds no suffix, so neither states a second convention.
- **A suffix that takes no count has nothing to derive**, so the derivation happens where the length lives — the rope helper's `len` field and the virtualized region's `length` — as a fact about a value in hand.
- **A pattern list is not checked.** A form missing from `rebase.rs` leaves a sequence recursion non-tail, a frame an element where a loop takes none, silently; `tests::runtime::loop_::arena_deferred_context_recursion_is_stack_safe_at_depth` holds the `UnconsSequence` case, by the worker it finds in the optimized program.
- **What remains is off the soundness board**: an inverted worker's `1 <= i <= len` is a runtime fact trapped rather than checked, detected only by the cross-stage corpus in `curios`.

**Rejected.**

- **A suffix operation without the control form**, which leaves each lowering open-coding a peel out of two operations.
- **A form of its own for a loop over a sequence**, a fold node the lowering builds a loop from: a loop below Core is a tail call, which the CPS optimizer already makes one, so the form is a second elimination for every pass to read and the lowering to implement, its peel the second copy of the convention.
- **Lifting the case split above erasure**, so its reads become Core terms the certifier checks: the peel needs `1 + (len - 1) <= len`, a `/std` lemma the compiler would reach through a registry slot to prove — a compiler that constructs proofs, the defect a reducer that does is.
- **Checking below erasure**, where a window's bound is a runtime length and the trap is the check.
- **Emitting window fields directly where a loop is built**: regions are found by a whole-module walk after the module is built, so the lowering must emit something concrete for the pass to recognize.
