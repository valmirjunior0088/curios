# A value costs when it is kept, not when it is named

**Decision.** A value's representation is a compiler fact decided by what its consumers do, never by how it is spelled, and a representation gain is a class every consumer of the representation shares, never a blessed type. An immutable aggregate whose fields travel through compiler-controlled control flow does not pay for a heap object, which `curios-cps` delivers three ways on one recorded representation: continuation scalar replacement turns a join parameter every flow reaches as one aggregate's construction into that many field parameters, loop headers and backedges included; window virtualization carries a rope through a walk as `(base, end, length)`, counting down to its end so that every field is a length the representation holds in a word read unsigned, each slice becoming monus arithmetic behind a `WindowExtent` guard that keeps the bounds trap at its original evaluation point, answered where the arm it stands in has already decided the bound (`answer_window_guards`); and a non-escaping known function takes its aggregate parameters as fields, with no wrapper, since every call site is one the rewrite reaches. Each split is a `FieldGroup` on the module, which the verifier holds to its continuation's parameters as it holds arities. A scalar crosses the same boundaries in a register: a known function's parameters and its tail-call class's results are held at the carriers every flow reaching them agrees on, as a loop header's are ([`curios-cps`'s README](../../../curios-cps/README.md#representation-is-decided-wherever-every-party-is-visible)). A list is flat at birth only where `curios-anf`'s sequence-usage census, computed inside the door where family identity exists, marks a constructor field's values indexed-only, or where the demand lattice proves a local result's every read indexing-shaped; the fact is spent as an internal `ListSettle`, semantically the identity, and everything growth-shaped keeps the lazy rope. A construction beside a dying value of its own shape, which an impure program would mutate in place, rebuilds that value in place only where the compiler has proved it unshared and dead there — a fact of the whole module, proved at compile time and never tested at run time, so no count and no flag rides a value — and is left to the host collector everywhere else; how the native heap absorbs what is left is [`curios-native`'s README](../../../curios-native/README.md)'s. `/std` writes what it rebuilds linearly: a function that takes a node apart and hands a part of it on builds the node again on every path rather than returning it, so the proof reaches every level of the descent.

**Rationale.**

- **A class pays off for every consumer**, where a blessed type pays off for one and mints an abstraction the optimizers must know about. `/std/Map`'s cost on `spines` is three classes — per-element read dispatch, scatter-then-gather construction, and boxed small packed values ([A field is declared at the carrier its shape names](a-field-is-declared-at-the-carrier-its-shape-names.md)) — and the library's own reshape, judged on its own probe, is declined (`map_wall_spines_slope`).
- **Whether a sequence is read by index or grown by append is a fact about its consumers**, which the compiler sees and a spelling cannot promise, so every idiom keeps the complexity it reads as.
- **Admission composes one backward fact with one forward one.** The demand lattice says every use on every path is a field read or an eligible transfer; the origin lattice says every incoming flow is a construction of one shape, with boundaries — resume parameters, escaping functions' parameters, the entry — stated by injection, so a surviving bottom means unreached. A window needs no origin fact, since any rope opens as its own whole window; its region is declined whole at any hostile use.
- **Materialization is exact.** A split rebuilds the aggregate at the continuation's head, and projection forwarding and dead-binding elimination erase the rebuild precisely where nothing needed the object.
- **The decision survives only where every pass can see it.** Erasure has exposed the fields and CPS still knows continuations and direct callees, which Wasm emission loses; Binaryen sees the module after signatures and helper calls hide the flows, and does not run in the browser path. GHC's unboxed tuples in Core, Lean's explicit boxing and MLton's flattening as data are the same lesson.
- **Measured**: the emitted `/std/Str/fold` body carries no accumulator tuple and no slice call, and the idiomatic and hand-flattened accumulator spellings compile to identical counts (`curios`'s `tests::codegen` ladder, census and mirror).
- **Churn the proof does not reach is the collector's**, as the WasmGC mainstream has it — V8's porting guidance, dart2wasm and Kotlin/Wasm ship no reuse machinery. Natively, the churn workloads' cost is mostly the collector recopying survivors, which sizing the semi-space removes (`tests::codegen::churn`). The death-birth census (`death_birth_census`) finds 508 of 2 130 row sites beside a dying value of their row and 359 of 843 tuple sites beside one of their width, every tuple pair across a frame, the dying value arriving as a parameter and none constructed in the same function (counted at `f5bfe7f60`): the shape a rebuild of a parameter reaches and no reuse within a frame does.
- **A proof costs nothing at run time.** On an engine-owned heap a count frees nothing and is bought only as a test of uniqueness, while a proof leaves the value as it is; what it admits is what a rebuild is worth, a construction a level of a persistent map's descent. Timed at `12cc732e7` against the compiler released at `fe6820d96`, release, x86-64 Linux, seven interleaved rounds of the time at N less the time at N = 1, median and span, each pair printing one answer: `programs/spines` at N = 2,000,000 takes 1,011 ms [1,009–1,025] before and 710 ms [690–715] rebuilding natively, and 891 ms [888–900] and 655 ms [652–659] under V8, Node 26.4 calling the `start` of the page `compile --target browser` writes with the module's bytes, a process a run; a map threaded once through a loop inserting the keys 1 to 500,000 takes 703 ms [700–725] and 132 ms [129–133]. Mercury's compile-time garbage collection proves reuse from structure sharing and liveness and calls a reuse version where a caller shows its argument dead ([Mazur et al., 2001](https://arxiv.org/abs/cs/0110037)), Shankar's analysis compiles PVS's aggregate updates destructively ([Shankar, LOPSTR 2001](https://researchr.org/publication/Shankar01/bibtex)), and Lean's and Koka's reference counts reuse the same shape tested at run time ([Ullrich and de Moura, IFL 2019](https://arxiv.org/abs/1908.05647); [Reinking et al., PLDI 2021](https://www.microsoft.com/en-us/research/publication/perceus-garbage-free-reference-counting-with-reuse-2/)).
- **Writing linearly is what lets a proof reach.** A function in place is one linear in what it takes apart, as FP² characterizes it ([Lorenzen, Leijen and Swierstra, ICFP 2023](https://www.microsoft.com/en-us/research/wp-content/uploads/2023/07/fip.pdf)): a function that returns the node it took apart after handing a part of it to a call that may rebuild it shares that part on every path, and every peer — counts, structure sharing or uniqueness types — refuses its reuse alike. Rebuilding the node on every path costs a shared map one construction where its insert parts a level — the same loop looking each map up again after its insert takes 765 ms [756–776] before and 815 ms [811–817], timed as above — and makes the descent's every level a rebuild where the map is used once.

**Rejected.**

- **Relying on Binaryen**, too late, blind across helper calls and absent from the browser; **source-level unboxed types**, a spelling promising what the analysis should earn; **threading bare fields by convention**, which the return protocol's width-two floor shows is re-decided every round.
- **Eager mixed literals**: `[..acc, x]` is an O(1) append while `[..acc, x, y]` would copy, so a one-element edit flips a builder loop from O(N) to O(N²). **A `List/settle` surface form**: a representation verb coupling source to the backend, handing the optimizers an identity they cannot delete.
- **Reference counts, a sticky sharing bit, regions or arenas**: a count on an engine-owned heap frees nothing and is bought only as a uniqueness test, with dup/drop traffic, mutable payload fields and an undercount corrupting a shared value; regions are inexpressible on WasmGC; owning allocation in linear memory forfeits the engine collector and the browser. Perceus is the comparator, never the mechanism.
- **A uniqueness the user writes**, as Clean's and Futhark's types, OCaml's modes and Koka's `fip` have it: a spelling promising what the analysis should earn, as a source-level unboxed type would. **A whole-program analysis held to no budget**: Roc's Morphic slowed its compiler and measured within a few percent of none ([Roc's discussion](https://roc-lang.github.io/zulip-export/stream/395097-compiler-development/topic/remove.20morphic.3F.html)); this proof runs over one module, its cost measured against a budget its specification states.
- **Inferring which result of a call left an argument unwritten**, so a function may return the node it took apart after handing a part of it to a call that rebuilds it on some results alone: no peer does it, and it would serve one function's shape where writing that function linearly serves every analysis.
- **Static array-scoped reuse**, whose builder population is not copy-bound — the rope amortizes a builder to one node per extend and one fill at force time; **construction coalescing and tail-modulo-cons**, whose shapes measure zero.
