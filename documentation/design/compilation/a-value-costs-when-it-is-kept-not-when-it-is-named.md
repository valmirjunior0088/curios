# A value costs when it is kept, not when it is named

**Decision.** A value's representation is a compiler fact decided by what its consumers do, never by how it is spelled, and a representation gain is a class every consumer of the representation shares, never a blessed type. An immutable aggregate whose fields travel through compiler-controlled control flow does not pay for a heap object, which `curios-cont` delivers three ways on one recorded representation: continuation scalar replacement turns a join parameter every flow reaches as one aggregate's construction into that many field parameters, loop headers and backedges included; window virtualization carries a rope through a walk as `(base, offset, length)`, each suffix slice becoming offset arithmetic behind a `WindowExtent` guard that keeps the bounds trap at its original evaluation point; and a non-escaping known function takes its aggregate parameters as fields, with no wrapper, since every call site is one the rewrite reaches. Each split is a `FieldGroup` on the module, which the verifier holds to its continuation's parameters as it holds arities. A list is flat at birth only where `curios-ersd`'s sequence-usage census, computed inside the door where family identity exists, marks a constructor field's values indexed-only, or where the demand lattice proves a local result's every read indexing-shaped; the fact is spent as an internal `ListSettle`, semantically the identity, and everything growth-shaped keeps the lazy rope. The compiler carries no reuse machinery: a construction beside a dying value of its own shape, which an impure program would mutate in place, is left to the host collector, and how the native heap absorbs it is [`curios-runtime`'s README](../../../curios-runtime/README.md)'s.

**Rationale.**

- **A class pays off for every consumer**, where a blessed type pays off for one and mints an abstraction the optimizers must know about. `/std/Map`'s cost on `spines` is three classes — per-element read dispatch, scatter-then-gather construction, and boxed small packed values ([A field is declared at the carrier its shape names](a-field-is-declared-at-the-carrier-its-shape-names.md)) — and the library's own reshape, judged on its own probe, is declined (`map_wall_spines_slope`).
- **Whether a sequence is read by index or grown by append is a fact about its consumers**, which the compiler sees and a spelling cannot promise, so every idiom keeps the complexity it reads as.
- **Admission composes one backward fact with one forward one.** The demand lattice says every use on every path is a field read or an eligible transfer; the origin lattice says every incoming flow is a construction of one shape, with boundaries — resume parameters, escaping functions' parameters, the entry — stated by injection, so a surviving bottom means unreached. A window needs no origin fact, since any rope opens as its own whole window; its region is declined whole at any hostile use.
- **Materialization is exact.** A split rebuilds the aggregate at the continuation's head, and projection forwarding and dead-binding elimination erase the rebuild precisely where nothing needed the object.
- **The decision survives only where every pass can see it.** Erasure has exposed the fields and CPS still knows continuations and direct callees, which Wasm emission loses; Binaryen sees the module after signatures and helper calls hide the flows, and does not run in the browser path. GHC's unboxed tuples in Core, Lean's explicit boxing and MLton's flattening as data are the same lesson.
- **Measured**: the emitted `/std/Str/fold` body carries no accumulator tuple and no slice call, and the idiomatic and hand-flattened accumulator spellings compile to identical counts (`curios`'s `tests::codegen` ladder, census and mirror).
- **Churn is the collector's**, as the WasmGC mainstream has it — V8's porting guidance, dart2wasm and Kotlin/Wasm ship no reuse machinery. Natively, the churn workloads' cost is mostly the collector recopying survivors, which sizing the semi-space removes (`tests::codegen::churn`). The death-birth census (`death_birth_census`) finds 509 of 1 168 constructions beside a dying value of matching width, every one across a frame, the dying value arriving as a parameter, so no intra-function reuse reaches it.

**Rejected.**

- **Relying on Binaryen**, too late, blind across helper calls and absent from the browser; **source-level unboxed types**, a spelling promising what the analysis should earn; **threading bare fields by convention**, which the return protocol's width-two floor shows is re-decided every round.
- **Eager mixed literals**: `[..acc, x]` is an O(1) append while `[..acc, x, y]` would copy, so a one-element edit flips a builder loop from O(N) to O(N²). **A `List/settle` surface form**: a representation verb coupling source to the backend, handing the optimizers an identity they cannot delete.
- **Per-tag call-pattern specialization of the scan state**, which the specializer declines on its growth budget (`step_specialization_extent`).
- **Reference counts, a sticky sharing bit, regions or arenas**: a count on an engine-owned heap frees nothing and is bought only as a uniqueness test, with dup/drop traffic, mutable payload fields and an undercount corrupting a shared value; regions are inexpressible on WasmGC; owning allocation in linear memory forfeits the engine collector and the browser. Perceus is the comparator, never the mechanism.
- **Static array-scoped reuse**, whose builder population is not copy-bound — the rope amortizes a builder to one node per extend and one fill at force time; **construction coalescing and tail-modulo-cons**, whose shapes measure zero and need the mutable field the representation lacks.
