# Depth is bought with stack, not with hand-rolled frames

**Decision.** A walk over data-shaped depth — a spine erasure generated, a chain of metavariable solutions, a module's block nesting — recurses inside `curios-utilities`'s `recurse` bracket, which grows the native stack rather than aborting, and is not rewritten into an explicit frame machine. Each stage's entry point takes its first segment once, through `grown`, so every `recurse` beneath sees the reserve its figures were sized for on any thread. The exceptions are few: a trampoline that makes a sequence iterative (`Step`, `Reduce::Continue`/`Break`), a shared driver whose value is a seam (`Term::walk`), a document interpreted after it is built (`curios-print`'s `Printer`), and the closed machine, the one place frames are hand-rolled on purpose ([A reduction step costs what it builds](../soundness/a-reduction-step-costs-what-it-builds.md)).

**Rationale.**

- **The checkers' reduction is written twice to be read side by side**, and two hand-rolled state machines are far harder to diff than two recursive strategies. A machine also re-implements what the call stack does — scope entry and exit, sibling order, unwinding — each as a comment arguing it still holds, and a lapse is silent: a typing worklist that reaches child positions through inference alone drops the checked rules from every one of them and fails nothing the prelude exercises ([Checked rules at deferred child positions](../soundness/introduction/checked-rules-at-deferred-child-positions.md)). The closed machine costs neither: both strategies stay complete and diffable, and it evaluates nothing either strategy's judgment reaches.
- **Where the first segment is taken matters.** On a thread smaller than `recurse`'s reserve, every Rust test thread among them, the bracket would map and unmap a segment around every outermost guarded call, which costs re-erasing the standard library more than the walk does.
- **A machine accumulates frames, a loop accumulates results.** A loop's results fold afterwards with no effects, as the elaborator's `let` gathers triples and folds them into `Term::let_`. A machine's elements mirror a function's locals and carry a reverse phase with effects. An element mirroring locals is the tell; a reverse phase alone is not, because an undo record has one too.
- **An undo record stores what was destroyed, never what can be derived** — the refinement a scope overwrote, a node's distance before relaxation moved it — since a derived key parked for a subtree's extent is memory held for nothing — in `curios-cont`'s scoped CSE, a packed literal's bytes per pending retraction.

**Rejected.** Defunctionalizing for memory: `recurse` grows rather than aborts, a term's acceptance should not depend on the host's stack, and what bounds reduction's depth is the budget, which charges each new peak of it the native frame it takes.
