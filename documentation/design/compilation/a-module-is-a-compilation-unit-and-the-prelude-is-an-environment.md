# A module is a compilation unit, and the prelude is an environment

**Decision.** A `Module` holds the items its own compilation produced. What precedes it reaches each stage as an *environment* the stage is seeded from, never as items spliced into the front of the module — `Globals` at the certifier, `Established` at elaboration, `Resumed` at erasure, `Scoped` at the lowerer — so no stage carries an index, a delimiter or a caller contract about where one region of a module ends and the next begins. A compilation is a set of units folded over a dependency order, each stage taking its predecessors borrowed (`curios-unit`'s `Predecessors`) rather than one merged map, and an archive is a unit's serialized form, one per root, as a `.vo`, an `.olean` and a `.hi` are. `/sys` and `/std` are two units in that order, first in every product's scope. `compile_entrypoint` cannot tell which unit is `/std`: `curios-pipeline`'s `standard` module alone names the fixed prelude, withholding the archived `/std` for a package named `std` that is the fold's first unit. Every other unit arrives from a manifest that declared it; no flag mounts one. A declaration's root — what privilege and coherence are decided by — is the mount whose prefix owns its name, found by longest match, never a value carried beside the name, and two units claiming one prefix are refused.

**Rationale.**

- **Every stage builds the environment anyway**: erasure re-seeds its predecessors' Core beside the arena it resumes over, the certifier defines their items into a kernel, elaboration re-seeds its own. Splicing makes each stage also depend on those items sitting at the front of the module — a claim each could state and none check — which takes a delimiter index, a `checked_from` offset, provenance queries recovering what a merged registry discards, and four entry points where there is one judgment. Coq's `Require`, GHC's `.hi` interfaces and Lean's replay from the environment its imports provide do the same.
- **A root is a prefix, not a stamp**, which is what makes the orphan rule work between two ordinary units: were every ordinary root one enum variant, two packages would compare equal exactly where the rule is needed. No stage derives a root from a name's spelling.
- **A scope with no declaration behind it is one nothing can state the dependencies of**, which is why only a manifest mounts a unit.

**Rejected.**

- **A root as an index into the compilation's root list**, rustc's `cnum_map` reinvented: an identity meaningful only in the compilation that assigned it, stamped into an artifact another reads. `curios_core::validate_stored_identities` refuses any such identity at every seam a unit is written, and what a cached one may be believed on is [Cached verdicts](../soundness/cached-verdicts.md)'s.
- **Resolving a mount collision by precedence**: Swift did, and then needed `::` module selectors to say what had become unsayable.
- **Checking the positional claim instead of removing it**, sound and the wrong direction, since a wart that stops hurting stops getting removed; **carrying the boundary on `Module`**, which makes it the elaborator's claim — the kernel raises its own binder counter past each local as it enters the context rather than believe a floor a caller computes.
