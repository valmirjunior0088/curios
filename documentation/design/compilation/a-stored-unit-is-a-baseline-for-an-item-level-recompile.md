# A stored unit is a baseline for an item-level recompile

**Decision.** A unit the store holds is a baseline, not a hit or a miss. `Cache::get` returning a unit whose record agrees is the empty case: reuse everything. When the record disagrees, the slot still holds a unit compiled from an earlier text of the same sources, and a *question* takes it as the baseline for an item-level recompile (`Cache::baseline`, `curios-pipeline/src/recompile.rs`): the fold lowers the unit whole, diffs the lowered items against the baseline's by declared name, takes the reverse transitive closure over the baseline's elaborated graph (`Module::reaches`: mentions, construction heads and registry-entry names) of every changed, added or removed name, reads every item outside it where the baseline holds it, as a unit in scope is read, elaborates the closure, each declaration deciding its own vectors, totality and erasure obligations as it is published, reassembles one `Module`, puts it in the order a module is stored in, and hands it to the kernel with the baseline whole, which adopts the baseline's verdict on each declaration that stands by its own record and judges the rest ([Cached verdicts](../soundness/cached-verdicts.md)), and erases the closure, every other item's erased form being the baseline's ([`curios-unit`'s README](../../../curios-unit/README.md#an-erased-form-is-its-items)). The archived `/std` is the baseline of the package named `std`, offered through the same `Cache` seam. A build recompiles whole on a miss. A unit compiled over a baseline is filed as any other, since it is stored as the bytes a whole compile of the same text stores. The reassembly is handed what the closure's elaboration dropped — a dependent withheld behind a refused or unparsed item records no refusal of its own — and leaves it out exactly as a whole compile does. A module is parsed once per path and text, at `RootSource::load`.

**Rationale.**

- **An editor asks about a file on every edit**, and a whole-unit answer costs a whole compile of the unit — for the standard library, every declaration it holds, per keystroke. Every mechanism existed for whole units: a predecessor is read where it stands and never re-checked, the kernel passes over a declaration its environment holds, the dependency graph exists after elaboration, a stored item is position-free, and a `Unit` holds both the lowered and the elaborated module.
- **The reverse closure contains every item whose result can differ.** Every fact an item's elaboration consumes from outside itself arrives through a name it reaches — a definition's type and body, a registry entry, a witness head, a derivation's vocabulary — and conversion unfolds through what it names, so the closure is transitive. Ordering does not enter: a goal is answered from every witness the unit declares, each known by the key its signature spells, the local tiers see binders only, and an item elaborates after what it reads wherever either is written ([A declaration is a function of what it reads](a-declaration-is-a-function-of-what-it-reads.md)). The diff compares lowered items modulo a bijection on the universe metas and holes lowering numbered (`Term::equal_modulo_metas`), so an inserted declaration leaves the items after it reused, and the graph is `reaches` rather than `mentions`, since constructing a struct or matching a variant depends on the declaration as naming it does.
- **Evidence holds the claim**: `curios-pipeline/src/tests/incremental_tests.rs` compiles each fixture whole and over a baseline and requires the elaborated modules to agree structurally, item by item and on every registry table and the tests (`assert_modules_agree`), and the two units to be stored as the same bytes (`assert_stored_alike`), which is what lets one be filed in the other's place; `curios-pipeline`'s `std_recompile_reproduction` holds the standard library to the same for a leaf and a hub. The predicate is equality: a declaration is lowered and elaborated in identities and a state of its own, so one elaborated over a baseline is the one a whole compile elaborates, down to the spelling of a solved implicit and of a proof the elaborator wrote ([A declaration is a function of what it reads](a-declaration-is-a-function-of-what-it-reads.md)). `curios-pipeline`'s `std_recompile_closure_census` measures the closure and each phase's time on the standard library, for a leaf edit — a declaration added to `/std/Nat`, whose closure is itself — and for a hub, `/std/Bool/not`'s body, the worst case by construction.
- **The closure is no part of the trusted base.** Which of the baseline's verdicts stand is the certifier's decision, from the reads its own walk filed, and the closure decides only what is elaborated and erased again: a declaration it wrongly leaves out is judged again where what it read has moved, and is stored as the baseline elaborated it ([Cached verdicts](../soundness/cached-verdicts.md)). What a declaration is judged under does not follow what else the module holds: the elaborator, the kernel and erasure each spend a budget restored for each judgment of it ([A declaration is a function of what it reads](a-declaration-is-a-function-of-what-it-reads.md)). A resource verdict still follows the baseline in one way, since an adopted verdict is the one its baseline reached under whatever budget that was, where a whole compile judges it under its own; the differential test excludes resource verdicts and says so.

**Rejected.**

- **A closure the fold hands the certifier**, the one it elaborates by or one narrowed by the elaborator's record: the trusted base would rest on a record the certifier did not make.
- **Suffix re-elaboration from the first change**, Lean's per-command model: the emitted order is a Kahn sort over the unit, so an early edit re-elaborates most of the library.
- **Identifying the standard library by its tree's directory**, which makes the answer depend on the binary's checkout; **a manifest key or root kind for it**, forgeable, and a tier no mount needs; **recognizing the prelude in `curios-wonder` or in `curios-package`'s placement**, which cannot reach the archive.
- **Deriving the record from the spans in the image**: inputs are recorded at the seam they pass through, never believed from a structure that happens to hold them.
- **Per-declaration store slots**, redundant beside the unit slot and the item diff; **the recompile as the server's private state**, a third spelling of the fold that `test`, `document` and dependents would not share.
- **Withholding a unit compiled over a baseline from the store**: every question after a saved edit recompiles the closure until a build files the unit, and a question never files the package `std`. What is filed is decided by the one `Cache` implementation that answers `baseline`, on the disk alone.
- **A digest-keyed parse memo**: keyed by path and replaced on change, the table is bounded by the file count.
- **Reading an elaboration's refusals as whether it kept every item**, two different questions: a run whose only fault is an unparsed item refuses nothing and still drops that item's dependents.
