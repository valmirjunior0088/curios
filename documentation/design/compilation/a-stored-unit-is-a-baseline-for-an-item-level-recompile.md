# A stored unit is a baseline for an item-level recompile

**Decision.** A unit the store holds is a baseline, not a hit or a miss. `Cache::get` returning a unit whose record agrees is the empty case: reuse everything. When the record disagrees, the slot still holds a unit compiled from an earlier text of the same sources, and a *question* takes it as the baseline for an item-level recompile (`Cache::baseline`, `curios-pipeline/src/recompile.rs`): the fold lowers the unit whole, diffs the lowered items against the baseline's by declared name, takes the reverse transitive closure over the baseline's elaborated graph (`Module::reaches`: mentions, construction heads and registry-entry names) of every changed, added or removed name, replays every item outside it as one more predecessor, elaborates the closure in the lowered order, reassembles one `Module`, runs the whole-module passes and judges it with `Globals` seeded from the reused items, so the kernel walks the closure alone. The archived `/std` is the baseline of the package named `std`, offered through the same `Cache` seam. A build recompiles whole on a miss, and an incrementally compiled unit is never filed. The reassembly is handed what the closure's elaboration dropped — a dependent withheld behind a refused or unparsed item records no refusal of its own — and leaves it out exactly as a whole compile does. A module is parsed once per path and text, at `RootSource::load`.

**Rationale.**

- **An editor asks about a file on every edit**, and a whole-unit answer costs a whole compile of the unit — for the standard library, every declaration it holds, per keystroke. Every mechanism existed for whole units: a predecessor is replayed and never re-checked, the kernel skips by name, the dependency graph exists after elaboration, a stored item is position-free, and a `Unit` holds both the lowered and the elaborated module.
- **The reverse closure contains every item whose result can differ.** Every fact an item's elaboration consumes from outside itself arrives through a name it reaches — a definition's type and body, a registry entry, a witness head, a derivation's vocabulary — and conversion unfolds through what it names, so the closure is transitive. Ordering does not enter: a goal is answered from every witness the unit declares, each known by the key its signature spells, the local tiers see binders only, and an item elaborates after what it reads wherever either is written ([A declaration is a function of what it reads](a-declaration-is-a-function-of-what-it-reads.md)). The diff compares lowered items modulo a bijection on the universe metas and holes lowering numbered (`Term::equal_modulo_metas`), so an inserted declaration leaves the items after it reused, and the graph is `reaches` rather than `mentions`, since constructing a struct or matching a variant depends on the declaration as naming it does.
- **Evidence holds the claim**: `curios-pipeline/src/tests/incremental_tests.rs` compiles each fixture whole and over a baseline and requires the elaborated modules to agree structurally, item by item and on every registry table and the tests (`assert_modules_agree`). Agreement is the predicate rather than byte equality, since a declaration's identities count the declarations elaborated before it, so the spelling of a solved implicit or of a proof the elaborator wrote can differ where nothing observable moves. `curios-pipeline`'s `std_recompile_closure_census` measures the closure and each phase's time on the standard library, for a leaf edit — a declaration added to `/std/Nat`, whose closure is itself — and for a hub, `/std/Bool/not`'s body, the worst case by construction.
- **The trusted base is unchanged.** A reused item was judged by the walk that filed the baseline, as a whole-unit hit is ([Cached verdicts](../soundness/admission/cached-verdicts.md)). Resource verdicts are context dependent — the passes after the items spend one budget over the module — so a budget-marginal declaration can move either way, which the differential test excludes and says so.

**Rejected.**

- **Suffix re-elaboration from the first change**, Lean's per-command model: the emitted order is a Kahn sort over the unit, so an early edit re-elaborates most of the library.
- **Identifying the standard library by its tree's directory**, which makes the answer depend on the binary's checkout; **a manifest key or root kind for it**, forgeable, and a tier no mount needs; **recognizing the prelude in `curios-wonder` or in `curios-package`'s placement**, which cannot reach the archive.
- **Deriving the record from the spans in the image**: inputs are recorded at the seam they pass through, never believed from a structure that happens to hold them.
- **Per-declaration store slots**, redundant beside the unit slot and the item diff; **the recompile as the server's private state**, a third spelling of the fold that `test`, `document` and dependents would not share.
- **Filing an incrementally compiled unit**, until the differential gate has earned it; the policy lives in the one `Cache` implementation that answers `baseline`.
- **A digest-keyed parse memo**: keyed by path and replaced on change, the table is bounded by the file count.
- **Reading an elaboration's refusals as whether it kept every item**, two different questions: a run whose only fault is an unparsed item refuses nothing and still drops that item's dependents.
