# A top-level value is computed where its unit is compiled

**Decision.** An item whose top-level statements apply something is evaluated where its unit is erased, and what its erased form holds is what they compute. The item's fragment is linked last into a module of what it reaches, of its unit and of its scope, and of nothing else, which holds each row as the fragments linked into it hold it, an import at the count or width they state with the constructors they name (`curios_anf::Resolution::imports_rows`); the closed applications among its own items are folded by the evaluator a program's optimizer runs, on the budgets it runs on, a round at a time until one installs nothing (`curios_anf::evaluate_since`); and what stands past the place the fragment was linked at is taken back out as a fragment (`curios_anf::Module::taken`), which names what it still reads of another item as an import and holds each schema as an import holds one. That fragment is the item's erased form where it computes nothing (`curios-erase/src/evaluated.rs`). A program links what its entry reaches (`curios-erase/src/link.rs`), and computes a value its unit's compile could not finish the first time it reads it.

- **A name is bound to what its item computed.** A finished statement is an alias of its result, and the name the statement bound is bound to that result: a constant, which an item that names it reads in place and imports nothing for; a function, which one applies as it applies any, under the interface its item files for it; or a value. An item is evaluated before the items after it are erased, so each reads the binding once, as it reads any. A closure one item computed is so a function another imports by the first one's name, which is what lets a value computed over it be taken out.
- **A closure a value was computed to is marked as its item's evaluation.** A program marks a function as terminating by the certifier's verdict on the item whose erased form holds it (`curios_anf::Function::total`), and a value's verdict says that computing it ends, closed over everything it mentions, so what a closure it computed runs is code of definitions the verdict covers and ends where they do. It says nothing of performing what it computed: a description of an effect that runs forever is a total value, so a description's performance, and the machinery that runs one, are no evaluation's, whichever erased form a copy of one lands in (`curios_anf::Role`).
- **An item is left as it was erased where evaluating it does not finish.** A statement that is no closed application, a match over a value or an intrinsic, is no candidate. One the evaluator gives up on, for fuel, depth or size, or declines to copy, is tried again by each program's own rounds. And a result that names what another item binds under no name, a method a witness's dictionary holds, has nothing to import it by. Each leaves an item that still computes.
- **What is left is computed the first time a program reads it, once, and not where nothing reads it.** A top-level statement that computes — applies a function or an intrinsic, matches, or may trap (`curios_anf::Rhs::computes`) — or reads a value lowered so is lowered as a recursive group's computed member is: a write-once cell, its initializer, and a force standing right before the statement that reads it on each path that reads it (`curios_anf::lower_to_cps`). One that only builds from what is bound ahead, an alias, a row, a constructor or a list, is bound where it stands, which no program can tell from by need. So a program that never reads a value whose computation does not end ends, and one that reads it diverges at the read.
- **An item that declares a row is not evaluated**: what is taken out holds a schema at its width, and a declared row is its fields.
- **What evaluating it read is every erased form it was linked after, whole.** An erased form is otherwise read for how a name is bound; an evaluation runs what the items it reaches define. The item's erasure record names each, its forms read whole (`curios_erase::Part::Forms`), whether or not the evaluation finished, since another form of one may be what lets it finish, and a unit erased over a baseline erases and evaluates the item again where one of them is another form: an item of the unit erased again to other bytes, or one of another unit that digests otherwise than was recorded ([A stored unit is a baseline for an item-level recompile](a-stored-unit-is-a-baseline-for-an-item-level-recompile.md)). Nothing is recorded of a fixed unit's.

**Rationale.**

- **What a top-level value computes is its item's to say, and no program's.** It is a function of the item's erased form and of the erased forms it reaches. Computed in each program, it is the same work for every program its unit is in scope of, with the link of everything that computes and of what each reaches ahead of it.
- **A value is computed when it is needed, which is what the language means by one.** The language reference says a recursive value is "computed the first time it is read", and a top-level value is no other: no document states a run at a program's start, and a top-level value performs no effect, so all its computation can show a program is that it does not end. Computing ahead what a unit's compile finishes, and binding where it stands what only builds, are what no program can tell from it. Swift initializes a global at its first access, and one whose initializer is a constant statically; Lean 4 since 4.29 embeds a constant value in its executable where it can and computes every other on demand ([v4.29.0](https://lean-lang.org/doc/reference/stable/releases/v4.29.0/)); Kotlin/Native moved its top-level properties from the start to the first access; Java initializes a class at its first active use; Haskell evaluates a top-level value where it is demanded. A read pays a cell's test only where the value still computes, and counted at `8a57b09ac`, no program of `programs/` keeps one past its optimizer (`curios wonder --stage anf-optm` over the 31).
- **One evaluator.** The rounds are the ones a program's optimizer runs, over a module linked as a program's is but for its rows, so a value is what a program would have computed it to, and a difference between the two is a difference in what was linked.
- **A row is held as its readers hold it.** The evaluator holds a family, a product and a constructor by its identity and reads nothing of one, so a row linked whole from its declaration is one an evaluation pays for and never reads: each of a family's values, evaluated in a module that registers the family, costs the family, and the values of a family cost its square. Held as an import, a row costs an evaluation what its fragments name of it, as it costs each of them. A program's own rounds are unchanged, and find less closed to fold in what a library hands them.
- **The record is what was linked.** The module an item is evaluated in holds the items it reaches and no other, so nothing can be run that the trace does not name.
- **An item at a time, in a module of its own.** The item is linked last, so what stands past its mark is its own with what the rounds appended for it, and taking it out reads no ownership off anything. The evaluator shares a closure's copy between the candidates of one pass, and a pass over one item shares within the item.
- **The recursion rules reach a computed closure as they reach a function.** An initializer of a recursive group that applies one is held to its interface, where a value applied there is taken as dormant (`curios-anf/src/verify/eager.rs`): the rule that was written, over one more callee.
- **Measured**, counted at `a10135de5`. Of the 137 items of `/std` that compute as erased, 133 are finished where the unit is erased and the evaluator gives up on none (the samples `evaluate::item::finished` and `evaluate::item::bailed` of the profile `cargo xtask profile prelude` files); the four left are two recursive parsers whose closures it declines to copy, and two `Io` values built through a monad dictionary's methods. Evaluating the 137 is 0.42 M of the 12.79 M allocations erasing `/sys` and `/std` takes (`evaluate_item` under `erase_unit`, the same profile), each in a module of the 55 items it reaches on average and 334 at most (`evaluate::item::linked`). `programs/hello_world.crs` links 289 items (`link::reached`, filed by `cargo xtask profile programs/hello_world.crs --profile release`), and its compile is 1.55 M allocations, the evaluator's rounds 0.34 M of them (`compile_entrypoint`, `evaluate_closed_terms`).

**Rejected.**

- **Linking every item that still computes**: every program then links, to drop, what nothing reads, a total loop the evaluator gave up on, a description, a match over a constant, a command line declared as a value, and `/std`'s own test values among them.
- **Computing a value not known to end as every program in scope starts**, whether or not the program reads it: a program then hangs before its entry on a value it never names, and a lint that cannot be suppressed asks the author to restructure what the language admits. OCaml and Go initialize what is linked at the start because their initializers perform effects, a registration or an output, which a Curios value cannot, and Lean 4 initialized every closed term before `main` until 4.29, a constant computed by a partial definition hanging every executable.
- **A force at the entry of each region that reads the value**: a path that does not read it computes it, so an arm not taken diverges for it.
- **Every top-level value by need**, constructions included: a force at every read of a row a program binds at the top level, a witness's dictionary among them, whose methods Curios/CPS's optimizer then cannot read off it, for no change in what any program does.
- **By need only for a value not known to end**: a total computation the evaluator gave up on runs at the start of every program that reads it on any path, the hoisting `curios-cps` rejects, and the effect summary would have to read the read of a value lowered by need as whatever its computation may do.
- **Linking every declaration in scope and pruning**, or every one that computes: a program's link, its first analysis and its first prune walk what the library reaches, to drop nearly all of it for every program.
- **A unit evaluated whole in one module.** One link in place of one for each item, and a copy the evaluator shares between two items' candidates is then bound by one item under no name and named by the other.
- **The name left bound to the value it bound**, an alias of what was computed. A closure an item computed is then a function it binds under no name, and every value computed over it names what nothing can import, which is every parser `/std` builds from another.
- **A name for every function an item binds**, so that a dictionary's method could be imported: an erased form's inner layout would be what other items are erased against, where today they read how a name is bound and no more.
- **A refusal where the evaluator gives up.** What a top-level value may cost at compile time would be the language's, and the budgets are an optimizer's.
