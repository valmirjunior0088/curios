# The closed machine binds a proof unreduced

**Decision.** The closed machine, the evaluator both checkers run a closed term on, leaves a proof as it is written. An argument, the value a `let` binds and a constructor's payload are substituted unreduced, as an induction hypothesis is, where their binder states that what it binds is a proof: its type is a proposition, or a function into one. The proof of an operation's bound is not forced. An elimination that reads a proof still demands it, and the run's memo keeps the demand to one evaluation. A type is evaluated before it is bound, as every other substituend is. A binder states it in what its scope remembers of it, beside its hint: when a declaration is published, each binder a function literal or a `let` binds in its final terms, and each payload of the constructors it declares, is asked at its declared type with the binders before it opaque. The machine reads the answer where it substitutes, an arm binds under its constructor's, and the kernel refuses a mark its own reading of the binder's type does not bear.

**Rationale.**

- **No judgment reads a proof's value.** Conversion holds two proofs of one proposition equal before either is reduced ([`Prop` is strict, proof-irrelevant, and definitionally K](../theory/prop-is-strict-proof-irrelevant-and-definitionally-k.md)), so a proof left as written is the same term to every judgment, and evaluating it is work whose answer nothing asks for. The run time already keeps the sentence [Totality of the erased program](../soundness/totality-of-the-erased-program.md) states, that an expression in an erased value position is not evaluated and costs nothing, by holding a stand-in where the expression was; the machine is the evaluator a type calls, and keeps it for a proof.
- **A certificate costs what its lemma does.** The proof of a bound is a lemma proved by induction on the number a computation walks, so evaluated at each closed call a walk over a text costs the square of its length, in work whose answer no step reads.
- **A type is evaluated, because a judgment reads it.** Erasure computes neither a proof nor a type, and the two part here. Conversion compares the reduct it is handed, and which levels two instances of a definition are held to follows the spelling they reach it in ([a universe level is implicit, cumulative, and settles by where it stands](../theory/a-universe-level-is-implicit-cumulative-and-settles-by-where-it-stands.md)): a family bound as written is met as an instance of its definition, and one bound as its value as what it unfolds to. Left as written, `Try/bind` over a bare `Io` refuses a region a level above its action.
- **A mark is a cost and never a verdict.** A closed term has one value whichever order finds it, so a proof left unreduced changes no reduct, and a binder left unmarked costs a reduction. Nothing is admitted by a mark, which is why the kernel's check runs one way: it holds the machine it runs to what no judgment reads, so its budget counts what the totality decision says it counts.
- **It says what every reading of the binder agrees on.** A declared type that is a proposition or a function into one with its binders opaque is one at every instantiation, so the mark states the case no reading computes; a `Type` variable a call instantiates at a proposition is left unmarked, and costs that call a reduction.
- **The binder says it, because the question is about the binder.** Whether a value is a proof is read off its type under the binders before it. Where the machine substitutes it holds a value and a closed body, and no telescope to stand them in.
- **In what a scope remembers, because it is no part of a term.** Two functions apart in a mark alone are one function: equality, conversion and every memo read no label, a stored node is kept under its binders' labels, and a traversal carries them, so the mark travels with the binder and identifies nothing.
- **At publication, with everything else decided of a declaration's final terms** ([A declaration is a function of what it reads](a-declaration-is-a-function-of-what-it-reads.md)): once, by the declaration, before any other reads it.
- **Precedent.** Rocq marks a binder's relevance and its kernel refuses a mark the binder's sort does not bear; Agda's irrelevant arguments are type-checked and never evaluated; Lean makes the proof a well-founded recursion descends on opaque to its reducer.

**Rejected.**

- **A type bound as written, and a type's operands left unevaluated to form it**, on the ground that the erased program computes neither: conversion and the levels it settles read the spelling they are handed, so it changes which programs elaborate.
- **A third value on the mark**, telling a type from data, so that an index of a family is left as written where the family is applied and an equation's sides are run once: a second question asked of every binder and held by the kernel, for a cost a memo of closed runs can meet with no word on a binder.
- **Reading the sort where the machine substitutes**, off the head of the binder's type: a relation given as a function literal, a variable of the same telescope and a curried family each read as kept, and each miss is a cost nothing reports.
- **A mask per declaration**: it says nothing of a local function, a `let` or an arm, which is where a walk binds its proofs.
- **A mark beside a binder's plicity**, in the telescope: part of a function type's identity, a second field on a `let` and an arm, and a new key for every stored node.
- **A mark a program writes**, a quantity on the binder: a change to the language, for what the binder's type already says.
- **Call by need throughout.** Substituting a value keeps what a memo retains linear in how far a walk has come ([A reduction step costs what it builds](../soundness/a-reduction-step-costs-what-it-builds.md)); what is left as written is what no judgment reads.
- **Each certificate written behind the decision of its goal**, so that a closed instance takes the arm holding no lemma: a respelling per lemma, and a comparison the erased program then runs.
- **Firing a match on a proof without reducing it**, which [`Prop` is strict, proof-irrelevant, and definitionally K](../theory/prop-is-strict-proof-irrelevant-and-definitionally-k.md) rejects as a rule.
