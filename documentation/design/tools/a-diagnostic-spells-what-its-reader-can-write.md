# A diagnostic spells what its reader can write

**Decision.** A term a report shows its reader — a goal's answer and scope, a mismatch's two sides, a candidate fit — is spelled so that, written where the reader stands, it elaborates back to the term shown. Printing runs resolution in reverse at that position. A name takes the shortest spelling resolution would take back to it there: a declaration of the reader's module by its label, a path into a child module, an import in scope as it was written, else the shortest absolute path whose audience includes the reader — the facade a re-export offers, never the internal root. The absolute paths a unit gives a name are listed once for the unit, where a report first asks over it, from the direct interface and export view it stores, and stored by none (`curios_text::PreparedText::spellings`); a report reads the lists of the units in scope in order, and which paths the reader's unit may name, and which it reaches relatively, is decided where a name is spelled (`curios_core::Spellings::spell`). What else a report spells a name of its scope by is each unit's own too, its lexicon (`curios_core::Lexicon`): the globals it declares, which a name is shortened against where no reader stands, its nominal families' parameter marks, and its concepts' fields and witnesses' declared types. A unit's is made once, of the declarations it is about and no other, and kept with the unit (`curios_unit::Uncertified::lexicon`); a report makes its own unit's and reads the others in order, so it builds no table over its scope and reads no declaration of it that it does not print. A `use` argument is left out exactly when witness resolution would put it back, a witness binder of a function type prints unnamed, and a concept method projected off a witness prints as the method call or operator a program writes. Where no spelling resolves back — a witness shadowed by another of its concept, a name the reader's unit cannot reach — the faithful spelling stays, since a different program is worse than an unpasteable one. A term past the Core print's bound is shown elided, `…` standing for what is left ([A printer states each fact once, where it is bound](a-printer-states-each-fact-once-where-it-is-bound.md)): no reader writes such a term back, and an elided report is still a report. `wonder stage` dumps and the kernel's refusals keep the faithful spelling: they are read about the compiler. `curios-pipeline`'s paste-back tests compile a program, write each goal's reported answer over the goal and compile again, over each form found to break it and over every public declaration of `/std`.

An unsolved written goal's report may offer up to three verified candidates (`? ≈`), each at depth one: a scope binder or a constructor the goal's indices admit, a function whose instantiated output unifies with the goal, with holes where its arguments are not determined, pooled from the goal's scope, the entry module, the globals it references and the bindings its `use` declarations import — never the whole prelude. Every attempt runs sandboxed in the solution-rollback bracket. A hole-free constructor fit must also survive an oracle-mode check in the goal's scope and under the guards it was written under, since inversion refuses positions it cannot decide, while an application fit is definitive by the conversion that found it, so a complete suggestion compiles when pasted. A goal that is a bound is put, in the same sandbox, to the procedure that proves a bound from the facts in scope ([A bound that follows from the facts in scope is proved by the elaborator](../arithmetic/a-bound-that-follows-from-the-facts-in-scope-is-proved-by-the-elaborator.md)): its proof is a complete fit, and its refusal is reported beside the goal. A suggestion is text the author's paste is checked from, so the trusted base is never consulted.

**Rationale.**

- **A report is read to be acted on, and the action is writing something at that position.** A printer answering a narrower question than the reader's departs from it: a suffix unique among all symbols rather than one resolution reaches from the reader's module (`Ord` offered where only `/std/Ord` resolves), imports merged across the unit though `use` binds from where it is written, a resolved witness shown as an internal identity, a projection as `(w).0`. Each is a fact about resolution only the stage that owns it can invert: the text stage hands reports an index of the paths each global can be written by, and the printer, the one walk that opens every binder, knows which witness binders are in scope at each node.
- **The gap between stating an obligation and answering it is smallest where beginners live** — compute-both-sides equalities, index-forced constructors — and closing it composes pieces elaboration already runs: the resolution probe, the shared inversion unifier and the re-validation oracle. Depth one keeps the cost bounded, the verdicts definite and the output deterministic.

**Rejected.**

- **A written-or-resolved flag on each argument**: terms are hash-consed, so a flag outside equality would let two differently flagged nodes collapse, and it answers the wrong question — whether resolution restores the argument in the reader's scope, not how it arrived.
- **Rendering through the surface syntax tree**, which guarantees output that parses, not output that elaborates to the same term, and makes the checkers depend on the surface crate; **absolute names everywhere**, writable noise; **extending the elaborator's `denoise` fold**, which cannot see binders introduced inside the term it rewrites.
- **Recursive suggestion search**, filling a suggestion's holes by further search: the motivating induction step needs a function invented from a unification problem outside the Miller fragment, and a useful search over applications needs hint indexing and a search policy the workspace does not have. Resolution's bounded backtracking and conversion's history and deterministic budget would be its loop control, and the depth-one tiers its leaf steps.
- **The tables a report spells by built over the scope for each report**, every unit's symbols counted again, its marks and its witnesses' types copied out of every definition it holds: a refused program then reads the whole of a library it named two declarations of, for each report it is given.
- **A unit's paths listed by its lowering and stored with it**, made and filed by every compilation for a reader only a refused one has; and **one table of the whole scope for each report**, which lists every unit's paths again for each compilation that reports, where a unit's are a function of the unit alone ([Privacy is scoped to a subtree](../surface/privacy-is-scoped-to-a-subtree.md)).
- **Prelude-wide candidate pools without an index**, cost without precision; **suggestions for a solved goal**, noise beside its `? =` answer.
