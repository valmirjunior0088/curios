# A command narrates on one transcript and reports in blocks

**Decision.** What a command says takes one of four forms, each with one writer, and which form a line takes says whose it is.

- **What a command does is a transcript**, written on standard error and nowhere else. A subject stands alone on its line, and each step is a node of a tree beneath it, `label; outcome`: the label written before the work, the outcome after it — a time where the step succeeded, a verdict and a time where it did not, `refused` where a rule said no and `failed` where the machine did, or the place its product stands. Nothing is erased or redrawn, a unit taken from the cabinet prints nothing, and the bytes are the same in a pipe as on a terminal, colour apart. A test is a node opened before it runs; what it writes is relayed as it writes it, each line quoted behind `>`, and a test that wrote nothing closes on its own line. A test's verdict leads with its mark, `✓` where it passed and `✗` where it did not, which stands in the quote's column beneath what the test wrote, so one rule beside the tree's marks what is quoted; beneath the verdict stands what only the runner holds, a trap's text and what a failing test found, which the test answers as data rather than writes. A total is the last line, flush left.
- **What a command finds or refuses is a report, and a report is a block.** Its first line is a tag: one to three lower-case words that name the kind of thing reported, with nothing of the program in them, the same whichever stage or command meets it; a goal's block and a query's answer open instead on what they answer, the goal's type, the path the query asked about, or the term written at the place it asked about. Beneath it, on a trunk, stand its facts, a statement a line in one order — what stands here, each value at issue behind a label, the rule, the way out —, and whatever a fact shows of the program, a term, a name, a pattern, a label or a value as written, stands in backticks, behind a label or inside a sentence (`curios_common::Code`); then each further place it is about, its line shown and closed by what stands there, then its own place. A way out that is a command stands behind `try` on the line above the close. The block closes on its kind in brackets and what it is about: `[error]`, `[goal]` or `[lint]`, or for an answer `[declaration]`, `[module]`, `[local]`, `[field]` or `[term]`, then a place in a text, a file or a directory as a whole, or a thing by the name that was written.
- **A report is data until the edge that writes it** (`curios_common::Report`): a tag, facts, further places, ways out and what it is about, with no severity and no reader in it. Whoever prints decides the kind and the reader — where they stand, which a path is spelled from, and whether they see colour, which changes no byte beneath it — and an editor is handed the same data, never a rendering. A place is spelled by the file that holds its text, and by its source's name, its package and its path within it, where no file on the reader's machine does, as in the library a compiler carries.
- **What a query lists is rows**, on standard output, after the block of what was asked where there is one: a row a line, its fields joined by tabs and as many in every row of the listing, `-` where a field has nothing to say, so a script splits any listing alike.
- **A refusal of what a manifest states stands at the row that states it**, named by the keys that lead there and found in the manifest's text when the refusal is reported (`curios_package::Refused`). The records a manifest is read into keep no positions.
- **What a running program stops on is its own, and is one line**: the kind of stop, a colon, and what there is to say of it (`curios_native::Stop`). It is no block, it carries no frame of the machine, and a built executable says it as `curios run` does. What could not be linked is a block where the compiler meets it and that same line where a built executable does, from one value (`curios_native::Unlinked`).

**Rationale.**

- **One writer per form keeps the forms from drifting.** A transcript that is only ever appended to is the same text in a terminal, a log and a continuous-integration page, so no second renderer exists to disagree with it, and a step that hangs is the line left open. A report drawn in one place has one shape for a parse failure, a type mismatch, a lint, a manifest row and a mistyped flag, so a reader learns it once.
- **A tag is what a reader, a search and a tool can hold on to.** A sentence that carries the program's names is different every time it is met; a tag is the same, and the facts beneath it are where this program's names go. Statements a line each, in one order, let the eye find the value it wants without parsing prose.
- **The kind stands in brackets because `;` is taken.** On every other line of a tree `;` joins a label to what it came to, and a kind is no step whose outcome is a place: `check; refused in 0.3s` is a step, and `[error]` closes a report.
- **A place is the most useful thing a refusal can end on**, so every block ends on what it is about, in a form a terminal opens where it is a place, and which `wonder --at` asks of as it is printed ([A place in a file is answered from the declaration that writes it](a-place-in-a-file-is-answered-from-the-declaration-that-writes-it.md)). A manifest's refusal is most useful at the row, and reading the text again for where the row stands costs nothing on the one path that reports.
- **An answer opens on what was asked, as a goal opens on its answer**: the kind it closes on is what a tool holds on to, and the path is what its reader looks for first. **A listing is read by a script as often as by an eye**, so its fields are told apart by one character no field holds and stand in the same column in every row.
- **A program's stop belongs to the program.** Once a program runs, what it prints is its own, and so is the line it stops on: a frame around it would be the compiler speaking for a program that, built into an executable, runs with no compiler beside it. The frames the engine can list name machine code, which the program's author did not write.
- **Structure is data because every consumer needs a different drawing.** A terminal, a pipe, an editor, a served test page and a test of the compiler each show a report their own way; a rendering parsed back for its parts would hold each to the others' wording. What a test found is such data too: written by the test as a sentence, it could be quoted and never drawn, and would read as one more line of what the test wrote.

**Rejected.**

- **A live display beside the transcript**, a bar or a spinner that erases what it wrote: two renderers, one of which a pipe cannot show.
- **Capturing what a test writes and showing it on failure**, which hides the output of a test that hangs, and reorders it against the test's own timing.
- **A stream of results beside the answer a test's entry gives**, each check as it happens: a test runs in an instantiation of its own, so its runner knows a trap, an exit and the time without one, and what the test found is its entry's answer, the one thing its body cannot forge.
- **A severity before the headline**, `error: type mismatch`: the kind is known to whoever prints and is the same for every report of a run, so it closes the block and the tag leads.
- **A sentence as the headline**, which no reader can match and which pushes the facts into clauses.
- **`kind; subject` as the closing line**, which reads as a step of the tree and collides with the step `format`.
- **A note for a file no `mod` reaches, or for a cabinet that took nothing**: neither is a finding about the program, and a reader who asked about a file is not asking where it hangs.
- **A separator of a listing's own**, a ` → ` between a witness's place and what it says: a second rule for a script to learn.
- **A block for a run-time stop**, under a kind of its own, and **the engine's frames beneath it**.
- **Positions carried through the manifest's records**, a span on every field for a refusal most reads never make.
- **The parser library's own message for a line that does not parse**: its wording is another program's, and a report is built from the parts it keeps of its refusal, never from its text.
