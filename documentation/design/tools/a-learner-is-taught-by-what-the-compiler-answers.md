# A learner is taught by what the compiler answers

**Decision.** `/learn-curios` (`.claude/commands/learn-curios.md`) teaches the language inside an agent's session, and the command holds its own contract: its end, its stance, its opening, where a session leans, what done is, what only a teacher knows and the notes a resumed session reads. It meets a developer where the language first answers one: at a program that would have crashed in the language they know, refused with the input that breaks it and accepted once a guard is written ([A bound that follows from the facts in scope is proved by the elaborator](../arithmetic/a-bound-that-follows-from-the-facts-in-scope-is-proved-by-the-elaborator.md)). The guard is a proof, and the learner hears so after writing it.

The command is as free-form as it can be made: it states no plan, no order of topics and no script of turns. It teaches a reader reluctant to sit down and read what a model writes at length, who skims, takes the author's word for little and came to do something: a beginner or an average developer, neither a senior one nor a student of type theory. The language is met as a proof assistant in a programming language's clothing: the learner does proofs before knowing they are proofs, in the loop of write, run and fix a developer already works in, and the compiler's refusals are that loop's nudges. The crash that cannot happen comes first and the theorem last — a bound a guard discharges, then an obligation a signature or a type carries, then a claim about every input — and a proof by induction is a next step the session offers and no session owes. The opening is an index guarded one short of its bound, and the compiler's fits are part of what is taught: a `?` and what it offers is how a developer asks the compiler, and no report is withheld to keep an answer back.

It is a slash command of a checkout, for few learners, picked by the maintainer and instructed by them in person: what a learner needs before the command is the maintainer's to say, and what a session shows is the maintainer's to ask for. A learner clones the repository and runs a release, so the command, the reference and the compiler they meet are one version; the command asks `./target/release/curios` where the tree has built one and `curios` otherwise, and a first session has no editor, the loop being `!` and a run. The tree sets the session up: `.claude/settings.json` allows the compiler's `run`, `test` and `wonder`, under both spellings, and writing under `.learn/`, for every session of the checkout; the Curios rule reaches the sources the tree tracks, so a learner's file loads none of it; and the command names the sections of the reference a teacher reads. What only a teacher knows is a list in the command while it is under a dozen lines.

What holds the command is the learners' own sessions, not a cohort of simulated learners.

Counted from each transcript, by reading: the words of the teacher's prose in a turn, outside code and compiler output, as median and maximum; the lines of compiler output a turn shows, as median and maximum; turns that end with nothing for the learner to do; fixes the teacher wrote unasked; statements about Curios with neither output nor a run beside them; steps set with no private run before them; the first turn at which "proof", "proposition" or "theorem" is said, and whether the learner had written a guard by then; replies before the first compiler output is on screen; the calls listed in `permission_denials` after the first turn; and whether done was reached with no teacher turn between the last refusal and the run that accepted its fix, recorded as not reached where ten replies end first. Two more check the simulation itself: whether the learner writes Curios syntax nobody showed it, and whether it drops a wrong belief only after the compiler's counterexample. A figure is its median and span over the three runs, three unlike learners.

**A learner's session** leaves `.learn/`, the programs in the order they were written and `notes.md`, which the maintainer reads for whether the last refusal was resolved unaided and for each place the language got in the way, a finding of its area ([`.claude/rules/findings.md`](../../../.claude/rules/findings.md)).

**Rationale.**

- **A command is held as text, and a grant as one turn's.** A command's text stays in context once loaded, "so every line is a recurring token cost", and its `allowed-tools` grant "clears when you send your next message": "To pre-approve tools for the whole session rather than a single turn, add allow rules to those permission settings instead" ([Skills](https://code.claude.com/docs/en/skills.md)). So the command is short, and the leave to probe is the tree's settings: a Bash rule matches the whole command with a trailing ` *` for its arguments, a here-document is no file target, and an `Edit` rule covers every tool that writes a file ([Configure permissions](https://code.claude.com/docs/en/permissions.md)). Run with `-p`, a session expands `/learn-curios` written in its prompt and is continued by `--resume` under its session id, and under `--output-format stream-json` its last message lists each call it was denied in `permission_denials` ([Run Claude Code programmatically](https://code.claude.com/docs/en/headless.md)), which is what the dry run reads.
- **A session in a checkout loads what was written for someone changing the compiler.** `CLAUDE.md` is in every session and gives `cargo run --package curios --` as how a program is asked, and `.claude/rules/curios.md` asks for `documentation/language.md` "in full", 98,147 bytes at `76a6cf3cf`, counted. The command sets the first aside, and the rule loads only where a Curios source the tree tracks is read — under `curios-prelude/std/`, `programs/` and `editors/` — so the reference is read by the section a step needs.
- **Help that gives the answer harms, and help that withholds it does not.** Nearly a thousand high-school students practised mathematics with GPT-4: with a plain chat they did 48% better in practice and 17% worse on the exam taken without it; with a tutor prompted to safeguard learning, 127% better in practice, the harm "largely mitigated" (Bastani et al., [Generative AI Without Guardrails Can Harm Learning](https://hamsabastani.github.io/education_llm.pdf)). The fix stays the learner's.
- **A model asked to tutor tells.** Asked to tutor a student, ChatGPT revealed the solution in 66% of cases and gave incorrect feedback in 59%; the dataset's dialogues average 17.3 words an utterance, teacher's and student's together (Macina et al., [MathDial](https://arxiv.org/abs/2305.14536), Findings of EMNLP 2023).
- **Tutoring teaches by what the student builds, and a student told less reads more.** With tutors "suppressed from giving explanations and feedback", "students learned just as effectively", by "their greater effort to take control of their own learning by reading more", and "What they learned from reading was limited, however, by their reading abilities" (Chi, Siler, Jeong, Yamauchi and Hausmann, [Learning from human tutoring](https://doi.org/10.1207/s15516709cog2504_1), Cognitive Science 2001). What a reluctant reader reads is the compiler's report, so the teacher picks programs whose report is short.
- **A novice helped by a model can finish sure of what they cannot do.** Of 21 students observed with generative tools, those who struggled "finished with an illusion of competence" (Prather et al., [The Widening Gap](https://arxiv.org/abs/2405.17739v1), ICER 2024). Done is something the learner does with no one beside them.
- **A second language is read through the first, wrongly.** Of 450 questions developers asked while learning another language, 276 showed interference from one they knew, and sixteen professionals interviewed tried and failed to map the new language onto the old (Shrestha, Botta, Barik and Parnin, [Here We Go Again](https://www.microsoft.com/en-us/research/publication/here-we-go-again/), ICSE 2020). A refusal is set beside what the learner's language does with the same program, at run time.
- **Assurance is adopted from the bottom.** SPARK's guidance orders its levels "proving absence of run-time errors", then "proving key integrity properties", then "a full functional proof" ([AdaCore and Thales](https://www.adacore.com/press/new-spark-adoption-guidance-published), 2017). The crash that cannot happen comes first here, and the theorem last.

**Rejected.**

- **A theorem as the end every session reaches.** It is the end of a learner who came for a proof assistant, and the learners here came to see what the language is for.
- **The logic named first.** A developer told they are about to prove something hears a subject they did not come for; one who has just fixed a refusal hears a name for what they did.
- **A sequence of levels in the command**, each a step with its own hint. It is the plan the command rules out, and it is learning material, which is written elsewhere.
- **A report cut to keep an answer back.** A fit that names the fix is the compiler doing what it was built to do, and a learner who takes it has used the tool as a developer does.
- **An output style shipped to hold the bound.** A style is the user's to pick and applies to every response of their session.
- **The reference carried in the command.** It is a second copy, and it is in context on every turn.
