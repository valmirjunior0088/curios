# An argument names one subject, and each command states what it accepts

**Decision.** Every command resolves its argument by one rule into one subject, and states as data which subjects it accepts. The text alone decides the kind: `-` is standard input, an argument ending in `.crs` or holding a path separator is a file, any other word is an executable's name, and no argument is the governing package entire. The governing package is the one whose `curios.toml` is nearest at or above where the argument is located — the file's directory, or the working directory for a name or none — or the one `--manifest` names; standard input has none, and an umbrella governs nothing. A build names the manifest on its `Processing` line whenever it does not stand beside the invocation. A file is placed by what declares it, never by where it sits: it is an executable's when that executable's entry or `mod` lines reach it, the library's when `lib.crs`'s do, and loose otherwise — compiled against `/std` alone and filed nowhere, checked as a module when it has no final term, with a note when its package's directory holds it: a question's names the `mod` line that would place it, and a build's the `[[executables]]` row that declares a program. Each command's contract in `curios/src/contract.rs` states what it accepts, whether a program must be named by its own file, how it reaches the store and what it leaves on disk; admission refuses every unaccepted kind in one sentence naming the command, a target's help is read off the same contract, and `curios/src/contract/tests.rs` pins every command against every spelling from every place an invocation can stand. A flag lives on the commands that read it, and `--profile` alone is global. What a command files for a project is [A command compiles only as far as its answer needs, and a project keeps what it compiled](a-command-compiles-only-as-far-as-its-answer-needs-and-a-project-keeps-what-it-compiled.md)'s; a question stopped by written goals alone exits 2, as a build does. What each command accepts is [usage.md](../../usage.md)'s.

**Rationale.**

- **One resolver and one table make agreement a property of the code.** Several places deciding what an invocation is about, each into a type missing different cases, let one argument mean three things across commands and leave flags silently inert where nothing reads them.
- **Each piece is taken from a toolchain that got it right.** The upward search is Cargo's, with Deno's split between the working directory and the named file, and without Go's resolving a file elsewhere against the working directory's module. A file checked on its own is TypeScript's inferred project, and the note is rust-analyzer's unlinked-file warning, about placement rather than the program, so it counts toward no exit code. Running the file that was named is every surveyed file runner's rule — Deno, Zig, Go, uv, Lean — while a question about a file is answered within its project, as an editor server answers it. Flags after the command, refused where they do not exist, are Cargo's, Go's and Deno's.
- **A question stopped before its answer exits as the build it would have been**, so a script tells an incomplete program from a broken one by one code whichever command it ran.

**Rejected.**

- **A meaning per command for one argument**, the inconsistency itself; **a manifest always required**, which a heredoc probe cannot afford.
- **Membership by location**, as Go and Agda decide it, which lets a scratch file beside a package acquire its scope; **running a module's owning program when a module is named**, which executes something nobody asked for.
- **Narrowing `lint` or a question to the named file alone**: elaboration withholds a declaration's diagnostics when something it depends on is refused, so a file-only answer could be falsely clean.
- **Every flag global, refused at run time where unread**, which brings back tracking which flags were read; **git's `-C DIR`**, a second spelling of `--manifest`.
- **Writing a loose program's executable to `./<stem>` by default**: nothing is filed where the command was not pointed, and standard input has no stem.
- **Dependencies or a cache for a loose file**, an in-file manifest as uv and cargo script have: a loose file has `/std` and nowhere to file what it built.
