# A printer states each fact once, where it is bound

**Decision.** Every rung `wonder stage` prints is printed by one rule: **print every declaration something refers to, state each fact once at its definition site, and spell every reference as short as is unambiguous.** An identity prints exactly when something else can refer to it, a header declares only the rows the program reaches, and a function or continuation prints nested at its binding site. The dump is faithful: nothing inlines a single-use binding, folds a constant, reorders a statement or drops dead code, and a binding nothing reads prints `let _ = …;`.

- **`curios-ersd` prints as A-normal-form Curios** — `let`-chains closed by a tail term, `match … end` eliminators, function bodies nested at their binding sites — with scalar operations spelled by carrier, `Nat/add(a, b)` and `2:int`, since Ersd keeps no type to recover a carrier from. `Function::description`, which one optimizer pass reads to cap a copy budget, is not part of the program and is not printed.
- **`curios-cont` prints as one nested program**: every function and continuation under the `LetFun` or `LetCont` that introduces it, each region closed by the transfer that leaves it. The bodyless return continuation is not printed, an edge to it being `return x` and a call returning through it `return ~f7(x)`, and a continuation minted for a role carries it — `join`, `arm/cons`, `loop/step`, `foreign/resume`.
- **Compiler-minted identities share one hint convention** from the erased stage through Wasm emission: `curios-ersd`, `curios-cont` and `curios-emit`'s machine IR spell theirs `~{kind}{index}`, the Wasm names `curios-emit` mints are `kind/uniquifier`, and all append the stored debug name after `$`, the only hint separator. Surface names are alphanumeric with underscores, so no printed identity collides with a source spelling, and a hint never affects identity.
- **A Core print is bounded by its term's graph.** A Core term is a graph and its print is that graph's tree, so a render builds at most sixty-four child documents for each distinct node of its term, never fewer than five thousand, and prints what is left as `…` (`curios-core`'s `RENDER_PER_NODE` and `RENDER_FLOOR`). A term whose tree is within that prints whole — every definition of `/std` does, none having a tree past the floor and the largest ratio of tree to graph among them being 10.9 (`curios-prelude-archive`'s `printed_tree_measurements`, counted, at `84eff3c90`) — and one that outgrows it, a chain of `let`s each naming the one before it twice, prints its beginning. One rule serves a `wonder stage` dump and a report.
- **Layout is the Wadler document algebra in `curios-print`**: documents carry `line`, `soft_line` and `hard_line` choice points and `group` fit-or-break units, one IR-agnostic engine resolves them against a width, and the unbounded `Display` path renders every group flat. A printer states its layout only by where it places groups and lines, readability rewrites run before printing, and the formatter is one more client (`run_printer_placing`). The Ersd and Cont printers print outside it, one statement per line.

**Rationale.**

- **A printed rung must read as the program it is.** Ersd *is* ANF Curios — a `Let` per computation, `Statement::Functions` as `let … and …`, `Terminator::Return` as a chain's tail — so a reader arriving from `text`, `core` and `core-elab` meets a fourth rendering in one notation. A flat section prints a lifted function over a body naming its enclosing function's parameter, an open term, because `Function` stores no capture list; nesting at the binding site is the only placement `let f(x) = body;` has, and makes captures visible with no annotation.
- **Control is what the continuation rung has to show.** A continuation's body reads values bound in the one enclosing it, so only nesting shows them bound rather than free, and a continuation's scope never leaves its function. Spelling `return` makes a tail call legible where a sentinel `-> ~k11` sends the reader to a header.
- **Each elision removes only what the reader can recover**: an unreached row is named by nothing printed, a fact is found from the identity that refers to it, and a reference shortens only to uniqueness, `curios-core`'s `build_shorten` rule. Unelided, a small program's header is mostly standard-library rows it never reaches. The Core print's `…` is the one elision that gives nothing back, and it stands only where the print it replaces is one no reader finishes and no report survives writing: a dump that ends is worth more than a faithful one that does not.
- **Reserving the separator makes clash-freedom structural**, and keeping hints display-only stops behaviour growing back onto spellings.
- **One engine serves every document printer**, a printer opts in one separator at a time with no output change until a caller asks for a width, and the one-line fits scan keeps layout linear. The Ersd and Cont printers print one statement per line, always broken, so `group` and `fill` would decide nothing there.

**Rejected.**

- **Annotations in place of nesting**, a `captures …` list on each lifted function, which states captures a second time and keeps the overloaded `return`; **a flat function section**, which splits one binding into a declaration and a definition.
- **Folding single-entry continuations into `let`s and arms**: most would collapse, but there is no `let` in the representation, and the fall in their number from `cont` to `cont-optm` is the optimizer's visible effect.
- **Flat labelled blocks per function**, the Cranelift, SIL and MLIR shape, which prints a value bound in an enclosing continuation as free and cannot state the nesting the verifier holds. The unoptimized `cont` staircase is the accepted price; the optimized rung nests shallowly.
- **Extending the Curios notation past Ersd**: Curios has no labelled block, and a continuation is not a binding.
- **Naming a shared Core node with a `let`**, which keeps a print pasteable and moves every rung and report where a term shares a node; **a flat bound on a Core print**, Lean's `pp.maxSteps` and Rocq's printing depth, which elides a large declaration that shares nothing; and **a tighter bound for reports than for dumps**, an axis with two settings where one rule ends both.
- **A configuration axis for elision, faithfulness or vocabulary**: each resolved to one answer, and a parameter with one setting is scaffolding.
- **Per-construct formatting with threaded width budgets**, **penalty-based optimal line breaking**, **no width limits**, and **build-time propagation of mandatory breaks**, which the fits scan derives at each decision.
