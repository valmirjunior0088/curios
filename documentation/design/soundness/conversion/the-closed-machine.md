# The closed machine

**Assumes.** On a closed, metavariable-free term with no refinement in scope, `curios-core`'s `reduce_closed` computes the weak-head value the host's recursive strategy would — the same reduct, the same errors, the same divergence under budget.

**Status.** **probed**, and carrying [the board's shared route](../the-soundness-board.md) at its widest: the machine shares β, ι, δ and ζ on closed terms as the folds share arithmetic ([An independent kernel re-checks what the elaborator accepts](../an-independent-kernel-re-checks-what-the-elaborator-accepts.md)). Three evaluators exist — the machine and both recursive strategies, complete for everything the gate declines — and a differential holds the machine to the strategy at both demands.

- **The gate has two halves.** `accelerable` is the representation half: no local frees and no metavariables, two bits cached per node. No refinement in scope is the judgment half: inside an arm a closed scrutinee is the arm's case value, even where evaluation says otherwise, so both hosts decline the machine while any case equation or recorded refinement is live.
- **Substituted terms are values first, except a bare global name.** Arguments, `let` values and `Induct` payloads are evaluated before substitution, which keeps an accumulator a literal; on closed input confluence leaves the reduct unchanged. A global name stays a name, as the strategies keep it, since substituting a function-valued global's value inlines it per occurrence (`kernel::whnf::closed_machine_tests::the_closed_machine_keeps_a_global_argument_as_a_name`). A substituend whose evaluation errors falls back to its unreduced spelling; one that exhausts the budget propagates, so a program computing something expensive in a dead closed position may refuse on budget, never on a value.
- **A value may be deeper than the strategy's, except through a fold.** A more-reduced weak-head form is still one, but a folded recursive spelling is the answer a plain demand stops at, not a form to improve. The machine remembers each value in the table of the demand that produced it, a plain request reading the plain table alone, and recognizes a folded call at the head of its spine (`curios-core`'s `spine_rec_proj`), so `f(a)(b)` past a member's parameters is the call applied to what is left. Eta is not left to conversion: the machine runs the hosts' own contraction probe, because the elaborator's witness keying reads rigid heads off weak-head forms. `Induct` arms bind payload values directly on both sides.
- **Evidence.** `curios-core`'s `machine::tests` is the battery — both recursion encodings and the eliminator form under linear budgets, folded spellings surviving plain reduction, a dead erroring argument deferring, a non-productive group exhausting, a closed neutral accumulator staying linear — with `a_forced_bare_selection_does_not_answer_a_plain_probe`, mutation-checked. `curios-cert`'s `the_closed_machine_agrees_with_the_strategy` puts the same closed terms to a kernel with and without the machine and asserts identical reducts at both demands, including a bare selection, a call and a match forced then asked plainly, and `past_parameters` and `plain_then_forced`, mutation-checked. Every `/std` declaration elaborates and certifies with the machine live, and `kernel_disagreements` reports zero. Whether a run-dependent rigid head could reach the elaborator's witness keying is unprobed.
