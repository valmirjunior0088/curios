# Reused payloads

**Decision.** A precompiled payload filed under an address naming the executable that declares it, the compiler binary that built it, the ordered slots of its predecessor units and the engine that will run it may be executed without compiling or judging anything again, provided a record of the entry file, of every file its loader read and of what each predecessor contained still agrees with the disk. It stands on [Cached verdicts](cached-verdicts.md) one level up, with claims of its own beneath: an edited entry, an edited module of the entry, an edited dependency, a corrupted payload, each half-written slot state, and a foreign project's slot staged into this one are each a miss. A hit skips the entry's kernel recheck on the strength of the record, as a reused unit's is; what is handed back is machine code.

- **The entry's read set is closed, and its header is recorded apart.** The entry's modules join by the layout rule, as a unit's do. The entry's own header is parsed by the caller before resolution, so no loader logs it; it is recorded as a field of its own, by canonical path and a digest of the text that was parsed — never of a re-read, which races an edit and records newer text against an older artifact (`Entrypoint::opened` hands the parsed source back). Its path is checked for equality, since the address says nothing about which project asked, and two projects declaring one package and executable name address one slot; the loader's files keep the containment check, since a dependency materialized once under a shared store is genuinely shared.
- **A stale unit is a payload miss by construction.** The probe walks the unit sources in fold order, computing each slot, checking its record and digesting its stored bytes — the verification half of the unit store's own consultation, shared rather than restated — and a unit that fails, or that the store may not file at all, is a miss.
- **The machine is in the address.** A payload is what Cranelift emitted for the host's ISA, which neither the compiler digest nor any source covers, so the engine's compatibility stamp — target triple, ISA flags, tunables, wasm features and Wasmtime's version, folded by `curios-runtime` into a caller-supplied hasher — joins the address. Wasmtime's own stamp inside the artifact is the backstop: a deserialize failure at run time stays a hard error.
- **The budget is not in the key**, on [Cached verdicts](cached-verdicts.md)'s argument and one premise more: exhaustion is a refusal everywhere downstream of the judgment, since it propagates as an error and the erased optimizer takes no budget, so no pass degrades into a different artifact under a smaller allowance. The day one does, the budget enters the record. The output path and the program's arguments are not inputs.
- **The payload's digest is in its record**, a slot is one file renamed into place, and a store that cannot be written costs the reuse and never the verdict. Where it is weakest: Wasmtime's engine fingerprint is trusted to separate every pair of engines whose artifacts are mutually unreadable, with the artifact's stamp turning a too-coarse fingerprint into a loud refusal.
