# A group is total when every repeatable call path descends

**Assumes.** The size-change principle, as `curios-analysis`'s `decide` applies it: a recursive group whose call matrices, closed transitively under composition, carry a strict decrease on the diagonal of every idempotent matrix from a member to itself cannot recurse forever — given that the size order its matrices grade in is well founded on the values the calls are made at.

**Evidence.** Argued for the principle, which is Lee, Jones and Ben-Amram's theorem (POPL 2001) in the shape Abel's `foetus` gave it for dependent types, and probed at the engine's algebra. It is the one rule that turns a group's calls into `Total`, shared by both checkers (`grade` and `decide`), so a wrong verdict here is one neither catches in the other, and (T) and (V) inherit it whole ([Nothing reachable from a type is partial](nothing-reachable-from-a-type-is-partial.md), [Nothing at a proposition is partial](nothing-at-a-proposition-is-partial.md)).

- **The algebra.** A call matrix grades every callee argument against every caller parameter as strictly smaller, equal or unrelated; composition is the (join, compose) semiring over those sizes, the best relation reachable through any intermediate position (`curios-analysis`'s `totality/tests.rs`: `composition_annihilates_on_unknown_and_absorbs_on_less`, `join_keeps_the_strongest_of_two_routes`). An idempotent matrix is a path that composes with itself unchanged, the paths that can repeat forever, and a decrease on its diagonal is one that cannot be sustained. A self-call with no parameters is a 0×0 matrix, idempotent with no diagonal, so it never descends (`a_nullary_self_call_cannot_descend`), which is what refuses `rec inf : F = F/more(inf)` and `rec Bad : Type = Sink(Bad)`.
- **The closure is what sees mutual recursion.** Only a composite path is a cycle when members call each other, so the matrices are closed by extending each discovered element by the generators, without knowing which members were declared together (`mutual_recursion_is_caught_only_by_the_closure`). A closure that outgrows `CLOSURE_LIMIT`, 4 096 matrices, claims nothing: the group is `Partial`, the refusing direction.
- **The order is well founded on what it reads.** Sizes compare values by the proper subterm order (`shapes_are_compared_by_the_proper_subterm_order`), a rebuilt constructor below the binder it rebuilds, a literal as one packed run however large, and a function-typed payload as a branching node whose applications are its children ([Nothing reachable from a type is partial](nothing-reachable-from-a-type-is-partial.md)). Two terms the reader could not read are never equal (`an_unread_term_is_never_equal_to_another_unread_term`), since a manufactured `Same` is what a spurious idempotent matrix needs. Match refinement is part of the order: a parameter scrutinized by an enclosing arm is expanded through that arm's constructor before it is compared, without which `add/raw`'s two nil-arm matrices compose to an all-unknown idempotent matrix (`add_raw_is_accepted_only_because_arms_refine_the_scrutinee`). That the values themselves are finite trees is what (T) and (V) guarantee wherever the verdict is consulted.
