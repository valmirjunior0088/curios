# Universe instances and constraints

**Assumes.** An occurrence's universe instance satisfies its scheme's constraints before the declaration is read at it; every level an occurrence's type or sort is reported at is the instance's, not the scheme's; and the constraint set a declaration is checked under is satisfiable.

**Status.** **probed** at the instance check, the sort clause and satisfiability, and **probed differentially** against the elaborator's solver.

- **Instance, width and counts first.** The check fires at every polymorphic occurrence. The width is checked before the constraints, since discharging an empty constraint set says nothing, and a parameter index past the declaration's own count is refused in both checkers, since instantiation renumbers an out-of-range index down by the instance's width and would capture it. The `InductAt` and `StructAt` handles make the preconditions structural: holding one proves the instance's width and constraints, the parameter count and an inductive's index count passed, and an arity cannot be opened at parameters other than those checked (`arity_matches`). `Instance` carries an `InstanceHead` — a variable or a group projection — so only those heads are representable.
- **A bare occurrence of a scheme is refused.** A bare `Var` naming a polymorphic definition denotes no instance: answering its type from the stored scheme captures the scheme's parameters and discharges its constraints nowhere. `Globals::type_of` refuses it as `Globals::value` withholds a body — `recheck::universes_tests::a_bare_occurrence_of_a_universe_scheme_is_refused`, with `an_occurrence_stating_its_universe_instance_is_still_accepted` as the control, mutation-checked. From source, `tests::board::an_inferred_value_under_a_refined_proof_keeps_its_universe_instance` holds the elaborator to building every polymorphic occurrence as an `Instance`.
- **The sort clause holds over both head populations.** A local head is monomorphic, so its levels say nothing (`kernel::sort::tests::a_universe_instance_over_a_local_head_takes_the_locals_sort`); a bodiless polymorphic global classifies at the instance's level, through the lookup that types the same head inside a spine (`a_universe_instance_over_a_bodiless_scheme_classifies_at_the_instances_level`), reachable only through `Kernel::declare`; a defined scheme is instantiated by reduction first (`a_universe_instance_over_a_defined_scheme_classifies_at_the_instances_level`); and a `let`-bound head dissolves under reduction rather than aborting the walk (`recheck::universes_tests::a_let_bound_instance_head_dissolves_under_reduction_rather_than_aborting_the_walk`).
- **Satisfiability is decided over the naturals.** The kernel assumes a declaration's constraint set while checking under it, so a set wrongly called satisfiable is a hypothesis set entailment proves anything from. It is decided by loop-checking a least model with zero below every head, so a parameter forced below zero through another derives `0 + 1 ≤ 0` (`satisfy::tests::a_parameter_forced_below_zero_through_another_is_unsatisfiable`), and `a_set_is_satisfiable_exactly_when_it_has_a_model_in_the_naturals` holds the decision to a brute-force search both ways. `both_checkers_decide_universe_context_validity_alike` puts every definition's context to the kernel and the elaborator's solver; closure is decided once, in `curios-core`, and is no part of the differential.
