# Foreign wire contract

**Assumes.** A `foreign` declaration's type is drawn from the wire grammar, so an embedder cannot supply an inhabitant of a proposition, and every reply the program reads is a value its row allows.

**Evidence.** Probed at the surface, where the grammar refuses, and from Core with a forged row, the half no surface program reaches. The contract is representational: a builtin is an identity whose row is the roster's and cannot be written on the term, a declared row's signature is a closed enum of wire types with no case for a nominal type, and typing constructs a host call's type through `curios_core::foreign_signature` rather than reading one off the term. `tests::board::a_foreign_declaration_is_confined_to_wire_types` is the surface half; `curios-cert`'s `recheck/foreign_tests.rs` refuses a forged declared row and a builtin held at another row's type.

**What the contract does not claim.** The native adapter refuses its own host's reply outside the row, and the guest holds every reply to its row before reading it ([A host operation has one contract, checked at both ends](../../runtime/a-host-operation-has-one-contract-checked-at-both-ends.md)), so no host hands the program a value its type does not admit. Whether a host told the truth about the world — that accepted bytes reached the file, that an address is the one a name resolves to — is assumed. The native host assumes one thing of its embedder: the process leaves `SIGCHLD` at its default and reaps nothing, which keeps a child's pid reserved until the host has recorded how it ended, so `proc/kill` never signals a pid the system has handed on (`curios-runtime`'s `os_child`).
