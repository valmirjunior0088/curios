# The soundness board

**Decision.** The intended claim is that no closed term has type `/std/Bool/False`. What the compiler enforces is narrower: nothing in a type position and nothing at a `Prop`-sorted type is partial ([Totality of the erased program](totality-of-the-erased-program.md)), and every rule that can admit a term holds. That claim quantifies over every such rule, so it is stated against an enumerated board: one entry per rule in the directories beside this decision, each stating what it **assumes** and its **status**, and naming the fixtures that are its evidence. The two claims coincide only if the soundness board is complete and each entry correct, which is not established. The trusted base is `curios-cert`'s kernel and the shared layer it judges through — `curios-analysis`, `curios-core`, `curios-num` and `curios-algebra` ([An independent kernel re-checks what the elaborator accepts](an-independent-kernel-re-checks-what-the-elaborator-accepts.md)) — and the Rust implementation of all of it.

**How an entry is read.** *Probed*: an adversarial program is written and refused. *Argued*: a written justification exists. *Auditable only*: no surface program can exercise the rule, so reading the implementation is the only evidence. Probed and argued are independent. An entry names its fixtures rather than counting them, because a name is a contract and a count goes quietly false; a rung reached by exactly one fixture records a mutation check, which is all that separates a sole-reach fixture from dead code. Some rules are decided over structure no source program constructs — level subsumption the elaborator did not choose, the internal state index inversion and the conversion recurrence turn on, an intrinsic's signature read from the roster that spells it — so their evidence is fixtures written against the checkers directly. A defect's history is kept only while the defect is expressible.

**The soundness board is divided by the part of the judgment a rule belongs to**, one directory beside this decision per part: *typing*, the kernel's walk itself — binder identity, telescope instantiation, the checked rules; *formation*, what counts as a type or a declaration, positivity and universes; *conversion*, definitional equality and every component it believes about computation — the intrinsic folds and the free-monoid peel, the carriers' algebra, the bounds oracle, the binary64 model, the closed machine and the evaluation memo; *elimination*, the guard, coverage, inversion, and the case equations an arm assumes; *totality*, the erasure obligations and the size-change principle they rest on; *effects*, what keeps a term outside `Io` pure and a host's answer inside its row; and *admission*, the verdicts believed without judging again. The components conversion believes about computation — the folds and the peel, the algebra, the oracle, the model and the machine, each one function below both checkers, and the kernel's evaluation memo, its own pure function — share one route: a wrong answer is a false definitional equation that conversion believes and congruence carries to `False`. Each names that route rather than restating it.

**An entry earns its place by assuming something** beyond the term in front of it: a declaration, a carried number, a cached verdict, an equation stated elsewhere. A rule that only destructures inherits its correctness from the representation — `Var`, `Let`, the bare `Func` rule and the sort heads inherit [Telescope instantiation](typing/telescope-instantiation.md) and [Binder identity](typing/binder-identity.md) — and a component several rules read earns one entry rather than an argument at each reader. Three things meet the criterion's letter and stay off it. Representation privacy rests on a declaration but cannot reach `False`, because a proposition over an abstract type still quantifies over its representation, so forging an inhabitant falsifies no theorem a module can state; it is [Privacy is scoped to a subtree](../surface/privacy-is-scoped-to-a-subtree.md)'s. `Term`'s equality is a structural walk whose cached hash is consulted only to refuse, so a collision costs a walk and never a verdict. Level arithmetic is checked throughout and refuses with `OffsetOverflow` (`successor_distributes_and_overflow_is_checked`), so the hierarchy cannot be collapsed by saturating it.

**An entry states what it assumes and its status; a decision states what was decided, why, and what was rejected.** The two formats sit side by side, because a decision changes when someone decides something and an entry's grade whenever its rule is attacked.

**Four boundaries are stated here, because none is a rule that can admit a term.**

- **Nothing below Core is certified.** `certify_module` runs inside `compile_entrypoint` against each elaborated unit; erasure, the optimizers, the CPS lowering and Wasm emission run afterwards with no semantic check between them, and `curios-cont`'s `verify` checks scoping and arity, not preservation. *No closed term inhabits `False`* and *the emitted module computes what the source says* are different claims, and the second's ledger is a sample: `curios`'s `tests::erasure::value_tests` prints, at each of erasure's deletion sites, a value a proof in the same program states.
- **What is already in scope is believed, on a ground.** `certify_module` judges each unit's own items against a `Globals` over the units in scope, the archived prelude's built by its establishing walk, which panics on the first refusal, and every pass skips by name what that environment declares. Strict positivity walks everything, since a user declaration may name a prelude one, and so does conversion, which unfolds arbitrarily deep. The rest is [Judging only what is not in scope](admission/judging-only-what-is-not-in-scope.md)'s.
- **Acceptance is relative to a deterministic step budget, and upward closed in it.** Running out refuses and never selects anything: both checkers zero the remainder on a refusal, a real exhaustion propagates, `curios-elab`'s `Context::within_allowance` absorbs one only where its cap rather than the remainder bound, the size-change engine reads what it could not reduce as unread or as establishing nothing, and no clash, inequality or impossible case is concluded from an unfinished computation. That is argued from a sweep of those sites and checked by the ignored `tests::inference::budget_tests::acceptance_is_upward_closed_in_the_budget`. A free memo hit can only undercharge, and a `Partial` classification may be the budget's rather than the program's ([The certifier's totality record](totality/the-certifiers-totality-record.md)).
- **The Rust implementation sits off the soundness board and fails closed.** A panic, an abort or a stack overflow is acceptable only where it refuses. Blindness refuses everywhere but one place: positivity answers `Mixed` for a name outside its set, reduction goes stuck on a shape it cannot fire, inversion derives nothing at a `Prop`-valued position, the size reader answers unread and an under-applied call grades unknown, while a recursive call nobody found contributes no edge and a group with no edges is accepted — which is why the kernel takes a group's calls from the applications it types ([`curios-cert`'s README](../../../curios-cert/README.md#a-groups-calls-are-the-ones-the-kernel-types)).

**Rationale.** Each boundary is reachable by reading the code and by no other route, which is what the enumeration exists to remove; a reader who trusts the soundness board without them trusts a narrower claim than they think.

**Rejected.**

- **The trusted base as prose**, which cannot be checked or falsified and cannot tell an attacked rule from an assumed one.
- **A passing corpus as evidence of coverage.** A defect is found by counting or probing, not by the corpus failing: the corpus passes whether or not a rule fires at its sites, and passes obligation (V) inert at argument positions ([Totality of the erased program](totality-of-the-erased-program.md)). An inert rule admits nothing, but the corpus is then no evidence about it, and a fixture reaching it has to be constructed.
- **An index of the entries and their grades**, a second copy that could only drift.
