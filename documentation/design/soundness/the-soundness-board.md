# The soundness board

**Decision.** The intended claim is that no closed term has type `/std/Bool/False`. What the compiler enforces is narrower: nothing in a type position and nothing at a `Prop`-sorted type is partial ([Totality of the erased program](totality-of-the-erased-program.md)), and every rule that can admit a term holds. Every proof of `False` found through one is a ticket on the board, `xboard/src/board/`, put to the checkers again by `cargo xboard` ([`xboard`'s README](../../../xboard/README.md)); an attack that found nothing is a test of the crate it attacked; and a rule's design is its decision's — beside this one, under [theory](../theory/) or in the README of the crate that implements it. The two claims coincide only if every such rule holds, which is not established. The trusted base is `curios-cert`'s kernel and the shared layer it judges through — `curios-analysis`, `curios-core`, `curios-num` and `curios-algebra` ([An independent kernel re-checks what the elaborator accepts](an-independent-kernel-re-checks-what-the-elaborator-accepts.md)) — and the Rust implementation of all of it.

**The components conversion believes about computation share one route to `False`** — the folds and the peel, the algebra, the oracle, the model and the machine, each one function below both checkers, and the kernel's evaluation memo, its own pure function: a wrong answer is a false definitional equation that conversion believes and congruence carries to `False`.

**Three things read as rules that could admit, and cannot.** Representation privacy rests on a declaration but cannot reach `False`, because a proposition over an abstract type still quantifies over its representation, so forging an inhabitant falsifies no theorem a module can state; it is [Privacy is scoped to a subtree](../surface/privacy-is-scoped-to-a-subtree.md)'s. `Term`'s equality is a structural walk whose cached hash is consulted only to refuse, so a collision costs a walk and never a verdict. Level arithmetic is checked throughout and refuses with `OffsetOverflow`, so the hierarchy cannot be collapsed by saturating it.

**Four boundaries are stated here, because none is a rule that can admit a term.**

- **Nothing below Core is certified.** `certify_module` runs inside `compile_entrypoint` against each elaborated unit; erasure, the optimizers, the CPS lowering and Wasm emission run afterwards with no semantic check between them, and `curios-cont`'s `verify` checks scoping and arity, not preservation. *No closed term inhabits `False`* and *the emitted module computes what the source says* are different claims, and the second is held by a sample: tests that print, at each of erasure's deletion sites, a value a proof in the same program states.
- **What is already in scope is believed, on a ground.** `certify_module` judges each unit's own items against a `Globals` over the units in scope, the archived prelude's built by its establishing walk, which panics on the first refusal, and every pass skips by name what that environment declares. Strict positivity walks everything, since a user declaration may name a prelude one, and so does conversion, which unfolds arbitrarily deep. What holds the skip is the mount discipline: mount sets are pairwise disjoint, checked in `curios-text`'s `into_core` before discovery, so two units cannot declare one name, a unit claiming a prefix the prelude mounts collides and is refused ([A module is a compilation unit](../compilation/a-module-is-a-compilation-unit-and-the-prelude-is-an-environment.md)), and the elaborator's registries refuse a duplicate rather than overwriting one. The kernel's skip rests on that refusal, and nothing in `curios-cert` checks it.
- **Acceptance is relative to a deterministic step budget, and upward closed in it.** Running out refuses and never selects anything: both checkers zero the remainder on a refusal, a real exhaustion propagates, `curios-elab`'s `Context::within_allowance` absorbs one only where its cap rather than the remainder bound, the size-change engine reads what it could not reduce as unread or as establishing nothing, and no clash, inequality or impossible case is concluded from an unfinished computation. A free memo hit can only undercharge, and a `Partial` classification may be the budget's rather than the program's ([`curios-cert`'s README](../../../curios-cert/README.md#a-later-walk-reads-the-certifiers-own-totality-record-never-elaborations-stamp)).
- **The Rust implementation sits off the soundness board and fails closed.** A panic, an abort or a stack overflow is acceptable only where it refuses. Blindness refuses everywhere but one place: positivity answers `Mixed` for a name outside its set and variance `Invariant` for a family no registry holds, reduction goes stuck on a shape it cannot fire, inversion derives nothing at a `Prop`-valued position, the size reader answers unread and an under-applied call grades unknown, while a recursive call nobody found contributes no edge and a group with no edges is accepted — which is why the kernel takes a group's calls from the applications it types ([`curios-cert`'s README](../../../curios-cert/README.md#a-groups-calls-are-the-ones-the-kernel-types)).

**Rationale.** Each boundary is reachable by reading the code and by no other route, which is what the enumeration exists to remove; a reader who trusts the soundness board without them trusts a narrower claim than they think.

**Rejected.**

- **The trusted base as prose**, which cannot be checked or falsified and cannot tell an attacked rule from an assumed one.
- **A passing corpus as evidence of coverage.** A defect is found by counting or probing, not by the corpus failing: the corpus passes whether or not a rule fires at its sites, and passes obligation (V) inert at argument positions ([Totality of the erased program](totality-of-the-erased-program.md)). An inert rule admits nothing, but the corpus is then no evidence about it, and a fixture reaching it has to be constructed.
- **An entry per rule, stating what the rule assumes and grading its evidence**: a second statement of each rule beside its decision, and an inventory of tests nothing held to the tree. A flaw is a ticket the board runs, an attack that found nothing is a test, and a rule is its decision's.
