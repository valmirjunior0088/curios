# Patterns are compiled where their types are known

**Decision.** Lowering hands Core a match as it is written, and the elaborator compiles its patterns, where the type of what each matches is known.

- **The match as written.** A match reaches Core as its scrutinee, its motive where one is written, and its arms, each a pattern and a body (`curios_core::Matrix`, a member of `Transient`). A pattern mirrors the surface's, a constructor kept as the tag it is spelled by; a body is an ordinary function over the names its pattern binds, in the order it writes them, lowered once under those names. A `choose` bind arm is the two arms `pattern => body | _ => rest`. Only the elaborator reads the form: it never survives elaboration, and the kernel refuses it as it refuses every `Transient`.
- **The tree.** The elaborator builds the decision tree the arms come to, each column's cases read off its type. Columns are taken left to right. A column no arm takes apart is retired, each name written there bound to it. A tuple or struct column is flattened into its fields' projections, a struct pattern's head held to the structure the column's type is, and a tuple written in place is flattened into the terms written in it, each a scrutinee of its own that an arm refines as it refines any other. Any other column is split by its type: the arms that name a case are grouped under it, an arm that writes a binder there joins the group of every case some arm names, and the cases no arm names, where inversion leaves one possible, are one arm over the arms that write a binder. A case inversion rules out is no group unless an arm names it. Arms of one constructor meet its payloads each by its own marks.
- **An arm is typed once, where its own pattern states it.** An arm's body is elaborated once, in the context of the match with the arm's own cases entered and nothing else: each constructor or carrier case it writes is entered as an arm of that case is, and nothing is assumed of a column where it writes a binder. An arm whose every case on the way to its leaf is one it states is elaborated at that leaf. Any other is elaborated by a walk of its own cases alone, standing on the frames held where the match is entered, and each leaf that takes it holds that body with the leaf's binders in the places of the walk's. The elaborator does not type such an instance again: the kernel types it where it stands ([An independent kernel re-checks what the elaborator accepts](../soundness/an-independent-kernel-re-checks-what-the-elaborator-accepts.md)).
- **The arm that cannot fail is typed where the match stands.** A final arm whose pattern takes nothing apart that could fail states no case, so it is elaborated in the match's own context and against the match's own type, once, after the arms before it. It is written in place where one leaf takes it, and where more do it is bound once, as a function of no argument, and called from each.
- **Coverage and reachability are read off the tree.** The arms that reach a leaf are its candidates and the first written is taken; it is a case of each of the others or has each of them as a case, or the match is refused with the two arms and the leaf's value written as a pattern. A case no arm reaches is a value no arm matches, and the match is refused with that value as a pattern, `_` wherever no case was read. An arm no leaf takes is refused. Each is an error and no lint. Arm order decides none of it ([An arm is checked in a context specialized by index inversion](../theory/an-arm-is-checked-in-a-context-specialized-by-index-inversion.md)).

**Rationale.**

- **A column's cases are its type's.** The step for a column that mixes a binder with constructors puts each binder row into every constructor's group and makes the binder rows alone the case of every constructor no row names (Maranget, "Compiling Pattern Matching to Good Decision Trees"), and the second half needs the column's signature: "the default case is present, if and only if the set of constructors is not a signature". Lowering reads a constructor as a bare tag whose namespace the scrutinee's type supplies, so it cannot say which constructors a binder stands for, and both of its guesses are wrong somewhere: a default it always emits is dead where every constructor is named and is still checked, and with none emitted a binder covers no constructor that lacks an arm.
- **A body typed where its leaves meet is typed without what its arm states.** A default bound above its match is elaborated before the arms and in inference, so a numeral in it is realized at its default type and an action in it finds no monad; and a body that rests on a bound its own guard decides is refused when it is lifted out of the arm that decides it.
- **A body typed again at every leaf is accepted or refused by the arms beside it.** A column is split because some arm names a constructor in it, so a body typed under that split is typed with a case another arm caused, loses it when that arm is edited, and would type or not by the order the columns are taken in. It is also elaborated once for each leaf, a written goal in it reported once for each. Typed at its own pattern, what an arm's body may rest on is what the arm says.
- **A leaf's frame holds what the arm states and more.** Typing is closed under substitution and under a case added, which is the rule the kernel is held to, the arms no reduction takes excused. An elaborator that typed each instance again would refuse, with the kernel, a program that is well typed.
- **One binding of the arm that cannot fail keeps a ladder its size.** It is typed with no case of its own to assume, so one function types where the match stands, and a ladder of bind arms stays as long as it is written, where a copy for every refutable pattern of the arm before it would double at each arm.
- **The tree answers both questions exactly.** It visits every case some value has and no other, inversion included, where usefulness computed over the patterns alone knows no index. One default arm for the constructors no arm names bounds an arm's instances by the constructors arms name, where a group for every constructor of a wide family would write one for each.

**Rejected.**

- **Compiling in lowering**, by either guess about a binder's cases, or by skipping a default no constructor reaches, which stops checking a default a reader wrote after exhaustive arms.
- **A body bound once as a local function and applied from each leaf.** Core has no equation outside an arm, so the kernel types such a function without the arm's cases, and a function written without its parameters' types is refused.
- **A second kind of Core node that shares a body among leaves.** The kernel would need a rule for what the body may assume. What the copies cost in a compiled program is [a body an arm writes once is emitted once](../../roadmap/compilation/210-a-body-an-arm-writes-once-is-emitted-once.md)'s.
- **Keeping a hole for the type of a default bound once**, which is what types it in inference, and **a copy of it at each leaf**, for the ladder.
- **A group for every constructor, named or not**, and **choosing the column to split by necessity**, which changes what every match compiles to for trees nothing has found large.
- **A second pass computing usefulness beside the tree**, a second statement of which cases there are, and **a lint for an arm no value reaches**, which lowering cannot find.
