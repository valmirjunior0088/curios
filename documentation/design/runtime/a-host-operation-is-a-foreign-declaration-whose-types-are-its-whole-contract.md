# A host operation is a foreign declaration whose types are its whole contract

**Decision.** Everything a program asks of its host is a `foreign` declaration, the standard library's exactly as a package's. `/std/Handle` declares `foreign handle_read: (Handle, Nat) -> {status: Nat, bytes: Bytes}` privately, beside the function that reads its reply, and a program imports the row under `ffi` by the name it is declared under, `/std/Handle/handle_read`. That name is private in the language and public on the wire: no program can call the row unread, and it is the name every host, module and embedder answers by. The compiler knows no host: a term carries the declaration it calls, `/sys` declares no host operation, and the one `sys` import is `panic`, the emitter's own refusal. Who answers a row is decided where the program is linked — a module's export or an embedder's binding where there is one, and the host otherwise — and nothing in the program says which.

The host's side of each declaration is one typed row of `curios-abi`'s `for_each_host_op!` table: the Rust signature a host implements, operands arriving owned and the reply typed as what it is — `Result<Handle, Failure>` for an open, `Result<Option<Vec<u8>>, Failure>` for a read, `Option<Vec<u8>>` for a lookup, `Termination` for exit — the `/std` module that declares it, and what its operands must hold before the host is asked, with what its types cannot say in the rustdoc beside it. `curios-prelude-archive`'s `the_library_declares_every_row_a_host_answers` holds the library's declarations and the table to each other, by name and by signature.

A row's wire types are its whole contract, and each side keeps the half it alone can. An adapter stands between the guest and whatever answers a row — the native runtime's before a host or a module, the browser harness's before its own rows or a hook — and the wire is the adapter's: it decodes each operand into its type, refusing a malformed one, admits the call to the row's requirements, and writes the reply from a value of the row's types, refusing an answer that is none. The guest therefore checks no reply. It narrows a `Nat` or an `Int` to the wire on the way out and refuses one the wire cannot carry, and a call to a row declared `-> Never` is followed by `unreachable`. What a host promises beyond its types — a read no longer than was asked, a nanosecond count below a second, a mask within the interest given — is that host's to keep, and each host's own tests hold it to it.

`/std` reads every reply where it asks for it, totally: the status before any payload, a status it has no name for carried as `Io/Error/other`, a closed code it cannot read a failure rather than a default, and a write that accepts nothing of a buffer that holds something a failure rather than a loop. No reading is shared between rows, and no reading can fail to produce a value. Every host keeps one behavior per operation — a stream used against its direction fails with `EBADF`, a resource that cannot do what was asked with `not_found`, a poll reports a failed handle as `err` for its slot — and how the native host keeps them without waiting is [Only a fiber waits](../standard-library/only-a-fiber-waits.md).

**Rationale.**

- **One mechanism leaves nothing for the compiler to know.** A table of builtin operations inside the compiler is a second way to say what `foreign` already says: its own namespace, its own identity on a term, its own minted declarations and its own reading of a reply, each to be kept in step with the first. With one, a host is whatever answers the names a program reaches, and a module, an embedder or a test replaces it row by row with no door of its own.
- **A check can only guard what its author cannot see.** An adapter sees every operand a guest sends and no guest it can trust, so it validates them. A reply is produced by the adapter's own side from a typed value: a check of it against the row is the row's types stated twice, paid on every call, guarding a fault that only the code beside the check could make. Types the adapter enforces by construction are a structural guarantee; a contract re-examined on arrival says the types guarantee nothing, and then no reading beneath `Io` could rely on them either.
- **A promise the types do not make is behavior, and behavior is tested where it is implemented.** No check at the wire establishes that a host told the truth about the world. A total reading in `/std` bounds what a broken promise can do to a wrong value or a named failure, in code the kernel certifies, and never to a read of something that is not there.
- **A reading beside its row is the row's whole meaning in one place.** The readings differ in their payloads, and the few lines they share are the comparison of a status with `ok`; a function shared for those lines belongs to no module that could own it.
- **The declarations are private because the reading is the interface.** A program that could call a row could discard the status it answers.

**Rejected.**

- **A builtin's identity carried on a term and read back from a table**, beside declared rows carrying their own: two kinds of row at every stage from the surface to the linker.
- **Replies held to their rows in the guest**, a refusal class and a run of comparisons after every call; **in the adapter**, the same sentences evaluated one step earlier; **or only where assertions are on**, a contract that exists in one build of the host and not the one that ships.
- **A reading that can refuse** — a panic in `/std` for a reply it cannot interpret — which makes a total function partial for a case its types already exclude.
- **Invalid tags read as defaults, failures as successes, or polling errors as inactivity**, each erasing a distinction a caller relies on; **a refusal that promises rollback or retries on its own**, when work may already have happened.
- **`/sys` reading each outcome into a `Result` or an `Option`**, which puts a host's vocabulary in the compiler's own unit and a generated function between every row and its caller; **one shared reader in `/std`**, the same function with a home that owns none of what it reads.
- **The wire codes as declarations too**: a status or a mode is a constant both sides must agree on with no call to carry it, so `/sys` keeps minting them from `curios-abi`, the one table.
- **Guest sums on the wire**, and **one codec chosen by the guest result type**: a lookup's absence and a read's end cross by different conventions, and the row chooses.
- **A spawned stream read by its token**, which keeps the empty token alive in a success position, and **a call per stream**, which leaves a started child unguarded when one fails.
- **The browser's signatures in a custom section**, a second encoding of rows that already travel beside the program.
