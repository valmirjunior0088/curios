# A wait is a suspension, and only the host waits

**Decision.** Nothing in a program blocks. A forced `Io` description answers its value or a suspension: the handles and the cells it waits on, the description that cancels it, and the rest of it. Whoever advances a description decides what a suspension means — the host waits on its handles, a combinator runs another branch — so a lifted action is atomic only between its suspensions. `/sys/Io` states the two operations, `suspend(on, filled, cancel, rest)` and `advance(action, done, suspended)`, and `/std` alone names them, by their full `/sys` path, keeping what the pair asks of whoever advances: a rest performed once, and a dropped rest's cancel performed. A program waits through `/std/Io`'s waits, brackets and combinators.

The host runs a program by advancing it and waits between turns, on the handles a suspension names and nowhere else: no row sleeps. A suspension waits on handles the host can see and on `Cell({})`s the program fills. A deadline is a timer's handle, a stream's readiness a watch's, a reply a row answers later a handle the host files; a condition on the program's own state — a future fulfilled, a channel holding an item or room — is a cell the change fills, so a suspension is advanced again only once something it waits on has moved, and the host never reads a cell. A suspension on no handle at the top of a program is a deadlock, whatever cells it waits on: the host runs its cancel, reports, and ends the program with status `1`.

The host never waits on a peer. Every handle whose progress another party decides — a socket in any state, an accepted stream, a pipe to a child, a FIFO or device opened by path, a serial port, standard input — is non-blocking from the moment it exists, and a row that cannot progress answers `would_block`, on which its caller suspends on a watch and tries again. The standard streams' flags are the process's and are never changed: a read of standard input and a write to standard output or standard error ask first, without waiting, whether the descriptor would block. `connect` is two rows, the second reading the outcome once the socket is writable; a TLS session is filed without a handshake, which the reads and writes that follow drive. Every write is one attempt that reports how much it accepted, a flush row hands on what the host still holds, a finish row ends a stream's sending half with its receiving half left open, and close never waits: a serial port's close discards what the wire has not taken. A wait that only blocking can make — a name lookup, a serial port's drain, an embedder's slow work — is a row answered later, run off the host's thread while its call suspends ([A host operation is a foreign declaration](../runtime/a-host-operation-is-a-foreign-declaration-whose-types-are-its-whole-contract.md)).

Cancellation is structural. A combinator that no longer needs a suspended branch performs the branch's cancel and drops its rest; `using(release, body)` carries `release(cancelled)` on each suspension that leaves its body and calls `release(finished)` where the body answers. Concurrency is structured combinators in `/std/Io` — `both`, `all`, `first`, `race`, `timeout`, and `scope` with `spawn`, `join` and `join_all` — over one driver that holds each branch's rest, advances a suspended branch once something it waits on has moved, and suspends outward on the union of what its branches wait on. A scope answers with its body, and the children still running then are cancelled where they wait, so no child outlives the scope that runs it.

Branches coordinate through write-once cells and channels in the guest heap, whose operations are `Io` descriptions that complete without calling the host or suspending. A cell publishes one answer. A channel's nonblocking push and take each commit and report their own outcome — `Push` taken, full or closed, `Take(A)` an item, empty or ended — and closing keeps queued items for draining. A future keeps a cell its fulfilment fills after the value, and a channel one for each side: a waiter checks, takes the cell there or makes one, and suspends on it, with nothing run between, so no fill is lost; every waiter of a side wakes and checks again, and a waiter dropped drops its cell, so nothing registered needs removing. Selection over offers keeps list-order priority and takes nothing out of a source it did not win.

**Rationale.**

- **A lifted action was atomic, and a wait inside one held every branch.** A resumption monad's lift runs an action whole, as "an atomic action in a concurrent setting" ([Claessen, A Poor Man's Concurrency Monad](https://www.cse.chalmers.se/edu/course.2018/pfp/Papers/PMCJFP.pdf)), and a description that can stop part-way is what lets the lift stay without the stall: the branch that waits is the only one that does.
- **The host owns every wait, as a host does once it runs one event loop for everything it hosts** ([WASI 0.3](https://bytecodealliance.org/articles/WASI-0.3), the Component Model's [callback ABI](https://github.com/WebAssembly/component-model/blob/main/design/mvp/Concurrency.md)). A program that waits in a row of its own sleeps the host's thread, which the browser cannot do at all; a program that answers its suspension and returns is a step function the host drives, natively over `poll(2)` and in the browser over the event loop.
- **Suspension needs no stack of its own.** A description's answer is a value or a request with its rest, as a freer monad's is, and a bind that tests what its action answered and appends itself to a suspension's frames is the shape Koka compiles its effects to: a test the common path pays and predicts, a slow path shared by every bind, and no test where no flow brings a suspension.
- **A cell the program fills wakes exactly what can move.** Advancing a waiter on every step of a sibling spins two waiters against each other, and advancing it only on a handle's readiness reports a deadlock where a sibling has already sent; a cell is filled by the change itself, needs no host call, and is dropped with its waiter.
- **Cancellation runs where the cancelled code waits**, as Eio's and Trio's do, and nothing is resumed with a cancellation, so a wait cannot fail by one and a row needs no `cancelled` of its own.
- **Non-blocking is a property of the host**, so the library cannot forget to ask for it and the scripted host can answer `would_block` at any row. A close that flushes waits on the peer or drops what it cannot send, and a write that loops until the buffer is taken cannot report the prefix it wrote before a failure.

**Rejected.**

- **Keeping waits out of `Io` and guarding the scheduler's driver** — an opaque entry, a turn row carrying a continuation, a second carrier: each moves the bridge between the library's continuations and the host's wait, and none removes it. **A blocking monad beside a fiber monad**, a thread that waits where the host owns every wait; **walking the lift back or making it explicit**, after which a lifted wait stalls as an inserted one does; **a host that refuses a nested scheduler at run time**, a report of what a suspension makes harmless.
- **Stack switching**, a proposal behind a flag in Wasmtime and unshipped in browsers, for a suspension a description already affords; the pair is the seam a captured continuation could replace once it is standard everywhere.
- **Cancellation delivered as a value at a suspension**, which gives every wait a failure; **an explicit `cancel`**, where a combinator already decides when a branch is no longer needed.
- **A condition on the program's state as a suspension on no handle**, "until a sibling runs", which spins or reports false deadlocks; **that condition as a host handle the program signals**, a host call for every wait and every fill; **a counter every change moves**, which wakes every waiter on every change; **waking one waiter rather than every one**, which makes a waiter dropped after its wake pass it on.
- **Setting a handle non-blocking inside a lift**, which cannot see the handles an action touches and would change the standard streams' flags under the processes sharing them; **a `set_nonblocking` row the library calls after every open**; **timeouts as socket options**, where `timeout` bounds any wait from the branch that waits; **a blocking `connect` for local peers**; **a handshake run with the socket briefly blocking**.
- **A general rewritable cell beside the write-once one**, two mutation vocabularies; **a queue of write-once cells**, which retains consumed chains; **unbounded channels**, which give up the storage bound; **capacity-zero rendezvous**, which entangles buffering with receipt; **`Bool` for push and `Option(A)` for take**, which merge outcomes a later observation cannot recover.
- **Completion for every stream**, every row redesigned and an abandoned read in flight to cancel or keep, where readiness holds nothing in flight while a reader is suspended.
