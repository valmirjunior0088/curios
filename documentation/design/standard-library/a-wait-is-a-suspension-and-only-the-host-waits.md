# A wait is a suspension, and only the host waits

**Decision.** Nothing in a program blocks. A forced `Io` description answers its value or a suspension: the handles and the cells it waits on, the description that cancels it, and the rest of it. Whoever advances a description decides what a suspension means — the host waits on its handles, a combinator runs another branch — so a lifted action is atomic only between its suspensions. `/sys/Io` states the two operations, `suspend(on, filled, cancel, rest)` and `advance(action, done, suspended)`, and `/std` alone names them, by their full `/sys` path, in four places: the loop every wait on the program's own state goes through, a handle's wait, the driver every combinator is written over, and the bracket a scope's releases run through. Each keeps what the pair asks of whoever advances: a rest performed once, and a dropped rest's cancel performed. A program waits through `/std/Io`'s waits, brackets and combinators.

The host runs a program by advancing it and waits between turns, on the handles a suspension names and nowhere else: no row sleeps. A suspension waits on handles the host can see and on `Cell({})`s the program fills. A deadline is a handle `clock_deadline` mints at an instant of the monotonic clock, a stream's readiness a watch's, a reply a row answers later a handle the host files; a condition on the program's own state — a future filled, a channel holding an item or room — is a cell the change fills, so a suspension is advanced again only once something it waits on has moved, and the host never reads a cell. A suspension on no handle at the top of a program is a deadlock, whatever cells it waits on: the host runs its cancel, reports, and ends the program with status `1`.

The host never waits on a peer. Every handle whose progress another party decides — a socket in any state, an accepted stream, a pipe to a child, a FIFO or device opened by path, a serial port, standard input — is non-blocking from the moment it exists, and a row that cannot progress answers `would_block`, on which its caller suspends on a watch and tries again. The standard streams' flags are the process's and are never changed: a read of standard input and a write to standard output or standard error ask first, without waiting, whether the descriptor would block. `connect` is two rows, the second reading the outcome once the socket is writable; a TLS session is filed without a handshake, which the reads and writes that follow drive. Every write is one attempt that reports how much it accepted, a flush row hands on what the host still holds, a finish row ends a stream's sending half with its receiving half left open, and close never waits: a serial port's close discards what the wire has not taken. A wait that only blocking can make — a name lookup, a serial port's drain, an embedder's slow work — is a row answered later, run off the host's thread while its call suspends ([A host operation is a foreign declaration](../runtime/a-host-operation-is-a-foreign-declaration-whose-types-are-its-whole-contract.md)).

Every wait on the program's own state goes through one loop: it runs an attempt, and where the attempt declines it suspends on what the attempt waits for — a deadline, the cell a future or a side of a channel keeps — with nothing run between the check and the suspension, so no change is missed, and it releases what it made for the wait whether the wait ends or is cancelled. A handle's operation is retried in a loop of its own around a watch of the handle, which the host reports ready when the handle is ready already as well as when it becomes so, so no readiness between the attempt and the watch is missed either. An attempt takes nothing unless it answers: a row that would block commits nothing, and a channel's take and a future's poll take only what they answer with.

Cancellation is structural. A combinator that no longer needs a suspended branch performs the branch's cancel and drops its rest. Concurrency is structured combinators in `/std/Io` — `both`, `all`, `select` and `timeout` — and `Io/scope`, which hands a body a scope to `spawn` children into, `join_all` and `Task/join` waiting on them, over one driver that holds each branch's rest, advances a suspended branch once something it waits on has moved, and suspends outward on the union of what its branches wait on. `select` answers with the first of its actions to finish and cancels the rest where they wait: the driver steps its branches one at a time in list order and advances none once one has answered, so of two that can answer at once the earlier wins, and an action cancelled where it waits has taken nothing, unless it took something and then waited again. `timeout` is a `select` against a sleep. `/std/Try`'s `both` and `all` answer the first failure and cancel the rest where they wait, composed from these. A scope answers with its body; the children still running then are cancelled where they wait, and then every release `defer` gave it runs, the latest first, told whether the scope `finished` or was `cancelled` where it waited — a release carried on each suspension that leaves the scope, so a scope that whatever advances it drops releases as surely as one that answers. A child's failure is a value its join reads, as its answer is. Every resource is opened into a scope — a file, a connection, a listener, a child process, a serial port, a terminal's raw mode, a terminal session — so nothing a program opens outlives the scope that opened it, as no child outlives the scope that runs it.

Branches coordinate through `/std/Cell`'s write-once cells and `/std/Channel`'s channels, backed by guest-heap primitives whose `Io` operations complete without calling the host or suspending. A cell publishes one answer. A channel is one value, its bounded queue beside the cells its waiters wait on: its nonblocking push and take each commit and report their own outcome — `Push` taken, full or closed, `Take(A)` an item, empty or ended — finishing it keeps queued items for draining, and its length, its capacity and whether it was finished are observations, which hold until the branch reading them waits. A future keeps a cell filled after its value, and a channel one for each side: a waiter checks, takes the cell there or makes one, and suspends on it, with nothing run between, so no fill is lost; every waiter of a side wakes and checks again, and a waiter dropped drops its cell, so nothing registered needs removing.

**Rationale.**

- **A lifted action was atomic, and a wait inside one held every branch.** A resumption monad's lift runs an action whole, as "an atomic action in a concurrent setting" ([Claessen, A Poor Man's Concurrency Monad](https://www.cse.chalmers.se/edu/course.2018/pfp/Papers/PMCJFP.pdf)), and a description that can stop part-way is what lets the lift stay without the stall: the branch that waits is the only one that does.
- **The host owns every wait, as a host does once it runs one event loop for everything it hosts** ([WASI 0.3](https://bytecodealliance.org/articles/WASI-0.3), the Component Model's [callback ABI](https://github.com/WebAssembly/component-model/blob/main/design/mvp/Concurrency.md)). A program that waits in a row of its own sleeps the host's thread, which the browser cannot do at all; a program that answers its suspension and returns is a step function the host drives, natively over `poll(2)` and in the browser over the event loop.
- **Suspension needs no stack of its own.** A description's answer is a value or a request with its rest, as a freer monad's is, and a bind that tests what its action answered and appends itself to a suspension's frames is the shape Koka compiles its effects to: a test the common path pays and predicts, a slow path shared by every bind, and no test where no flow brings a suspension.
- **A cell the program fills wakes exactly what can move.** Advancing a waiter on every step of a sibling spins two waiters against each other, and advancing it only on a handle's readiness reports a deadlock where a sibling has already sent; a cell is filled by the change itself, needs no host call, and is dropped with its waiter.
- **One loop holds the rule that no change is missed.** A wait that checks, then runs anything that can suspend, then registers misses a change made in between; stated once, in the loop every wait on the program's own state goes through, the rule holds for a deadline, a future and a channel alike, and no such wait of `/std`'s is written to keep it by hand. A handle needs no such care, its watch reporting what is ready already.
- **A choice among descriptions needs no commit protocol here.** Where branches run in parallel, a choice has to be committed inside the channel, as Go's `select` and Concurrent ML's `choose` commit it ([Reppy, Russo and Xiao, Parallel Concurrent ML](https://www.microsoft.com/en-us/research/wp-content/uploads/2009/09/Parallel-Concurrent-ML.pdf)), and a library that opens the protocol hands it to whoever writes a source, as Lean's `Selector` does under a contract its documentation states ([`Std.Async.Select`](https://lean-lang.org/doc/api/Std/Async/Select.html)). One driver stepping branches one at a time commits the choice by stepping, so `select` takes any description, a stream's read among them, and what an operation loses where it is cancelled is stated on it, as tokio states cancel safety ([`tokio::select!`](https://docs.rs/tokio/1/tokio/macro.select.html)).
- **Ties go to the earlier action**, so a run under the scripted host repeats, as Kotlin's `select` prefers its first clause; in a loop an action always ready starves the ones after it, which `select`'s documentation says.
- **A failure is a value, so a scope does not fail with its child.** An effect system with typed failures surfaces a child's failure where the child is joined and fails fast in its parallel combinators ([ZIO's fibers](https://zio.dev/reference/fiber/fiber.md/)); a nursery propagates a child's exception because an exception is control flow, which a `Try` is not.
- **A channel is one value.** A sender and a receiver are two names for one queue where nothing closes a side by being dropped and positivity holds a channel invariant in its element, so no end varies in it either. Its length, its capacity and whether it was finished are observations, which change nothing and so skip no wake; its sends, takes and finish stay behind the wake they owe the other side.
- **Cancellation runs where the cancelled code waits**, as Eio's and Trio's do, and nothing is resumed with a cancellation, so a wait cannot fail by one and a row needs no `cancelled` of its own.
- **A resource belongs to a scope, as a fiber does**, as an Eio switch holds what is opened under it and a Cats Effect `Resource` or a ZIO `Scope` releases its finalizers in reverse: an open that needs a scope cannot leak past one, and one scope releasing what was opened into it in reverse states the order a nest of brackets would spell again for every resource.
- **Non-blocking is a property of the host**, so the library cannot forget to ask for it and the scripted host can answer `would_block` at any row. A close that flushes waits on the peer or drops what it cannot send, and a write that loops until the buffer is taken cannot report the prefix it wrote before a failure.

**Rejected.**

- **Keeping waits out of `Io` and guarding the scheduler's driver** — an opaque entry, a turn row carrying a continuation, a second carrier: each moves the bridge between the library's continuations and the host's wait, and none removes it. **A blocking monad beside a fiber monad**, a thread that waits where the host owns every wait; **walking the lift back or making it explicit**, after which a lifted wait stalls as an inserted one does; **a host that refuses a nested scheduler at run time**, a report of what a suspension makes harmless.
- **Stack switching**, a proposal behind a flag in Wasmtime and unshipped in browsers, for a suspension a description already affords; the pair is the seam a captured continuation could replace once it is standard everywhere.
- **Cancellation delivered as a value at a suspension**, which gives every wait a failure; **an explicit `cancel`**, where a combinator already decides when a branch is no longer needed.
- **Selection over offers as a public form**, Concurrent ML's events and Lean's `Selector`: an offer's contract — its attempt takes nothing unless it answers, and neither its attempt nor its wait suspends — is held by prose alone, a wait that suspends before it registers loses a wake, and no stream's read joins one. **A random choice among ready actions**, Go's and tokio's default, under which a scripted run does not repeat.
- **A scope that fails when a child fails**, as a nursery does with an exception, where a failure is a value its join reads; **a `Try` form of every combinator**, where a `select` or a `timeout` over `Try` actions is a `Try/run` and a `Try/attempt` away and fails no faster for a form of its own.
- **A bracket per resource** — `with(open, body)` for a file, a connection, a child, a port, the terminal — each restating one release around its body, a resource opened outside one never closed, and two resources nesting brackets in the order their opening already states; **a public `using(release, body)`** beside the scope, a second way to say what `defer` says; **a release that fails its scope**, whose failure would race the body's own, where a body that must know its last writes left flushes or drains them itself.
- **A condition on the program's state as a suspension on no handle**, "until a sibling runs", which spins or reports false deadlocks; **that condition as a host handle the program signals**, a host call for every wait and every fill; **a counter every change moves**, which wakes every waiter on every change; **waking one waiter rather than every one**, which makes a waiter dropped after its wake pass it on.
- **Setting a handle non-blocking inside a lift**, which cannot see the handles an action touches and would change the standard streams' flags under the processes sharing them; **a `set_nonblocking` row the library calls after every open**; **timeouts as socket options**, where `timeout` bounds any wait from the branch that waits; **a blocking `connect` for local peers**; **a handshake run with the socket briefly blocking**.
- **A general rewritable cell beside the write-once one**, two mutation vocabularies; **a queue of write-once cells**, which retains consumed chains; **unbounded channels**, which give up the storage bound; **capacity-zero rendezvous**, which entangles buffering with receipt; **`Bool` for push and `Option(A)` for take**, which merge outcomes a later observation cannot recover; **a sender end and a receiver end**, as channels have where dropping the last sender closes one; **a raw push or take for programs**, which would skip the wake the other side is owed.
- **Completion for every stream**, every row redesigned and an abandoned read in flight to cancel or keep, where readiness holds nothing in flight while a reader is suspended.
