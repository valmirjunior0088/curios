# A fallible operation returns `Try`, and `!` lifts along declared edges

**Decision.** `/std/Result` is `Result(E: Type, A: Type)`, error first, and carries the `Monad((A: Type) => Result(E, A))` witness itself: `!` on a `Result` is early return, `Result/raise` stops a region and `Result/rescue` handles the stop. A `/std` operation that can fail is declared `Try(M, E, A)`, a nominal wrapper over `M(Result(E, A))`, over the base monad it would otherwise have — `Try(Io, Io/Error, File)` for `File/open`, `Try(Async, Io/Error, Socket)` for `tcp/Socket/connect` — and `raise`, `rescue`, `attempt` (admitting a hand-built `M(Result(E, A))`) and `run` (handing one back at the boundary) are its vocabulary. The host's failure vocabulary is `/std/Io/Error`, owned by `Io` because a failure is a fact about the effect. An operation that never fails stays in its base: `print` is `Io({})`.

`/std/Monad/Lift(M, N)` is the canonical embedding of one monad into another, one witness per ordered pair under the ordinary coherence rule. `!` reads its region's monad from the region's *type*, never from a sequenced action: a region whose type is an unsolved metavariable parks the sequencing as a checking problem, and a region in inference position is refused. When an action's declared monad differs from the region's, elaboration wraps it in `lift` and resolution finds the declared edge or reports its absence. The action's monad is a read, not a speculation: its explicit spine is peeled to a named head whose declared result type is keyed, or, where that monad is one of the head's binders — the `M` of `Try(M, E, A)` — the explicit argument that fixes the binder, so `Try/rescue(t, h)!` lifts as `t` was declared over; anything unreadable abstains. A lift is inserted only at the `!`-desugared bind and at a region's tail, and only upward. `/std/Try` declares its `Lift` witnesses once each, with a premise on the base, so a `Try` region sequences a `Try` over any base that embeds in its own, a bare `Result` as early return, and an `Io` or `Async` action wherever its base admits one; an action of any other base is refused.

**Rationale.**

- **An error channel that is a monad lets `!` carry the failure as it carries the sequencing**, where `Async(Result(A, E))` on every fallible operation makes each caller match twice. A wrapper over the base gives `Io` the same early return a fiber has and leaves `Result` a value with no effect.
- **A witness for a partially applied family keys on its last parameter being the abstracted one**, so a family meant to be a monad orders its context first and its result last: base, error, value. Haskell's `Either e a` and Scala's `Either[E, A]` agree; value first is Rust's, whose `Result` is no monad.
- **Auto-lifting needs a known target, obtained by waiting rather than divining.** Systems whose bind elaborates bottom-up (Idris, Agda) do not lift; Lean's do-elaborator postpones until the expected type is known and extracts the monad from it, and F* carries effect labels in the judgment. Curios's annotated signatures make the wait almost always zero.
- **An embedding is a monad morphism**, so an inserted `lift` cannot change what a program means, while the downward direction is a runner (`block_on`, `State/run`) that decides things no compiler should decide silently. The finished term holds an ordinary `lift` application, so the kernel is untouched.
- **A premise on the base serves every base with one witness per edge** ([Concepts resolve with global coherence](../surface/concepts-resolve-with-global-coherence.md)).

**Rejected.**

- **Value first, with a `Throw` monad as its face**: a second type, two conversions and an edge per consumer; **left-biased inference for partial application**, which reverses the reading of every other family.
- **An error-carrying `Async(E, A)`**, which fixes the channel to one monad and leaves `Io` with none; **aliases such as `Fallible(A)` in `/std` signatures**, which hide the base and the error a reader wants; **exceptions or a `panic`**, an effect the type does not state.
- **The transitive closure of edges**, Lean's `MonadLiftT`: adding an edge becomes a breaking change downstream and which lift ran is buried in search order. The missing-edge report prints any declared chain and asks for the composite.
- **Retrying the wrap under rollback**: a speculative elaboration can consume parked goals rollback cannot re-park.
- **F*-style composition at a lattice join**, which reintroduces the search explicit edges avoid; **a general coercion mechanism**, where the door is exactly the `!` and the tail, and the tail fires only between registered monads; **letting the action elect the monad where the region is flexible**, two semantics for one form.
