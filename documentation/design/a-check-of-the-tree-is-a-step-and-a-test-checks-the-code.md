# A check of the tree is a step, and a test checks the code

**Decision.** A test holds code to what it promises, and a step holds the tree to what it states: a standard's corpus, as `conformance` holds `/std`'s codecs to theirs; a revision published elsewhere and a copy agreeing with its original, as `zed check` holds the Zed extension's pins, query and lint table; a citation reaching its file, as `jig agents` holds the agent files; and a program linting clean, as `compiler lint curios-check` holds the tree's programs. A crate that reads a file as its given keeps its checks of that file as tests: `curios-unicode`'s and `/std`'s conformance to the cases the crate pins, the formatter's laws over the tree's sources, the parser's words where the editors' grammars state them, and the documentation's examples, the compiler holding its documented behaviour (`curios/src/tests/readme.rs`, `reference.rs`). So does a test of a binary's own behaviour on fixtures it writes. The task files are descriptions the runner reads, and nothing outside the runner's crate reads them, as [`xtask`'s README](../../xtask/README.md) decides of the runner's own tests.

**Rationale.** A check of the tree among a crate's tests fails that crate's suite for a reason none of its code holds — a pin left behind, a citation of a moved file — and a test of the code that reads the tree's files holds the files of the day rather than the rule: the runner's scheduler failed for every step a subject gained and passed a fault the files of the day did not exercise. As a step, a check of the tree is named for what it holds, run where the handoff and the check workflow reach it, and the suite of each crate holds that crate's code alone. A crate that reads a file as its given is where the file's meaning is decided, so its agreement with the file is a property of its code, and a test of it.

**Rejected.** The Zed extension's checks as the extension's own tests, run by a step of that crate's; the corpora's checks as Rust tests handed the cases, which hold a codec through no program; Unicode's conformance files held by a step, a second pin of the database or a path into `curios-unicode`'s kept files; the task files' agreement with their other owners checked by the runner before every command, where one pair that disagrees would stop every command, `format` among them.
