# A partial primitive is totalized by a canonical extension, or it states its domain

**Decision.** An intrinsic whose reduction can fail is made total by its *canonical total extension* — the one total function agreeing with it on its domain that the structure determines rather than a designer chooses — where one exists, and otherwise states its precondition in its type. `Nat/sub` clamps, monus being what subtraction is on a monoid with no inverses; `Nat/div` demands `Holds(0 < b)`, and `get` its index's bound. A window is a start and a length, so a reversed range cannot be spelled at all, and only its end's bound is stated. A carrier's width is a third case and neither route: `Nat` and `Int` are unbounded, and the one width left, the host wire's, is refused where it is crossed.

**Rationale.**

- **The test is whether the structure forces the answer, not whether the result type has an inhabitant.** `0` inhabits `Nat`, which would license `x / 0 = 0`; `get` at a generic `T` has no element to return, so its precondition or an `Option` is the only shape available.
- **Deleting a bad case beats deciding it, where the representation can forbid it.** The laws are stated over the free-monoid spine, which fuses adjacent windows on a matching seam with no ordering check, so clamping an out-of-order `slice` would make `tests::aggregates::bin_slice_is_a_monoid_citizen`'s `split` a proof of a false equation. A start and a length leave no out-of-order case; the remaining end bound has no canonical extension, and clamping it would equate windows that differ.
- **A mask is chosen, not forced.** Wrapping `Nat/to_byte` to eight bits agrees on the domain and is total, but nothing in `Byte`'s structure says `256` becomes `0` rather than `255`. With the domain stated, `Byte/to_nat` reduces back through the constructor, an inverse a mask would lose.
- **A width is whose the partiality is.** `get` has no element and `x / 0` no quotient whatever runs them, while a `Nat` past the wire has a value only that boundary cannot carry. Stating `Lt(n, 2^31)` on every host operation would write a backend's width into Core, so the refusal is the wire's ([`Nat` and `Int` are an i31 until they outgrow it](nat-and-int-are-an-i31-until-they-outgrow-it.md)). `Flt` differs because its width is the language's: binary64 is in its type, so its narrowings state domains — `Finite(a)` on `to_int`, `NonNeg(a)` on `to_nat`.

**Rejected.**

- **`x / 0 = 0`, as Lean and Isabelle take it.** Junk is free at run time in a proof assistant and must be emitted here — `i32.div_u` traps, so every division would pay a compare-and-select for a case correct programs never reach, where a proof parameter erases to nothing — and a decided proposition discharges definitionally at any concrete argument, so the precondition costs an author little.
- **Per-module reach audiences** — `/sys/Bytes` reachable only from `/std/Bytes` — as the guard against calling a partial primitive past its precondition: it would miss a bypass inside the one module it authorizes, derive its table from the corpus it polices, and need exceptions in its largest entries. The defect is what code does, not where it sits.
