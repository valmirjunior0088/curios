# A stored unit is a baseline for an item-level recompile

**Decision.** A unit the store holds is a baseline, not a hit or a miss. `Cache::get` returning a unit whose record agrees is the empty case — nothing changed, reuse everything. When the record disagrees, the slot still holds a unit compiled from an earlier text of the same sources, and a *question* takes it as the baseline for an item-level recompile (`Cache::baseline`): the fold lowers the unit whole, diffs the lowered items against the baseline's lowered module by declared name, takes the reverse transitive closure over the baseline's elaborated graph (`Module::reaches`: mentions, construction heads and registry-entry names) of every changed, added or removed name, replays every item outside the closure as one more predecessor (`Established`), elaborates the closure in the lowered order, reassembles one `Module`, runs the whole-module passes over it, and judges it with `Globals` seeded from the reused items so the kernel walks the closure alone (`curios-pipeline/src/recompile.rs`). The archived `/std` is the baseline for the package named `std`, which is the standard library by the meaning of the name: `standard.rs` withholds the archived root for it when it is the first unit of the fold, grants it the roots before it, and offers the archived unit through the same `Cache` seam. A build — `run`, `compile`, `test`, `document` — recompiles whole on a miss and files as before; an incrementally compiled unit is never written. Elaboration recovers per item, so the closure's refusals are reported together and a dependent of a refused item is withheld (`curios-elab/README.md`), and the parser resynchronizes past a broken item, which lowering carries as a name the elaborator withholds dependents of (`curios-text/README.md`). A module is parsed once per path and text at the seam every read passes through (`RootSource::load`).

**Rationale.** An editor asks about a file on every edit, and the answer cost the whole unit the file belongs to — for the standard library, nineteen hundred declarations of which the median costs ten milliseconds, about a hundred seconds a keystroke. Every mechanism the design needs existed for whole units: a predecessor is replayed and never re-checked, the kernel skips by name, the dependency graph exists after elaboration, a stored item is position-free, and a `Unit` holds both the lowered and the elaborated module. The design applies them one level down. The equivalence argument is this: every fact an item's elaboration consumes from outside itself arrives through a name it reaches — a definition's type and body, a registry entry, a witness head in the table, a derivation's vocabulary — so the reverse closure over the graph the previous elaboration produced contains every item whose result can differ, provided the closure is transitive, since conversion unfolds bodies and a dependent's judgment reaches through what it names. Ordering does not enter: the global witness table is a keyed lookup, the local tiers see binders only, and a deferred goal resolves to the same registered head whenever it is retried. The universe seed table is unit-global and is rebuilt by re-lowering; reused items carry closed universe contexts. Two corrections were found building it. Term equality excludes spans, but a *lowered* item carries the universe metas and holes its lowering minted, compared by identity and numbered densely in lowering order, so an insertion earlier in the file renumbers everything after it: the diff compares modulo a per-item bijection on those identities (`Term::equal_modulo_metas`), which is what lets an inserted polymorphic declaration leave the items after it reused. And the graph is `reaches`, not `mentions`: an item that constructs a struct or matches a variant depends on the declaration exactly as one that names it does, and `mentions` cannot see it. The claim is held to by evidence rather than by this paragraph — `curios-pipeline/src/tests/incremental_tests.rs` compiles each fixture whole and over a baseline and requires the elaborated modules to agree structurally, with the binder floor compared as a bound — and best effort is the right predicate: a witness goal the whole compile defers can resolve inline in the recompile, so universe minimization may differ where nothing observable does. Measured on the standard library in a debug build, a declaration added to `/std/Nat` costs a closure of one item of 1947 and a nineteen-second question against a hundred-second whole compile, most of it the lowering; a respelling of `/std/Bool/not`'s body reaches 866 items, which is the transitive closure that soundness requires and the worst case by construction.

**Rejected.** *Suffix re-elaboration from the first change*, Lean's per-command model: the emitted order is a Kahn sort over the whole unit, so an edit to an early lemma re-elaborates most of the library. *Identifying the standard library's tree by the record's directory*: it made the answer depend on the binary being built from that checkout, and a package named `std` is what every language reserves the name for; the name is not a way to swap `/std` under a dependency, which means what it means against the `/std` it was compiled after. *A manifest key or a `RootKind` for the standard library*: forgeable by any package, and it reintroduces the tier the mount design removed. *Recognizing the prelude in `curios-wonder` or `Membership`*: `curios-package` cannot reach the archive, and every other product would keep colliding. *Deriving the record from the spans already in the image*: inputs are recorded at the seam they pass through, never believed from a structure that happens to hold them, which is the store's own lesson. *On-disk per-declaration slots*: redundant while the unit slot plus the item diff gives the same reuse with no new key. *Building this into the server as private state*: it would be the third place a fold is spelled, and `test`, `document` and the executables compiled against a moved library would gain nothing. *Filing an incrementally compiled unit*: the argument says it is identical and the differential gate is what earns the right; until it has run for a while only questions take a baseline, and the policy lives in the one `Cache` implementation that answers `baseline`. *Byte equality as the differential predicate*: it was the spec's sentence, and it is stricter than the claim — universe minimization can differ where nothing observable does. *A digest-keyed parse memo*: keyed by path and replaced on change, so the table is bounded by the file count rather than the edit count; a generation sweep is the eviction to add if a workspace ever makes it matter.

**What this rests on.** The trusted base is unchanged: a reused item was judged by the walk that filed the baseline, exactly as a whole-unit hit is, and the soundness argument is [Cached verdicts](../../soundness/admission-without-judgment/cached-verdicts.md) applied per item. Resource verdicts are context dependent — the retention quota is compilation-scoped and a memo hit is free — so a partial walk can move a budget-marginal declaration across the line in either direction; the differential test excludes them and says so.
