# The erased IR prints as ANF Curios

**Decision.** `curios-ersd`'s `Display` renders the module as A-normal-form Curios — `let`-chains closed by a tail term, `match … end` eliminators, function bodies nested at their binding sites — rather than as a brace-delimited statement dump. Compiler identities keep the `~{kind}{index}$hint` spelling of [one naming scheme for compiler identities](one-naming-scheme-for-compiler-identities.md), so the output reads as Curios without ever being mistaken for source. One rule decides what appears: **print every declaration something else refers to, state each fact once at its definition site, and spell every reference as short as is unambiguous.** Applied to identities, an identity prints exactly when something else can refer to it — `~v`, `~f`, `~p`, `~d`, `~t` and `~x` do, and the structural `~b`, `~s`, `~c` and `~r` do not. Applied to the header, only the rows the program reaches are declared, with no flag for the rest.

**Rationale.** Ersd *is* ANF Curios: every non-atomic computation is bound by a `Let` so evaluation order is statement order, `Statement::Functions` introduces a group into the rest of its enclosing scope exactly as `let … and …` does, and `Terminator::Return` yields a block's value exactly as a let-chain's tail does. Printing that structure in some other notation cost three things at once. A reader arriving from `text`, `core` and `core-elab` — three rungs of one program in one notation, progressively decorated — met a fourth with no bridge. `return` meant "this block's value" and so read as a function return wherever an eliminator's arm nested one inside another. And a lifted function printed in a flat section with an empty parameter list over a body naming its enclosing function's parameter, which is an open term: `Function` stores no capture list, and the flat section had no place to put one. Nesting a body at its binding site is not a layout preference but the only placement `let f(x) = body;` has, and restoring the scope is what makes the captures visible without an annotation to carry them.

The elision rule is what keeps that legibility from costing information. Each clause removes only something the reader can recover: an unreached row is named by nothing printed, a fact stated at its definition site is found from the identity that refers to it, and a reference shortens only to the point of uniqueness — `build_shorten`'s rule from `curios-core`'s printer, applied to field names as well as to paths. The header clause is the one with a measured motive: `products()` is a dense arena with no liveness, so schemas are never pruned, and a five-line program used to carry 151 standard-library rows in front of eleven lines of program.

**The dump is faithful, and that fixes where the rule stops.** Faithful forbids *hiding*, not *not repeating*. Nothing inlines a single-use binding, folds a constant, reorders a statement or drops dead code: a binding nothing reads prints `let _ = …;`, so dead code announces itself instead of disappearing. Two things are absent rather than elided. A `_` binder is what a hintless value with no uses *is*, which is `curios-core`'s own rule for an unreferenced unnameable binder. And `Function::description` is not printed at all, because it is not part of the program: one writer stamps it, one optimizer pass reads it to cap a copy budget, and no verifier, no semantics and no lowering consults it — it does not exist in `curios-cont`, where the stage that genuinely depends on a thunk's meaning derives that structurally from arity zero instead.

**Rejected.** Keeping the statement grammar and adding the missing facts as annotations — a `captures …` list on each lifted function and a `description` marker. It closes the open term but leaves the notational break and the overloaded `return`, and it states a function's captures in a second place when scope already states them in the first.

Keeping the flat function section under the new grammar. A flat section cannot express `let f(x) = body;`; it has to split one binding into a declaration and a definition, which is the same "one fact in two places" the rule forbids and the shape the open term came from. The cost accepted in exchange is that a diff of an inner function is no longer local to one top-level block.

Spelling scalar operations infix, as `curios-core`'s printer does. Core can afford `a + b` because it still has types; Ersd keeps its shapes distinct by design and has nothing left to recover a carrier from, so the carrier has to live in the spelling — `Nat/add(a, b)`, and `2:int` beside `2`.

A configuration axis for any of this. Header elision, faithfulness and the vocabulary were each considered as a `Spelling`-style parameter threaded through `Stage` in the manner of `curios-core`'s. Every one of them resolved to a single unconditional answer, and a parameter channel with no second setting is scaffolding for a choice nobody makes. A reader who needs the rows the header withheld has the module in a checkout.

Moving this printer onto the document algebra, which [one document algebra decides layout for every printer](one-document-algebra-decides-layout-for-every-printer.md) already rejected and this rework confirms. The output is one statement per line and always broken, so `group` and `fill` decide nothing; the explicit job stack that prints a 50,000-deep module on a default test-thread stack stays.
