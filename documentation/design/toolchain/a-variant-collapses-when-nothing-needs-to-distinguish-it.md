# A variant collapses when nothing needs to distinguish it

**Decision.** A variant family's runtime encoding is decided per family at the one-way door (`curios-ersd`'s `lower_to_cont`), as a pure function of its registered schema, and a family pays for discrimination only where discrimination can happen. Three encodings exist. A **single-constructor family** collapses exactly as the struct with the same relevant row erases: one payload is the bare value, several are an untagged tuple, none is the interned `Nat` zero, and its matches have no dispatch at all. A **multi-constructor family with exactly one immediate-unary constructor** — one constructor carrying one always-immediate payload — rides that constructor as the bare payload while every sibling keeps its tagged tuple; matches open with an `IsImmediate` test (one `ref.test (ref i31)` in the emitted code) instead of a tag read, and when only one boxed constructor exists the tag is never read either. Every other family keeps the general `(tag, payload…)` encoding.

**The eligibility fact is recorded at erasure, because that is the last walk holding the types.** Ersd's `Constructor` schema carries a `FieldShape` per relevant payload field, written by `curios-elab`'s erasure from the declared Core field type: `Immediate` iff every runtime value of the type lives in the uniform carrier's immediate population — an intrinsic head riding the i31 carrier (`Nat`, `Bool`, `Byte`, `Int`), or a chain of single-relevant-field collapses (newtype structs, subset tuples, single-constructor families) landing on one. The chain-chase carries a visited set because a self-referential struct elaborates (it is merely uninhabited), and a cycle classifies `Opaque`. Polymorphic payloads disqualify themselves: parameters open opaque, so their fields reduce to stuck heads. The conservative direction is the only safe one — a wrongly `Opaque` field misses an encoding, a wrongly `Immediate` one would corrupt it.

**Why the door and not erasure.** Ersd deliberately keeps `Construct`/`MatchVariant` semantic — every encoding decision belongs to the lowering into Cont — and the tag this decision declines to mint is *born at the door* (ersd's `Construct` carries no tag value). There is nothing to erase earlier; there is only a dispatch encoding to decline. Deciding per family from the schema alone is what makes every construction and match site agree with no shared state, and the lowering runs whole-program, so no cross-unit coordination exists to get wrong.

**Why `IsImmediate` is sound and where it lives.** The test answers whether a value is an immediate or a heap aggregate — an `Flt` is a scalar by any semantic reading but answers no, because it boxes. It is total, pure, and allocation-free, and the encoding only ever asks it where the answers are disjoint by construction: the bare constructor's payload is always an i31 and every sibling lowers to a struct, with typed erasure guaranteeing no foreign value reaches the match. Exactly one immediate-unary constructor is admitted per family because two would collide on the same immediates. The op is named as a kind question and exists only in `curios-cont`'s vocabulary — ersd stays encoding-free above it, and the i31 spelling stays in `into_wasm` below it, which keeps the numeric-carrier law's border intact.

**What it buys, and where the figures live.** The single-constructor collapse removes the invisible cost asymmetry between `struct Meters { Nat }` and `induct Meters | m(Nat) end` — a wrapper at rest paid a tagged heap tuple per value in the inductive spelling and nothing in the struct spelling, a difference the call-pattern specializer already erased for values *in flow* but structurally cannot reach for values *stored*. The immediate encoding removes the leaf allocations of tree-shaped data outright — half the objects of the binary-trees workload — and with them their share of every collection the semi-space collector runs. The structural evidence is pinned in `curios`'s codegen probes (`trees_leaf_rides_its_payload`, the into_cont encoding tests); the trees timing lives with the benchmark harness that reproduces it.

**The limits, named.** Boxed constructors' payload fields stay uniformly boxed `(ref null any)` — this decision removes objects and dispatch reads, never field representations, which remain `represent.rs`'s locals-only scope and its successor's subject. A family with two immediate-unary constructors, a polymorphic payload, or a boxed-only roster is untouched. The split-return protocol and this encoding meet honestly: an immediate family's return edges are variant-width (a bare immediate on one edge, a tuple on another), so the protocol declines such components — the `SPLIT_RETURN` fixture keeps both its constructors wider than unary for exactly that reason.

**Rationale.** The struct newtype collapse already established the principle at erasure — a wrapper adding no information adds no representation — and single-constructor inductives are semantically the same record; encoding them differently was an artifact of the uniform tag scheme, visible to users only as a memory cost with no source-level explanation. The immediate-unary case is the same principle carried to the one place a *partial* collapse stays sound: OCaml's int-versus-block split, expressed per family instead of globally, admitted only where a single `ref.test` reconstructs everything the tag said.

**Rejected — relying on the optimizer.** The call-pattern specializer and construct-then-match folding already dissolve known-constructor flows, but a heap field, an escape, or an unknown merge defeats them structurally, and a representation guarantee must hold where the analyses cannot see — the same lesson `a-value-costs-when-it-is-kept-not-when-it-is-named.md` records.

**Rejected — nullary constructors as bare immediates.** Encoding tags as i31s collides with an immediate constructor's payload values on the same 31 bits, and nullary constructors' tuples are already interned constants, so there was no allocation to win — only the dispatch shape would have changed.

**Rejected — dropping the boxed side's tag when the test already discriminates.** With one boxed constructor the tag is never *read*, but it is still written; removing the field shifts every payload index for no measured byte (the collector's 16-byte alignment absorbs it). Left to a successor with a measurement in hand.
