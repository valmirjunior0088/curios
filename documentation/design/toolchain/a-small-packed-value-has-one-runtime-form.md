# A small packed value has one runtime form

**Decision.** A packed value inside the envelope — `Bytes` of at most 3 bytes, `Bits` of at most 26 bits — has exactly one runtime form, the i31, and every producer normalizes on the way out, so a mixed immediate/rope pair for one value is unrepresentable rather than a case every operation must remember. Two corollaries were paid for and are not to be re-derived: canonicity needs *every* materialization site — the module-level hoisted constants were a second producer, and their miss surfaced as canonical equality answering false on a mixed pair — and the two grains' layouts must be unconfusable by construction, which is what `Repr::Bin(Grain)` is for, since nothing at runtime distinguishes them. `FieldShape::Immediate` keeps meaning *always*: a sometimes-immediate packed carrier stays `Opaque`, because a wrongly `Immediate` field corrupts the encoding where a wrongly `Opaque` one only misses an optimization.

**Rationale.** Small-canonical is the invariant that keeps an immediate honest. It is one of the three compiler classes [The map wall falls by classes, not by symptom](the-map-wall-falls-by-classes-not-by-symptom.md) extended, and the one that carried almost the whole of that campaign's figure, because a map keyed by short byte strings reads its key on every descent.

**Rejected.** The opportunistic alternative — both forms legal, immediates as a fast path. It was priced and declined: every equality, hash-shaped walk, and future structural test would carry the mixed case forever, against a normalization epilogue costing a bounds check on operations that already branch.
