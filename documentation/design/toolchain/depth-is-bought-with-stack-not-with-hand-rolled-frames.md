# Depth is bought with stack, not with hand-rolled frames

**Decision.** A walk over *data*-shaped depth — a spine erasure generated, a chain of metavariable solutions, a module's block nesting — recurses, inside `curios-utilities`'s `recurse` bracket, which grows the native stack rather than aborting. It does not get rewritten into an explicit frame machine. The exceptions are deliberate and few: a trampoline that makes a *sequence* iterative rather than a structure (`Step`, `Reduce::Continue`/`Break`), a shared driver whose value is a seam rather than depth (`Term::walk`), a document that is walked by an interpreter after it is built (`curios-print`'s `Printer`, whose running and freeing stay iterative) — and one that supersedes this decision on exactly the fragment it covers: `curios-core`'s closed machine, below.

**Where the first segment is taken is part of the decision.** `recurse` grows only when less than its reserve remains, and a thread smaller than that reserve — every Rust test thread, at its default two mebibytes — can never meet it, so on such a thread the bracket maps and unmaps a fresh segment around every outermost guarded call instead of around none: re-erasing the standard library cost 2.5 s that way against 620 ms on a thread that had the reserve, and a fifth of the cross-stage corpus's wall clock with it. Each stage's entry point therefore takes its segment once, unconditionally, through `grown`, and every `recurse` beneath sees the reserve the figures were sized for whatever thread the caller is on. The figures themselves are unchanged and stay in the one place they are written.

**Superseded for closed terms, and only there.** [Evaluating a closed term is representation, not judgment](evaluating-a-closed-term-is-representation-not-judgment.md) evaluates closed, refinement-free terms on an explicit frame stack — precisely what this decision forbids, taken knowingly, because a level of guarded recursion is charged the native frame it takes and a closed fold's acceptance was being bounded by the evaluator's recursion habit rather than by anything the term does. What this decision protects is untouched: both recursive strategies remain complete, readable and diffable side by side, the machine evaluates nothing either strategy's judgment reaches, and the readability bet is guarded by a differential fixture rather than eroded by a rewrite.

**Rationale.** `curios-elab` and `curios-cert` implement reduction and conversion twice so that a bug in one is caught by disagreement with the other, and that bet only pays if a person can read the two side by side. Two hand-rolled state machines are far harder to diff than two recursive strategies, so defunctionalization erodes the value of the duplication it sits inside. It also re-implements by hand what the call stack already does — scope entry and exit, sibling ordering, unwinding on the error path — and each of those becomes a comment arguing the machine still does what recursion did for free. That is not hypothetical: the kernel's typing worklist silently dropped the three *checked* rules from every argument, payload and field position and passed every gate for two weeks, because nothing in the corpus reached the shape that shows it. [Checked rules at deferred child positions](../../soundness/per-term-rules/checked-rules-at-deferred-child-positions.md) records it.

**What distinguishes a machine from a loop**, since the first pass over this got one wrong in each direction. Ask what the accumulator holds. A **loop** accumulates results, and folding them afterwards carries no effects — the elaborator's `let` gathers `(label, type, body)` triples and folds them into `Term::let_`. A **machine** accumulates *frames*: an element mirroring a function's locals, a reverse phase carrying effects such as scope exit or unwinding, and a comment arguing that ordering is preserved. The lowerer's `PendingLet` held six fields that were `build_let`'s locals verbatim, twelve lines away in the same file. An element that mirrors locals is the decisive tell; a reverse-with-effects phase alone is not, because an **undo record** has one too and is legitimate.

**An undo record stores what was destroyed, never what can be derived.** The refinement a scope overwrote, a node's distance and predecessor before relaxation moved them — those are gone once overwritten and must be kept. A key recomputable from a node the walk never mutated is not, and carrying it means parking a derived value for the extent of a subtree; `curios-cont`'s scoped CSE did exactly that, holding a packed literal's whole byte string per pending retraction. The same mistake at scale is recorded in `curios-elab`'s README: an unconditional universe-rewrite journal kept every intermediate width of every constraint it rewrote, which measured as most of the fixed-prelude build's peak until it was scoped.

**Rejected.** Defunctionalizing on the grounds of memory: `recurse` grows rather than aborting, and a term's acceptance should not depend on how much stack the host handed the process. What bounds depth is the budget, which charges a level of guarded recursion the native frame it takes — [A reduction step costs what it builds](a-reduction-step-costs-what-it-builds.md) — a fact about the program rather than about the machine. Quoting the one performance figure taken (defunctionalization costing up to 1.73× on `Term::warm_frees`) as a reason in either direction: it is a debug build over one synthetic input with correctness unverified, and it has already been restated in conversation as something it does not say.
