# Depth is bought with stack, not with hand-rolled frames

**Decision.** A walk over *data*-shaped depth — a spine erasure generated, a chain of metavariable solutions, a module's block nesting — recurses, inside `curios-base`'s `recurse` bracket, which grows the native stack rather than aborting. It does not get rewritten into an explicit frame machine. The exceptions are deliberate and few: a trampoline that makes a *sequence* iterative rather than a structure (`Step`, `Reduce::Continue`/`Break`), a shared driver whose value is a seam rather than depth (`Term::walk`), and a document that is walked by an interpreter after it is built (`curios-base`'s `Printer`, whose running and freeing stay iterative).

**Rationale.** `curios-elab` and `curios-cert` implement reduction and conversion twice so that a bug in one is caught by disagreement with the other, and that bet only pays if a person can read the two side by side. Two hand-rolled state machines are far harder to diff than two recursive strategies, so defunctionalization erodes the value of the duplication it sits inside. It also re-implements by hand what the call stack already does — scope entry and exit, sibling ordering, unwinding on the error path — and each of those becomes a comment arguing the machine still does what recursion did for free. That is not hypothetical: the kernel's typing worklist silently dropped the three *checked* rules from every argument, payload and field position and passed every gate for two weeks, because nothing in the corpus reached the shape that shows it. [Checked rules at deferred child positions](../../soundness/what-the-kernel-consults/checked-rules-at-deferred-child-positions.md) records it.

**What distinguishes a machine from a loop**, since the first pass over this got one wrong in each direction. Ask what the accumulator holds. A **loop** accumulates results, and folding them afterwards carries no effects — the elaborator's `let` gathers `(label, type, body)` triples and folds them into `Term::let_`. A **machine** accumulates *frames*: an element mirroring a function's locals, a reverse phase carrying effects such as scope exit or unwinding, and a comment arguing that ordering is preserved. The lowerer's `PendingLet` held six fields that were `build_let`'s locals verbatim, twelve lines away in the same file. An element that mirrors locals is the decisive tell; a reverse-with-effects phase alone is not, because an **undo record** has one too and is legitimate.

**An undo record stores what was destroyed, never what can be derived.** The refinement a scope overwrote, a node's distance and predecessor before relaxation moved them — those are gone once overwritten and must be kept. A key recomputable from a node the walk never mutated is not, and carrying it means parking a derived value for the extent of a subtree; `curios-cont`'s scoped CSE did exactly that, holding a packed literal's whole byte string per pending retraction. The same mistake at scale is recorded in `curios-elab`'s README: an unconditional universe-rewrite journal kept every intermediate width of every constraint it rewrote, which measured as most of the fixed-prelude build's peak until it was scoped.

**Rejected.** Defunctionalizing on the grounds of memory: `recurse` grows rather than aborting, so a runaway type-level computation now runs until the *step budget* stops it, and nothing bounds the heap it allocates on the way — a deliberate trade stated at `curios-elab`'s `reduce`, because a term's acceptance should not depend on how much stack the host handed the process. Quoting the one performance figure taken (defunctionalization costing up to 1.73× on `Term::warm_frees`) as a reason in either direction: it is a debug build over one synthetic input with correctness unverified, and it has already been restated in conversation as something it does not say.
