# The map wall falls by classes, not by symptom

**Decision.** A library type's performance wall falls by extending compiler classes every consumer shares, never by blessing the type. The 2026-08 campaign decomposed `/std/Map`'s worst-in-any-table `spines` position (81× off Rust, 10.6× off Lean) into three classes — per-element read dispatch, scatter-then-gather construction, and boxed small packed values — plus two library-local facts, fixed the classes first, and judged the library reshape last on its own probe, which declined it. The classes landed as the leaf split and in-helper cache probe on the read protocol, flat-at-birth construction (`BinChunk`, and the census-and-demand-admitted `ListSettle`/`ListFlat`), and small-canonical `Bytes` and `Bits` on the i31; the spines insert slope closed at ~1353 ns/insert against the 8320 baseline — 6.1×, carried almost entirely by the immediate key. `map_wall_spines_slope` in `curios`'s codegen probes holds every figure with its method; the retired campaign specification in git history holds the step-by-step schedule and the decomposition's throwaway-probe figures.

**Small-canonical is the invariant that keeps an immediate honest.** A packed value inside the envelope — `Bytes` of at most 3 bytes, `Bits` of at most 26 bits — has exactly one runtime form, the i31, and every producer normalizes on the way out, so a mixed immediate/rope pair for one value is unrepresentable rather than a case every operation must remember. The opportunistic alternative (both forms legal, immediates as a fast path) was priced and declined: every equality, hash-shaped walk, and future structural test would carry the mixed case forever, against a normalization epilogue costing a bounds check on operations that already branch. Two corollaries were paid for and are not to be re-derived: canonicity needs *every* materialization site — the module-level hoisted constants were a second producer, and their miss surfaced as canonical equality answering false on a mixed pair — and the two grains' layouts must be unconfusable by construction, which is what `Repr::Bin(Grain)` is for, since nothing at runtime distinguishes them. `FieldShape::Immediate` keeps meaning *always*: a sometimes-immediate packed carrier stays `Opaque`, because a wrongly `Immediate` field corrupts the encoding where a wrongly `Opaque` one only misses an optimization.

**Eagerness is admitted by demand, never by spelling.** Flat-at-birth list construction fires only where the sequence-usage census (`curios-ersd`'s `into_cont/census.rs` — computed inside the door, where family identity still exists and the fact cannot go stale against the arena it lowers) marks a constructor field's values indexed-only, or where the demand lattice proves a local result's every read indexing-shaped; everything growth-shaped keeps the lazy rope, so the builder and patchwork idioms keep their O(1) steps. The fact is spent as a door-inserted internal `ListSettle` — semantically the identity, representationally a flat guarantee, never a surface name.

**Rejected — eager mixed literals.** `[..acc, x]` is a lazy O(1) append while `[..acc, x, y]` would copy the accumulator, so a one-element edit to a builder loop flips O(N) to O(N²); a spelling that subtle does not signal consent, and the join idiom `[..acc, sep, ..item]` falls off the same cliff.

**Rejected — an explicit `List/settle` surface form.** A representation verb in the language: semantically the identity, so it couples source to the backend while handing the optimizers an op that is identity-yet-not-deletable.

**Rejected — persistent index-update functions (`List/set`/`insert`/`delete`).** Pure copy-on-write, but an index-update vocabulary `/std` deliberately does not have; mutation stays quarantined in `Cell` and the library keeps reading that way.

**Rejected — the qp-trie reshape, on its own figure.** Implemented in full and measured at 1802 ns/insert against 1353 for the crit-bit trie it would replace: the premise that priced it — each avoided level also avoids the per-level protocol — was true when written and false after the immediate key, whose bit test is a few register operations, while a wide fork pays an O(width) child-array copy per rebuilt level on an all-insert workload. A future lookup-heavy consumer reopens it against these figures with a get-weighted probe. The shapes rejected without building: a 16-field `fork16` struct (a 16-way `br_table` per descent, ~4.5× sparse node memory, a 17-ary constructor hostile to certification); a dedicated flat child carrier (deletes the rope's per-child tag test and cast, but mints a parallel storage abstraction for one consumer where the classes pay off for every `List` consumer); HAMT/CHAMP (needs a hash, makes canonicity conditional on collision handling, loses the sorted structural order `Toml/encode` publicly promises); balanced trees (shape depends on rotation history, breaking canonicity outright, beside the 3–114× extensional-setting penalty Rocq measured); deterministic treaps (hash-dependent and expected-depth deeper); an intrinsic Map carrier (grows the trusted base with map laws — the whole sequence exists to make that unnecessary).

**A consequence of that rejection: the retired campaign's step-3 hedge is no longer superseded.** Its single-walk insert was written to be landed only if the reshape slipped, because the reshape would have replaced the crit descent outright. The reshape was declined instead, so nothing supersedes the hedge, and it landed on its own figure — one descent that decides on the way back up, −27% on the insert slope measured like-for-like. The invariant that licenses the return-side decision is stated in `/std/Map` itself, and the figure lives beside `map_wall_spines_slope`.

**Boundaries.** Canonicity is API, not implementation: `Toml/encode` promises one deterministic document in the map's structural order, and same-entries-same-shape is what makes map equality structural. The `Key` boundary stays — byte-string identity with write-side injectivity, stated where it can be checked. Proofs, if a certified-Map campaign arrives, bind to `entries`/get-extensionality rather than node anatomy, so the runtime shape stays free to change width. The successor for field representation is [A monomorphic field carries its own type](../../roadmap/typed-heap-fields-spec.md), gated on its own census; the parked classes — known-flat dataflow, payload-carrying windows, rebuild-walk reuse, the key boundary as an accessor concept — carry their reinstate conditions in the retired specification's appendix, in git history.
