# The map wall falls by classes, not by symptom

**Decision.** A library type's performance wall falls by extending compiler classes every consumer shares, never by blessing the type. `/std/Map`'s worst-in-any-table `spines` position was decomposed into three classes — per-element read dispatch, scatter-then-gather construction, and boxed small packed values — plus two library-local facts; the classes were fixed first and the library reshape judged last on its own probe, which declined it. The classes landed as the leaf split and in-helper cache probe on the read protocol, flat-at-birth construction (`BinChunk`, and the census-and-demand-admitted `ListSettle`/`ListFlat`) under [Eagerness is admitted by demand, never by spelling](eagerness-is-admitted-by-demand-never-by-spelling.md), and small-canonical `Bytes` and `Bits` on the i31 under [A small packed value has one runtime form](a-small-packed-value-has-one-runtime-form.md), which carried almost the whole of the figure. `map_wall_spines_slope` in `curios`'s codegen probes holds every figure with its method.

**Rationale.** A class pays off for every consumer of the representation it improves, where a blessed type pays off for one and mints a parallel abstraction the optimizers then have to know about. Judging the reshape last, on a probe taken after the classes landed, is what let it be declined on its own figure rather than on a premise the classes had since falsified.

**Rejected — the qp-trie reshape, on its own figure.** Implemented in full and measured slower per insert than the crit-bit trie it would replace: the premise that priced it — each avoided level also avoids the per-level protocol — was true when written and false after the immediate key, whose bit test is a few register operations, while a wide fork pays an O(width) child-array copy per rebuilt level on an all-insert workload. A future lookup-heavy consumer reopens it against the probe's figures with a get-weighted probe. The shapes rejected without building: a 16-field `fork16` struct (a 16-way `br_table` per descent, several times the sparse node memory, a 17-ary constructor hostile to certification); a dedicated flat child carrier (deletes the rope's per-child tag test and cast, but mints a parallel storage abstraction for one consumer where the classes pay off for every `List` consumer); HAMT/CHAMP (needs a hash, makes canonicity conditional on collision handling, loses the sorted structural order `Toml/encode` publicly promises); balanced trees (shape depends on rotation history, breaking canonicity outright, beside the extensional-setting penalty Rocq measured); deterministic treaps (hash-dependent and expected-depth deeper); an intrinsic Map carrier (grows the trusted base with map laws — the whole sequence exists to make that unnecessary).

**Rejected — persistent index-update functions (`List/set`/`insert`/`delete`).** Pure copy-on-write, but an index-update vocabulary `/std` deliberately does not have; mutation stays quarantined in `Cell` and the library keeps reading that way.

**Boundaries.** Canonicity is API, not implementation: `Toml/encode` promises one deterministic document in the map's structural order, and same-entries-same-shape is what makes map equality structural. The `Key` boundary stays — byte-string identity with write-side injectivity, stated where it can be checked. Proofs, if a certified-Map campaign arrives, bind to `entries`/get-extensionality rather than node anatomy, so the runtime shape stays free to change width. Field representation was taken up by [a field is declared at the carrier its shape names](a-field-is-declared-at-the-carrier-its-shape-names.md); the parked classes — known-flat dataflow, payload-carrying windows, rebuild-walk reuse, the key boundary as an accessor concept — carry their reinstate conditions in the retired specification's appendix, in git history.
