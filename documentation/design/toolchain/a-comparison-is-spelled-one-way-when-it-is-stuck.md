# A comparison is spelled one way when it is stuck

**Decision.** `gt` and `ge` are spelled as their `lt` and `le` mirrors from the moment they enter Core: the `/sys` rows for `Nat`, `Byte`, `Int` and `Flt` build `a > b` as `b < a` and `a >= b` as `b <= a`, and the reducer rewrites an intrinsic built by hand the same way before it decides anything about it. A comparison that folds folds the same way it did; one that is stuck rebuilds as its `Lt` or `Le` mirror, so the six comparison heads leave the reducer as four. The surface language, the `/syn` propositions and the erased program keep every spelling they had: `Int/NonNeg` still reads `Int/ge(a, 0)`, and a runtime `a >= b` still erases and compiles as written.

**Rationale.** `a >= b` and `b <= a` denote one proposition and were two terms — `NatGe(a, b)` and `NatLe(b, a)` — that neither conversion nor scrutinee refinement related, so a decided bound had to be spelled exactly as its `/syn` proposition spelled it. `/std/Flt/finite` was written `Flt/le(min, a)` for no reason but that `Finite` says `Flt/le(min, a)`, and a user's guard `0 <= a` would not discharge `Int/NonNeg(a)`, which says `Int/ge(a, 0)`. That is a spelling deciding a judgment, which is what a normal form exists to prevent. The ground is the one `compare_nat` already states for its own operands: it hands back a stuck comparison with the shared floor peeled so that *`cmp(x + m, y + m)` and `cmp(x, y)` reduce to the same term, which conversion needs*. Mirroring is the same rule at the head rather than the operands.

**Soundness.** `Ge`'s reading of `compare(a, b)` is `Le`'s reading of `compare(b, a)`, and `Gt`'s of `Lt`'s, because the comparison is antisymmetric; on `Flt` every ordered comparison against the NaN is false on both sides, so the mirror holds there too — the binary32 model states both readings and the fixture grid closes them at every closed instantiation. Nothing false is decided that was not decided before; two spellings that were unrelated are now one term.

**Why at the boundary and not only in the reducer.** The first cut mirrored in the reducer alone and broke `/std/Char/of_nat`: a case equation is recorded on its guard *as written*, and the proposition it discharges met the same guard reduced — one spelling in the key, the mirror in the occurrence, no hit. A spelling that never exists cannot be keyed on, so the rows build the mirror and the reducer's rewrite is the net for a term no row made.

**What it costs.** A `>=` written in source renders as `<=` with its operands swapped in a diagnostic and in `Module` display. No fixture moved: the two that build a `>=` decide it to a literal, and a folded comparison folds the same. It is a spelling every reduction sees and a rewrite in the reducer both checkers share, so `documentation/soundness/per-term-rules/intrinsic-fold-laws-and-the-free-monoid-peel.md` records it beside summand cancellation.

**Rejected — teaching conversion the mirror instead.** A rule in both converters relating `Ge(a, b)` to `Le(b, a)` keeps the spellings apart and adds a case to the trusted comparison, where a mirrored row is one line per head and is exercised by every reduction. Normal forms belong to the boundary that admits a spelling and to the reducer, not to the judgment that compares.

**Rejected — rewriting the `/syn` propositions to the canonical spelling.** They would still be one spelling a user has to match; the reducer makes the match unnecessary, and leaves `Int/NonNeg` readable as `0 <= a` in the direction its doc states it.

**Precedent.** `Nat::cancel_common`, which normalizes a stuck comparison's operands "which conversion needs"; `Nat::sum` and `Nat::product`, which put a sum and a product in one order so `x + y` and `y + x` are one term; the free-monoid peel, which flattens concatenation. Each is a stuck term spelled one way so that conversion compares values and not spellings.
