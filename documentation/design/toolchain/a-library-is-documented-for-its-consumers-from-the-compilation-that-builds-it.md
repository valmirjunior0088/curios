# A library is documented for its consumers, from the compilation that builds it

**Decision.** `curios document` writes a package's library interface as static pages, and everything on a page is read off the compilation that builds the library: which modules and declarations appear is the export view the text lowering resolves to a fixed point, so a private declaration is absent rather than hidden and a re-export is a link to the declaration it names; a constructor or field appears exactly when the representation is public; a test never appears. Signatures are the surface tree's, printed by the printers `curios format` prints them with, and every name in a signature is resolved through the visibility functions the lowering resolves names with, over the same tables, seeded by the import scopes the lowering recorded per definition — a referent inside the unit is a link, one outside renders as its qualified name. Prose is syntax: `-- | ` opens a documentation comment the parser attaches to the declaration, constructor, field, concept method or `mod` immediately below it, and a block before anything else is refused. A module's prose is the block on the `mod` that declares it, and a package's is the manifest's `description`. The record the engine produces is plain data in the `wonder` module, with the subcommand as its one renderer today; the pages land under the store's `documentation/` family beside `executables/`, and only a package is documented, because a library is the one thing with an interface and a program has no consumer.

**Rationale.** Every generator built in the last decade reads the compiler's result rather than the text — Lean's doc-gen4 the environment, OCaml's odoc the typed interface, Scala's the typed trees, Swift's a symbol graph, Elm's the compiler's own JSON — and Curios already computes every fact a page needs: visibility is a subtree-scoped judgment the elaborator makes, so a heuristic would be wrong rather than imprecise; `curios-print` prints every tree; the export view is a table built once. The surface signature rather than the elaborated one, because every top-level declaration states its signature and the elaborated print spells `Nat` as `/sys/Nat/Nat` under universe variables. A documentation comment that is syntax rather than an adjacent plain comment, because the dominant modern answer — Rust, Lean, Elm, Idris, Swift, Haskell, OCaml — attaches a distinguished token in the parser and stores it in the tree, so a reformat cannot break the association; Go's plain-comment adjacency works only because a blank line breaks it and everyone knows. A directory of pre-rendered pages readable from `file://`, because a renderer over data — DocC, Zig's autodoc, doc-gen4 — pays with a serving requirement. A record before a renderer, because Elm, Gleam, Swift and EEP-48 show one artifact serving a site, an editor and a registry. Only a package, because a product written to disk needs an owner to be filed under and a name to be filed as, and the manifest is what supplies both.

**Rejected.** Inferring the association from a plain comment's adjacency: zero grammar, but a blank line or a reformat silently changes the prose, and every implementation note above a declaration becomes public. Documentation as typed terms, Unison's design: a language campaign, not a generator. Rendering the elaborated module: it spells nothing the way an author wrote it. A `wonder document` query that writes files: a query answers on stdout and writes nothing, and the record is the query's future transport. A second comment marker for module prose, Rust's `//!`: one rule and one marker suffice while a module's essay can sit on its `mod`. Documenting the dependency closure into one bundle so every link resolves: deferred with the audience parameter, since the record already carries each referent's identity. Loose files and standard input as subjects: they have no consumer and no place to file a product, so `run` and `wonder` keep them and `compile` and `document` do not. Positional rules for a block at the top of a file, and a `-- |` after code on a line: each admitted a reading that a reformat could change.
