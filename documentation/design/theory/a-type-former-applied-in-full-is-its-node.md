# A type former applied in full is its node

**Decision.** A type former applied in full is one term however it is reached: its node, `StructType`, `InductType` or the intrinsic former — `NatType`, `ListType(T)` — in both checkers' terms. Elaboration spells a former's written name as that node: an intrinsic former before it is elaborated, so its operands are checked against the node's own signature and no level of its name's instance is minted, and a nominal former as the body its entry spells (`curios_core::former_spelling`) at the occurrence's levels, read from the entry where the name's type is and from no body. A former short of its full application is its η-form, the lambdas over its node one to a call — `(T) => (n) => Vec(T)(n)` bare, `(n) => Vec(A)(n)` at its parameters — and a term built as an η-form applied over its whole parameter list is built as the node it applies, where every term is made (`curios_core::former_eta`, `Term::rebuilt`), so a substitution, an imitation's solution and elaboration build one node. No elaborated term holds a former's name (`curios-prelude-archive`'s `no_term_of_the_prelude_names_a_type_former`). The printers read a node and an η-form back to the former's name, through the recognizer the β-step reads. Conversion still reads a recursive family's group projection applied in full as the node it builds, and two applied short of it as one pair (`Term::applied_former`, `bare_former`, `curried_former`): the kernel decides any module it is given, one no elaboration of this tree made among them.

**Rationale.**

- **A written implicit is the inferred one.** [The surface language](../../syntax.md#names-calls-and-projections) holds an implicit argument written to be the argument inferred, and a former reached by unification is the node reduction hands out: an intrinsic's type operand is reduced, and `/sys`'s types, a literal's, a struct literal's and a constructor's are nodes. A written former that stays its name is another term, which every structural reading tells apart — a case equation's exact key, a plain reduction, a remembered reduct, an atom known as written.
- **The node is closed under reduction, and the η-form's application closes it under substitution.** Reduction makes a name into its node and never a node into a name, and an η-form applied is made the node where any term is made. GHC keeps the same invariant for its one primitive former: "saturated applications of FunTyCon must use FunTy" while "unsaturated FunTyCons do appear as TyConApps", held by smart constructors that substitution builds through ([`GHC.Core.TyCo.Rep`](https://hackage-content-origin.haskell.org/package/ghc-9.14.1/docs/GHC-Core-TyCo-Rep.html)). Isabelle expands an abbreviation in its check phase and contracts it in uncheck: the representation is one, and the display is the reader's.
- **The name holds a level its node does not.** `/sys/List/List.{c}(Nat)` stands at `Type c` where `ListType(Nat)` stands at its operand's level, a level a declaration's conversion can hold and its sizing then reads. An intrinsic former elaborated as its node mints none.

**Rejected.**

- **The name**, every node read back to the former that holds it wherever one is made: reduction makes a node at every intrinsic's type operand and every literal, so the rule never closes under reduction; and reading a reduct back to the name it came from is the model of reduction beside the printer that [A diagnostic spells what its reader can write](../tools/a-diagnostic-spells-what-its-reader-can-write.md) rejects.
- **A former respelled after its elaboration**: an intrinsic former's name mints a level its node then drops, left to close on nothing, and the schemes of the declarations that wrote one drift.
- **Each committed solution's former applications respelled**, in place of the β-step where a term is made: a method's instantiated type and a reduct keep the name, which an exact key and a plain reduction still tell apart from the node.
- **A key that reads through a former's name**, as GHC's type maps expand synonyms and Lean's discrimination trees reduce at reducible transparency: [Case equations and their key](../soundness/case-equations-and-their-key.md) keys structurally in both checkers, and with one spelling there is nothing to read through.
- **No node**, a former a constant with no value, as in Lean, Rocq and Agda, where an inductive and its constructors carry no value to unfold ([*Type Checking in Lean 4*](https://ammkrn.github.io/type_checking_in_lean4/declarations/declarations.html)): a node carries its family's name and parameters so conversion compares two with no lookup, and every reader of a nominal node and of an intrinsic type would be rewritten for an invariant elaboration states once.
- **A node short of its parameters**, as GHC's `TyConApp` takes partial application: every reader of a node then meets one that is no type, and an intrinsic former has no partial form.
- **Stopping reduction at a type former's operand**: it keeps the name a written `List(T)` and leaves every other node a program reaches.
