# Implicit cumulative universes, general recursion

**Decision.** Surface `Type` remains nullary, but Core assigns every occurrence an inferred level in an infinite cumulative hierarchy: `Type u : Type (u + 1)`. Reusable declarations generalize their inferred universe inputs and instantiate them freshly at external uses; recursive calls remain monomorphic within their shared group instance. Recursion is unrestricted and implicit at the type and value layers alike — a definition may mention itself, and a mutual group is declared with `and` — and totality is required only where erasure deletes the result, as [Totality of the erased program](totality-of-the-erased-program.md) sets out.

**Rationale.** Implicit levels remove the inconsistency specific to `Type : Type` without burdening programs with universe syntax or changing runtime code. Curios remains a programming language first: general recursion needs no marker, since whether a definition recurses is read off its body and a group is the one thing the source states, and type-level computation is bounded operationally by the reduction deadline rather than by a termination proof.

**Rejected.** Retaining `Type : Type`; exposing universe variables or level expressions in surface syntax; specializing runtime code by universe instance; gating the whole language on termination checking; and a `rec` keyword marking recursive definitions. Soundness did not arrive as a second language of accepted-versus-rejected recursion imposed on all code, but it did not arrive as an opt-in subset either: the obligation is keyed to *position* rather than to a mode or an annotation, so a definition is checked for totality exactly when something erases it. General recursion needs no opt-out because it was never restricted where it is used. The keyword told the compiler nothing it could not recover — a top-level forward reference already reorders, and a self-reference is a fact about the body — and its one semantic effect, that a definition written with it kept its applications folded in conversion while a `let` unfolded eagerly, made what a program elaborated depend on a spelling: a fold through `; ih` names nothing, so `/std/BigNat/trim` written either way must unify `trim(?t)` with `trim(x)` the same. That discipline is now the conversion checker's for every global head, and the keyword is gone.

**Generated declarations.** Lowering records whether a definition is authored or generated and records a generated definition's owner explicitly; flattened path spelling is never used to infer ownership. Registry entries and their actual type-former definitions share one finalized context. Generated constructor and concept-method wrappers independently generalize their own schemes because they may use only a subset of, or additional independently instantiated dependencies beyond, the owner's scheme; their explicit owner metadata validates provenance without conflating the wrapper's binders with the nominal registry's binders.

**Inexpressible paradox.** Every declaration generalizes over the levels it infers, so each occurrence of a name instantiates at fresh ones, and the surface language offers no universe variables, level expressions, or explicit universe arguments with which to force two occurrences to share a level. A program therefore cannot write the self-application Girard's paradox needs: a self-reference such as `Box/wrap(Box)` stratifies into two distinct levels and is admitted, which is stratification working rather than a hole. This is the accepted outcome, not a gap to close — the hierarchy exists to make the paradox underivable, and being unable to spell it at all is the strongest form of that. It does leave open whether any surface program can reach `UniverseInconsistency`; the check guards Core construction either way, and no end-to-end rejection test is claimed, because one would pin behavior that holds for the wrong reason.
