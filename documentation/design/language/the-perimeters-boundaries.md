# The perimeter's boundaries

**Decision.** The perimeter is a claim about the *term language*, checked at one point in the pipeline, over a bounded amount of work. Three boundaries follow, and they are stated here rather than as entries because none of them is a rule that can admit a term.

**Nothing below Core is certified.** `recheck_module_verdicts` runs inside `compile_entrypoint` against the elaborated module; erasure, the erased optimizer, the lowering into CPS and its optimizer, and Wasm emission all run afterwards with no semantic check between them. `curios-cont`'s `verify` is a well-formedness pass — scoping and arity — not a preservation argument. So *no closed term inhabits `/syn/False`* and *the emitted module computes what the source says* are different claims, and only the first has a perimeter. For a language whose proofs are certificates to be erased, the second is worth as much as the first and has no ledger at all.

**What is already in scope is defined on faith, and the faith has a ground.** The compile path judges the entry's own items alone: the archived prelude was walked in full when the archive was built, where `curios-prelude/build.rs` panics on the first refusal and there is no source fallback to fall back to. What it leaves unasserted is which items those are — an item already in scope is skipped whatever it holds — and that is answered by *name* rather than by position, so the answer comes from the archive itself instead of from a length taken off it.

**And the faith is acted on by the whole walk, not one loop of it.** `recheck_module_verdicts` takes a `Globals` — the environment an earlier walk established, its definitions and nominal registry together with the binder floor derived over them when the archive was built — where it once took an item count. The count was the reason the saving was partial: it could express "stop judging here" and nothing else, so while the judgment loop skipped the prelude, the passes around it re-derived facts about all of it on every compile. Under an environment each pass asks the same question the judgment loop does. The metavariable-and-universe residue scans, the universe-context scan, and declaration acceptance skip what is already in scope, each being a verdict the establishing walk already reached; the dependency sort orders only the items being judged, since the rest are *defined* and never judged and `define` records rather than checks; and the binder floor is read from the archive and combined by maximum with one derived over the remainder, which is the widening that a bound — unlike a verdict — permits. Two passes deliberately keep walking everything: strict positivity, because reaching oneself through a non-strict path is a property of the whole declaration set and a user declaration may name a prelude one, and the environment itself, because a judged item may reach any prelude item and conversion unfolds arbitrarily deep. On a trivial program the saving was most of the compile — the rest being the standard library re-examined for a program that barely mentions it.

**Skipping by name is what makes the boundary checkable rather than stated.** The environment is a set of names, so an item is skipped exactly when the archive already declares what it declares, and the archive is where the environment came from — there is no second object for a length to be taken off. What the design then rests on is that an entry program cannot reuse a prelude name, and that is enforced rather than assumed: `sys`, `syn` and `std` are mounted as children of the entry's own root, so a program declaring `mod std` is refused as a `DuplicatePublicDeclaration` before any of this runs. The positional form of this claim had a row on the soundness perimeter and no such enforcement behind it.

**Acceptance is relative to a step budget.** `Spend::spend` fails with `Exhausted` rather than accepting, so the budget can only refuse, and it is deterministic: the same program spends the same steps on every machine, which makes exhausting it a fact about the program rather than about the host that checked it. The consequence to state is that *well-typed* is budget-relative — the fixed prelude is certified at `DEFAULT_STEP_BUDGET` while a user program is certified at whatever its caller passes, and nothing holds acceptance monotone in the budget.

**Rationale.** Each of these was reachable by reading the code and by no other route, which is precisely the property [soundness.md](../../soundness.md) exists to remove. They are decisions rather than entries because an entry is a rule that can admit a term, and these are the edges of the region such rules are looked for in — but a reader who trusts the perimeter without them is trusting a narrower claim than they think they are.
