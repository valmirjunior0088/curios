# Monads embed along declared edges, and `!` lifts across them

**Decision.** `/syn/Lift(M, N)` is the canonical embedding of one monad into another: a single `lift` method with `Monad` superclasses on both parameters, one witness per ordered pair under the ordinary coherence rule. Postfix `!` reads its region's monad from the region's *type* — never from a sequenced action — parking the whole sequencing as a checking problem while that type is an unsolved metavariable and refusing an inference-position region outright (strict postponement). When a sequenced action's declared monad differs from the region's, elaboration wraps the action in `Lift`'s `lift` and lets ordinary witness resolution find the declared edge or report its absence. The wrap decision is a *read*, not a speculation: the action's monad comes from peeling its explicit spine to a named head and keying that head's declared result type, abstaining on anything unreadable, so nothing elaborates twice and a wrong abstention costs an error message rather than a solution.

**Rationale.** The comparative fact that settled the shape: systems whose bind elaborates bottom-up (Idris, Agda) have no auto-lifting, while the systems that lift obtain the target monad top-down — Lean's do-elaborator postpones until the expected type is known (`tryPostponeIfNoneOrMVar`) and extracts the monad from it (`extractBind`), and F* carries effect labels in the judgment itself. Auto-lifting's prerequisite is a known target, obtained by waiting rather than divining, and Curios's annotation-mandatory grammar makes the wait almost always zero: the region's monad is the annotation three lines up. Measured on the whole corpus, strictness cost a single fixture, which now carries the annotation as documentation. Insertion happens at the `!`-desugared bind and at a region's tail — the two places a sequencing region is written to end in a monad — never at a hand-written `Monad/bind` and never in general conversion, and only upward, because an embedding is a monad morphism (`lift` preserves `pure` and `bind`, so inserted code cannot change what the program means) while the downward direction is a runner (`block_on`, `State/run`) that decides things no compiler should decide silently. The kernel is untouched: the finished term contains an ordinary `lift` application, recheckable with zero new rules, so the perimeter does not move.

**Rejected.** Transitive closure of edges (Lean's `MonadLiftT`): resolution through a computed path makes *adding* an edge a breaking change for downstream code and buries "which lift ran" in search order; the missing-edge report instead prints any declared chain and asks for the explicit composite. Retry-under-rollback for the wrap decision: a speculative elaboration attempt can consume parked goals that rollback cannot re-park, so the read-only oracle replaced it. F*-style composition at the lattice join: computed joins reintroduce the search-and-coherence machinery explicit edges exist to avoid, and the region's declared monad is a better authority than a computed join. A general coercion mechanism: the door opens exactly two syntactic forms wide, the `!` and the tail, and the tail fires only where both heads are registered monads, so a mismatch between two data types is never turned into an embedding search. A compatibility fallback letting the action elect the monad where the region is flexible: two permanent semantics for one form, retired by the measured near-zero cost of strictness.
