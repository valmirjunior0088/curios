# A fallible operation returns `Try`

**Decided.** A `/std` operation that can fail is declared `Try(M, E, A)` — `/std/Try`, a nominal wrapper over `M(Result(E, A))` with `Result` error first — over the base monad the operation would otherwise have: `Try(Io, Io/Error, File)` for `File/open`, `Try(Async, Io/Error, Socket)` for `Socket/connect`, `Try(Async, http/Error, Response)` for `http/perform`. A `Try` region sequences four kinds of action with `!` and nothing else: a `Try` over the same base, a bare `Result` as early return, an action of the base, and an `Io` action wherever the base admits one — each through a `Lift` witness `/std/Try` declares once, with a premise on the base rather than a witness per base, which is what [a witness premise is smaller than its head](a-witness-premise-is-smaller-than-its-head.md) admits. `raise` stops a region, `rescue` handles the stop, `attempt` admits a hand-built `M(Result(E, A))` and `run` hands one back at the boundary, which is where a program decides what a failure means. The host's failure vocabulary is `/std/Io/Error`, owned by `Io` because a failure is a fact about the effect rather than about the handle that reported it, and an operation that never fails stays in its base monad: `print` is `Io({})` and drops the write's status, since a program that wants the status writes through the stream.

**Rationale.** The standing shape, `Async(Result(A, Handle/Error))` on every fallible operation, made every caller match twice — once on the fiber's result and once on the outcome — and the propagation matches outnumbered the operations they propagated. An error channel that is a monad lets `!` carry the failure as it carries the sequencing, and a wrapper over the base rather than an error slot on `Async` itself keeps the channel available in `Io`, so a synchronous program gets the same early return a fiber does and `Result` on its own stays a value with no effect. The parameter order — base, error, value — is what makes the family partially apply as a monad under the right-biased rule the elaborator keys witnesses by. Two elaborator relaxations were needed for the shape to be ergonomic rather than merely expressible: premises on a binder, so one witness per edge serves every base, and the lift oracle reading a binder in a context slot, so `Try/rescue(t, h)!` lifts as `t` was declared over; both are recorded in the compiler and in [monads embed along declared edges](monads-embed-along-declared-edges-and-bang-lifts-across-them.md).

**Rejected.** An error-carrying `Async(E, A)`: it would fix the channel to one monad, leave `Io` with none, and make every non-failing fiber name an error type. `Throw` as a separate monad beside `Result`: with `Result` error first, `Result` is its own monad and the second name said nothing. Aliases such as `Fallible(A) = Try(Io, Io/Error, A)` in `/std` signatures: they key a region correctly but hide the base and the error a reader wants to see at the signature, so the full spelling is written and a program may alias for itself. Exceptions or a `panic`: an effect the type does not state is the thing the effect discipline exists to refuse.
