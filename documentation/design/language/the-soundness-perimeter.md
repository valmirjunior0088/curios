# The soundness perimeter

**Decision.** The intended claim is that there is no closed term of type `/syn/False`. What the compiler *enforces* is narrower and is the actual statement: nothing in a type position and nothing at a `Prop`-sorted type is partial — [Totality of the erased program](totality-of-the-erased-program.md) — and every rule that can admit a term holds. That claim quantifies over *every* such rule, so it is stated against an enumerated perimeter rather than against prose: one entry per rule under [soundness/](../../soundness), each stating what it assumes and how far that has been checked. The two coincide only if the perimeter is complete and each of its entries is correct, which is not established. The trusted base is the elaborator's kernel, `curios-cert`'s independent kernel now that it runs on the compile path, `curios-analysis`, which holds the rules both of them run, and the Rust implementation of all of it. No entry is re-graded on account of the second checker — it changes the cost of being wrong about a rule, not the perimeter's own coverage; what it is worth, and what it cannot be worth, is set out in [An independent kernel re-checks what the elaborator accepts](an-independent-kernel-re-checks-what-the-elaborator-accepts.md).

**How an entry is read.** Each entry names what it **assumes** and its **status**, and the vocabulary is deliberate: **probed** means an adversarial program was written and the compiler rejected it; **argued** means a written justification exists; **auditable only** means no surface program can exercise the rule, so reading the implementation is the only available evidence. An entry may be probed and unargued, or argued and unprobed; they are independent. An entry's evidence is the fixtures it names. A fixture is named rather than counted because a name is a contract — moving it is a change someone must make deliberately — while a count is true on the day it is taken and quietly false afterwards; a population figure is retaken from the probes beside the code, `curios-prelude-archive`'s `kernel_disagreements` for the whole-prelude walk and each crate's own test module for the rest. Where a rung is reached by exactly one fixture — the elimination guard's non-informativeness excuse, inversion's reconciliation acceptance, the kernel's irrelevance — that fixture records a mutation check, which is the only thing separating a sole-reach fixture from dead code. Some rules are decided over structure no source program can construct: levels are implicit and inferred, so surface Curios forces no subsumption the elaborator did not itself choose; index inversion and the conversion recurrence rule turn on internal state no source text reaches; an intrinsic's signature is read from the same roster that spells it. What stands behind those is fixtures written against the checkers directly rather than programs put to the compiler, and which entries they are is each entry's own status to say. A defect's history is kept only where the defect is still expressible; where the mechanism that admitted it is gone, git holds the account.

**The perimeter has four parts.** Two are halves of the same thing and differ only in how coverage is obtained; the third is different in kind, and is a rule about *not* running the other two; the fourth is not a rule at all. The **whole-module passes** run once over a module: the elaborator's from `finalize_and_check` in `curios-elab`, the single site every entry point that produces an elaborated module comes through, which is what keeps a check from reaching one configuration and not the other. The **per-term rules** run during elaboration, so their coverage follows from the elaborator visiting every term rather than from a pass enumerating positions. **Admission without judgment** is the rule about *not* running the other two: a verdict already reached, under an address carrying what it was reached about, may be believed instead of re-decided. **What the kernel consults** holds the components a rule reads an answer *out of* rather than deriving — a remembered reduct, an assumed equation, a classification recorded earlier, a verdict carried from a walk already run. None of them decides whether a term is well typed; each of them supplies something a rule then believes, so a wrong answer there is admitted by whichever rule asked. One admission route is shared by every entry whose rule is a single function below both checkers — the intrinsic folds and the free-monoid peel, the bounds oracle, the binary32 model, the closed machine, the evaluation memo: no disagreement between the checkers is structurally possible there, and a wrong answer is a false definitional equation that conversion believes and congruence with substitution carries to `False`. Each such entry names that route rather than restating it.

**What earns an entry.** An entry earns its place by *assuming* something, not merely by admitting. The discriminator is whether the rule rests on anything beyond the shape of the term in front of it — a declaration, a carried number, a cached verdict, an equation stated elsewhere. A rule that only destructures inherits its correctness from the representation and is not listed; `Var`, `Let`, the bare `Func` rule and the `Type`/`Prop` head rules are the ones that fall the other side of that line, and they inherit [Telescope instantiation](../../soundness/per-term-rules/telescope-instantiation.md) and [Binder identity](../../soundness/per-term-rules/binder-identity.md) rather than earning entries. Three of the things the criterion names — a cached verdict, an equation stated elsewhere, a carried number — are components rather than facts, and a component earns its own entry instead of being re-argued at each rule that reads it, which is what the fourth part is for. The criterion is written down because entries first arrived by being attacked: a rule nobody had thought to attack had no entry, so the enumeration recorded the history of the hunt where it claimed to record the surface, and the two coincide only until someone asks. Three things were looked at under the criterion and kept off it, recorded so the routes are not re-walked. Representation privacy — an `induct` or `struct` whose representation is not exported, enforced in `curios-elab` against the use site's island and read by no rule in `curios-cert` — rests on a declaration and admits, so it meets the criterion's letter, but it cannot reach `False`, and structurally rather than by luck: a proposition over an abstract type still quantifies over that type's representation, so no module can state a theorem that forging an inhabitant would falsify; the standard library commits to that reading, declaring `BigPos` with a public representation on the stated ground that the accompanying proof, not an opaque wrapper, enforces the invariant. Privacy is an abstraction property and is [Privacy is scoped to a subtree](privacy-is-scoped-to-a-subtree.md)'s; the interface audience graph in `curios-text` is off the perimeter for the same reason. `Term`'s equality is a structural worklist walk and the cached structural hash is consulted only to *refuse* — a collision costs a walk, never a wrong verdict — so the hash-consing and the memo keys that rest on it inherit nothing weaker than structural equality. And universe level arithmetic is `checked_add` throughout with an `OffsetOverflow` refusal, pinned at the top of the range by `successor_distributes_and_overflow_is_checked`, so the hierarchy cannot be collapsed by saturating it; `Level::cancel_offset` mixes a `saturating_sub` on the constant with a `checked_sub` on the atoms, which is exact only because normalization leaves the constant either zero or strictly above every atom offset — a coupling worth knowing and not a route.

**It is a separate directory because the two halves have different lifecycles.** A decision changes when someone decides something, and rarely. An entry's grade changes every time its rule is attacked, and the evidence under it accumulates run by run. The split is by what churns, not by what the topic is: the decisions this perimeter rests on stay here, beside the rest of the language's, and the entries live under [soundness/](../../soundness).

**Four boundaries follow, and they are stated here rather than as entries because none of them is a rule that can admit a term.** The perimeter is a claim about the *term language*, checked at one point in the pipeline, over a bounded amount of work.

*Nothing below Core is certified.* `recheck_module_verdicts` runs inside `compile_entrypoint` against the elaborated module; erasure, the erased optimizer, the lowering into CPS and its optimizer, and Wasm emission all run afterwards with no semantic check between them. `curios-cont`'s `verify` is a well-formedness pass — scoping and arity — not a preservation argument. So *no closed term inhabits `/syn/False`* and *the emitted module computes what the source says* are different claims, and only the first has a perimeter. For a language whose proofs are certificates to be erased, the second is worth as much as the first and has no ledger at all.

*What is already in scope is defined on faith, and the faith has a ground.* The compile path judges the entry's own items alone: `recheck_module_verdicts` takes a `Globals` the archive's establishing walk built — where `curios-prelude/build.rs` panics on the first refusal and there is no source fallback — and every pass skips by *name* what that environment already declares, each skip being a verdict the establishing walk already reached. Two passes deliberately keep walking everything: strict positivity, because reaching oneself through a non-strict path is a property of the whole declaration set and a user declaration may name a prelude one, and the environment itself, because a judged item may reach any prelude item and conversion unfolds arbitrarily deep. What the skip admits, what enforces that an entry program cannot reuse a prelude name, and the fixtures that hold it are [Judging only what is not in scope](../../soundness/admission-without-judgment/judging-only-what-is-not-in-scope.md)'s; the binder floor, the one carried bound the walk widens rather than believes, is [Binder identity](../../soundness/per-term-rules/binder-identity.md)'s.

*Acceptance is relative to a step budget.* `Spend::spend` fails with `Exhausted` rather than accepting, so the budget can only refuse, and it is deterministic: the same program spends the same steps on every machine, which makes exhausting it a fact about the program rather than about the host that checked it. The consequence to state is that *well-typed* is budget-relative — the fixed prelude is certified at `DEFAULT_STEP_BUDGET` while a user program is certified at whatever its caller passes, and nothing holds acceptance monotone in the budget.

*The Rust implementation sits outside the perimeter, and it must fail closed.* A panic, an abort, or a stack overflow is acceptable only where it refuses a program rather than admits one. One analysis on the perimeter fails open where every other one fails closed: positivity answers `Mixed` for a name outside its set, reduction goes stuck on any shape it cannot fire, inversion derives nothing at a `Prop`-valued position, the size reader answers *unread* on a term it cannot decode, and an under-applied call is graded unknown — each turns blindness into a refusal — while the size-change engine's call-site discovery does not, since a position the walk never visits contributes no edge and a group with no edges is accepted. That asymmetry is why [`record_totality` + (T)](../../soundness/whole-module-passes/record_totality-t.md)'s position coverage is a test rather than prose.

**Rationale.** Each of the boundaries was reachable by reading the code and by no other route, which is precisely the property the enumeration exists to remove. They are decisions rather than entries because an entry is a rule that can admit a term, and these are the edges of the region such rules are looked for in — but a reader who trusts the perimeter without them is trusting a narrower claim than they think they are.

**Rejected.** Stating the trusted base as prose, which is what the enumeration replaces: it could not be checked, could not be falsified, and gave no way to tell a rule that had been attacked from one that had merely been assumed. Also rejected: treating a passing corpus as evidence of coverage. Every defect this design has produced was found by counting or by probing, and none by the corpus failing — the corpus passed throughout the long period when (V)'s argument rule was firing at almost none of the sites it was written for. A rule that never runs cannot admit anything, so an inert rule is never unsound while inert; what inertness means is that the corpus is not evidence about the rule, and that a fixture reaching it has to be constructed rather than found. Also rejected: an index of the entries and their grades kept beside them. Each entry states its own grade, so a second copy could only drift, and listing the directory is how an entry is found.
