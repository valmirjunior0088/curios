# Subsumption is a relation, not a traversal order

**Decision.** `Γ ⊢ t : A` together with `A ≤ B` gives `Γ ⊢ t : B`, where `≤` is `Type u ≤ Type v` whenever the level algebra proves `u ≤ v`, `Prop ≤ Type v`, and `Π(x:A).B ≤ Π(x:A').B'` when `A ≡ A'` and `B ≤ B'` under `x` — conversion otherwise. **Domains are compared by conversion and codomains cumulatively**, which is the choice Coq makes. Both checkers decide the relation structurally, on the Π being subsumed — `curios-cert/src/kernel/infer.rs`'s `subsumes` and `curios-elab/src/typing.rs`'s `subsume` — and what it assumes and how it is probed are [Subsumption and level entailment](../../soundness/per-term-rules/subsumption-and-level-entailment.md)'s.

**Rationale.** A traversal can reach the relation's verdicts without stating it, and only for the terms it introduces. Bidirectional checking pushes a λ against a Π down to the leaves, where both sides are sorts and a head-only rule suffices — but a *name* checked against a function type has no leaves to push to. The Π is formed and compared whole, and a head-only rule then refuses `(b : Bool) -> Prop` where `(Bool) -> Type` is wanted: a program this relation admits, and one the standard library writes, handing `Bool/Holds` to `Eq/subst` in `/std/BigNat`. An emergent rule is also not a statable one — it holds where a traversal happens to bottom out and changes silently when the traversal does. Deciding subsumption structurally in both checkers is what forces the rule onto the page, where it can be read, disagreed with, and be the same rule twice.

The elaborator carries one obligation the kernel does not: a side still stuck on an unsolved metavariable has no shape to decompose, so the function-type case fires only on two rigid Πs. A rung the walk cannot decide abandons it for conversion rather than surrendering goals — `Context::park` freezes the live frame, so a goal naming a binder the walk minted would be retried under a frame that no longer assumes it, and a parked conversion is retried by equality, which is the rule this relation exists to widen. A subsumption blocked on a metavariable is therefore decided by conversion, refusing what the relation admits; that is what a parked-work variant carrying the relation would lift.

**Rejected.** Contravariant domains. The fork is asymmetric and that is why it was taken conservatively: widening to contravariant domains later accepts strictly more, so it breaks nothing already accepted, while shipping contravariance and withdrawing it would break programs.
