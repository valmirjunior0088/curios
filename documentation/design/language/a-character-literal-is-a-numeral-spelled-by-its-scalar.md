# A character literal is a numeral spelled by its scalar

**Decision.** A character literal lowers to the same polymorphic-literal transient a numeral does — `Transient::NumLit`, an enum whose `Character` variant carries a Rust `char` and whose `Number` variant carries a magnitude with a three-valued `Sign` — and elaboration realizes it against the expected type: the certified `/syn/Char` value wherever nothing pins it (the shape default, preserving every existing program), and the code point at `Nat`, `Byte`, or `Int`, under the numeral's own range rules; `Bool` and `Flt` are excluded. In a match, a character literal is a `Nat` dispatch case compiled exactly as the numeral it denotes, nested and top-level alike, and a packed `Bytes` literal takes character atoms. A `Char` *scrutinee* is dispatched through `Char/to_nat`, keeping the projection visible at the head.

**Rationale.** The compiler already owned the whole mechanism: `elaborate_num_lit`'s candidate table with a shape default, the `switch` the match compiler emits for `Nat` dispatch literals, and the certified-value emitter for `'a'` — realization only moves the emitter from lowering to elaboration and adds rows to tables that exist. The representation is an enum rather than a flag because a flagged struct admits every bogus pairing — a signed character, a radixed character, a character-marked magnitude outside the scalar range — while `Character(char)` makes each unrepresentable through the host type's own invariant, and splitting `Sign` out of two booleans retires the one contradictory state the old struct carried.

**Rejected.** A `character: bool` beside the existing fields (the bogus states above). Matching a `Char` scrutinee directly by projecting its `code` field in the match compiler: it would be the first place pattern compilation knows a library type's representation, it needs a registry slot for the field label, and it hides a projection the explicit `Char/to_nat` head states in the source; the desugar remains addable later without disturbing this design. Character spellings for `Bool` (`0`/`1` have no character) and `Flt` (a character is not a float literal). Equality-guard patterns over arbitrary values — `choose` with `==` already owns that shape, and `Str` patterns stay out for exactly that reason.
