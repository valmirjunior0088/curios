# curios-cont

The Curios continuation-passing IR and its optimizer: `curios_ersd::lower_to_cont` constructs the CPS graph, and the optimizer rewrites it before `curios-emit` lowers it to WebAssembly. How the module prints is [A printer states each fact once, where it is bound](../documentation/design/tools/a-printer-states-each-fact-once-where-it-is-bound.md), and entry capability is [An entry exports only the turns it can return](../documentation/design/compilation/an-entry-exports-only-the-turns-it-can-return.md); the representation invariants belong to the crate rustdoc.

## Design

### A copy is planned within its allowance

**Decision.** A budgeted copy selects its node allowance before requesting its complete lexical extent, including nested definitions. Planning stops at the first excess distinct node and returns a complete executable plan only where the extent fits. Binding-group members are enumerated when their node is visited, so the node allowance does not bound that metadata work. A plan reads the current graph and is consumed without an intervening rewrite; specialization's final revalidation remains an exact comparison with its admitted extent. Refusal mints no identities and spends no expansion allowance.

**Rationale.** A callee refused for its size should not be traversed in full at every call site. The same bounded planner supplies admission and execution, so a successful copy retains its extent and identity allocation order. Fresh planning also accounts for a callee whose internal call was inlined earlier in the same sweep.

**Rejected.** A separate counting walk before copying, which walks accepted bodies twice and separates admission from execution; retaining executable plans by callee across rewrites, which requires invalidation; and lowering allowances to reduce planning cost, which changes optimization policy.

### A loop copy finishes the contification it admits

**Decision.** A loop copied for an additional caller is admitted over its complete lexical extent, including nested definitions and the contification scaffolding, and is contified at that caller in the same rewrite. A nested function that calls the loop would give the copy another external entry, so that extent is declined. Every copying transformation uses one plan for admission and execution; its own parameter and backedge mapping remains its own.

**Rationale.** The purpose of this copy is to put a loop inside its caller, where local representation can hold its state in registers. That purpose is a condition the rewrite proves and completes, rather than an opportunity left for a later optimizer round. Counting and copying the same extent bounds what admission authorizes, including the callbacks a nested definition carries.

**Rejected.** Keeping selected generated helpers shared by name, which leaves the same shape in an ordinary program unprotected; treating all recursion as a reason to refuse, which loses useful self-tail loops; changing the ordinary call graph to include definitions, which answers a different question from a call's component; and spending a clone budget on a function another round may never contify.

### A pass applies the independent plans its snapshot admits

**Decision.** Worker splitting, returned-closure uncurrying and the three specializers discover candidates against one invocation's analyses, then apply independent candidates in deterministic order. A candidate whose source, callers, arguments, signature or return relationships an earlier rewrite changes waits for fresh facts. Discovery mints nothing; an executable copy plan is prepared immediately before application. Equivalent specialization sites share one copy. Appending a definition to a shared lexical anchor preserves the other groups' scope.

Specialization spends a non-refundable, module-wide allowance of copied nodes, including reconstruction scaffolding, under a separate ceiling per copy. The allowances are the former clone counts multiplied by those ceilings, so small copies can share the allowance more fairly without increasing maximum cumulative copied-node growth. Contexts are prioritized by matching sites per copied node, with stable identity-based ties. A successful rewrite alone spends the allowance; deleting a copy does not refund it. The pass order and ordinary cleanup remain the optimizer's, and dependent work waits for the next round. The limits and pass-specific judgments belong to rustdoc.

**Rationale.** Independent candidates need one set of analyses rather than one round of every pass each. Independence includes the assumptions a rewrite reads, not only the nodes it writes. Pricing the complete copied extent bounds expansion and charges differently sized copies differently. Keeping judgments local to each pass preserves the differences between changing signatures, absorbing applications and making private recursive components.

**Rejected.** Draining one-step passes by rebuilding their analyses after each candidate; holding executable copy plans across mutation; resetting or refunding expansion fuel; moving all specialization after shrinking has settled; and a general analysis cache or speculative optimizer for work that pass-local snapshots can decide.

### A dead-parameter phase repairs the graph once

**Decision.** Dead-parameter cleanup reads one demand snapshot and commits continuation removals before taking the escape snapshot that admits function removals. Each phase repairs the complete live node arena once, with removal masks in original parameter positions: signatures and incoming arguments lose the same positions, remaining inert occurrences become fillers, and removed bindings are tombstoned after the repair. Continuation field records follow their complete removal mask. Result receivers and escaping functions keep their signatures.

**Rationale.** Removing uses cannot falsify `Unused`, and different targets own different argument vectors, so one phase can repair every admitted removal together. The escape boundary preserves which opportunities an invocation takes: a function reference dropped from a continuation argument permits immediate cleanup, while one dropped from a function argument permits cleanup on the next invocation. An arena-wide walk reaches nested captures and live nodes awaiting pruning without maintaining an occurrence index.

**Rejected.** A graph scan per entity or removed binding; discovering function removals before continuation cleanup; refreshing escape facts during function cleanup; and persistent use lists or a general graph-edit framework for edits one phase can commit.

### Mutation hides behind instruction atomicity

**Decision.** Each write-once cell and bounded channel operation ([A wait is a suspension, and only the host waits](../documentation/design/standard-library/a-wait-is-a-suspension-and-only-the-host-waits.md)) is a CPS node that completes before invoking its continuation: the emitter performs its state transition and chooses its outcome without calling the host or suspending, optimizers preserve these nodes and their order, and a readiness query observes state without reserving a later operation's outcome. Compiler-generated knots use the same operations: a result cell and a capacity-one initializer channel per computed member, every storage object and closure bound and every initializer enqueued before forcing starts. A force polls the result, otherwise takes and runs the initializer, then fills the result; an empty result beside an empty initializer channel is recursive re-entry and emits `Panic::Cycle`. The force captures only the two storage objects, so taking the initializer releases the knot's reference to its captures. The lowering and its structural tests live in `curios-ersd/src/into_cont/`.

**Rationale.** A push or take reports the outcome of its own attempt, and a transition inside one operation keeps a cooperative branch from observing a partial update, within one guest instance. Initializers are pure and cannot suspend between the knot's operations, so the pair needs no atomic transaction.

**Rejected.** Holding the initializer and the eventual result in one channel, which needs tagged wrappers to tell them apart and an operation reading the result without consuming it.

### Representation is decided wherever every party is visible

**Decision.** `represent.rs` decides whether a value is held in a machine register or behind a reference wherever the module sees every party to it: a local; a parameter of a function that neither escapes nor is the entry, a join whose edges are its call sites; and a result slot of a tail-call class, a join whose edges are the class's return edges and whose uses are the resume parameters of every call into it. The emitter declares a function's type at what those settle to, loads a call's arguments as an edge loads its own, and boxes a result once where it enters a resume parameter held as a reference. What crosses a position no single party controls keeps the reference: an escaping function's parameters and results, which its closure wrapper reaches at the shared `clsr/N` type; the entry's, which the host calls; the results of a class a member of which ends in a tail call through a closure, a foreign, a cell, a channel or a call-shaped intrinsic; a value free in some function's body; and what a cell, a channel or a call-shaped intrinsic hands back. A `Nat` or `Int` is a reference whatever its size, so a position is offered a machine word only when every argument reaching it is a small literal, a result its literal operands bound, or another such position ([Nat and Int are an i31 until they outgrow it](../documentation/design/arithmetic/nat-and-int-are-an-i31-until-they-outgrow-it.md)). A reference states no shape, so a position is offered a float only when every argument reaching it is a float literal, a filler, a definition producing a float, or another such position.

**Rationale.** A boundary the module sees whole is a join like a loop header: the calls name every argument a parameter receives and the return edges every value a slot hands back, so the fixpoint that decides a continuation parameter decides it, and the analysis stays one client of the shared solver whose answer the emitter reads; nothing in the module is rewritten to carry it. Deciding results per tail-call class is what `return_call` requires, the condition the return protocol already meets for its widths, and the escape set is the one the emitter builds closure wrappers from (`Module::escaping_functions`), so no wrapper tail-calls a function at a signature it no longer has. Leroy finds local unboxing with calling protocols for known functions as effective as coercion-based type-directed unboxing (*The effectiveness of type-based unboxing*, 1997), and wasm_of_ocaml took the same two steps on WebAssembly GC. The free-value withdrawal reads the set lambda lifting reads, since deciding a lifted value from the scope binding it sends a reference into integer arithmetic; `represent::tests::a_value_free_in_another_function_stays_boxed` holds it. A parameter has one type only where no type computes one: a variant's constructors share a payload slot that scalar replacement makes a parameter, and a value whose type is a match on another is a float on one edge and a string on the next. An edge coerces its argument before any tag or branch is read, so a float register casts whatever else arrives, and a reference says nothing of what it is; `represent::tests::a_parameter_a_reference_reaches_is_never_held_in_a_float_register` holds it, and `curios`'s `tests::codegen::structural::layout_tests` the three programs that met it.

**Rejected.** Types deciding every binder's representation, Lean's explicit boxing and Leroy's coercions: every pass that mints a binder would have to derive a type, and a value that only travels would be unboxed and boxed again. Raw parameters behind an escaping function's wrapper, which unboxes for an unknown caller: a closure's results stay uniform, since its tail calls return through the wrapper, and what the parameters would buy over the body's own unboxing is a cast per use. A loop versioned by a type test at its seed, which copies the loop. Relying on Binaryen, whose Heap2Local replaces no allocation that shares a local with another value, as a loop's seed and back edge do.
